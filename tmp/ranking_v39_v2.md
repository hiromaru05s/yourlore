# カードパワーランキング v2 (v39, bot paired A/B)

## 方法と信頼性

- 総ゲーム数 **1,336,000** / 各カード **4000ペア** (同一シード・同一デッキで「カードあり vs なし」を1対1比較)。
- デッキ環境: 両者とも 50% ボットのアーキタイプ・プリセット(AGGRO/RAMP/MIDRANGE/GAMBLER/ELF ほか、botTune適用) / 50% DECK_POOL からランダム8枚。先攻・被験者側はペアごとに交互。
- ボット: greedy(hard相当・ブランダーなし)、リーサル探索なし。探索ありの検証走行との比較は末尾。
- **Δ勝率** = 被験者側の勝率(カードあり) − 同一ゲームの勝率(カードなし)。引き分け(4000手上限)は0.5。±は95%信頼区間の半幅。
- **順位95%区間** = ペアをまとめてブートストラップ再抽出(600回)した時の順位の2.5〜97.5%点。区間が重なるカード同士は順位を断定できない。
- **信頼度**: ◎確実 = |Δ| ≥ 3.9SE (p<0.0001) / ○有意 = ≥1.96SE (p<0.05) / －誤差内。
- **効果値**(購入のみ) = Δ − マナ浪費基準(そのコストの「ボットが一度も使わなかったカード」の平均Δ = 純粋なマナ損+デッキ希釈)。0 なら「効果ゼロのカードと同じ」、正なら効果がコストに見合う。
- **評価**: ○ = 使用率50%以上 / △参考 = 10〜50% / ✕評価不能 = 10%未満(ボットが扱えないカード。Δはマナ浪費分でありカードの強さではない)。
- 購入カードは最初に買える自ターンに強制購入(マナ消費、墓地へ)。「使用率」= 購入後に1度でもプレイ(罠は設置)した割合。使用率が低いカードはボットが扱えていないので過小評価。
- 対照群(カードなし)の平均: 購入側 勝率 49.0 / 平均ターン 27.1 / 引き分け 0.0。

### 再現性 (独立シードの第1走行 1000ペア との順位相関)

- 購入カード: Spearman ρ = **0.956** (n=236)
- スターター(1枚): ρ = **0.747** (n=34) — スターターは効果が小さく順位が不安定
