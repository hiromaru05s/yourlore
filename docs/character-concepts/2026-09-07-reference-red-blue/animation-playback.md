# LORE キャラクター再生方式 — 固定アニメーション

更新日: 2026-09-07。ユーザーの「決まったアニメーションの再生だけでいい」を反映。この文書を現行の検討方針とし、前回のLive2D第一候補という提案を取り下げる。

## 構成

各キャラクターに、あらかじめ完成させた動きを用意する。Idleは短いループ。操作が成立すると対応する動きを一度再生し、終わったらIdleへ戻る。待機中の呼吸・髪の揺れ・瞬きも、そのループに描き込む。実行中に目や髪を個別制御する必要はない。

初期方式案は「透過した連番画像をアトラス化して、Canvasでコマ送りする」。制作方法とゲーム内の再生方法は分ける。動きの素材は選んだデザインを基に制作・整える工程が必要で、今回の静止画6枚にアニメーションが含まれているわけではない。

## クリップ一覧

| 名前 | 再生 | 内容 |
|---|---|---|
| idle | ループ | 小さな呼吸・髪や衣服の揺れ・瞬き |
| damaged | 一度→idle | 短くひるむ |
| attacking | 一度→idle | 攻撃を指示する手振り |
| playing_magic | 一度→idle | 本・手から魔力を放つ |
| playing_trap | 一度→idle | 伏せたカードや栞を滑らせる |
| playing_monster | 一度→idle | カードを掲げる |
| buying_cards | 一度→idle | カードや本を受け取る |
| reroll | 一度→idle | 手を払う・頁をめくる |

尺・コマ数・解像度は、実際の表示サイズで一人分の試作を見て決める。最初に全身を大量の高解像度コマへ展開しない。

## 最低限の制作ルール

- クリップ間で顔、衣装、座標、拡大率、基準位置を揃える。
- Idleの最初と最後がつながるループにする。
- 各動作の開始・終了を基準姿勢に寄せ、切り替え時の飛びを抑える。
- 必要な透過背景は実アルファで用意する。格子模様を透過と扱わない。
- 被ダメージは通常動作に割り込み可、同種の細かい連続イベントはまとめる。
- 対戦ロジックやターンタイマーをキャラクターの再生終了で止めない。
- 低負荷表示では同じキャラクターの静止画へ切り替える。

現行コードの攻撃・被ダメージ・魔法・罠・購入イベントへの連動方針は前回調査を利用できる。リロールの専用イベント追加、召喚の起点判定、表示領域の調整は実装時に対応する。前回のパーツPSD・moc3・表情パラメータは今回方式の必須要件ではない。

本番実装もアニメーション素材の制作も、今回のキャラクター画像生成には含めていない。
