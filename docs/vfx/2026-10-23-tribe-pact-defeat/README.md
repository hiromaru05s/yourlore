# 多種族契約 — 契約不履行

ローカル実装。`/tribe-pact-defeat.html` はDEV専用の実盤面プレビュー。
本番・ステージングへのデプロイは行っていない。

## 演出と接続

- 0–1.05秒: 場の公開契約カードの実位置から同じ面を浮上。カード絵・枠・コスト・永続表示を保持する。
- 0.5–2.16秒: 五つの契約紋と接続線を刻む。金から赤へ段階的に失効し、一本の裂け目が表面を横断する。
- 1.75–2.9秒: 破棄印が接触し、カードの同じ裂け目から二つの面が開く。
- 3.35–4.34秒: 元の絵柄を残した破片が欠けながら敗北側のポートレートへ収束。到着と局所反応を同期。
- 1.38–4.9秒: 「多種族契約」「契約不履行」「45ターン到達・種族シナジー未達成」「あなた／相手の敗北」を表示し、既存の結果画面へ進む。
- HPは変更しない。ゲーム状態とwinイベントの公開メタデータに敗北原因を保存し、再接続・演出スキップ後も結果画面に残す。
- 日本語・韓国語・英語に対応。低減モーション・ソース欠落時は静止宣告へ切り替える。

## 品質参照

`docs/animation-quality-benchmark.md` の「銀紋の流墨」動画から6fpsの連続フレーム、既存代表フレーム、制作メモを確認。
翻案対象は「元の面の細部→同じ座標系での物質変化→到着」の連続性。
Toon資料の24.50秒以降の裂ける主形状と細い明縁を、契約面の暗い切断線・赤い断面・狭い明部へ置換した。
独立した粒や環を主役にしない。静止画・機能試験だけで見た目を承認済みとは扱わない。
