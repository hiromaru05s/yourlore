**再検証は合計42,528試合を完了。** 特攻の多積みは大きく弱体化し、呪術魔法書1回購入による無制限ドローと支配の連続予約は止まった。一方、特攻1枚を採用したゴブリン軸は依然として有力で、大賢者による無料ドローの別経路も残る。今回の4枚調整で全OPが解消したとは判定しない。

## 再現方法

`before.cjs.gz` / `after-final.cjs.gz` は比較に用いた共有ルールとBOT評価関数の固定バンドル。`engine-sha256.json` は展開後のSHA-256、`source.json` は変更後のソースとコミットを記録する。`before-raw.jsonl.gz` / `after-raw.jsonl.gz` / `adapted-raw.jsonl.gz` に全対戦のデッキ・乱数・先後・結果・使用カード・購入カードを保存する。購入禁止試験では両者の購入を禁止した。

```sh
mkdir -p /tmp/lore-caps-replay
gzip -dc docs/balance/2026-10-26-caps/after-final.cjs.gz > /tmp/lore-caps-replay/after.cjs
gzip -dc docs/balance/2026-10-26-caps/combined-plan.json.gz > /tmp/lore-caps-replay/plan.json
CORE=/tmp/lore-caps-replay/after.cjs node docs/balance/2026-10-26-caps/harness/sim.cjs /tmp/lore-caps-replay/plan.json /tmp/lore-caps-replay/results.jsonl
node docs/balance/2026-10-26-caps/harness/sage-reachable.cjs /tmp/lore-caps-replay/after.cjs /tmp/lore-caps-replay/sage.json
```

対戦出力は既存ファイルを上書きしない。再実行時は別の出力先を指定する。`sim.cjs` の末尾引数で `shardIndex shardCount` を指定できる。公開配信の確認は `scripts/verify-balance-caps-release.mjs`、詳細画面は `tests/balance-caps-browser.mjs`、実際の配信BOT workerは `tests/balance-caps-worker-browser.mjs`。
