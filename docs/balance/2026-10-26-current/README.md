## 1. 対処を優先するもの

### A. 無料ドローの自己循環 — ルール上の危険を再現

**青藍の書庫（または予知のルーン）＋呪術魔法書＋摩耗。**

1. 発動コスト1の書庫/予知を、購入時に効く魔法書の-1で0にする。
2. このゲームでは単発魔法が効果処理前に墓地へ入る。山札が空になると墓地を再シャッフルするため、解決中のドロー魔法自身を引き直せる。
3. 同名の使用回数制限がなく、0マナのまま繰り返せる。摩耗があれば各追加ドローで相手にダメージ。予知なら回復も繰り返せる。

**再現結果：** カル8枚の合法な初期デッキ＋固定アチューンから開始し、必要札を正規のマナ支払いで購入。相手がパスする到達性試験で、通算15ターン目に45回使用し、同じターン・残り4マナのまま相手45HPを0へ。予知版は自分40HP→175HP。カードやマナを途中で注入していません。固定市場は必要札を置いた条件付き市場です。手順全78行を `witnesses.json` に保存。

これは「どんな相手にも15ターンで勝てる」という結果ではありません。専用の簡易操作方針を組んだ対戦試験では、通常相手への勝率は構築別 **2.1〜15.2%（完了試合のみ）** にとどまりました。専用試験384件のうち3件は血鬼術のある相手へドローを続ける循環で1,500行動上限に達し、未完了として勝率計算から除外しています。完成前の速攻、沈黙、血鬼術等の対策があり、環境最強デッキとしての勝率は立証していません。一方、完成後に通常のマナ消費制約を失うことは再現済みで、バランスの修正対象にする理由は十分です。

**推奨案（未適用）：** 回数制限のない低コストドロー群に「同名合計で自分の各ターン1回」を付ける。まず書庫・予知を対象にし、忘却の新札・初心・リフレッシュ・回収カードの代替循環も併せて確認する。割引をすべて無効にするより影響範囲が小さい。通常BOTの一部ドローには12回の行動方針上限がありますが、これはプレイヤーに適用されるルールではありません。

### B. 支配の自己再ドロー — 生成後の独立ループを再現

**支配1枚が0コストの2ドローと相手ターンスキップを持ち、虚無・同名回数制限がありません。** 山札と墓地が空で、支配と固定アチューンを手札に持つ取得後の状態では、支配が墓地→山札→手札と戻るため単体で反復します。

取得後fixtureで **同一ターンに70回、マナ消費0、相手スキップ予約70回** を再現しました。生成専用で、通常の初期デッキに入れたり直接購入したりはできません。城下町の「兵士・カジノ・ワイン」達成と、その後の圧縮が必要です。今回は城下町の獲得からの全試合再現は行っていません。

**推奨案（未適用）：** 支配を虚無の使い切りにし、同名ターン1回も検討する。単なる1ターン1回だけでは、薄いデッキで毎ターン回収して相手の手番を継続的に奪う問題が残ります。

いずれも実エンジンの再現で、認証済みの本番PvPを操作した検証ではありません。オンラインの手番時間・送信頻度制限による操作可能回数は別です。

## 2. スターターだけで生まれる強さ

### 要調整候補：ゴブリン4＋特攻ゴブリン4

コピー上限8の現行ルールで合法です。特攻の強化は同名で重なり、自分自身にも効きます。例えばゴブリン3体＋特攻3体の盤面は攻撃力 **4,4,4,5,5,5**。全て直接攻撃できればゴブリンの追加ダメージ込み **30点**。同じ盤面に弱化2枚を正規に発動すると **0,0,0,1,1,1** になるため、無条件に突破できるわけではありません。

独立シードの市場あり比較（6相手×8シード×先後、各96戦）：

|初期構築|得点 / 試合|勝率相当|
|---|---:|---:|
|ゴブリン8|92 / 96|95.8%|
|ゴブリン4＋特攻ゴブリン4|90 / 96|93.8%|
|ゴブリン4＋ラストマッシュルーム4|87 / 96|90.6%|
|ゴブリン3＋特攻3＋逆算1＋支援ラッパ1|81 / 96|84.4%|
|ゴブリン2＋特攻2＋ラスト2＋逆算1＋血鬼術1|81 / 96|84.4%|

これらは市場購入も許可する試合で、**初期構築の比較**です。純粋なスターターのみの比較は、別途両側の購入を止めた960戦を実施し、`results.json` の `pure` に保存しています。派生カードの生成と固定アチューンは通常どおりです。純スターター条件でも、ゴブリン4＋特攻4は166/192（86.5%）、混成型は161/192（83.9%）、ゴブリン8は150/192（78.1%）でした。

対策の精度を上げた追加試験では、弱化2＋カル6で圧縮し、ガーディアン→神官→鉄壁の購入/使用を優先する相手に対して：

|初期構築|得点 / 試合|勝率相当|
|---|---:|---:|
|ゴブリン8|13 / 32|40.6%|
|ゴブリン4＋特攻4|25 / 32|78.1%|
|ゴブリン2＋特攻2＋ラスト2＋逆算1＋血鬼術1|22 / 32|68.8%|

**判断：** ゴブリン8枚を一律に「対策不能」とする根拠はありません。特攻の重複構築は対策後も高く、調整候補としてより強い根拠があります。ただし32戦/相手は小さく、相手も最適解ではありません。人間の最適プレイに対する勝率や全構築中の最適性までは主張しません。

**推奨する調整試験：** 特攻の+1を同名非重複にする案を最初に比較し、次に自身を対象外にする案、同名コピー上限の案を比較する。ゴブリンをさらに単体弱体化すると、既に存在する弱化・ガーディアン対面まで悪化させるため、重複による伸びを先に切り分けるのが妥当です。現時点では変更していません。

### 幽霊＋血鬼術＋ファイアー/戦場

幽霊が相手の回復ごとに伸びるためシナジーはあります。幽霊3体に血鬼術、その後ファイアー3回を使うfixtureでは、幽霊は全て2→5ATKになります。ただし相手も6回復し、合計5マナを使う。無限でも無条件OTKでもありません。今回の独立試験では幽霊構築の市場あり勝率は22.9%、戦場型は17.7%で、即ナーフの根拠は得られませんでした。専用操作方針が不十分な可能性は残ります。

### 弱化2枚・血鬼術・城

局所的には強いロックですが、相手の戦い方を限定する役割です。弱化は双方対象、血鬼術は自分の火力も回復へ変え、城は自分の大型召喚も制限。対策札の入手前に速攻側が勝つ速度と、解除後の再展開を含めて評価すべきです。これら単体を「アグロが止まるからOP」とは判定しません。

## 4. ランキングの読み方と検証範囲

全体347種の順位は効果・コスト・条件・専用コンボの上限を加味した**暫定の設計評価**です。全カードの完全な最適プレイを解いた順位ではありません。比較可能な実測は別の列/別表に残し、二つの異なる実験の勝率差を混ぜて全体順位を計算していません。

スターターの総合順位は初動と重複コンボを重視し、1位 特攻ゴブリン、2位 ゴブリン、3位 ラストマッシュルーム、4位 弱化術式、5位 逆算としました。微差まで確定した順位ではありません。

これとは別に、スターター44種は同じ背景7枚の最後の1枠を入れ替えた試験。ゴブリンとラストマッシュルームがカル比+8.3pt、特攻が+7.8pt、逆算+2.1pt。細かな順位は95%区間が重なり、同順位相当です。未使用/低使用カードは順位保留にし、弱いと断定していません。

購入可能303種は、対象の1回の提示機会を作り、優先購入と通常方針を比較。購入コスト、購入制約、買ったカードを墓地から引くまでの待ち時間を守ります。高コスト札・セット札・AI未活用札を安く初期デッキへ混ぜる実験は行っていません。対象を早く買うことで展開を遅らせるため、負の値がそのままカードの弱さではありません。

全ペアの走査は、44種の異なる2種946組＋単一種44組＝990構築を各8戦。各4枚の構築だけであり、全ての配分/3枚以上のシナジーを網羅したものではありません。上位16構築を別シードで再試験しました。

試合の主操作は現行greedyを公開情報サンプル経由で使い、別条件で未活用札の使用を補う方針や対策優先方針を加えています。Hard/Hellの全探索や人間同士の競技勝率ではありません。とくに高コスト・特殊勝利・生成カードの評価は独立したルール確認を重く見ています。**BOT同士の高勝率と、全人間に対するOPの証明を区別しています。**

95%区間は探索用で、多重比較補正を行っていません。小さな差の有意性や順位を確定するものではありません。

シード・先後・市場・構築・行動方針を生ログに保存。引き分けは0.5点、未終了/拒否された行動は勝敗として補完しません。ゲーム上限は通算60ターン（自ターン60回ではありません）。集計時に全件数・重複job・完了・無効行動を検証しています。実施51,504件、完了51,501件。専用コンボ試験の3件だけが循環による行動上限で未完了。拒否行動0件。通常の44種/303種ランキング試験は全件完了。購入試験78種、スターター試験9種は使用不足のため実測順位を保留しています。詳細件数と集計は `results.json`。

```sh
gzip -dc docs/balance/2026-10-26-current/plans/holdout-plan.json.gz > /tmp/lore-audit-replay/holdout.json

```
