# v52：承認済み10枚のリワーク

基準コミット `240d0a5` に適用し、実装コミット `1477896` として保存。共有エンジンをクライアント・オンラインサーバー・BOTが利用する。測定ソースは `harness/source` に固定し、SHA-256を `source-manifest.json` に保存。前回v51と購入プール282種・スターター33種は同一。カード定義の差分は10枚だけ（`catalog-diff-v51.json`）。

| カード | 適用内容 |
|---|---|
| 小さな発見 | 同名合計、自分の各ターン1回まで。購入2／発動0／2枚ドローは維持 |
| 発見 | 同名合計、自分の各ターン1回まで。3枚＋条件付き1枚ドローは維持 |
| 大きな発見 | 同名合計、自分の各ターン1回まで。4枚＋条件付き2枚ドローは維持 |
| 創造 | 同名合計、自分の各ターン3回まで。生成した新個体も回数を共有 |
| ウォーロード | 騎士召喚には自身以外の味方2体以上が必要。4コスト5/3・反撃は維持 |
| 魂の収穫 | 相手のデッキ構成の呪い1枚につき7→4ダメージ |
| アチューン・真 | 購入4を維持、発動4→2 |
| 幸運の宝箱 | 合計4・5で相手に出すマスターミミック12/6を、通常ミミック3/2へ |
| 魔界 | 発動時の自分の場の魔族と、以後自分が召喚する魔族のキーワード能力も無効化 |
| エルフの憩い場 | 提示から世界樹購入時、最大体力＋10→＋5。現在体力も5回復 |

回数制限は別コピー・生成コピー・墓地循環を通して合算。発見3種は別名なので、小さな発見→発見→大きな発見は使用可能。無効化された使用も回数を消費。不正な使用要求は支払い前に拒否し、BOT候補とUIも同じ判定を使う。次の自分のターンにリセットし、保存・復元しても回数が残る。

魔界は従来の発動時・召喚時という適用タイミングを維持。配列形式の能力（威厳・オーラ・反撃等）と、別フィールド形式の能力（連撃・暗襲・虚無）を消す。相手の魔族や他種族は対象外。魔界が消えるだけでは能力を戻さず、場を離れた実カードは従来のリセット処理で元の定義へ戻る。召喚条件と種族は維持。後から新たに付与された能力まで継続禁止する変更は含めない。

最大体力の増加には既存の `addMaxHp` を使用し、同じ量の現在体力回復も行う。憩い場の対象は従来どおり「提示から購入する世界樹カード」。全カード購入への拡張ではない。
