# v52 リワーク適用後の測定方法

[10枚の変更](source-audit.md)を適用した実装を凍結。前回v51の有効な実験計画を再利用し、乱数・初期構築・先後・購入方針・BOT方針を揃える。旧版の実測値を新版の試合へ混ぜない。

## 計画：819,648戦

本計測773,696戦：通常BOT478,336、補完BOT110,784、64コンボ131,072、28購入ルート48,384、戦術探索BOT5,120。別枠に構成・BOT方針43,264戦と、ギャンブラー0/1/2枚2,688戦。

- 市場282種：各512シード×先後。同じ初期8枚で対象カードと同コスト対照の購入を優先。コスト・召喚条件・購入制限は正規ルールを維持。自然な提示範囲と異なる入手機会を与えるため、自然環境の勝率ではない。
- スターター33種：各1,024シード×先後×カルからの置換前後。カル1枠を置換した勝率差。固定アチューンは独立順位なし。
- 背景は初期カル・無作為8枚・既定BOT・固定16レシピの4層。全カードで背景・シードを共通化。対照は同じ印刷コストから循環。
- 補完BOTは市場128シード、スターター256シード。一部準備呪文等の見落としを補い、両側の方針を変更。
- 自然観測40,000戦：通常購入と購入探索を半数ずつ。探索では購入・終了の選択時に40%の確率で他の合法購入を試す。
- 初期16構築は通常BOT各対面60シード、補完BOT20シード。購入ルート28種は各対面64シード。
- 戦術探索は通常カード24種・スターター8種、各32シード。状態内の乱数から未来の出目まで評価しうるため、対人と同じ情報条件の強さとは扱わない。

指定購入は提示マーケットにカードを置く。憩い場の「提示から世界樹購入時に最大体力＋5」等も発動する。通常購入リーグも併記し、異なる試験の勝率差を単一原因へ帰属させない。基準BOTは製品コードの `greedyDecide(g,false)` で、難易度の誤操作確率・追加リーサル探索は無効。

## コンボ・自然保有

各組256シード×先後×4条件。00＝両方対照、10＝Aだけ、01＝Bだけ、11＝両方。相互作用は11−10−01+00。8戦すべて決着したブロックを採用。11の高勝率と、単体能力を超えた相乗効果を分ける。

対照はスターターならカル、市場カードなら同コストの別カード。魔界＋魔王には全条件に斥候、カースを含む組にはリバース、インフィニティを含む組にはファイアーボール・アローを補助。生成専用の騎士は直接購入せず、ウォーロード＋馬小屋で正規入手する。前回の無効な騎士直接購入試験は今回の計画には含めない。

自然対戦の2枚同時保有勝率も保存するが、「優勢だから買えた」等の偏りを含み、因果的な相乗効果ではない。

## 統計・保留・未決着

勝ち1、負け0、引き分け0.5。市場・構築は先後2戦、スターターは置換前後×先後4戦が揃うシードを採用。95%区間はシード平均/対応差の標準誤差×1.96。多数比較はBH法でq値を計算。主順位には共通シード400回の再標本化による順位95%範囲も表示。

市場順位は「同コストの他カードより有利になる度合い」で、コスト間の絶対的な単体強度は同定しない。同コスト内順位も併記。使用率10%未満と同コスト対照なしは順位保留、50%未満は注意。未使用・条件未達を弱さと断定しない。

1試合1,600手で打ち切り。未決着・不成立・例外を勝敗に置換せず、比較ブロック全体を除外。ゲーム本来の60ターン体力判定は正規決着。60T分類は60ターン目の通常決着も含みうる。欠測5%超は注意、市場には欠測が全勝/全敗の場合の範囲も保存。無作為欠測とは限らない。

## 専用構築・BOTの追加試験

43,264戦はレシピ10案（24シード×28相手×先後×2案）、BOT補助4ルート（32シード×28相手×先後×2方針）、カード4種（128シード×先後×2方針）。腐敗3個の除去、摩耗/成長とドローの順序、炎術の準備、リバース時の自傷回避を補う。未来の出目の選別はしない。補助BOTは分析専用。

ギャンブラーは同じカジノ・伝説のギャンブラー購入方針で0/1/2枚を比較（28相手×16シード×先後×3案）。全6試合が揃うブロックを採用。追加試験は前回計画を再利用した診断で、主順位へ混ぜない。

## 前後比較・再現性

v51/v52双方で同じ条件が揃うブロックを対応比較。10変更の総合効果であり、個別調整の因果効果には分解できない。共通ブロック限定なので、各版の全件順位の値と僅かに異なる場合がある。

`source-manifest.json` に凍結ソース・バンドル・計画・ランナーのSHA-256を保存。`verify-study.py` で全計画/生ログ、重複ID、デッキ、購入の合法性、件数、ソースを照合。高速化ランナーは200条件で通常版と完全一致を検証。事前試験は主計測に含めない。`pilot-superseded` は魔界の派生キーワード表現への対処を追加する前の試行で、採用データから完全分離。

再実行は別出力で `node harness/resume-worker.mjs 計画ファイル 出力ファイル`。補助BOTは `sensitivity-worker.mjs`。再開時は既存の全行を計画と照合。集計は `python3 harness/analyze-deep.py 出力先`。未決着・使用率・背景・BOT方針も含め、「必須ナーフ／バフ」を勝率だけの自動判定にしない。
