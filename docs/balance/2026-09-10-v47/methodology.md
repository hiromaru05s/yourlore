# v47 実験条件・再現方法

実行対象は `source-manifest.json` のコミットとファイルSHA-256。カードの変更は `changes.md`。v46の共有ゲームソースとの一致を確認してから指定変更を適用した。旧結果の必要項目と出典ハッシュは `baseline-v46.json` に収録。

- 本実験119,040戦：自然観測24,000、スターター26,400、全体プール61,440、16構築総当たり7,200。
- 前回の17コンボを同じ条件で再検証。新たに魔族の斥候＋魔王、魔界＋魔王を各160シード×4条件×先後2戦で検証。
- 魔界＋魔王の4条件では、魔王の召喚条件を支える斥候を全条件で先に優先購入する。他の背景・相手・乱数は全条件で同じ。魔界を含む腕はその後に魔界を購入して発動するため、必ず効果が無効化された魔王を出せることまで保証しない。
- 前回と同じ戦術探索ありの小標本、商人・卵・カル特殊勝利のBOT使用判断補完も再実行。

全体プールは双方の初期8枚を同じにし、対象と同じ印刷コストの別カードを無作為に対照とする。対象カードを購入可能になった最初の行動時に提示枠へ置き、正規の購入アクションで1回買う。即時魔法の条件は共通の `purchaseAllowed` で確認。初手に無料配布する試験ではない。その後の購入は通常通りで、対照側が自然に対象カードを購入する場合もある。勝率は購入方針の効果であり、単体カードそのものの純粋な性能ではない。

スターターはランダムな背景7枚＋カル1枠のうちカルを対象に置換し、同じ相手・シード・先後で比較。背景8枚は半分をスタータープールから独立抽選、半分をBOT既定レシピ5種＋初期カル構築から抽選する。アチューンは別枠で固定。構築の試験は16レシピ間の総当たりであり、最適な構築を自動探索した結果ではない。

大量対戦のBOTは既存 `greedyDecide(g,false)`。追加の深いリーサル探索を省くが通常の打点計算は行う。自然観測の半分は購入時40%の無作為選択で探索範囲を広げる。`tactical:true` の検証は別集計。測定専用 `coverage` 方針は特定の未使用呪文・カル特殊勝利の使用判断だけを補い、本番BOTへは反映しない。

JSONの `damage` は相手プレイヤーが受けたダメージイベントの合計で、自傷も含む。`maxBurstReceived` はそのプレイヤーが1ターン中に受けたダメージの最大値。純粋な与ダメージや単一コンボの打点とは区別する。

自然観測の2枚組は初期採用または通常の購入イベントで両IDを保有した側の成績。コンボを実際に発動した勝率ではなく、効果で取得した全カードも網羅しない。序盤保有は双方合計10ターン以内に限定。観測だけでOPコンボとは断定しない。

コンボの4条件は00=両対照、10=Aのみ、01=Bのみ、11=両方。相互作用は11−10−01+00。条件付きの片側を入れるともう一方を使えるようになる相互作用も含む。17組では各160シード×8戦、魔王の2組も各160シード×8戦。

勝率は引分を0.5勝とする。ステップ上限1,600やBOT停止は未決着として除外し、比較実験は同シードの先後・対照腕がすべて決着した組のみ採用。独立単位はシード。95%区間はシード平均の標準誤差から算出し、q値はカード群単位のBH補正。区間が重なる細かい順位は暫定。全体プールの同コスト対照が存在しない2種は順位保留。観測ペアのWilson区間は参考値。

戦術探索ありの追加試験では、攻撃が拒否されてゲーム状態が全く変わらない場合にその試合を未決着として打ち切る。ログだけを繰り返す既知の攻撃停止を1,600回探索し直すことを避けるためで、勝敗を補完しない。実行途中に残り286件を分割したが、最初の98件はすべて決着しており、この停止判定の違いによる決着標本の差はない。

大量対戦では測定専用のplain objectクローンを使用。数値、undefined、配列、同一参照を維持する。Node標準クローンとの80試合・全アクションの状態/イベント/勝敗一致を `clone-verification.json` に保存。本番エンジンのクローン方法は変更しない。

## 再現コマンド

リポジトリルートで実行する。保存したエンジンバンドルを使い、将来のカード変更が再現実行へ混ざらないようにする。プランは圧縮版も保存し、復元すれば同じ対戦割り当てを再実行できる。

```sh
gzip -dc docs/balance/2026-09-10-v47/engine-v47.bundle.mjs.gz > scripts/balance/core.bundle.mjs
python3 -c "import gzip; from pathlib import Path; [(p.with_suffix('').write_bytes(gzip.decompress(p.read_bytes()))) for p in Path('docs/balance/2026-09-10-v47').glob('*plan.json.gz')]"
node scripts/balance/suite.mjs docs/balance/2026-09-10-v47 6 main factor weak-factor king-factor coverage validation market-validation
python3 scripts/balance/analyze.py docs/balance/2026-09-10-v47
python3 scripts/balance/report.py docs/balance/2026-09-10-v47
node scripts/balance/check.mjs docs/balance/2026-09-10-v47 --complete
```

`suite.mjs` が各プランを別の `raw/<名前>` ディレクトリへ出力する。生ログが既にある出力先には上書きしないため、再現実行は空のrawディレクトリを使う。生ログはローカルに保持しGitでは除外。途中の仕様修正前のパイロット対戦は集計に入れない。未決着の一覧は `results.json`、生ログのSHA-256と件数は `raw-manifest.json` に保存する。
