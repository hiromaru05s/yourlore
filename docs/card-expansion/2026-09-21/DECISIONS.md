# v50 実装時の補足仕様

指定の反撃対象43種、新規カード48種（依頼47種＋参照先「大砲兵」）、既存2種のリワークを実装。v49とリーディングボードのデザインを引き継ぐ。

| 項目 | 採用した解釈 |
|---|---|
| 反撃 | 有効な攻撃を受けた際、自分の実効攻撃力の半分・切り上げで攻撃者に返す。倒されても発動。貫通・反撃の連鎖・攻撃時効果は発生しない。回避・攻撃無効では発動しない。ダメージ無効のモンスターには反撃ダメージも通らない。 |
| 対象名 | 「精鋭氣志團長」は精鋭騎士団長、「選ばれしけんし」は選ばれし剣士。ドラゴン系は竜・ドレイク・騎乗系を含み、卵を除く。捕食種族は現在の全4種。 |
| 大砲兵 | 数値指定がなかったため、新規のコスト0・4/2・虚無。自分のターン終了時、ランダムな相手プレイヤーかモンスターに2ダメージ。砲撃兵は指定の3/1・1ダメージ。 |
| コスト | 指定のない発動コストは購入コストと同じ。0コストの生成カード・報酬は通常マーケットに出ない。 |
| デッキ条件 | 既存ルールに合わせ、デッキ・手札・墓地・モンスターフィールドの構成で判定。リフトは含まない。魔法の枚数条件にスターターやクエストは含めない。 |
| 支配 | 報酬は手札へ。「最初の3枚」はこのターン、以降に手札からプレイする3枚。元のコスト0でも1になる。購入時即時発動のクイックは数えない。最大マナの既存の上下限は維持。 |
| 傭兵術 | 召喚時・自分のターン開始時の効果を2回発動。複数枚でも4回にはならない。+3/+3は条件を満たす間のオーラ。 |
| 傭兵ギルドマスター | カジノによるダイス10個は召喚時と自分のターン開始時の両方で発動。カジノはどちらの場にあってもよい。 |
| 農場管理者・ミミックハンター | 醸造は自分の場。ハンターは両方の場の「ミミック」そのものを破壊し、マスターミミックなど系列全体は含まない。 |
| クエスト | 発動後のイベントを数える。ダイスは実際に振った個数。城下町は両プレイヤーの行動で達成可能。イカサマの除外では既存の神機による除外不可を尊重。 |
| 呪い・インフィニティ | 呪いは既存の呪い付与と同じく相手の墓地に生成。インフィニティは無効化したダメージの数だけ新しいカルを自分のリフトに生成。 |
| リバース・ダブルアップ | 同名複数枚でも転送・倍化は1回。リバースの使用上限2回はプレイヤーごと。発動条件はそのターンの実際の魔法ダメージ累計5以上（モンスターへのダメージを含む）。 |
| 持続ターン | 既存の残存魔法と同じく、自分のターン開始で残り回数を減らす。仕込みは自分の次の7回のターン開始に追加ドロー。 |
| ポイズンマスター | 通常の腐敗1個に追加2個で、攻撃対象に合計3個。 |
| 発見・摩耗・成長 | 実際に追加ドローしたカード1枚ごと。通常のターンドローは除き、ターン開始時の追加分は含む。成長の最大体力上昇は既存ルールと同じく現在体力も増える。 |
| ファイアー系 | ファイアーボール／アロー／ゾーン／メテオの4枚が対象。炎術の極意とファイアーマスター自身は対象魔法に含まない。コスト減少の下限は0。 |
| 対象選択 | ファイアーボールは両プレイヤーと対象にできるモンスター。ゾーンは残った手札1枚を除外してからダメージ。メテオは各2ダメージごとに生存対象から再抽選。 |
| 緊急応援・麻酔 | 応援の3体は次の実際の相手ターン終了時に破壊。麻酔は発動時に自分の場にいたモンスターをそのターンだけ保護。破壊や能力による体力減少はダメージ無効の対象外。 |
| ミミックキング2世 | 旧召喚時効果を置換。隠れ家は生成された残存魔法として配置し、魔法ゾーンの上限に従う。 |

新カードの一覧は [CARDS.md](CARDS.md)、完全な定義は [catalog.json](catalog.json)。アート48枚は `client/public/art/cards/`、表示用の2サイズは `cards-sm/` と `cards-xs/`。プロンプト・生成記録・寸法・SHA-256はこのディレクトリに保存。

Botのカード評価値は初期の効果見積もりであり、勝率測定に基づくバランス評価ではない。
