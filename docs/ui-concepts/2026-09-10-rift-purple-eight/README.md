# 紫黒のリフト — 8案

紫黒の配色、控えめな縁の光、強い斜め向きに絞った静止画の素案です。

| 案 | 形の方向性 |
| --- | --- |
| 01 一閃 | 細い直線と鋭い両端 |
| 02 静かな裂け目 | 柔らかな曲線と非対称の両端 |
| 03 折れた亀裂 | 分岐を省いた角張った亀裂 |
| 04 細い開口 | 中央に少し幅を持たせた黒い開口 |
| 05 墨の切れ目 | 墨のように流れる一本の曲線 |
| 06 ずれた空間 | わずかにずれた裂け目の縁 |
| 07 楔の裂け目 | 非対称の細い楔形 |
| 08 薄紫の縁 | 細い曲線に沿う柔らかな紫の光 |

[比較ページ](index.html)で白／暗紫の背景を切り替えられます。各画像をクリックすると原寸PNGを表示します。

PNG保存先: `client/public/art/biblion/rift-purple-eight/`。
生成方法: built-in `image_gen`、1案につき1回。全プロンプトと生成元は `manifest.json` に記録しています。

今回はデザイン比較用の素案です。ゲーム内への選定・差し替えやアニメーション制作は含みません。
