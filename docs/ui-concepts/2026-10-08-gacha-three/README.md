## 仮仕様

既存のスリーブ画像を見本として再利用。特装・箔押し専用アートは未制作。対戦カードの所持や強さを変えるガチャではない。

通常確率はSSR 3%、SR 17%、R 80%。各等級2種で均等、個別確率も表示。10連で最初の9枠にSR以上がない場合のみ、最後はSSR 15% / SR 85%とする仮説明。未実装の抽選アルゴリズムを実行済みと扱わない。開催期間は未定、重複変換量も未定。実商品・価格・確率の確定を意味しない。
