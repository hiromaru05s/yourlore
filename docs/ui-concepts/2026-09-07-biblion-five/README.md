# ビブリオン インゲームUI — 5つの近接案

2026-09-07。内蔵 ImageGen 使用。既存コードの実装変更ではなく、正典と添付画像に基づく通常対戦画面の表現比較。

## 今回の判断基準

ユーザーが今回提示した正典・2枚の画像・上下中央の指定を優先する。参照は `docs/world-bible.md` と `docs/characters/README.md`。旧コンセプトは履歴であり、新案のオブジェクト辞典として使用しない。

- 自分の青いシーカーは中央下、相手の赤いシーカーは中央上。全5案で固定。
- 固定8枚と提示4枠は画面中央。両者を同時に見渡せる。
- 添付の白い石材、青い魔導光、暗青の周縁、控えめな金属、赤青の服色、アニメ調の人物を強く参照。
- 各案で変えるのは表面、カードの支え方、操作部の埋め込み方、NPCの存在感。配置の習得を案ごとにやり直させない。
- デザイン上の豊かさはカード絵・素材・接地感に配分する。機能を持たない大きな装飾や新しい操作を増やさない。
- キャラクター外見は基準原画が正本。生成による顔・服の小差はキャラクター設定の変更ではない。
- 参照画像中の本などをゲームのゾーンへそのまま割り当てない。カードのデッキはカード束として扱う。

## 5案

| 案 | 表現の差 | UXの意図 | 検証したい点 |
|---|---|---|---|
| 01 白亜のデュエルテーブル | 円卓と低いカード台。最も標準的 | 盤面を見渡す速さと世界観の両立 | 小画面でのカード幅 |
| 02 アチューンのインレイ | 石面に馴染む操作部とマナ装置 | 操作対象を装置の形と反応で理解する | 装飾線と操作線の区別 |
| 03 マーケットのカードケース | 開いた薄いカードケース | 候補のまとまり、借用する対象の明快さ | ケースの厚みが盤面を狭めないか |
| 04 アチューンのプロジェクション | 石面の少し上に投影されたカード | 軽さと具現化の存在感 | 浮遊表現と選択範囲の一致 |
| 05 NPCのマーケットカウンター | 小さな2人のNPCと低いカウンター | 固定/提示を担当する存在で区別 | NPCがカードより目立たないか |

## 機能を担うオブジェクト

これらは外形の提案であり、世界観の新しい固有名や設定ではない。

| 既存機能 | 新案の表示・物 | 操作/状態 |
|---|---|---|
| プレイヤー | 赤/青のシーカーの小さな肖像 | 中央上下に固定。個人名・背景は設定しない |

| マナ | 小さい設置型アチューン＋数値 | 支払い、現在/実効最大値、最大30。装置そのものに未実装の追加操作を与えない |
| 手札 | 手元のカード列 | 拡大、展開、ドラッグ使用、取消、使用不可理由 |
| モンスター | カード/カードの上に具現化した絵 | 現在攻撃力/HP、行動可能/済み、対象、順序、状態帯 |
| スペル・トラップ | 同じ別容量の小さなカード群 | 合計7。罠はカード裏面、永続効果は残ターン/∞ |
| デッキ | スリーブを着けたカード束 | 枚数、構成/残りカード。相手は公開履歴だけ |
| シェルフ | 低い棚と収まるカード | 枚数、一覧・拡大。既存の購入処理の着地先もここ |

| 2つの市場の担当 | 小さな異なるNPCの存在感 | 既存の市場機能を担う視覚的案内。独自会話/ショップ操作は追加しない |
| 手番/終了/残時間 | 卓面の小さい物理操作部 | 手番とターン数、エンドターン、残秒、制限状態 |
| シナジー | 小さい文字と到達マーク | 両者の系統数/達成閾値。新しい経験値やレベルにしない |

## NPC・チャーム・シャードの扱い

- 正典の固定/提示マーケット担当は別のNPC。今回は匿名の小さなシルエットを使う。名前・正体・由来・所属・秘密の匂わせは設定しない。容姿は未確定の提案で、採用済みデザインではない。
- 闇商人・ナイトマーケット・巨人の交易・記録者などは、既存カード効果が呼び出した選択UIを維持する。常設の別市場や新しいサービスボタンを追加しない。
- チャームは正典上の存在だが現行 `PlayerState` と盤面にはデータモデルがない。今回の「現行機能継承」の盤面には効果や起動ボタンを創作しない。実装時は正典の1個持参・カード1枚分未満という条件のもとで別途確定する。
- シャードは対戦中のカード借用コストではない。盤面にシャード残高や寄付/購入導線を常設しない。
- ランク別カードプールのマッチ規則も未確定。画像で新しい制限やランク能力を追加しない。

## 全案共通の機能継承

現行 `boardView.ts` / `cardView.ts` / `modal.ts` / `controller.ts` / `online.ts` / `tutorial.ts` / `engine.ts` を基準とする。前回の調査を継続し、現行の7枠・8市場・更新トークン等を再確認した。

| 機能群 | 維持する内容 | 見せ方 |
|---|---|---|
| 両者の識別・資源 | 肖像、名前、スリーブ、精神力現在/最大、マナ現在/実効最大、プレイヤーカウンター | 通常は数値中心。カウンターは該当時のみ |
| モンスター場 | 各7体上限、順序、並べ替え、攻撃/直接攻撃条件、選択可能候補、不可理由 | 通常の場＋ドラッグ中のガイド |
| モンスター情報 | 攻撃力、現在HP、被ダメ/強化、パッシブ/付与、攻撃済み、複数攻撃、孵化/耐久、カウンター | 主要数値を常設、詳細と長文は拡大 |
| スペル・トラップ | 各者合計7、伏せ情報、公開済み条件、残ターン/∞、回数/カウンター | 裏面/表面＋小バッジ |
| 自分の手札 | 枚数、コスト、読取、展開、ドラッグ使用、取消、使用不可理由 | 下中央付近のカード列 |
| 相手の手札 | 裏面、枚数、スリーブ、非公開情報保護 | 上中央の肖像横 |
| デッキ | 枚数、自分の構成/残り、相手のゲーム中公開済み構成 | 束を選ぶと閲覧 |
| シェルフ/リフト | 各枚数、一覧、拡大、空状態 | 各者の盤面脇。両者分を同じ強さで表示 |
| 種族シナジー | 場の異なるカード数、2/3と対象種族の4、発動済み | 小さい進捗表示＋詳細 |
| 固定マーケット | 8枚、購入価格、在庫初期3、売切れ差替え/再補充、ウォッチ、閲覧 | 中央で常設 |
| 提示マーケット | 4枠、手番側の公開提示、購入済み/縮小による空き、種類順、更新 | 中央で常設。更新は提示側だけ |
| 更新コスト | 通常1マナ、無料更新トークン時0と残数、使用不可 | ボタンの値と説明を状態に合わせる |
| 借用操作 | プレビュー、購入準備/確認、実効マナ価格、誤操作防止、借用後のシェルフ移動 | カードの近くで確認。取得カードが手札やデッキへ即座に入るように見せない |
| 拡大カード | DBの正しい名前/全文、購入/発動/召喚コスト、キーワード、変化後数値 | 一時オーバーレイ |
| 対象選択 | 味方/敵/直接、各制約、キャンセル可否 | 有効対象だけ強調し短い指示 |
| 単数/複数選択 | 探索/回収、破壊、除外、捨てるカード、特殊選択肢、指定数/確定/取消可否 | 必要なときだけ選択パネル |
| 手札持越し | 5枚まで、超過分を指定、追加10秒、時間切れは右から | 終了操作時だけ選択を開く |
| ランダム処理 | 宝箱、ダイス、予測、振り直す/維持、結果 | 該当効果時のみ。常設ボタンを増やさない |
| ターン | 手番、ターン数、モード別残時間、警告、終了、保留中の無効状態、スキップ | 終了操作に残秒を近接 |
| 補助操作 | デュエル記録、音量/ミュート、ガイド、リタイア確認 | 周縁の小さい入口 |
| 開始 | 固定市場プレビュー、準備完了、先後決定 | 開始時だけ |
| 結果 | 勝敗/引分、理由、ランク差分、再戦、ホーム、盤面振返り | 終了時だけ |
| オンライン | 再接続、同期、切断/無効試合、残時間復帰 | 状況発生時だけ |
| チュートリアル | 現行の進行ガイドと終了 | 該当モードだけ |
| 多言語/入力 | 日韓英、PC、タッチ、拡大/長押し、狭い画面での再配置 | 同じ対象に同じ操作を割り当てる |

## 静止画と実装の境界

画像は表現を選ぶためのモックアップ。カードの絵・小さい記号・数値配置は仮で、カード追加や効果変更ではない。実装では現行DBの名前、種族、効果、コストを描画する。モーダルの実際の到達性、7体＋スペル/トラップ7枚、手札多数、最大マナ30、長い多言語テキスト、小画面は実機で検証する必要がある。

全機能を1枚で常時露出することと、機能を維持することを分ける。通常盤面では判断に必要な状態、選択後はその行動に必要な詳細を見せる。内部コードや正典のTODOの実装は今回の対象に含めない。
