# LORE — 수익 구조 (확정 스펙)

> 2026-07-03 확정, **2026-09-07 개정** (§8 참조). 원칙: **카드 파워는 팔지 않는다** (카드풀 = 랭크 열람 허가로만 결정, 카드 단위 과금 없음).
> 참(Charm) 1슬롯만 파워를 가지며, 전부 플레이로 획득 가능. 샤드 구매는 시간 단축 범위로 제한. 세계관 근거는 [world-bible.md](world-bible.md).

## 1. 광고 (무료 유저)

| 지면 | 규칙 |
|---|---|
| 상시 배너 | 게임 화면 중 상시 노출 (갱신 30~60초) |
| 전면 광고 | **3판당 1회** (매판 아님 — 리텐션 보호) |
| 보상형 광고 | **하루 3회**, 시청 1회 = 가챠 1회 |

- 구독자는 전 광고 제거 (보상형 포함).
- 포털(CrazyGames 등) 입점 빌드는 포털 SDK 광고 정책을 따름 → 자체 광고/외부결제 금지가 보통. **포털 빌드와 자체 도메인 빌드 투트랙.**

## 2. 크레딧 (단일 소프트 커런시)

- 가챠 1회 = 크레딧 **2~100 랜덤**, 고액은 희박 (기대값 ~12로 튜닝, 확률표는 확정 후 공개 페이지에 게시)
- 사용처: 카드 프로텍터(슬리브), 필드 디자인, 이모티콘

| 상품 | 가격 |
|---|---|
| 노말 디자인 (슬리브/필드) | 1,000 |
| 레어 디자인 (슬리브/필드) | 2,000 |
| 이모티콘 | 미정 (TBD) |

## 3. 무료 진행 보상 (첫 구매 동선)

- 봇전 4모드: 쉬움 / 보통 / 어려움 / 지옥
- 쉬움+보통+어려움 첫 격파 합계 **~600 크레딧**
- 랭크 신규 티어 도달 시 소액 크레딧 (제안: 초반 티어당 ~100, 수치 튜닝 대상)
- **지옥 첫 격파 = 비매품 전용 스킨** (크레딧 아님 — 돈으로 못 사는 위신 아이템)
  - 지옥 봇 = 클레어보이언트 봇 재활용 ("이 봇은 당신의 패를 봅니다" 명시 라벨)

설계 목표: 무료 유저가 **3~7일 안에 첫 스킨(1,000)** 획득. 이후 F2P 수입은 일 ~36크레딧(보상형 3가챠)으로 다음 스킨까지 ~1개월 — 첫맛 빠르고 이후 느린 표준 커브.

## 4. 유료 (SKU 3개만)

| SKU | 가격 | 내용 |
|---|---|---|
| **구독 (단일 플랜)** | **$7/월** | 전 광고 제거 + 매월 1,000크레딧 즉시 + 매일 가챠 5회 |
| 크레딧 팩 S | $4 | 1,000 크레딧 |
| 크레딧 팩 L | $7 | 2,000 크레딧 |

- 구독 월 가치 ≈ 1,000 + 가챠 150회(기대 ~1,800) ≈ **2,800크레딧 + 광고제거 = $11+ 상당을 $7에** → 구독이 항상 최고 가치 (의도된 설계).
- 광고제거 단독 상품 없음 — 광고제거는 구독에만 묶어 구독 가치를 유지 (1회성 판매는 장기 구조 훼손 우려로 기각).
- 크레딧 팩은 즉시성 니즈용 진입 사다리 ($4 첫 결제 → $7 구독 전환).

## 8. 2026-09-07 개정 — 샤드 · 참 · 기부

세계관 확정([world-bible.md](world-bible.md))에 맞춘 개정. 수치는 미정, 구조만 확정.

- **통화 명칭: 샤드(Shard)**. 위 §2~§4의 "크레딧"은 모두 샤드로 대체. **무료 샤드**(비블리온 지급: 듀얼 보상·첫 격파·티어 도달) / **유료 샤드**(외부 반입: 팩·구독) 로 구분.
- **사용처 = 비블리온 기부**. 기부하면 참, 슬리브, 필드, 이모티콘 등의 혜택을 받는다. 진행도 기반의 고정 저니가 아니라 기부 동선.
- **참(Charm)**: 듀얼당 1슬롯 지참. 카드풀의 존재들에게서 직접 받는 소품(엘프의 팔찌, 암살자 길드 운영 매뉴얼, 주술사의 휴대형 어튠 등). 획득 조건은 세계관과 직결(해당 계열로 N승 등).
  - 참은 **파워를 가진다**. 약간의 불균형은 의도. 상한: 카드 1장 미만(최대 마나 +1 / 초기 정신력 +3 / 특정 계열 +1 수준).
  - **모든 참은 플레이로 획득 가능**. 샤드로는 시간 단축만. P2W 금지 원칙은 유지.
- 카드풀 확장 무료 배포(§7)는 유지. 랭크별 카드풀은 티어 경계 매치의 풀 규칙을 별도 확정.
- 반영 필요: §2 크레딧 → 샤드 명칭, D1 스키마(참 인벤토리·슬롯), 참 효과 상한 검증(서버).
