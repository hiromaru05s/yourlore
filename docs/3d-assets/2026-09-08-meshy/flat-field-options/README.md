# 凹凸を抑えるフィールド土台 — 3案

既存の大理石模様を含む画像をMeshyで3D化した際、ユーザーから天板に凹凸が発生したとの報告。これを受け、天板を無地・均一色・平面に変更した比較案。輪郭と大きさの方向性は現行の大きく丸めた台を引き継ぐ。

| 案 | 画像 | デザイン |
|---|---|---|
| 1 白磁と濃紺の薄縁 | [原寸PNG](01-ivory-thin-rim.png) | 明るい無地の天板。非常に薄い濃紺の側面と金の細線。現行の白い台に最も近い方向。 |
| 2 夜藍と真鍮の段付き台座 | [原寸PNG](02-midnight-stepped-base.png) | 無地の夜藍の天板。下側の真鍮の帯と段差で、魔導装置のような重厚さを出す。 |
| 3 淡青の天板と白亜の側面 | [原寸PNG](03-pale-blue-ivory-arcade.png) | 無地の淡青の天板。白い側面だけに大きく単純なアーチを入れ、ビブリオンの建築に寄せる。 |

共通：天板に大理石の脈・ひび・粒子・文字・魔法陣・彫刻・段差を入れない。装飾は天板より下の外側面に限定。カード、周囲の家具、UIを含まない単体画像。

内蔵ImageGenで1案ずつ生成。参照は `../field-base-v2-from-current-board.png` の輪郭・低い比率・カメラ。大理石模様は引き継がない指定。[各案の生成プロンプトと生成元](manifest.json)。原寸画像を保存し、画像の合成や後加工は行わない。

これは画像による形状提案で、Meshyの出力メッシュは未検証。生成画像だけで完全な平面は保証できない。確実な平面が必要な場合は、3D化後に天板を平面メッシュへ置き換え、生成した縁・側面と組み合わせる。
