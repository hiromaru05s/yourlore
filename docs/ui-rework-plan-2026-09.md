## 3. レイアウト（v3 と同じ）

行構成: 相手灯 / 相手の頁 / 回覧車 / 自分の頁 / 自分灯 / 手札。`layout.ts` のソルバ温存、`railW` → 0。年代記・棚・裂け目は各頁の右。系譜の印は頁の左外。閲覧印は回覧車の右。対読記録は左下。

- 手札: 横一列アコーディオン。間隔 = min(カード幅+8, (画面幅×0.55 − カード幅) ÷ (n−1))。ホバー/タッチ中の 1 枚が浮き両隣が逃げる。タップ拡大、ドラッグ使用。2 状態（束→展開）は廃止。
- 回覧車: 提示 4＋安定 8 を 1 段 12 枚（1280px 以上）、未満は 2 段。ミニカードは本文なし。
- モバイル: 行構成同じ。回覧車は 1 段横スクロール、年代記・棚・裂け目は灯の横の数字 3 つ、手札は横一列アコーディオン。

## 4. シンプルさの担保

1. 物は 9 種（灯・皿・年代記・棚・裂け目・栞・頁・回覧車・閲覧印）。それ以外に装飾を置かない。
2. 各物は線 1〜2 本と面 1 つで描ける。細密な紋様は入れない。
3. 色は 8 色＋紫 1 色。発光は手番側の帯、攻撃可能な 1 体、着地ガイド、武装した 1 枚、タイマー弧、裂け目の 6 箇所。
4. ラベルは世界の名前＋ツールチップで機能名（ko/ja: 年代記 / 忘却の棚 / 裂け目 / 提示 / 安定書庫 / アチューン）。
5. 等幅大文字ラベル 0、絵文字 0、角丸箱 0。
