# 固定マーケットの回復対策を見落とすBOTの修正

神官が公開されている対戦でも、攻撃中心の単体評価と相手の購入予測が継続回復を過小評価していた。探索回数だけを増やしても、相手が神官やシールド札を買って回復を伸ばす展開を十分に予測できなかった。

## 変更

- 固定市場の在庫・購入可能になるマナ帯、相手の公開盤面・公開履歴から回復のリスクを評価。相手の実際の非公開手札・デッキは参照しない。
- 神官・高等神官・世界樹系の雫、シールド、継続回復を評価に反映。神官を獲得した後は、追加シールド札による雫の成長も評価する。
- 対策となる除去・砂漠化・シールド破壊・盤面の大型化を購入評価へ反映し、少量の直接ダメージへの追加投資を下げる。同じ対策を何枚も買う価値は逓減する。
- 除去の対象条件を区別する。モンスター除去は回復の永続魔法への解答にならず、購入コスト5以上が条件のルーンは神官を除去できない。両陣営を巻き込む除去も自軍損失を考慮する。
- ロールアウトと低難易度の基本方針でも、砂漠化・アーマーブレイク・雫／シールド獲得を使用。攻撃力0の回復エンジンも除去対象として評価する。
- 単純な決着予測に相手シールドを含める。確定勝ちを取れる場面では対策の購入より勝利を優先する。

カードのルール・数値、12種類の初期デッキ、初期体力／マナ、難易度別ミス率は変更していない。初期デッキを公開後に入れ替えることもない。公開市場を見て対戦中の購入・運用を変える修正。

## 検証の読み方

`tests/bot-market-strategy.mjs` は公開市場だけを変えた購入判断、在庫切れ、非公開情報の変更に対する評価の不変性、除去対象、継続回復の抑制、Hard/Hellの確定勝ち優先を実reducerで確認する。既存のWorker・思考安全性テストと合わせて production suite に登録。

`ml/bot-strength/market-gauntlet.cjs` は旧版と新版を同じ相手・シード・先後で比較する。相手は回復札を意図的に買い、先に神官を召喚する反アグロ方針。候補側は既存のHell初期デッキ3種、相手は合法なリフト系／エルフ系初期デッキ。候補の強制手札や追加資源はない。

- 固定市場: 神官／高等神官／回復エンジンなしの3条件。市場だけをfixtureで指定し、残りの対戦は通常reducerを使用する。
- 自然市場: `createGame` が生成した市場をそのまま使用する。
- 簡易思考は買い物・展開の診断であり、配信Hard/Hellの勝率とは区別する。
- 配信と同じHard/Hellも別に比較する。勝敗は完走した対局だけを集計し、不正行動／打切りを別に記録する。
- 人間の勝率、全デッキへの優越、無敵は検証していない。

再現例（出力ファイルは新規パスにする）:

```sh
CANDIDATE=/absolute/candidate.cjs BASELINE=/absolute/before.cjs \
OUT=/absolute/results.json MODE=hell SAMPLES=2 OFFSET=2 \
node ml/bot-strength/market-gauntlet.cjs
```

`NATURAL=1` で自然市場を使用する。固定市場の試験数は `3市場 × 2相手 × SAMPLES × 2先後 × 2版`、自然市場は `2相手 × SAMPLES × 2先後 × 2版`。

配信後は `tests/bot-staging.mjs` で実ガードビルドのJS/CSSと配信ファイルを照合し、公開環境の実Workerで初動12ケースと回復市場4ケースを検証する。認証済み対人戦の検証ではない。

最終結果・配信状態は evidence.json に記録する。

## 完了した比較

同じシード・先後で旧版／新版を比較した328対局が完走。不正行動0、打切り0。

| 思考と市場 | 旧版 | 新版 |
|---|---:|---:|
| 簡易・神官 | 24/32勝 | 31/32勝 |
| 簡易・高等神官 | 29/32勝 | 31/32勝 |
| 簡易・回復エンジンなし | 32/32勝 | 32/32勝 |
| 簡易・自然市場 | 28/32勝 | 28/32勝 |
| Hard・3市場合計 | 12/12勝 | 12/12勝 |
| Hell・3市場合計 | 24/24勝 | 24/24勝 |

同条件の勝敗が悪化したペアは0。Hard/Hellの比較相手には旧版も全勝しているため、この比較から実思考の勝率上昇は主張しない。簡易ロールアウトの盲点改善と、実思考での購入・使用判断の回帰検査を合わせて評価する。人間相手の勝率ではない。

`release-*.json.gz` に全対局結果・購入記録・設定・モジュールハッシュ、`before.cjs.gz` と `candidate.cjs.gz` に凍結した実装を保存した。各試行の思考時間は同じPCで他タスクが動作する条件の計測であり、速度保証には使用しない。
