# 不採用案・中間検証

このフォルダは最終採用版の検証ではない。初期7系統（腐敗・速攻・賭博・裂け目・エルフ・城・吸血）の候補、方策比較、途中のブラウザ確認を保存する。旧ヘル3構築との336対局ではエルフ候補が0/48などの弱点が露呈したため、構築案を撤回して選び直した。

`final-candidate.cjs.gz` という名前も当時の中間版であり、採用版は親フォルダの明示された最終バンドルを参照する。初期の実探索試験は不採用構築を使っていたため中断し、受入成績に数えない。方策改善と構築改善を分けて評価する。

第2段階の探索は `robust-second.json.gz` と全試合の `robust-second-games.jsonl.gz`（11,520試合）。`pool-holdout18.json.gz` は完了済み18候補・5,760試合だけを含み、未完了6候補は評価しない。対応する方策は `second-search-policy.cjs.gz` と `second-holdout-policy.cjs.gz`。それぞれのハッシュは `second-stage-artifacts.json` に記録した。これらも最終方策の性能証明ではない。
