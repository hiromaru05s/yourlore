# 孵化召喚02「螺旋の脱殻」

2026-10-13、ユーザーが02を選択し、カードサイズの不具合だけを修正してステージングへ適用するよう指示。

カード面の透明パディングを本体の幅・高さへ縮めていた比較用キャプチャと、リサイズ時の高さ固定を修正。実ゲームでは実寸のネイティブカードを同じ盤面投影で固定し、承認済みの殻だけを重ねる。殻の形状、軌道、時間は変更しない。共有レンダラーを ui/hatchSummon に移し、比較ページも同じ描画を使用する。

エンジンの summon に公開情報の hatchFrom を追加。既存の destroy / summon イベント、スロット、除外、召喚効果、ゲームルールは維持。コントローラーは対応する卵の destroy と summon を同一スロットで一度だけ演出する。通常の破壊・手札からの召喚経路とは区別し、途中のスロット再配置と二重演出を防ぐ。対象は DRAGON_EGG → D_BLACK / D_RED / D_BLUE、BEAST_EGG → DIVINE のみ。

検証:
- tests/hatch-summon.mjs: エンジン8ケース、同一スロット・除外・明示ペア、採用案、ネイティブ寸法、GPU共有、動き低減、中断、描画失敗時の復帰。
- client/hatch-runtime.html: 実 GameView / anim.hatchSummon、4種×両陣営の連続再生中のカード寸法サンプル、同一スロットの最終カード、キャンセル・スキップ・リサイズ、BaseController のイベント再生と最終描画。
- ブラウザー測定は docs/vfx-prototypes/2026-10-12-hatch-four/qa/runtime-*.json。デスクトップ1280px幅では演出中最大0.157px未満、前後は同一矩形。
- 公開は scripts/deploy-guard.mjs staging のコミット済みスナップショットから行う。
