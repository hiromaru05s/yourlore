# ダンジョン最下層 — 承認済みの浮上門

2026-10-14: 「これでOK。ステージング適用しといて」に基づく通常対戦への採用。

- ミミックは第3案「生体侵蝕」。門はキャラクター枠に重なる高さに置く。
- 自分の発動では門を180度回し、扉は相手側へ開く。ミミックも相手を向いて飛び降りる。相手発動は逆向き。
- 元カードのアートを門の下に置かず、門・扉・影は240msで一体として消す。
- 承認された `src/dev/dungeon-floating` と `dungeon-mimic-three` の造形・経路を `src/ui/dungeonFloor` に移植。通常バンドルから描画部分を遅延読込する。

## 通常対戦の接続

エンジンはこの効果で生まれた召喚イベントに `source: DUNGEON_FLOOR` を付ける。カードの効果・数値は変更しない。

BaseController の共通ダイス処理完了後、実際の召喚イベント数に対して門をひとつ作る。各召喚は従来通りイベント順に着地を待ち、永続魔法・カウンターなどの反応を処理する。次の召喚がまだ許可されていない場合、描画側はその着地の直前で待つ。通常の単体ミミック召喚経路は同時実行しない。

旧盤面の空き枠を先に予約し、着地で実カードへ置き換える。最終状態を先に描画しない。低減モーション、WebGL失敗、非表示、リサイズ、コンテキスト喪失、早送りではカードを確定して一括で後片付けする。
