# 対戦フィードバック修正 v101

2026-11-18。Ariesの専用カード調整と、対戦中の判断・表示・初手確認を修正。

- イカロスの翼／靴をコスト1、ゴブリンパーティーをコスト2・自分のマナ水晶+1のみへ変更。3体の発動条件を維持。
- ゴブリン鍛冶屋は自傷8・自分のゴブリン系1体の攻撃力+4。体力強化を撤去し、事前選択・サーバー・BOTとも対象制限を共有。
- ゴブリンの起源をコスト3、相手効果による破壊時は自分のゴブリン系全体に攻撃力+1へ変更。自分のターン開始時の召喚は維持。
- ルーン文字は攻撃を止める挑発と解除する能力を評価。浄化の手は公開された烙印に応じて購入・発動を優先し、探索も烙印の継続ダメージを評価。烙印がある場合は墓地が空でも発動できる。
- ミニ精霊の各個体を共通のモンスター効果発動経路へ接続。雫によるプレイヤー回復時、2体／3体全ての攻撃力+1を両陣営で検証。個別の効果無効も適用する。元の報告の対戦状態は未取得で、数値強化が1体だけになる現象そのものは再現していない。
- ファイアーボールの追加分と同一対象への連続属性攻撃は、先の演出の終了後に次の演出を開始。汎用ダメージ表示も数字の残存時間を確保。中断・低減モーションでも待機を解放する。
- マリガンの盤面確認中に、マーケットの左クリック／右クリック・キーボード操作と、自分のデッキ構成表示を用意。初手選択と残り時間を保持。
- 既存ルームの変更対象カードと進行中の鍛冶屋の選択を移行。新規ゲームはv101を適用済みとして作成。
