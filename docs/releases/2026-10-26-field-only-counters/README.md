# カウンターはフィールドに出てから表示

2026-10-26、ユーザー報告の「マーケットの卵にすでにカウンターが乗る」を修正。本番反映を指示。

- `fieldCounters` はフィールド描画のときだけカウンターを返す。定義の孵化ターン数を市場・手札・通常拡大の実カウンターとして表示しない。ライブ値を含むカードを非フィールドで描いてもカウンターは付けない。
- 卵の黒い耐久シールドもフィールド表示時のみ。場に出た卵の孵化・耐久値と増減演出は維持。
- カード定義・召喚・孵化ルールやサーバー状態の変更はない。永続魔法の蓄積・時間UIは従来どおり場の魔法に表示する。

`tests/card-counters.mjs` に両卵の市場・手札・通常拡大で非表示、フィールドでライブ値表示、非フィールドにライブ値が残っていてもカウンターなしを追加。既存対戦UIテストも通過。公開結果は公開後に記録。
