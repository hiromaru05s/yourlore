## 接続

採用された `poison-four?revision=emergence` の表面シェーダーと投影描画を `ui/poisonSummon` へ移動。比較プレビューも同じコードを参照する。見た目のパラメーターは保持。

`controller` → `ghostSummon` / `summonFromHand` → `flyIntoSlot` の専用分岐、および `playMonster('summon')` → `playSlateSummon` の専用分岐に接続。一般の召喚、着地粉塵、種族演出は重複実行しない。カードの表面は現在の公開DOMから取得し、枠・数値・カード効果を独立した古いデータで再生成しない。

カード面は盤面と平行。移動・落下・素材の変化を一つの時計で処理し、640msの接地時に一度だけ通知。描画準備完了後に0msフレームから開始する。同時発動は一つのWebGL rendererを共有し、各召喚の表面・影・テクスチャを個別解放する。全終了時にrendererを解放。

中断、DOM切断、リサイズ、非表示、早送り、低減モーションとGPU失敗の経路でカード表示を復帰する。

## 検証

- `tests/poison-summon.mjs`: 選択対応、0ms描画、接地一回、取得中の中断、置換、同時召喚の個別終了、低減モーション、GPU失敗と後片付け。production suiteに登録。
- TypeScript: client/serverの型チェック成功。
- `qa/runtime-report.json`: 3カード × 両陣営 × hand/generated/direct の18経路と中断2件。通常18経路は選択番号一致、描画済み0ms開始、専用層1回、rawFrames=0、後片付け・カード復帰を確認。directの接地通知は各1回。hand/generatedの `impacts=0` はその監視コールバックを渡さないためで、音の不存在を示すものではない。
- `qa/runtime-lifecycle.json`: 3体同時成功、接地3回、同一ソース置換、切断、リサイズ中断で残骸なし。
- `qa/runtime-frames.png`: 実時間再生中の表面サンプル。固定FPS映像・GPUベンチマークではない。
- 390×844の実盤面で3カードの再生・復帰を確認。

見た目の承認は今回のユーザー選択による。機能検証の成功を新たな視覚品質承認とは扱わない。通常コードのローカル実盤面fixture検証であり、認証済みオンライン対戦の検証ではない。
