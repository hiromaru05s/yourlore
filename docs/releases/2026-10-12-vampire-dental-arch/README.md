# 吸血鬼 01「吸血の歯列」の採用

2026-10-12。ユーザー指示「01でステージングに適用して」に基づく。対象は見習い・初級・中級・上級・特級・ヴァンパイア執事の6種。選定元はR6、上下の付け根をフレーム端に揃えた `25b0d076`。

## 実装

- 手札からの召喚と効果による召喚を `vampireSummon/runtime.ts` へ接続。通常のDOM拡大、汎用の着地と重ねず、選定した一回の噛み込みと接地を一つの時計で再生。
- プレビューと実装で歯の生成、DentalArch、噛み込み時刻、描画クラスを共有。ゲーム側は01の形状のみを生成し、02〜06は読み込まない。
- 開口時の根元中心はy=±136.5、噛み込み1080ms、接地1800ms、終了2600ms。カード表面の傷は接触位置に留まる。
- 実際の配置行列から描画し、上下両陣営で同じ座標系を使う。420msの手札移動も同じ時計に含める。
- 同時発動はGPUレンダラーを共有し、各カードのテクスチャを終了時に解放。最後の処理でGPU資源を破棄する。
- スキップ、AbortSignal、重複開始、画面離脱、非表示化、リサイズ、切断、低減モーション、描画不能時の元カード復元を扱う。

## 検証範囲

- `tests/vampire-geometry.mjs`: 6種×11時刻で選定元と実装のメッシュ・変換・接触点が一致。上下フレーム位置、噛み込み一回、接触前の圧力なし、傷の位置固定。
- `tests/vampire-summon.mjs`: JSDOMと描画モックで6種、手札移動、接地通知一回、同時実行、中断、待機中キャンセル、置換、低減、失敗復旧、資源解放を確認。
- 上記2件を既存のproduction suiteに追加。
- ブラウザの安全確認が以前ローカルURLの取得をプロトコル制限として拒否したため、その操作の再試行・別経路のブラウザ操作は行っていない。今回のテストは実ブラウザGPU映像や認証済み対戦の検証ではない。R5の画像を今回の実行証拠に流用しない。
