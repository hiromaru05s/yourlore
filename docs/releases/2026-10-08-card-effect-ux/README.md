## 対応した監査項目

1. 本文で参照するパッシブを、そのカード自身の能力と区別して説明する。元の26枚の説明欠落を含め、全カードの参照用語を明示的なメタデータに保存した。
2. 腐敗を与える能力のアイコンと、腐敗を受けた状態を分離。状態は現在数／破壊閾値、破壊と持ち主への3ダメージを説明する。拡大でも状態を保持する。
3. SHATTERを「崩壊振動／붕괴 진동／Shattering Tremor」に改称し、EARTHQUAKEの「地震／지진／Earthquake」と区別。全360枚の名称一意性を三言語で検査する。内部ID、効果本文、ゲーム処理は変更しない。
4. 盤面からの詳細には現在体力／最大体力、用途別カウンター（0個も含む）、持続補正、一時補正の期限、付与能力、条件成立中の能力を表示。期限切れのダメージ無効を有効として表示しない。
5. 用語説明は翻訳文の正規表現判定を廃止。「持続、自身を含む」の見落としとCounterの誤認を解消し、三言語で同じ用語群を説明する。墓地の説明も追加。
6. 効果本文を全言語で検索可能にし、案内文も更新。能力を持つ／付与する／効果で参照する、の絞り込みを追加。
7. 種別名を共通化し、クエスト・クイック・永続魔法を区別。クエスト進捗とツールチップを三言語化。クイックはリフトに移動した後に処理する説明で統一。
8. パッシブから本文への復帰、関連カードの閲覧履歴とスクロール・フォーカス復元、Escで一段戻る操作、スマホの固定見出しと閉じる操作を追加。

表記ルールへの追補は `docs/card-text-style.md` §9。
