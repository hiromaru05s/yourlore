# 提示マーケットのリロール

2026-10-08。承認された「めくり替え」をゲームの共通コントローラーへ接続。追加指示に従い、開始時に3枚が一瞬左へずれる問題だけを修正。

原因は `#supplyMarket:has(>:nth-child(4))` が演出用レイヤーを4枚目として扱っていたこと。旧4枚表示用の負のマージンがレイヤー全体へ約19.65px入り、元カードの間隔まで変わっていた。カードと空き枠のみを数え、負のマージンもそれらに限定した。めくる動作・色・時間は変更していない。

検証:
- 1280×720 / 1920×1080 / 390×844 × 3枚・旧4枚表示。レイヤー追加・除去による元カードの位置変化は0px。演出用カードとの開始位置・寸法の誤差は最大0.489px。
- 通常速度の連続再生、PC／スマホの途中フレームを実盤面で確認。
- 無料トークン、空き枠、短縮2枚、連打、相手側、旧表示からの誤購入防止、低減モーション、リサイズ・非表示・破棄、WebGLなしを含む15項目のブラウザ検証。
- 最新の対戦修正の `view.render` が返す完了待ちを維持して統合。

`geometry.json` は座標回帰。ステージングの配信SHA・Worker・アセット照合および配信版BOTでの確認は、デプロイ後の記録に追記する。見た目の確認と自動機能テスト、API fixtureを使うBOT検証と認証済みオンライン対戦は区別する。
