## 選定と接続

`client/src/ui/originRite/renderer.ts` は選定された01から描画を抽出。白熱芯と黄色い残光、術式表面の集光、左下から右上への切断、実際のカード面を使う二片の厚み・投影・影・冷める断面光を維持した。未選定の02/03や開発用フィクスチャには依存しない。

通常の召喚着地が完了した位置から420ms時点の反応を開始する。再召喚しない。術式→対象への接触はそこから1330ms後、破片の余韻は720ms。破片は実際の墓地／除外先へ向かう。通常の死亡演出と死亡音を重ねない。烙印はネイティブのカウンターへ接触時に反映し、汎用の付与演出を重ねない。無効化された破壊は光だけ届き、対象を切断・非表示にしない。

`enchantActivate.originRite` にルール処理で確定した召喚UID、対象UID、対象の領域、破壊／烙印／無効化、移動先、烙印の前後値を付ける。破壊後のログや場の差分から推測せず、同一バッチの死亡誘発や複数術式の結果を分離する。隠れたカードIDは追加メタデータに含めない。乱数・選択・破壊可否のルールは変更しない。

現行カタログではトラップは退役済み。古い保存状態のトラップは互換確認対象に限る。テストは既存の `removed-traps.json` の実データを使用し、カタログに復活させない。盤面には公開インスタンスUIDだけをアンカーとして追加し、汎用の封印面をキャプチャする。
