# 無の境地・創造 v61

- 無の境地は購入・使用コスト2。既存の購入条件と使用条件を維持。
- 創造はコスト0、通常魔法161種類から等確率で1枚を生成して手札に追加。生成専用・スターター・購入時発動のクイック魔法を除外。
- ユーザー指定により虚無を維持、同名3回制限を削除。旧ドロー・回復・自己複製・相手デッキ複製は新規発動しない。
- 抽選はゲームの決定的PRNG。農民の祈りなど既存の獲得時置換を適用。旧保存対戦で既に発生した複製選択の解決だけは互換処理を維持。
- 生成イベントは公開済みの発動元UIDと手札位置のみ。生成カードのIDや個体UIDを相手向けイベントに送らない。
- 承認済みの面が剥離する演出を維持し、着地点を墓地から手札へ変更。発動元は創造の面、生成物は取得カードの面（相手視点では裏面）として別々に描く。
