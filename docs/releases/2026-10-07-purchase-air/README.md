# 購入演出03「交互の渦跡」の適用

2026-10-07。ユーザーが購入6案・第3稿の03を選択し、通常演出への適用とステージング公開を指示。

- 実行経路: `BaseController` の購入イベント → `buyReveal` → `purchaseMana` → 共有前景キャンバスの `drawManaPurchase`。
- 現行GLBと光学シェーダーから生成した72方向のロスレス水晶アトラスを使用。台座の水晶は既存の実盤面のまま。旧式の平坦な多角形と直線の尾を置換。
- 飛行サイズは選定ベース01の1.2倍（カード幅×0.444）、75ms間隔で3石、620msで飛行。進行率 `u^1.55`、終端速度は平均の1.55倍。
- 03の左右交互の巻き込み、密度に沿った陰影、110msの侵食による消失を移植。選定版 `99f5473f` の密度場218,880サンプルと完全一致。色・光学描画の設定を変更していない。
- 支払いは940ms。支払い音を最初の石の到着620msに同期。その後のシェルフ移送・クイック魔法の公開と解決・無料購入の扱いは既存処理を継続。
- `GameView` 準備中にアトラスをデコード。3D描画の追加はなく、支払い時は共有アトラスと約1.7MBの密度場を利用。画像は約2.7MB。直接の描画は背景ピクセルを読まず、承認プレビューの実盤面と同じ透明層を使用する。
- 初回ロード待ちはスキップ可能で800msまで。読み込み失敗は購入進行を妨げず、旧トゥーン水晶を復活させない。盤面破棄時はアトラス参照・風の場・読み込み・共有キャンバスを解放。

## 証拠

- `client/public/vfx/purchase-air/manifest.json`: 選定コミット、素材元、PNG SHA-256、密度場ハッシュ。
- `tests/purchase-air.mjs`: 選定版との密度一致、PNG同一性、サイズ、加速、支払い時間。
- `tests/purchase-air-browser.mjs`: 本体の実 `BaseController` と `buyReveal`。PC／390px・両陣営、支払い完了、無料・クイック購入、スキップ、低減モーション、再初期化、画像読み込み失敗。`qa/browser.json` と実盤面の画像。
- 既存の購入VFX、クイック魔法、音声接触規則も確認。全回帰・typecheck・buildは公開ガードでも実行する。
- `tests/purchase-air-staging-browser.mjs`: 公開された未改変バンドルと追加素材のハッシュ照合、既存の `cosmetic-studio.html?board=1&runtime=1&set=default` で本体購入処理を再生。公開後の結果は `staging/` に保存。
