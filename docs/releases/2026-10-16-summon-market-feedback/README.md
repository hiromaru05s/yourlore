# 2026-10-16 召喚・被ダメージ・提示マーケット修正

対象はユーザーから報告された選別者の演出抜け、召喚中のカード面の画質／色の不連続、プレイヤー被ダメージの数字、ターン境界の自動リロール。ステージング適用の依頼に対応。本番は対象外。

## 変更

- `onPlay` は手札に実在するカードか確認した後に演出を早送りする。すでに召喚されたカードへの重複入力で、その召喚・効果・リフト移動を消さない。
- カル除外は公開イベント `cullExile` に実カードと出発ゾーンを記録する。召喚効果／選別者の常時効果の直後に、墓地→デッキ→手札の実際の除外順に再生する。最大3枚を時間差で並行移動し、末尾の状態差分から二重に除外しない。対戦相手の非公開手札・デッキをイベントへ追加しない（イベント内のカードは除外後の公開カードのみ）。
- 公開カード面のキャプチャはフルサイズのアートを使用する。全画面描画の魔法使い・呪術師・傭兵・吸血鬼・暗殺者・毒系・シールドタイタンは画素密度を考慮する。上乗せ画素数を制限し、CSS画素未満にはしない。
- 選ばれしシリーズの印刷面はシーンの露出／トーンマッピングから外す。召喚の終端では静止済みの通常カードへ180msで引き継ぎ、描画レイヤー削除の瞬間に絵が切り替わることを抑える。魔法使い系は既存の終端引き継ぎを維持する。
- 被ダメージ数字は Alegreya 800、深い赤と暗い縁に変更。短い拡大→左右の減衰する揺れ→可読時間→上方に消える0.8秒。ヒット時刻との同期、低減モーション、追従、中断の既存管理を維持する。数字のフォントを対戦準備時に読み込む。
- 各プレイヤーの提示マーケットはターンをまたいで保持し、購入済みの空き枠も保持する。明示的な更新／更新するカード効果のみ再抽選する。マーケットクラッシュは次の相手ターンで最後の枠を除き、残るカードのUIDを維持する。

## 検証と境界

- `tests/cull-exile-events.mjs`: 両陣営、カル0/1/3/7枚、効果の先行、元ゾーン、除外との一致、公開状態との照合。
- `tests/supply-persistence.mjs`: 両陣営の6ターン境界、空き枠、提示履歴、redaction、有料・無料更新、マーケットクラッシュ。
- `tests/summon-feedback-browser.mjs`: 実GameView/BaseControllerとredacted reducer状態で重複クリック、召喚、リフト、PC／スマホ、両側、低減モーション、中断、ダメージ数字を検証。
- GPU色テストでは、元色RGB(100,50,150)が選ばれし召喚の終端でトーンマッピング有効時(107,39,170)、無効時(100,50,150)。Voidの無加工面も(100,50,150)を保持。
- 映像の基準は既存「銀紋の流墨」の連続フレーム。カード面と除外の連続性を維持し、既存採用のリフト演出を使用する。機能テストの成功と視覚確認は別の根拠として記録する。
- ブラウザfixtureはログイン済みオンライン対戦の証明ではない。
