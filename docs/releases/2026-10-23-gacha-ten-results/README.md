# ガチャ10連の結果一覧

2026-10-23。ユーザーの補足「10枚一気に表示してよい。種類の違いが分かるようカードはフレーム込み」を反映。

- 10連の通常演出・スキップ・低減モーションは、確定済みの10件を直接一覧表示する。PCでは5列×2段。狭いウィンドウでは2列のスクロール一覧。
- モンスター／魔法カードは実カードのフレーム、名前、コスト、ステータスを表示し、種別ラベルも分ける。
- スリーブは実スリーブの画像、デッキ置き場＆墓地は装備と同じ3Dモデルのサムネイル、エフェクトは実カードへの適用見本。見本の宝箱カードは報酬そのものではない旨を明記。
- クリックで従来の個別表示へ進め、一覧へ戻れる。単発演出は維持。
- 一覧でもフレームとカードアートのデコードを待って表示。初回通信遅延時にアートだけを先出ししない。
- 抽選・価格・確率・付与・還元・サーバー処理は変更しない。

検証対象: `tests/gacha-rewards-browser.mjs`（通常/スキップ/低減モーション、10件、履歴、再購入なし、4種の拡大、画面幅、家具/スリーブ全系統、実エフェクトの時間変化）、`tests/gacha-reward-readiness-browser.mjs`（遅延したカード枠を待つ一覧/拡大と破棄）、型チェック、ビルド、本番デプロイガードのproduction suite。
