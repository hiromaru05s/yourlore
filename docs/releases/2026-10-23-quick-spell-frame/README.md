# クイック魔法の拡大フレーム — 03 瞬風のヴェール

2026-10-23。ユーザーが比較案03を選択し、下端の種別銘板を少し大きくして本番に適用するよう指示。

## 変更

- `cardInspection.zoomCard` で `t=spell && quick=true` のカードを拡大したとき、選択された三層のヴェール、枠に沿う光、金属枠の局所反射を表示する。
- プレビュー03の描画・速度・配色を保持。銘板は幅52%→64%、高さ5.8%→7.2%、文字幅係数4.05%→5.4%（約1.33倍、最小11px）へ拡大。
- 銘板は既存の種別翻訳を使い、日本語・英語・韓国語に対応。二重表示になる小さな種別チップは拡大加工中のみ隠し、破棄時に復元する。
- カード一覧／対戦の共通拡大経路のみへ適用。手札・マーケットの通常サイズ、一般魔法、カード効果・購入・戦闘ルールは変更しない。
- 参照履歴に入った拡大画面は停止し、戻ると再開。閉じる・置換・ページ破棄時にCanvas・ResizeObserver・メディア監視・RAFを解放。非表示タブでは停止。低減モーションでは静止フレームを表示してRAFを止める。
- Canvas描画を利用できない環境でも種別銘板を残す。
