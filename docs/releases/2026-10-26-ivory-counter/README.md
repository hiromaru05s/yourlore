# 象牙の計数窓 — カウンターUI本番適用

2026-10-26。ユーザー選択04・revision5の円章を採用。右上の象牙色の円章、凹んだ数字窓、中心位置を調整した数字を共通化。増加は上へ、減少は下へ連続した数字列を520msで移動する。+4は4目盛を通過し、再描画・途中反転でも現在位置から継続。

## 適用

- 気合・腐敗・孵化・城などの蓄積、永続魔法のcnt、公開条件を満たす罠のcntを同じUIへ。
- 卵の耐久は既存の右下体力シールドを黒色にして表示。
- 永続魔法の残り／経過ターン・無期限表示は既存のまま。新たなターン表示案の採用は含まない。
- 非公開の罠のカウンターや識別子を追加公開しない。ゲームルール・数値計算は変更しない。

## 検証

`tests/card-counters.mjs`で増減、+4、反転、再描画、消失、低減モーション、非表示、破棄を検証。既存の気合・腐敗・対戦UI・カード説明テスト、client/server型検査、ビルド成功。

`browser-check.mjs`は実際のGameView・共有エンジンをローカルで使用し、両陣営、城+5、孵化の減少、致死攻撃時の気合消費、気合と腐敗の併存、PC・スマホを検証。画像と結果はqa/。認証付きオンライン対戦の実施記録ではない。外観の選択はユーザー承認済みrevision5に基づく。

本番公開はコミット済みmainからdeploy-guardで型検査・本番テスト群・ビルド・競合確認を実行する。公開結果は別途記録。
