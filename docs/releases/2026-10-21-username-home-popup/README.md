# HOME上の初回ユーザー名設定

初回設定を独立ページからHOME上の共通「蒼銀のフレーム」ポップアップへ移動。HOMEの素材・描画準備と既存の入場演出が完了した後に開く。固定時間のタイマーは追加しない。

設定中はHOMEをinertにし、ルーターでも設定を飛ばせないようにする。保存後は同じHOMEを維持し、チュートリアル案内または進行中の対戦への復帰を続ける。ログアウトや画面破棄ではフォームと遅延表示を破棄する。公開名の仮名化・空欄初期値・入力検証は維持。

## ローカル確認

- 型検査、username-ui、private-usernames、logout-recoveryが成功。
- 実ブラウザで1280 / 390 / 320px幅を確認（APIはfixture）。既存の約3.8秒の入場演出終了後にポップアップが出現し、その時点でHOMEが存在、演出レイヤーが消えていることを確認。
- 空欄初期値、Escapeで閉じない、保存失敗後の再試行、プロフィールでの再変更、画面幅からのはみ出しなし、ブラウザ例外なしを確認。
- 単体試験でHOMEの再マウントなし、チュートリアル・対戦復帰の順序、ログアウト後の遅延表示と保存結果の破棄を確認。

本番反映はこのコミットのguarded releaseと別途の本番確認を参照。
