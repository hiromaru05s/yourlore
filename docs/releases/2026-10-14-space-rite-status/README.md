# 空間術式：承認済みの紫グレー表示を通常対戦へ接続

2026-10-14。ユーザーが承認した「紫＋グレーアウト、UIで理由表示」を採用。カードから伸びる演出は追加しない。

- ローカルプレイヤーのモンスター・通常魔法・スターター魔法を、相手の公開 `spaceLock` 永続魔法に応じて紫グレー表示。クエストと相手の非公開手札には適用しない。
- 手札上に召喚不可／魔法使用不可、原因カード画像・名前と残りターンを盤面に表示。カード詳細、ホバー、プレイ拒否のポップアップでも原因が読める。日本語・韓国語・英語対応。
- 複数の原因がある場合は全原因の残りターンを表示。最後の原因が消えると表示を除去する。捨て札選択中は手札の禁止表示を抑える。
- ルールとカードバランスは変更しない。GameViewとBaseControllerの通常対戦経路へ接続する。

## 確認

型チェック（client/server）、拡張した `tests/duel-ui.mjs` 成功。3言語、対象3種、クエスト除外、相手手札秘匿、複数源の一部除去／全除去、マナ不足との併存、手札上限処理、詳細表示、実controllerの拒否理由を確認。

実GameViewを使ったブラウザ固定状態で、PC 1280×720、スマホ 390×844、手札選択の理由、解除時の復色を確認。画像はこのローカル実装の記録であり、認証済みオンライン対戦の記録ではない。PCの原因パネルは相手HPと重ならない右上に配置。

ステージング公開結果は deployment.json / deploy.log に記録する。認証済みPvPは未検証。本番公開は対象外。
