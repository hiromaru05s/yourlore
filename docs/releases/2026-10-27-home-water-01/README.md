# HOME water 01

ユーザー採用の01「細かなさざ波」と、その後承認された水際の白線補正を本番へ反映する変更。

- `client/src/ui/homeWater.ts`: 採用済み背景の水部分だけを変位し、細かな反射を加える。水際の局所的な白い水平線を近傍色へ馴染ませる。
- `client/src/ui/homeAtmosphere.ts`: 既存の背景時計を共有。停止・非表示・低減モーション・破棄は既存の背景ライフサイクルに従う。時間uniformはインスタンスごとに保持。
- 既存の雲・蔦・鳥・キャラクター・メニューは最新mainを使用。未採用の02/03やプレビュー操作は製品コードに含めない。
- 元アートは変更しない。WebGL非対応時は従来の静止画フォールバック。

比較元: `docs/ui-concepts/2026-10-27-home-water-three/`。機能確認と見た目の承認は別に扱う。ユーザーは白線調整後の01を採用・本番公開指示済み。

公開前確認: 通常Viteの実HOME fixtureで製品用シェーダーを確認。公開は `scripts/deploy-guard.mjs production` による最新main・既存公開ソース照合、全typecheck、本番テストスイート、コミットスナップショットのbuildを通す。
