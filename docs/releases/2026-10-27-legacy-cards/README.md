| カード | 変更 |

| ブレード・ヘア | 自身が相手モンスターを破壊するたび相手に2ダメージ。付与された反撃・腐敗も対象。自分の魔法による破壊は対象外 |

| コロシアムの休憩場 | 自分のターン開始時に体力2回復。リフトのカル10枚以上なら自分のモンスター1体を選び全回復 |

| 夜城からの贈り物 | 購入・発動3 |
| アチューン・黒 | 購入・発動4。最大マナ-1、相手モンスター2体以上かつ自分0体で追加-1 |
| 銀月砲 | 購入・発動7 |
| 時空間操作 | 購入12・発動8 |
| 大地の祝福 | 購入・発動3。両陣営のモンスターの蓄積ダメージ全除去。両陣営の気合持ちへ気合カウンター1。プレイヤー回復なし |

| 見習い・初級・中級・上級呪術師 | 自分のターン開始時、自分の場の別名の呪術師の種類数だけ相手墓地に呪いを追加。各個体が発動。同名コピーは数えない。呪術師長も別名の種類には含む |
