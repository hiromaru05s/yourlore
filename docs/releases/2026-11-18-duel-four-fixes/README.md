# 対戦不具合修正（2026-11-18）

## 変更

- 手札から離れるカードを演出の開始時に除き、残りのカードを即座に配置し直す。最後の1枚も元の手札位置から飛ぶ。ドローは既存の表示タイミングを維持。
- マナ生成のブルーム入力を生成中の結晶・光の形状に限定。従来はHDR盤面全体を入力にしており、宝箱の使用時に相手リフトの銀色の枠まで増光した。画面全体の描画やリフトの部分更新だけでは差分が出ず、ブルームの有無の比較で再現。除外数の変化で合成していた、終了保証のない吸収クラスも除去。
- 気合カウンターの高さと位置を、他のパッシブと統一。
- 砲撃の複数対象を1弾ずつ表示。エンジンはモンスターへのダメージをプレイヤーに貫通させていなかったが、描画は最初の1弾しか見せず、別の対象のダメージも同時に表示していた。
- 螺子抜きなどの盤面破壊の対象選択は、通常のターン全体の探索から切り離して即座に確定。対象がない場合の取り消しは維持。
