# リフト②「双環の秘文」の通常経路への適用

2026-10-05、ユーザー指定「02で適用してステージングにあげて」に対応。
承認対象は `codex/rift-detail-six` / `2eceb799` の6案中② `membrane`。

カードに刻まれた架空文字が外20字・内16字の二重環へ開き、同じカード面と薄膜が収束する。矢印状の断片を8種類の手描き字形へ置き換え、黒紫の軌跡と補助粒を細くした。カード浮上→被覆→渦化→リフト転送→到着の順序、合計2800ms、転送経路は維持する。

`riftInkGlyphs.ts`、`riftInkMaterial.ts`、`riftInkRenderer.ts` に②のみを移植。6案選択UIと他5案は通常バンドルに含めない。共有GPU、最大8枚の顔テクスチャ、最後の利用者の解放、30秒後のGPU破棄、途中停止、裏向きカード、WebGL非対応時の代替経路は継続する。
