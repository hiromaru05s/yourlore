# シーカー修練書

チュートリアルへ任意の読み物タブを追加。12章40ページ。基本編完了時は修練書と「シングルで遊ぶ」を提示し、読了を対戦条件にしない。ページ位置は同じアカウント・ブラウザで保持する。

## 内容と参照元

- 最初の9枚、デッキ編集、ガチャ、日替わりスターター購入から編成する手順。
- 山札／デッキ構成／墓地／リフト、ターンと手札、マナ、購入／使用コスト、クイック・永続・クエスト、7体／14枠、雫・シールド・烙印・出血、戦闘、全パッシブ、5種族、卵と素材召喚、勝敗の例外。
- 最終章の総覧は439項目。共通ルールと処理順、全パッシブ・種族、生成カードを含む現行381カードの全文・補足・派生パッシブ・種族・基礎コストを検索できる。カード記述は現行カタログから直接生成し、二重に転記しない。
- 主なルール根拠: `client/src/shared/engine.ts`、`cards.ts`、`cardEffectText.ts`、`cardEffectNotes.ts`、`cardKeywordText.ts`、`protocol.ts`。ショップは `collection.ts`、`dailyStarterShop.ts` とサーバーの該当API。
- クイック魔法は購入時にリフトへ置いてから解決し、無効化されてもリフトに残る順序を明記。シールド維持などの個別例外を共通規則と併記。
- 基本編フッターの「ルール総覧」も同じ最終章を開く。旧課程の報酬案内は新総覧には収録しない。
