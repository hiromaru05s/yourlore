# 虚無空間の使徒 / 次元幽閉者 — ① 黒淵の噴出

2026-10-13、ユーザー指定「01でいい」「カードフレームの外側の余計なエフェクトを削除」「修正したらステージング適用」に対応。

- `VOID_APOSTLE` / `GM6_1` の通常召喚に①を採用。
- カードの透明部分からはみ出していた厚み用の長方形を削除。カード面の追加発光・濡れ模様・接地の発光も削除。本人のカード面、黒い穴、接地を示す控えめな影に絞った。
- 35〜135msで空中に黒い穴を開き、150msからカードが現れ、1110msで着地。穴は860msまでに閉じる。実盤面のリフト領域から飛ぶ動作はない。
- `client/src/ui/voidSummon/renderer.ts` を①プレビューと通常経路で共有。①以外の面・檻・膜片を通常バンドルに含めない。
- `focusSummon` で先行表示を隠し、`flyIntoSlot` の専用分岐から一度だけ再生。通常の `playMonster(...,'summon')` も同じ描画へ接続。接地音は1回。
- 元カードの公開DOM面をキャプチャし、元の枠・絵柄・現在値・言語を保持。相手の非公開手札の面は読まない。
- 同時再生のGPU共有、時刻0を描画してから表示、非表示・resize・abort・detach・skip・置換時の解放と復元を実装。低減モーションとWebGL失敗時はネイティブカードへ戻る。

- `tests/void-summon.mjs`: 両ID、同期非表示、時刻0、接地1回、共有GPU、中断、キャプチャ待ち中の中断、途中描画失敗、置換、低減モーション、対象外ID、全資源解放。
- `check.mjs`: 実GameViewで正規の通常・手札・生成召喚を両陣営で実行。3枚同時、停止・skip・resize・detach・abort・置換、390px、低減モーション、WebGLなしも確認。
- `qa/clean-frame.png` / `qa/portal.png`: 追加枠のない最終カードと、出現途中。
- `record.mjs`: 通常速度の両カードの実盤面経路を記録。

機能テスト・見た目の修正確認・公開ファイル一致は別の証拠として記録する。実GameViewフィクスチャは認証済みオンライン対戦の証拠ではない。

ローカル結果: 実ブラウザ64/64成功、page error 0。両ID × 両陣営 × 通常/手札/生成の12経路で、専用レイヤー1つ・先行する生カードなし・出現ピクセル・終了後復元を確認。3枚同時と低減モーション、390px、WebGL失敗時の復帰も成功。

検証の修正: 短い演出を外部からポーリングすると、多忙なホストで生成から消去までを見逃すことがあった。ページ内のMutationObserverで実際のレイヤー生成・描画・終了を記録する方法へ変更した。3枚同時のテストは実カード3枚を配置し、盤面レイアウト後に開始する。
