比較版 `docs/vfx-prototypes/2026-10-12-guts-four/` の04を本体へ移植した。プレビューの4案は参照として保持する。

## 接続

- 選定版の薄膜・くぼみ・反射線・両縁への収束を `ui/guts/material.ts` に保持。未採用の3案や開発画面を通常のビルドへ読み込まない。
- 共通エンジンが実際に気合を消費して致命傷を耐えた時だけ公開結果を生成する。通常／味方への攻撃では `attack.guts`、反撃／既存の反撃命令・落雷経路では `gutsSurvive` を使う。ゲームのHP・気合・貫通ルールは変更しない。
- 攻撃結果は接触コールバックから1回再生。反撃はその被弾イベントで再生。1 HPでHP減少が0でも、気合を消費したなら再生する。
- 従来の前後状態比較による文字バッジを削除。MIND_BURSTの全消費、カウンター獲得、無効化、卵の耐久では発動しない。
- 攻撃と同じ前景・カード射影・RAFを使い、通常の被弾コピーを抑制。カード面とキャンバスが一緒に動き、体力1と確定済みの気合数を表示する。
- 表面の寿命は命中から1600ms、低減モーションは280ms。スキップ、タブ非表示、リサイズ、カード切断、画面破棄で同じ終了処理を通す。描画終了時にはゲーム状態を巻き戻さない。
