# カード拡大画面のパッシブ説明への移動

効果欄上部のパッシブ名・アイコンを押すと、その拡大画面内の該当説明までスクロールし、説明にフォーカス枠を付ける。日本語・韓国語・英語に対応。PCは説明欄、狭い画面は拡大画面全体のスクロールで移動する。

- 名前とアイコンを一つの44px以上の高さのボタンにする。
- キーボードのEnter／Spaceにも対応。移動先からTabを押してもダイアログ内に留まり、Escapeで閉じる。
- 通常のカード文面・パッシブ説明・ゲーム処理は変更しない。
- 別セッションの対戦修正 `d4b9b284` を含める。
