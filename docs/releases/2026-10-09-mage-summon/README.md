# 炎術師・黒魔術師 ①「焔と影の立ち昇り」

2026-10-09 ユーザー選定: 「全部１で適用」「召喚が走ったらその最初のフレーム時点でアニメーション」「そこだけ対応したらステージング」。対象はファイアーマスター FIRE_MASTER、黒魔術師エルサ BLACK_ELSA、黒魔術師アリス BLACK_ALICE。

承認済みRevision 02の①を `ui/mageSummon` へ移し、比較画面も同じ材質・描画器を使用する。形状・色・厚み・中盤以降の動き・2.26秒の接地は維持。変更は開始経路と初期状態。時刻0で素材が形成済みの360ms相当を描き、800msまで単調に元の時計へ合流させる。

## 素のカードが先に出る問題への対応

- 対象3枚は通常のカード拡大と300ms転送を省き、選定①のランタイムに直結。
- 最初のawaitより先に元カードを非表示にする。読み込み・キャプチャ待ちの間も素のカードを出さない。
- 実際の公開済みカード面を非表示の複製から取得。炎／影を含む時刻0の画をオフスクリーンで完成させてからcanvasを追加する。
- 最初のRAFは描画済みの時刻0から継続する。準備待ち時間を再生時計に含めない。
- 素材が収束した最後の300msでネイティブ面へ引き渡す。終了・中断・非表示・リサイズ・DOM切断・早送りで表示と資源を復元。
- 3枚同時は共有GPUを使用し、最後の利用終了で破棄。runtimeでは選ばれていない案のメッシュを作成しない。
- 他のカードの召喚選定・通常経路は維持。比較用・QA用HTMLは公開ビルドの入口に含めない。
