# リフトカード・魔道列車・魔道銀行 — v67

## 変更

- 虚無空間の使徒: 他カードの効果でリフトへ送られると、新しいカル5枚を追加し、自身は墓地へ戻る。既存の召喚時・ターン開始時効果は維持。
- 虚空の攻城兵: 同条件で大砲兵を空き枠まで召喚。召喚上限・禁止に従い、自身はリフトに残る。既存の破壊時効果を維持。
- 次元幽閉者: 同条件で既存の召喚時効果（相手のリフトから最大8枚を自分のリフトへ移す）を発動。選択完了・キャンセル・対象なしのいずれでも、その後自身は墓地へ戻る。
- 選別者: 召喚時に新しいカル1枚をリフトに作る。既存の追加除外オーラは維持。他カードによるリフト送りで選ばれし4種から1体を決定論的PRNGで抽選・召喚し、自身を墓地へ戻す。
- 選別の掟: 現行クイック魔法 `QUICK_SORT` の購入コストを3→2。廃止された罠 `SORTER_LAW` は復活させない。
- 魔道列車: 購入・発動3。次の自分のターン開始直前に双方通算6ターンの時計を進める。ユーザー回答に従い、途中のドロー・回復・ダメージ・開始終了時の報酬は発生させない。有限期間は減り、満了した継続効果は終了する。卵などの遅延発動は時計だけが進み、実際の該当ターン開始で処理する。通常の次ターン開始処理は1回だけ。複数使用は加算、60ターン判定は維持。
- 魔道銀行: 購入5・発動4の継続魔法。発動時最大マナ-1（共通下限3）。現在と次の自分のターン終了まで、最大マナの増加1回につき追加+1。複数枚は各1回、銀行の追加分から銀行への再帰はしない。実際に増えた追加分は幽霊の増加イベントとして数え、上限30と増加禁止に従う。

他カードの明示的リフト送りと、自身のVoid能力／トークン消滅を別経路にした。対象選択は所有者を保持して待ち行列へ積み、相手ターン中・別効果の選択中・再接続でも処理先を変えない。三言語の効果文、参照カード、監査台帳を更新。

カード構成の変化でBOTの既存回帰テストが検出した、既知の除去を購入できるのに更新へマナを消費する問題を修正。Hard/Hellは、盤面を止める効果への対処カードを購入する基本方針を、少数の仮想ドローに基づいて放棄しない。
