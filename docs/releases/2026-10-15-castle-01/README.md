# 城 01「白亜の築城」通常召喚への採用

2026-10-15、ユーザーが繋ぎ目修正後の01を指定し、ステージング公開を依頼。

- 承認済み比較と通常経路は同じCastleRenderer・石材・塔・時間設計を共有。通常経路では01だけを生成する。
- `summonFromHand`、`ghostSummon`、`playMonster` → `playSlateSummon` から専用の01へ。汎用召喚との二重発火を避け、終了後も同じ盤面のDOMカードを保持する。
- カード画像のキャプチャ・WebGL画像への差し替えは行わない。石材と影のみを重ね、石材消失後2440msには空のGPU画像転写も停止。カードの合成レイヤーを維持する。
- 手札移動440ms、カード着地800ms、演出2600ms。着地音は一度だけ。生成時もカードを先に正しいスロットへ入れてから同じ移動を適用する。
- 同時発動でGPUを共有し、最後の利用者の終了時に解放。個別・全体中断、AbortSignal、非表示、リサイズ、画面離脱、低減モーション、描画失敗に対応。
