# 強制輪廻 — 墨脈の帰還

2026-10-14、最終実盤面プレビューの承認「これで適用してステージングあげて」に基づく通常対戦への適用。

- 選択案01を採用。墓地の実カード四隅を始点に、元の絵柄を保つ24×6メッシュが場のカード面へ復元する。元の縦横比を保持し、到着前に場表示へ連続的に混ぜる。
- 購入したQUICK_REBIRTHは既存のクイック魔法処理で消費。復活は手札を経由しない。
- 成功した召喚イベントだけに元のCardInstを記録。同じUIDを追跡し、一般召喚・モンスター固有召喚と重複しない。召喚音と召喚時資源演出は着地で開始。
- 接触後は次元術式と同じ `dimensionVoid/runtime.ts` を直接呼び出す。独自の紫膜や虚無バッジは作らない。
- 選択画面の見出し・説明を自然な文に分離。日本語・英語・韓国語を対応。
- 中断、リサイズ、非表示、期限超過時の処理を一本化。場のカードの表示を復帰し、Canvas、複製、RAF、GPU資源を解放。低減モーションは移動を省いて共通の短い虚無表現を使う。

## 検証

`tests/rebirth.mjs`: 24ケース。両陣営の実購入、手札非経由、コスト2/7/8、召喚禁止、既存虚無、無効なUID、元個体情報、召喚と虚無の二重発火防止。

`client/rebirth-runtime.html`: BaseControllerと通常UI/エンジンを通す開発用確認ページ。自動QAは両陣営、スキップ、リサイズ、低減モーション、コスト超過、召喚禁止を検証。手操作では実際の対象選択から復活後の虚無アイコンまで確認。

通常速度・実盤面の確認と機能検査は別扱い。最終プレビューで承認された移動メッシュを維持している。公開バージョンと配信ファイルの一致はデプロイ後に別途記録する。認証済みオンライン対戦を実施したという記録ではない。
