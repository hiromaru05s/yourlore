# 摩耗 — ③「微細なひび」の通常対戦への採用

選択: 2026-10-15「３でステージングあげて」。対象は改訂3の③。カードから伸びる線を出さず、摩耗カードの微浮上・最大1.075倍の拡大で発動元を示す。相手体力アイコンは最大1.12倍の反応と短い揺れ、輪郭の明暗、分岐する亀裂で被弾を示す。

従来は全イベント後の最終描画でカードを引くため、摩耗ダメージがドローより先に見えていた。今回、摩耗の直接ダメージを伴うdrawだけ、手札の表示を先に更新して既存の紙カードドローを再生。その後に摩耗発動と280msの被弾時刻を同期する。盤面や体力は先行描画しない。最後の手札描画では二重にドローしない。

即座に続く直接ダメージだけを発動イベントに対応づける。血鬼術の回復変換、無効化、反転は既存経路を維持。ダメージ値・ルール・通信プロトコルは変更していない。相手のドローは裏面を使う。低減モーションは拡大・揺れなし。中断、非表示、リサイズ、DOM撤去時に描画と個別スタイルを復元し、体力確定コールバックは一度だけ実行する。

実装: `client/src/ui/erosion/`、`anim.ts`、`controller.ts`、手札のみを更新する`GameView.presentDrawHand`。未選択案の描画はランタイムに含めない。

検証記録とステージング反映結果は完了後に追記する。
