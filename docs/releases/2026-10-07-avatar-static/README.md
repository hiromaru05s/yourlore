# アバターのアニメーション停止

自分・相手のシーカーを既存idleアトラスの先頭フレームに固定。待機、攻撃、被ダメージ、マナ増加、回復の再生処理と呼び出しを撤去し、CSSの呼吸・瞬き・のけぞり、およびアバター枠の回復エフェクトを削除した。動作用画像の先読みも終了。

アバターの絵・枠・配置、HP/マナなどの数値更新と数値側のフィードバック、カードの攻撃やマナ結晶の演出、対戦開始/勝敗の演出は維持。元画像は後の再制作に備えて保持する。

## 確認

- ローカルの実盤面で4.5秒の待機、両陣営への攻撃・被ダメージ・回復・マナ増加・再描画を連続実行。
- 304フレームの観測でアバターの描画内容の変化は0。再描画後も同じcanvasを維持。
- attack/hurt/mana/healアトラスのリクエストは0、ブラウザーエラーは0。
- desktop.png / mobile.png に1280px / 390pxの盤面を保存。動作確認の詳細は browser.json。
- ステージングへの配信検証は公開後の staging.json に記録する。認証APIを模擬したBOT表示確認と、実認証のオンライン対戦は区別する。
