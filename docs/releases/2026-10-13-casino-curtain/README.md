# カジノ召喚 — 緋幕の開宴 02

ユーザーは2026-10-13に修正版②を選択し、ステージングへの適用を指示。承認参照は `codex/casino-summon-four` の `9a7ab5b3`。布の材質、ひだの変形、金糸、照明、2.8秒の尺はこの修正版を継承する。

`CASINO` の手札召喚・効果召喚・直接のフィールド召喚を専用経路へ接続。カジノ以外のギャンブラー、建物、共通召喚は変更しない。比較用の未選択３案は通常バンドルに含めない。

カード本体は実カードDOMの複製を同じ射影・寸法で表示し、幕の描画だけを `.card-art` に置く。既存のSVG内窓が布と接触影をクリップし、名前・数値・現在のカウント表示は実カードのまま保持する。画像キャプチャの余白や縮小したカードを一度挟む処理はない。最初の閉じた幕を描き終えてからDOMへ追加し、時刻を開始する。終了時は元の実カードへ戻す。

- `tests/casino-summon.mjs`: 最初の描画、接触一回、ソースとアンカーの中断、同時発動時の共有GPU、置換、低減モーション、描画失敗時の復帰、資源解放。
- `tests/casino-summon-browser.mjs`: 1440/390px × 両陣営 × 手札・効果・直接召喚の12条件。最初の表示が時刻0の描画済みの幕、元カードと2px以内の寸法・位置、二重発火なし、スキップ・中断・リサイズ・低減モーション、ブラウザエラーなし。
- 型検査とリリース検査は、デプロイガードが最新mainのコミット済みスナップショットから再実行する。

検証用 `casino-runtime.html` はDEV専用で、通常のViteビルドエントリに含めない。ブラウザ結果はローカルの実盤面フィクスチャであり、認証済みオンライン対戦の実測とは区別する。配信後のWorker/sourceと配信ファイルの照合結果は `staging-verification.json` に保存する。
