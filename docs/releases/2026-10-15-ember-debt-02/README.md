# 火種の負債 — 02「巻く火種」

2026-10-15、ユーザー指定「０２でステージングあげて」による採用。
比較プレビュー Revision III の02を通常の FLAME 解決へ接続する。

- 相手に大きな火種、自分に55%の火種。カードから伸びる軌跡はない。
- 選定済み3Dボリューム由来の49フレームWebPをそのまま使用。未選択3案は配信しない。
- `elementalStart / elementalImpact / elementalEnd` をFLAMEに追加し、既存のダメージ・反射・回復・シールド処理を着火の時計に接続。
- 元のダメージ処理・カードの値・勝敗処理は変更しない。相手撃破時に自傷用の火を生成しない。
- 通常のカード提示と墓地移動は既存処理を使い、FLAMEには共通の魔法フレームを重ねない。
- 表示中断、非表示タブ、リサイズ、DOM除去、素材失敗時は全待機を解放し、キャンバスを除去する。

## 検証

`tests/ember-debt.mjs`: 採用前のエンジンと56ケースの最終状態・乱数状態・ゲームイベントを比較。演出だけのイベントとその追加で変化する反射リンク番号は正規化し、反射リンク先は別に検証。

`tests/ember-debt-browser.mjs`: 通常のBaseControllerとGameViewを使用するローカルの権威的リデューサーフィクスチャ。両陣営、致死、390px、低減モーション、スキップ、同時再生、中断、素材失敗。認証済みオンライン対戦の検証とは区別する。
