# 魔法03のプレイテンポ調整

ユーザー指定: 発動までと再生が遅いため約2倍速にし、ステージングへ反映。

- 承認済み03のシェーダー時間0–3200msを、実時間1600msで最後まで再生する。形・枠マスク・発光の順序・収束は維持。
- 通常/設置型/手札クイックと購入クイックの表示動作を2倍速化。自分側480→240ms、相手側640→320ms。モンスター、罠、クエストの表示動作には適用しない。
- 表示動作開始時にGPUモジュールの取得を開始。カードが中央に到着してから読み込みを開始していた直列待ちを短縮。マスク測定・GPU生成は配置後に行い、枠の位置合わせと既存の資源解放を維持する。
- フレーム演出終了後の配置・効果解決・クイック保持・Rift退出の順序は維持。
