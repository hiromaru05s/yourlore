# 運命の輪 01「逆刻の歯車」

ユーザー選択: 2026-10-15「０１でステージングあげて」。選択された試作01の歯車、材質、1480msの逆再生時計を通常対戦へ移植。既存の宝箱プレイとダイスを使い、同じダイスを保持して選択を待つ。

- エンジンは最初の対象ダイス直後・結果適用前の状態を保持。採用で保留した結果を一度だけ適用し、振り直しでは使用・支払いを重複させず再解決する。秘匿された継続状態は両クライアントから除去される。
- 表示された出目を保持 → 使用者だけが採用/振り直しを選択 → 運命の輪の盤面位置から接続 → 歯車が元のダイスを掴んでネイティブ軌跡を逆再生 → 再投擲 → 確定結果の演出。相手は待機表示のみ。
- 採用/振り直しの選択中にタブを隠したりリサイズしても勝手に選ばない。再接続時は公開済みの出目と選択を復元。低減モーション/GPU不可時は同じ選択・確定順を静的表示で維持。
- サーバーで保存済みの旧スナップショットは従来の継続分岐を維持。
