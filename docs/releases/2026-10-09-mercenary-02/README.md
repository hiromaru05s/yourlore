# 傭兵3種：02「煤火の帰還」適用

2026-10-09 ユーザー選定「02で適用して」。追加指定は、召喚開始時に生のカードを先に表示せず、最初のフレームからアニメーションを適用すること。ステージング公開まで許可済み。

対象: MERCENARY / MERC_LEADER / MERC_MASTER。選定元は codex/mercenary-six の dc1e6a1e、R3 の02（ゼロ始まり1）。他5案の選択UIは製品へ持ち込まない。

- 02の煤・焼け戻り・カード面の凹凸・下降・接地煙を維持。冒頭のみ、0msから煤の被覆が完成した状態に変更。
- 公開前の生カードrevealと汎用transferを経由せず、公開済みカードの取得前から同期的に元DOMを隠す。画面外で取得し、0msを描いたcanvasだけをマウントする。
- 手札／生成召喚は煤を乗せたまま350msで手札位置から盤面へ移動し、既存比較の時間変換で02を再生。直接召喚は同じ02を盤面上で再生。
- 通常のcontrollerのsummonイベント→ghostSummon、summonFromHand、playMonster→playSlateSummonに接続。旧の汎用召喚・砂煙を重ねない。接地音callbackは1回。
- GPUは同時召喚で共有。個別の顔テクスチャ解放、最後の利用者の資源解放、中断・スキップ・リサイズ・非表示・対象削除・再入を処理。低減モーションと描画失敗は元カードを復元する明示的な代替経路。

## 検証

- tests/mercenary-summon.mjs: 同期非表示、最初の描画時刻0、3カードの選択、接地1回、同時GPU共有、準備中断、再入、各中断経路、低減、取得／描画失敗、資源解放。
- tests/mercenary-summon-browser.mjs: 実GameViewで3カード×2陣営×直接／手札／生成の18経路。最初のcanvasに描画があり、生のghostが0、別召喚レイヤーが0であることを確認。初回描画と演出なしのカード画像の差も検出。
- 390px、スキップ・中断・リサイズ・低減、終了時の原本復元を確認。ローカルfixtureであり、認証済みオンライン対戦の証明ではない。
- 通常経路の変更範囲は傭兵3種のみ。共有作業フォルダの未コミット変更は取り込まない。
