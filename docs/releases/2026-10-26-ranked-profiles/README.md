## 動作

- 名前の補助ラベルとTOP100説明文を削除。名前はホバー／キーボードフォーカスで文字色と細い下線が変わり、プロフィールを開く。
- ランキングとフレンドは同じ `showProfileModal`、プロフィール概要ページも同じ `renderRankedProfile` を使用。
- 現在のランク／MMRと、完了済みランク戦の通算試合数・勝敗・勝率を表示。試合数と勝率の分母は引き分けを含む。試合ゼロ時の勝率は「—」。
- 完了時刻順の直近3ランク試合を表示。同じ開始デッキでも別の試合として3枠に並べる。アチューン1枚と自由枠8枚。カードは既存の詳細表示で確認できる。
- 過去の `ranked_recent_decks` は同構成を重複除去しているため、試合ごとの履歴には転用しない。カード使用回数からも開始デッキを推測しない。復元できない試合と未プレイの枠は「デッキの記録なし」。
- 購入率は、購入ログが保存されている完了済みランク試合のうち、そのカードを1回以上購入した試合の比率。同じ試合内の複数購入は分子で1回。サンプル試合数をプロフィールに明示。購入試合数、総購入数、カードIDの順で安定ソートし上位5件。
- ランキングの戦績右に購入率TOP5の丸アイコン。ホバー／フォーカスでカード名を小さく表示。記録不足・5種類未満の枠は空の丸表示。狭い画面では同じ行の2段目で戦績の右に配置。
- 既存の戦績非公開設定を維持。非公開プロフィールと、そのユーザーのランキング購入履歴を公開しない。

## 保存と移行

`server/migrations/0027_ranked_match_decks.sql` は追加テーブルと検索インデックスのみ。既存の結果確定処理で、確定した試合IDとキュー登録時の開始デッキを保存。主キー `(match_id,user_id)` と `INSERT OR IGNORE` で再試行は重複しない。未完了・準備未完了・ノーマル試合は保存対象外。既存データを埋め合わせたり変更したりしない。
