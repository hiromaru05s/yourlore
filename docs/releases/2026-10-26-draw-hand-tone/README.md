# ドロー中のカードから手札状態の表示を除外

ユーザー指定: 使用不可の灰色表示などは手札のみで発現させ、ドロー時には適用しない。完了後、本番公開。

ゴブリン集落などの使用不可カードをドローすると、枠だけ灰色が残る。盤面の状態表示がカードの子レイヤーへ分かれている一方、ドロー用コピーは枠のフィルターだけを引き継いでいた。

`paperDraw.ts` の飛行中のカードは、使用不可・使用可能・条件達成の状態を外した通常の印刷面を使用する。通常の枠フィルターは元の CSS 文脈で解決する。先に持っていた手札と着地済みカードのコピーは、絵柄・枠・数値のフィルターと透明度を保存し、手札状態を維持する。

カードの形状・動線・840ms の移動時間・着地・スリーブ・演出の光は変更しない。品質基準の発生源との結び付きと、カード表面から実カードまでの連続性を維持する。手札状態への切り替えは着地時に行う。

## 確認

- クライアント／サーバー型チェック、既存 `tests/solid-draw.mjs`: 成功。
- `tests/draw-hand-tone-browser.mjs`: Chrome の実盤面／実ドロー経路で成功。
- ゴブリン集落の条件未達、条件達成＋マナ不足、使用可能の各状態を PC／390px で確認。飛行中は通常色・条件の光なし、着地後は本来の手札表示。
- 先に持っていたカードの灰色と条件表示を維持。2枚の連続ドローでは、先に着地したカードから手札状態が適用される。
- 中断・リサイズ・スキップ・低減モーションで復帰と資源解放を確認。相手のドローは裏面のみ。
- [通常速度の連続再生](continuous.mp4)、[再生中の抜粋](playback-sheet.jpg)、[飛行中](flight.png)、[着地後](landed.png)、[機能検査結果](browser-report.json)。途中フレームでも枠と絵柄の色が揃い、着地後だけ灰色へ切り替わることを確認。

検証はローカルのゲーム状態 fixture。認証済みオンライン対戦やユーザーの見た目承認とは区別する。
