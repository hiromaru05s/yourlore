# チュートリアル：操作とポップアップの流れ

右上の説明を追いながら操作する構成を廃止。中央の短い案内を閉じて実際に操作し、盤面の演出が終わってから結果と次の操作を確認する。中央の案内中は入力と相手進行を止める。操作中は対象を強調し、ヒントから案内を読み直せる。対象選択中は盤面・選択ウィンドウを覆わない。

通常演出を初期設定にし、短縮設定も保持。正答後の重複確認は省くが、実習クリアは自動で飛ばさず「次の実習をプレイ」で進む。途中再開、回答判定、サーバーでの行動再生検証、報酬の冪等性は保持。練習盤面の切り替えを明記し、未計測の「15分以内」という説明は削除した。

実習一覧の「実習へ」「ゲームルールを確認する」を、面・縁・押し込み・フォーカスのあるボタンに変更。既存の章・進捗・報酬・復習導線は維持。

## 検証

- `tests/tutorial-academy-browser.mjs`: 36実習／66場面を実際のコントローラーとエンジンで通過。後半は行動入力をプログラムで与え、ポップアップ・回答・実習間遷移はUIから操作。
- マウスでの召喚ドラッグ、直接攻撃、敵モンスターの対象選択、アチューン、ターン終了、必須対象のキャンセル復帰を確認。
- 間違った操作・回答、途中再開、報酬再試行、再クリア時の二重付与防止、画面破棄を確認。
- 1280×720、1024×768、390×844、844×390と日本語・英語・韓国語でレイアウト確認。入力案内はマウス操作で統一。
- `tests/tutorial-academy.mjs`: 36実習／66場面のルール結果、サーバー再生、報酬の並行重複・ロールバック・アカウント分離を確認。
- 見た目：中央の見出し・操作・主ボタンを明確化。操作中の補助表示が相手の精神力に重ならない位置へ調整。初回召喚・攻撃は通常演出で確認。
- 初心者によるユーザーテストや所要時間の実測は行っていない。

ローカル結果は `qa/browser.json`。本番確認は `scripts/check-tutorial-production.mjs` で配信JS/CSSのSHA-256照合、隔離した一時QAアカウントによる実操作・実報酬・再読込を実施し、アカウントを削除する。OAuthログインそのものはこの確認の対象ではない。
