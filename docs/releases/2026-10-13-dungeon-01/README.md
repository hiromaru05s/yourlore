# 生きているダンジョン 01「坑口の目覚め」採用

ユーザー指定「０１でステージング適用して」により、比較4案の01を `DUNGEON` の通常召喚へ採用。

- 比較と通常対戦は `client/src/ui/dungeonSummon/renderer.ts` の同じ岩顎・石の牙・面変形を使用する。予兆、開口、噛み合わせ、岩肌への収束は承認案の3秒を維持。
- 手札と効果生成では先行する生カードを同期的に隠し、同じカード面を420msで盤面へ移動する。配置は実盤面の投影行列を使い、最終フレームをDOMカードへ一致させる。
- 汎用石板召喚を重ねず、接地音は岩の収束2040msで一度だけ発火。安定したカードIDで分岐し、他カードの召喚を変更しない。
- GPUを同時再生で共有し、初回表示前にコンパイル。元カードの公開面をキャプチャし、言語・数値・フレームを保持。中断・置換・リサイズ・画面非表示・スキップで描画と資源を破棄し、元の可視状態を復元。
- 低減モーション／WebGL失敗時はネイティブカードへ復帰。

## 検証

`tests/dungeon-summon.mjs` は時刻0の非表示／初回描画、接地1回、途中失敗、共有GPU、キャプチャ待機中の中断、置換、切断、非表示、resize、pagehide、低減モーション、事前abort、対象外ID、資源解放を検証。通常回帰スイートに追加。

`check.mjs` は `dungeon-runtime.html` から正規の `playMonster`／`summonFromHand`／`ghostSummon` を使う実盤面フィクスチャ。両陣営、同時3枚、通常終了、中断、skip、resize、detach、abort、置換、390px、低減モーション、WebGLなしを確認する。

見た目は採用済み01の造形と時間設計を維持したうえで、実盤面投影へ接続した結果を別途確認する。機能テスト合格と視覚確認は別の証拠。認証済みオンライン対戦はこのフィクスチャに含まない。

ローカル結果: 実ブラウザ39/39項目成功、page error 0。クライアント／サーバー型検査成功。ライフサイクル単体テストと既存石板召喚の回帰テスト成功。公開用ビルド成功（既存の500kB超チャンク警告あり）。

見た目の確認: `qa/runtime-hand.mp4` と連続フレームで、手札の同じ面から岩顎が開き、カード面へ沈んで戻ることを確認。PC両陣営と390pxの画像も保存。隣接カードを覆う全画面光や汎用エフェクトの重複なし。
