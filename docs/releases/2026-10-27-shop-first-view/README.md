# ショップの商品をファーストビュー内に収める

ユーザー指定: アクセサリーの「デッキの全カードに、動く質感を。スターターも、対戦中に購入したカードも、プレイ後まで同じフレームに。」と、スターターの「毎日00:00 KST更新・全ユーザー共通の5種類。各2枚まで、1枚100シャード。」を削除。両カテゴリの全商品と購入操作をスクロールなしで表示し、本番反映する。

## 実装

- 基準main `50898023`。`shopFrames.ts`、`shopStarters.ts` から指定の段落を全言語で削除。
- `client/src/styles/shopCatalog.css` で共通パネルの残り高さを使い、カードの完全な比率を保ったままサイズを調整。
- 広い画面は5列、狭い画面は5行の横並び商品、低い横長画面は画像と詳細を横に配置した5列。ページ送りや隠れた商品は追加しない。
- 日付・商品名・所持数・当日残数・数量・価格・購入/所持済み/残高不足表示は維持。購入確認とカード詳細の導線も維持。
