# 創造 — 01「薄膜の分生」採用

選定: 2026-10-14「０１でステージングにあげて」。ローカル比較 `/creation-four.html` の01を通常の創造・選択後の複製へ接続。

- 48×48の二面メッシュ、厚い縁、真珠質の反射、表面からの剥離、墓地への着地を移植。実盤面の距離に合わせてカメラの深度範囲を調整し、薄い面のちらつきを防止。
- 元の創造は同じ個体のままリフトへ。新規の創造と選択後の複製は、新しい個体として自分の墓地へ。複製元は相手デッキに残る。
- エンジンに公開済みの生成物だけを示す `creationBorn` イベントを追加。複製イベントは相手デッキの個体ID・順序を含まない。効果・条件・バランスは変更なし。
- コントローラーが元カードの除外を個体IDで一度だけ扱う。通常のドロー・回復と同時進行し、汎用魔法演出を重ねない。追加操作で早送り可能。
- 生成2180ms／複製2050ms。WebGL描画を準備してから時計を開始。低減モーション／描画非対応は240msの静かな着地。キャンセル・非表示・画面変更で一時DOMとGPU資源を解放。

## 検証

- `node tests/creation.mjs`: 両陣営、発動前8/9/10枚、ELF／CREATION複製、相異なるUID、元カード保持、ドロー・回復、非公開ID非送出、古い再選択の拒否。12ケース。
- `tests/creation-browser.mjs`: 通常の `BaseController.applyResult` と表示キューを使用。PC1280／スマホ390 × 両陣営 × 生成／複製、スキップ・resize・非表示・低減モーション。モーダル選択だけをfixtureで代用。
- `tests/creation-busy-browser.mjs`: 3体が並んだ盤面の両陣営・PC／スマホ4ケース。元カードと完成時の薄膜が最初のモンスターに重ならないことを確認。
- 同時に両側へ複製を再生し、canvasが2個から0個へ片付くことを確認。
- `qa/creation01.mp4`: 実際のコントローラーによる生成と複製の連続再生。見た目は機能検証とは別に確認。ユーザー選定01の曲面と表面ディテールを維持。
