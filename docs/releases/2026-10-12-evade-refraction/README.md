## 動作

- 回避ダイスに防御対象と攻撃者のUIDを添付。同名カードの複数配置と、後から付与された回避にも対応。ゲームの確率・ダメージ・攻撃回数の規則は変更しない。
- 対戦コントローラーが対応する回避ダイスを攻撃より先に1回だけ再生し、続けて700msの演出を待つ。成功では攻撃を無効化、失敗では軽い構えから通常攻撃へ続く。
- 世界樹の任意選択で処理が別バッチに分かれる場合、選択待ちの攻撃宣言を描画イベントから保留し、選択完了時に再発行する。選択前に攻撃が走ってから回避する順序を防ぐ。
- ダイス中に現在の公開カード面・現在の数値・付与能力アイコンを準備。描画の0msができるまで元カードを表示し、演出中のみ置換する。
- スキップ、中断、非表示、リサイズ、破棄、対象除去、同一対象の再発動で復元。低減モーションとGPU不成立では同じ時間の小さな明度変化を使う。並列実行時のGPUを共有し、最後の演出で解放する。
