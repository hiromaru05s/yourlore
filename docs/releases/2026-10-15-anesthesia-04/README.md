# 麻酔 04「硬直残響」通常経路への採用

2026-10-15。ユーザーが第3稿の04を選択し、ステージング反映を指示。

## 変更

- 通常の魔法プレイは既存の経路を維持。`GameView` が `immuneDamageTurn === g.turn` を持つ公開モンスター個体だけに04を表示する。
- プレビューから縦の電流・ずれた輪郭・収縮解除を採用。文字バッジはなし。カード名、コスト、攻撃、体力の領域は描画しない。
- 元カードと待機／攻撃の表示用カードにそれぞれ所有された描画面を付け、位置変化に追従する。揺れは加算アニメーションとし、攻撃・ドラッグ位置を上書きしない。
- 同一UIDの再描画は時計を保ち、途中参加の状態も復元。後から召喚した同名個体に引き継がない。
- 次ターンは420msで形を縮小して撤去。離場・画面非表示・低減モーション・破棄を処理する。古いターンの再生状態は保護を再有効化しない。
- エンジンのルール変更なし。ダメージ無効であり、行動不能や破壊耐性を追加しない。

## 検証

- `tests/anesthesia.mjs`: 両陣営×0/1/3/4体の8ケース。対象固定、追加個体、再描画、再接続、離場、期限、古い再生状態、破棄。
- `tests/anesthesia-runtime.mjs`: DOM上の所有・表示用コピーの重複排除、非表示／復帰、低減モーション、期限、再付与、離場、解放の10項目。表示担当との境界を差し替えた自動テストであり、見た目の証拠ではない。
- 既存のカード文言26シナリオ、v50の36スイート成功。型検査成功。
- `anesthesia-runtime.html` で実際の `BaseController.applyResult` と reducer を通して通常の麻酔プレイを実行。対象3体に04が付き、カード名・数値が見えることをアプリ内ブラウザで目視。console errorなし。
- 認証済みオンライン対戦の検証は未実施。ブラウザの追加操作は共有環境のタイムアウトで完了証拠を得られていない。対象・解除・再接続の自動テスト結果と区別する。
