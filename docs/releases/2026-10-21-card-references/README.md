# カードの生成元・本文リンク — 2026-10-21

カード詳細の関連表示は、効果文に登場するカードへの片方向の一覧だった。生成結果から生成元に辿れず、本文の固有名と詳細カードも離れていた。

## 変更

- 「このカードを生み出すカード」「このカードが生み出すカード」を明示。創造から無の境地、支配から城下町へ移動できる。固定の生成先・召喚先・展開先、卵の孵化先と、種族などで定義された生成候補を記録する。任意カードのコピーや墓地からの回収は、固有の生成元とは混同しない。
- その他の関連も逆方向に表示。カード画像の下に名前を併記し、元のカードへ戻る際はスクロール位置とフォーカスを復元する。
- 効果本文・ダイス結果・用語説明の固有カード名とシリーズ名を下線付きリンクにする。ホバー・フォーカスで単体カードと全文、またはシリーズのカード一覧を表示。クリックでカード詳細へ移動する。
- シリーズはゲーム側の判定に合わせる。ミミックの隠れ家はミミック系モンスターに含めず、黒魔女は黒魔法に含めない。吸血鬼系にはヴァンパイアの執事を含める。騎士1枚の条件と、装備職人が参照する名称系列も区別する。
- 三言語の名前・省略表記に対応。長いカード名を優先し、「総攻撃力」を「総攻撃」のカードへ誤リンクしない。
- プレビューは画面の空きスペースに配置し、リンク自体を覆わない。内部のカードまでポインターを移動できる。Escapeはまずプレビューを閉じ、ArrowDownで一覧へ移動できる。閉じる・スクロール・リサイズ・カード移動時はプレビューを片付ける。
- カード効果・数値・ゲームエンジンはこの変更で変更しない。
