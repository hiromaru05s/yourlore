# 雫 T2「月縁の雫」採用

2026-10-08、ユーザー指定のT2をゲーム本体へ接続。透明な内部・細い影側の縁・真珠色の明縁を持つ、承認済みの液体シェーダーを `ui/dew/glass.ts` に凍結した。

## 実装

- `gainDew` が正の増加に対して `statusGrant(resource:dew,before,after)` を発行。減少・ゼロ・再接続時の状態描画では獲得演出を起動しない。
- 通常魔法「潤う雨」は公開中のカード面を保持し、そこから既存の雫アイコンへ液体を移動。アイコン画像は変更しない。
- 世界樹の世話／心臓、エルフの隠れ里、世界樹、神官類、エルフ類、世界樹の番人などの増加は同じ経路を利用。発生元がある場合は公開UIDを渡し、ハイエルフの選択解決後も保持する。
- 複数の番人はそれぞれ1回の獲得として順番に発生元を示す。合計増加量・ルールは維持。
- カード面の短い濡れた反射→T2液体→既存アイコンへ収束。通常1450ms、1120msで表示数を更新。実ゲーム状態は同期Reducerが既に確定済み。
- 初回0→正数では到着時に既存アイコンを表示。追加は既存数値を維持してから更新。付与量が大きくても1点ごとに粒を増やさない。
- 低減モーション・背景タブ・WebGL不成立では最終表示へ移行。高速スキップ、resize、pagehide、destroy、同じ陣営への後続要求で資源を解放する。

## 検証と境界

- `tests/dew-grant.mjs`: 12ケース。両陣営・初回／追加・通常魔法・永続魔法・購入・複数番人・シールド連鎖・選択解決・減少の除外。
- `tests/dew-shield-server.mjs`: 両陣営の雫獲得を両ソケットへ送信し、before/afterと最終状態が一致。
- `tests/status-grant.mjs` 8ケース、`tests/dew-shield-v54.mjs` 32グループを維持。
- `tests/dew-grant-browser.mjs`: 実際のBaseController + GameViewへReducerの結果を渡す。潤う雨0→1／5→6、世界樹の心臓5→7、接触前後の数値、発生元、390px、低減、両側同時、中断、シェーダー失敗、破棄を検証。
- `qa/local-browser.json`、通常速度録画・代表フレームを保存。小さな白い盤面でT2の形と移動を確認した。ユーザー選定は試作T2への承認であり、実装後の美術判断と機能検査は別。
- 実盤面の屈折は公開カード画像と肖像Canvas、盤面色を使う局所的な近似。DOM全体を光学的に正確に屈折するものではない。
- 実行環境はローカル／ステージングのfixtureであり、認証済み2人対戦の目視検証とは区別する。
