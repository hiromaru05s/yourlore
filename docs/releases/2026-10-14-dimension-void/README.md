# 次元術式 — 承認された淡い紫の01を通常対戦へ接続

2026-10-14: ユーザーが淡色・透過版01の実カードプレイプレビューを承認し、適用とステージング公開を依頼。

- 対象カード全体に、760msの淡い紫の渦膜。最大不透明度66%。発動元から伸びる帯・粒子・環はない。
- 比較プレビュー01の渦・ノイズ・収束・色・透過率の計算をそのまま抽出した。02/03は採用しない。
- 共有エンジンの`voidAll`が新たに虚無を与えた公開UIDを、一つの`voidGrant`として出力。卵、元から虚無を持つカード、既に付与済みのカードを除外。空の対象では演出イベントを出さない。
- `BaseController`の通常イベント列でカードプレイの後に再生する。対象は両陣営同時。実際に表示されているカードの座標を用い、待機状態の立体カードにも追従する。
- 付与時は対象を退場させない。後の撃破では既存の虚無のルールと持ち主のリフト送りを使う。
- 新規のカード画像・枠・退場演出を追加しない。描画は共有の256×400テクスチャ1枚と一時キャンバス。終了・スキップ・非表示・リサイズ・対象切断で解放する。低減モーション／WebGL不可は短い静的な紫の膜。

## 検証

- `npm run typecheck`: client/server成功。
- `node tests/dimension-void.mjs`: 両方の発動側、空／混在／満場、卵／元から虚無／付与済みの除外、イベント順序、再付与なし、後の持ち主リフトへの退場を確認。
- `tests/dimension-void-browser.mjs`: 実`BaseController.applyResult`と共有エンジンを使った13条件。PC／390px、両陣営、両側7枠、卵のみ／全員虚無／空、スキップ・非表示・リサイズ・低減モーション、2組同時再生を確認。ブラウザエラー0、終了後の一時キャンバス0。
- `qa/play-through.mp4`: 通常カード提示から新規付与、カードが場に残るまでの連続録画。`qa/selected-live.png`はその途中フレーム。受け入れた淡い紫と絵柄の透けを維持した。

ブラウザ検証は実コントローラーのローカルフィクスチャであり、認証済みオンライン対戦の証明とは分ける。ステージングの公開証跡は公開後に追記する。
