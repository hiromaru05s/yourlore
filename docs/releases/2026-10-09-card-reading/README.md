# カード効果の文字・読みやすさ改善 — 2026-10-09

## 変更

- 効果本文はPC 18px、スマートフォン17px。パッシブ・共通ルール・種族条件・現在状態は16px、短い補助ラベルは14px以上。
- 本文と説明をUI用ゴシック体・行高1.75で統一。長い効果を縮小せず、段落と縦スクロールで表示。
- パッシブ名の強調時コントラストは3.97:1から7.58:1。通常は8.87:1。読む場所の発光アニメーションと内側の影を取り除き、枠で移動先を示す。
- 小画面では操作ボタンだけを固定し、長いカード名と200%の文字が説明を覆わないようにした。タイトル全文を保持。
- 表記ルールにサイズ・書体・行間・コントラスト・文字拡大時の検査基準を追加。
