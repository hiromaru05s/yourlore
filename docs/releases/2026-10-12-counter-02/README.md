# 反撃02「片刃の切り返し」の適用

2026-10-12 ユーザーが比較ページの02を選択し、ゲームへの適用とステージング公開を指示。
元の4案は `docs/vfx-prototypes/2026-10-12-counter-four/` に保存。

- カード面・片側の銀縁・捻りを一体で動かす。予備動作700ms、接触860ms、帰着1400ms。通常攻撃の180msの溜めを重ねない。
- UI専用の `counter` イベントに、実際の反撃元・対象・陣営・接触ダメージを記録。ダメージ、乱数、攻撃回数、行動済みのルールは変えない。
- 直前の実盤面カードを複写し、表示中の数値・絵・パッシブアイコンを維持。盤面と同じ射影で動かす。
- 致命傷後に反撃する場合、表示上の破壊だけ反撃後へ送る。ルール上の破壊時点と効果解決順は変えない。
- 最新mainの気合04と統合。反撃で気合が発動した場合も860msの接触に同期し、後続イベントで二重再生しない。
- 中断・スキップ・画面変更・タブ非表示・要素削除で一括解放。低減モーションでは移動をなくし、320msの面上の反射で示す。
- テクスチャ取得が失敗した場合はDOMの顔を維持し、同じ構え／接触時計で代替する。

## 検証

`tests/counter-animation.mjs`: 両陣営、生存／致命傷、騎兵、0反撃力、反撃なし、免疫、気合、決着、味方への反撃。02の承認済み座標と各時点で一致。700msの発射、860msの接触、低減、中断、大きいフレーム飛び、例外の後始末、接触音の一回性。

`tests/counter-animation-browser.mjs`: 実際のBaseControllerにreducer結果を渡し、通常速度で再生。両陣営、致命傷、反撃接触時の気合発動と重複抑制、390px、低減、スキップ、リサイズ、元要素削除、コントローラー破棄。11ケース、エラーなし、残骸なし。機能検証と視覚レビューは別扱い。これは公開盤面fixtureであり認証済みオンライン対戦の証明ではない。

ステージングの公開バージョンとアセット一致は、公開後の `staging-assets.json` に記録する。
