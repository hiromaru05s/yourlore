# カード詳細の能力見出し — 2026-10-09

「効果中の用語」は対象も目的も分からない見出しだったため廃止。既存の能力メタデータを使い、3言語で役割を明示する。

- このカードが持つ能力 / 이 카드가 가진 능력 / Abilities this card has
- この効果で付与する能力 / 이 효과로 부여하는 능력 / Abilities granted by this effect
- 効果文に出てくる能力 / 효과 설명에 나오는 능력 / Abilities mentioned in the effect text

古代の知識のオーラは付与、ナイトロードのオーラは保有、ダークエルフの回避は効果内の言及に分類する。説明リンクは維持し、効果そのものは変更しない。表記ルールにも曖昧な見出しを避ける基準を追加。

クライアント・サーバー型検査、全360枚×3言語の詳細UI検査1080件が成功。上記3枚の分類も回帰検査に追加。

ブラウザーでは320px・文字200%・字間拡大で古代の知識を3言語、ダークエルフとナイトロードを英語で確認。見出しの横はみ出しなし、古代の知識の説明リンクと復帰を確認。画像はローカルの実際の詳細コンポーネントを開いた確認画面（PC1280px）。実機端末・認証済みステージング対戦の検証ではない。
