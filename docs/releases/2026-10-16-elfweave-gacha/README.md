# Roots 02 — エルフの葉織

ユーザーが選択した02を、通常対戦のスリーブ・デッキ置き場＆墓地、およびガチャ報酬に追加。01/03は追加しない。

- `sleeve:gacha-elfweave` と `furniture:gacha-elfweave` は独立抽選・独立所持・独立装着。家具の獲得でデッキ置き場と墓地の両方を変更する。
- カテゴリー確率（スターター92.5%、外観7%、エフェクト0.5%）を維持。外観内は全項目等確率。既存サーバーの所有権検証、原子的な精算・履歴保存、重複時100 Shards還元を使う。
- 承認済みの白木の編み枝、青磁色の葉、葉脈、固定したスリーブ外枠をそのまま移植。葉の揺れと表面描画は通常の対戦・相手の手札・ドローに追従する。
- 家具は軽い動的レイヤーを既存の深度に合成し、毎フレームの盤面再描画を避ける。通常画質では02装着時の静止画面を2倍密度（6MP上限）に保ち、省電力設定は尊重する。
- 静止報酬画像も同一のCanvas/Three.js造形から生成。スリーブ768×1200、家具1024×1024。

## Validation scopes

- `tests/starter-collection.mjs`: 実WorkerルーターとSQLiteで抽選・重複還元・未所持拒否・別装着・保存を確認。
- `tests/gacha-cosmetics.mjs`: 全報酬の資産・ローカライズ・ID・異種装着の組み合わせ。
- `tests/elfweave-gacha-browser.mjs`: 実UI＋API fixtureでロック、確率・一覧、別々の獲得演出、装着保存を確認。
- `tests/elfweave-runtime-browser.mjs`: 実盤面で相手の空置き場と墓地、手札、ドロー、自分側、混合装着、縮小画面、reduced motion、繰り返し装着解除、描画頻度、破棄を確認。

ブラウザーのfixture確認と認証済みステージングAPI確認は区別して記録する。公開先はステージングのみ。
