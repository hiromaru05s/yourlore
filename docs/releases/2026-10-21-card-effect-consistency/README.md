# カード効果の正規語彙と階層 — 2026-10-21

## 変更

同じ出来事の条件名が揺れ、使用条件・効果・補足が平坦に並んでいた。全361枚の見出しを辞書に集約し、「使用条件」「効果」「補足」の大項目に分けた。モンスター効果は一つの「効果」大見出しの下に条件を配置し、キーワード能力のみのモンスターにも同じ構造を使う。

- 「場にいる間／場にある間」を「場にある間」に統一。「自分ターン」を「自分のターン」に統一。
- 召喚・破壊・攻撃・購入・使用・ドローの主体を見出しに明記。魔法の「使用時」と無効化されず「発動した時」は別見出しとし、血／黒魔法の対象制限と無効化された時の扱いを本文で明記。
- 雫の条件、同名カードの各ターン回数、カウンターの付与、破壊の用語を統一。共通用語とキーワード説明も合わせた。
- 赤竜は別のダメージ発生ではなく、各魔法ダメージを3増やすことを明記。ゴーレムキングの参照範囲は同じゾーンを表す「デッキ構成」に統一。
- ダイス表を該当条件の子要素に置く。キーワード所有・付与・参照と、説明への移動・復帰は保持。
- 正規カタログは未登録／欠落見出しを検査エラーにし、表記検査を本番公開時の必須スイートへ組み込む。旧セーブ由来の文面は表示を壊さず保存された内容を保持する。
- ゲームエンジン・数値・非テキストカード定義は変更なし。開始時点の現行カタログとの全件比較で確認。
