# ポップアップ 01「蒼銀のフレーム」

## 選択と範囲

2026-10-13、HOME上の4案比較後にユーザーが「０１でいい。」と選択。インゲームへの展開方針を説明した後、「ステージングに適用して」と指示。

`client/src/styles/popupSilver.css` で共通モーダルの紺の面、銀の二重線、見出しの帯、白銀の主要操作、余白を統一。HOME側の確認・名前変更・問い合わせ・招待・フレンドと、対戦中の確認・カード選択・効果確認・デッキ閲覧・操作説明を対象とする。NPC選択とキャラクター選択は専用構成を維持して共通の表面表現を適用する。

カード拡大UI、対戦盤面そのもの、勝敗演出、ガチャやショップの3Dプレビューなど専用演出はこの共通モーダル変更の対象外。

インゲームでは背景の暗転とぼかしを弱くし、カード一覧の横幅、選択マーク、固定操作欄、タイマーを確保。`modal.ts` は対戦用クラスをタイマーの表示状態から独立させる。カード拡大が上にある間は下のモーダルのフォーカス制御を止め、拡大UI内のTabとEscapeを維持する。効果解決・選択枚数・確定・キャンセルの処理は変更しない。

## 検証記録

- `tests/popup-silver-browser.mjs`: 実際のHOMEコンポーネントと盤面レンダラーを使うローカルfixture。PC・390px・320px・横向き、入力、キャンセル、カード複数選択、拡大内フォーカス、タイマー警告、デッキタブ、英韓の長文見出しを検証。
- `tests/target-choice-ui.mjs`: 選択・確定・キャンセル・置換・三言語の既存機能回帰。
- 配布前の型検査・production suite・buildは `scripts/deploy-guard.mjs staging` に従う。

ローカルfixtureとデプロイ後のfrontend確認は、実アカウント同士の認証済みオンライン対戦の証明ではない。ステージングの公開バージョンと配信確認は検証後に追記する。
