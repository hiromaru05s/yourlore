# 黒魔法：リバース — 02 黒漆の奔流

2026-10-14、ユーザーが第5稿②を選択し、通常対戦への適用とステージング公開を指定。

キャラクターの `.pt-ring` に薄黒い刻印を重ね、中心から濡れた黒い流体が弧を描いて転送先へ打撃する。すでに再生済みの到来攻撃は作らない。すべての有効な BLACK_REVERSE の実カードが同期して最大8.5%拡大・7px浮上する。余分な説明文やダメージ数字は表示しない。

- 採用元: `client/src/dev/reverse-four` 第5稿02（元の比較は制作ワークスペースに保持）。材質・流体・刻印・カーブ・時間は維持。出荷用レンダラーは02だけを割り当てる。
- ルールは変更せず、`dealDamage` の既存の転送分岐で `reverseDamage` イベントを追加。元のプレイヤー、転送先、公開カードUID、結果ダメージとの対応IDを持つ。
- Controllerは着弾1580msで対応する既存HPを一度だけ更新する。直後の追加効果やダイスがHP表示を遅らせない。Void Shot/Crystalが転送結果を先に表示する経路も除外した。
- シールド、血鬼術、インフィニティなど転送後の優先順位を維持。複数枚あっても転送は1回で、カードの浮上はすべて同期。
- 終了2700ms。低減モーションは移動なしの刻印/接点へ短縮。スキップ・タブ非表示・リサイズ・要素除去・画面終了でキャンセル、ソースのstyleを復元、最後の発動終了でGPU資源を解放。WebGL不可時は静的な刻印へフォールバック。

検証: `tests/reverse-pitch.mjs`（23ケース）、`tests/reverse-pitch-browser.mjs`（実Controllerの攻撃/魔法/自傷、両向き・カード所有者・390px、同時発動/低減/キャンセル/フォールバック）。追加の実Controller検証で虚空射撃・水晶魔術・ノーペインノーゲインも通過。型チェック成功。機能検証と見た目の承認は区別し、見た目はユーザー選択済み02を基準とする。認証済みオンライン対戦の実施は別証跡がない限り主張しない。

採用元と出荷用レンダラーは、両方向×5時刻の10フレームで全ピクセル一致を確認（`visual-parity.json`）。

公開結果は `deployment.json`、`staging-assets.json` に保存する。
