# ゴーレム01「岩殻の解放」採用

2026-10-09。ユーザー選択: 01。追加指定: 召喚が始まった瞬間から石の皮を被り、生のカードを先に見せない。7種共通でステージングへ反映する依頼。

原案は `codex/golem-summon-six` の `6bee1147`。動き・石肌・割れ方・接地・終わりの01は保持。変更は初期の被覆状態と実経路への接続。

- 01の被覆量を最初から100%にし、開き始める前のカード面を描画しない。
- `focusSummon` の通常の生カード拡大をゴーレムでは通さない。手札・生成召喚は最初から被覆したまま盤面へ移動。
- `playGolem` は同期的にDOMの表面を隠し、画像の非同期キャプチャ前に石殻を描く。画像読み込み中にも裸の面は出さない。
- `playMonster` の直接召喚にも同じ01を接続。通常の石板召喚・種族召喚とは排他的に選択。
- カード実画像の切り抜き範囲は試作と一致。ライブの枠・数値を保持。
- 中断、スキップ、非表示、リサイズ、切断、画面遷移、低減モーションではnativeカードを復元、GPU資源を破棄。
- 比較用の他5案はランタイムで生成しない。通常対戦への対象は `GOLEM1 / GOLEM2 / GOLEM3 / M10 / NGA3 / NWL3 / MANA_GIANT` のみ。

検証: `tests/golem-shell.mjs`（初回描画がキャプチャ完了より先、各7ID、着地callback一回、3同時、中断と資源解放）、`tests/golem-shell-browser.mjs`（実GameView、7種×2側×3経路、初回の石画像、生DOM非表示、低減モーション、スマホ幅）。画像と詳細結果は `qa/`。ブラウザ途中フレームには制御時計を使用。見た目の選択は01に対する今回のユーザー指示に基づく。

オンライン認証付き対戦の検証とは区別する。配信結果はデプロイ後の記録を参照。
