# カース 01 — 髑髏の五芒

ユーザー選定: 01、墓地と同じ X/Y に重なる髑髏、不透明度45%。今回の修正はプレイ直後のカード表示。元のカードUIを高解像度アートのまま動かし、650〜1220msは位置・大きさ・色を維持する。カード面の再キャプチャ／3D照明によるフレーム欠け・白飛びをなくす。

- `ui/curse/nativeCard.ts`: プレビュー／通常再生で共有するネイティブカード配置。
- `ui/curse/renderer.ts`: 承認済みの髑髏と5枚生成。実盤面はDPR最大2、カード面は別のDOMで保持。
- `curseGenerated`: 効果解決時だけ発行する公開枚数イベント。無効化時は生成演出を出さず、ルーン再発動は各5枚を描く。
- `controller.ts → anim.curseSpell → curse/runtime.ts`: 専用演出がプレイから墓地到着まで所有し、汎用魔法フレームを重ねない。
- スキップ／画面非表示／リサイズ／中断／GPU失敗で表示とリソースを解放。ゲーム状態は変更しない。

検証: `node tests/curse.mjs`、クライアント型チェック。テストは両陣営、無効化、ルーン再発動、5枚の着地時刻、カード保持、DPR2、キャンセルと資源解放を含む。見た目の確認とステージング反映結果は実施後のQA記録を参照。
