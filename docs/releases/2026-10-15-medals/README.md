- 217種類。アイアンを除く7ティア、累計ログイン30/100/300日、23シリーズの使用10/100/500/2000回・勝利10/50/100/300回、累計勝利、試合内容の勲章。
- 罠は対象外。対象カードは `client/src/shared/medals.ts` の明示リスト。プロフィールからシリーズの対象カードを確認できる。
- 使用回数は実際にカードを使った回数。シリーズ勝利は、そのシリーズの異なるカードを2種類以上使用して勝利した試合。ノーマル・ランクの対人戦を集計し、クライアント申告のBOT結果は含めない。
- パーフェクトは一度もHPが減らず勝利。回復して元に戻っても達成扱いにしない。スピードは画面上の通算ターン7以内。特殊勝利は選ばれし領域・始祖6種の実処理で判定。
- 試合内容の勝利勲章は降参・切断勝ちを除外。サイコロの振り直しは採用された結果だけを記録。最大マナは盤面効果・ペナルティ反映後の値。
- 既存の対戦記録・ログイン日・最高MMRから復元可能な進捗を反映。過去に記録していなかった試合内容は推測して付与しない。獲得済みは恒久保存。
- プロフィールの「保有中」「進行中」は独立タブ。装着は1つ、解除可能。所有チェックはサーバー側。対戦開始時に双方の装着を固定し、再接続でも保持。変更は次の対戦から。
- 文字のみの控えめな銘板。アイコン・バッジ画像・発光なし。対戦開始と対戦中に双方を表示し、ユーザー名より小さくする。短い横画面では名前と勲章をマナ枠の左へ配置。
