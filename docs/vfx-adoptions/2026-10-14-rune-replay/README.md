# ルーン学問・上級 — ③「翻りの再詠」採用

2026-10-14。ユーザー指定「３で適用して。ステージングにあげて」に基づく通常発動経路への統合。

## 挙動

- エンジンが出した `playSpell → 初回結果 → RUNE3 enchantActivate → 再処理結果` の順序に接続する。ルーン学問を設置しているだけでは演出を推測しない。
- 発動元は7.5%拡大・最大7px浮上。元の盤面投影を維持する。
- 公開済みの魔法カードを保持し、表→裏→同じ表へ一度だけ翻す。980msで通常の魔法発動フレームをもう一度再生し、その後に再処理の結果を表示する。
- ルーン学問から線・流体・物体を伸ばさない。複数枚のルーン学問は同時に浮上するが、魔法カードの再プレイは1回。
- 既存の炎・創世・禁術などの結果演出と退場経路を維持。専用演出が元のカード面を消費した場合は、公開済みのカードを通常の処理中カード位置で再提示する。
- ゲームルール、マナ、手札・墓地の枚数は変更しない。対象選択や勝敗でエンジンが再発動を出さない場合も追加演出を行わない。
- 低減モーションでは翻り・浮上を省く。中断・早送り・サイズ変更・非表示・切断で一時表示を破棄し、発動元のスタイルを復元する。

## 実装

`ui/runeReplay/plan.ts` は元の公開魔法との対応と重複抑制を担当。`runtime.ts` は選定されたカード運動と発動元の共通時計を担当する。通常の `game/controller.ts` と `ui/anim.ts` から呼び、専用プレビューへの依存は持たない。

参照した承認済み比較: `client/src/dev/rune-replay-three/`（共有作業フォルダーのローカル試作）。選定方向の前後移動14px・浮上30px・一回転・小さな押し戻しを維持し、実カードサイズに比例させる。実カードのDOMを使うため、新しいGPUコンテキストは確保しない。
