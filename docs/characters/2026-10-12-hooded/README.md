| 行 | 動作 | 再生後 |
|---|---|---|
| 0 | IDLE | ループ |
| 1 | マナ増加 | IDLE |
| 2 | 体力回復 | IDLE |
| 3 | 通常被弾・烙印付与 | IDLE |
| 4 | 強い被弾 | IDLE |

ダメージ10の条件は原依頼で重なるため、10以上を強い被弾、1〜9を通常被弾に割り当てた。0ダメージでは反応しない。烙印がダメージと同じ処理で付く場合は被弾を重複再生しない。

## 位置とつながり

生成原本はコマごとに足元がずれるため、画素を描き直さず、切り出し・一定倍率の最近傍縮小・白い128pxセルへの配置で登録した。足元の基準はx64／y110。非白画素の最下部は全コマでy110±1。キャラクターごとの倍率は固定し、個別のポーズを無理に拡大縮小していない。

IDLEの先頭・末尾、全動作の先頭、敗北以外の末尾は**同じ待機画像の画素**を使う。8コマの各再生列にはこの共通端点を含む。男の敗北原本の最終コマには立ち上がりがあったため、直前の膝つきコマを保持する。全画像が別ポーズという意味ではない。

通常動作は8コマを可変間隔で再生する。割り込み時は元のポーズ列を最大160msで待機端点へつなぎ、新しい動作へ移る。画像を半透明で重ねて二重の輪郭にする処理はない。実盤面は不規則な枠の内側に90%の安全域を設け、重い被弾と膝つきのマント先端も収める。

## 適用範囲

- 旧 `SEEKER_BLUE` / `SEEKER_RED` の保存IDは互換性のため維持し、男／女の新画像へ対応させる。既存ユーザーの選択も引き継ぐ。
- プロフィール概要のアバターと、設定タブの「キャラクター」から選択。各動作を試してから保存できる。製品では従来の `/api/social/me` を利用する。
- 対戦のマナ増加、回復、実ダメージ、烙印増加、勝敗へ接続。両陣営の再生時計は独立。再描画しても同じcanvasを再利用する。
- 勝敗動作を表示してから結果ダイアログを出す。再接続などアニメーションなしの終了スナップショットは最終姿勢を表示する。
- 低減モーション、タブ非表示、早送りで待機／敗北最終姿勢へ収束。画面破棄時に再生・監視を解放する。対戦の早送り状態はプロフィールのプレビューには持ち越さない。
- 対戦前表示・メニューアイコンも新しい絵へ統一。旧男女の配信用原画・旧アトラス・旧HOME人物背景を削除し、HOME／ログイン／ロビーは人物のいない既存図書館背景へ変更。原画資料は旧仕様の履歴として残す。
