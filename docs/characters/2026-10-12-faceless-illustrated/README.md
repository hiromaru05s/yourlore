# フードのシーカー — イラスト調・胸上まで

2026-10-12の修正指示「もうちょっとだけ胸の上部分くらいまでシルエット」「リアルすぎる」を適用した第2稿。

[最新版プレビュー](http://127.0.0.1:5194/hooded-seekers.html)。「キャラクター」「実盤面」「プロフィール設定」で確認できる。

## 修正内容

- フードのアップから、両肩と胸上の布が見える構図へ引いた。フードの顔は暗がりに隠したまま。白背景、性別の区別なし、1体。
- 前稿の写実的な布の繊維・細密な反射を除き、細い輪郭線と大きな陰影の色面によるイラスト調へ描き直した。
- 書面の一般的な画風指定だけでなく、実際の `client/public/art/cards/MERCH1.webp` と `ELF.webp` を画像生成の画風参照に使った。キャラクターや背景を複製せず、衣服の描線・明暗の整理を参照した。
- 被弾画も同じ画風・構図で再制作。通常は静止、ダメージ時に1コマを220ms表示して通常画へ戻す。プロフィールの設定・保存は従来どおり1体。

## 画像と再現

制作は built-in image_gen の画像編集。動画生成は使用していない。

- 原本: [通常](source/portrait.png) / [被弾](source/hit.png)
- [生成プロンプト全文](prompts.md)
- 配信用: `client/public/art/seekers/faceless-v2/portrait.webp`、`hit.webp`、`poses.webp`
- 512×512の2枚。2コマアトラスは1024×512、88,734 bytes。通常画44,960 bytes、被弾画42,024 bytes。
- `node scripts/build-hooded-seekers.mjs` で同じ倍率・同じ画角のまま書き出す。[ハッシュ](asset-hashes.json)。
- 前稿の配信用 `faceless-v1` は削除し、新URLで参照。古いブラウザーキャッシュが残っても、新稿の画像を取得する。

## 被弾時だけ枠ごと揺らす採用版

追加指示「攻撃された時だけ、キャラクターの枠ごと揺れつつ、被弾フレームを使う」を適用。

- 通常はIDLEを静止表示。正のダメージ時だけ被弾1コマと枠の短い揺れを220ms再生。マナ・回復・烙印付与・勝敗ではキャラクターを動かさない。
- 枠の `.pt-ring` と画像を一緒に動かす。約3〜6pxの振幅を減衰させ、最後に通常の位置・通常画へ戻す。既存の配置用transformを維持。
- カウンター再描画では枠のDOMを引き継ぎ、揺れの途中切れを防ぐ。連続被弾は1回分を再開始し、両側の同時被弾は独立。
- スキップ、非表示、低減モーション、画面破棄で揺れ・タイマーを解除。通常時の描画ループはなし。
- 最新mainのNPC専用肖像・カウンター・その他の演出を保持。旧男女アバターのIDは新しい1体へ表示を統一し、旧画像の配信用ファイルは削除。

[通常速度の盤面再生](qa/frame-hit-playback.webm) / [PC](qa/board-desktop.png) / [スマホ](qa/board-mobile.png)。実寸では揺れを短く抑えて、カードや体力表示を隠さず被弾を示す設計。描画位置の検証、同時被弾、再描画、連打、静止への復帰を含むブラウザー20項目が成功。絵柄をこの追加対応で再生成していない。

ステージング反映は `scripts/deploy-guard.mjs staging` で行い、結果は配信バージョンと実配信アセットのハッシュで確認する。本番は対象外。保存テストはフィクスチャアカウントであり、実アカウント同士のオンライン対戦の証明ではない。
