# 顔を隠したシーカー

> 履歴: ユーザーより「リアルすぎる」「胸の上部分くらいまで」と修正指示。現行は [イラスト調・胸上までの構図](../2026-10-12-faceless-illustrated/README.md)。以下は不採用となった前稿の記録。

2026-10-12の追加ユーザー指示を適用。性別の区別のない1体に統一し、顔まわりの静止画をアバター枠へ配置。被弾時だけ1枚の反応画を短く表示する。

## 確認

[プレビュー](http://127.0.0.1:5194/hooded-seekers.html) の「被弾を確認」「実盤面」「プロフィール設定」で確認できる。開発サーバーは `npm --workspace client run dev -- --host 127.0.0.1 --port 5194 --strictPort`。

## アート

- 画像は built-in image_gen による新規制作と編集。動画生成は使用しない。
- 世界観は [world-bible](../../world-bible.md)、画材・質感は [card-art-direction](../../card-art-direction.md) に基づく。暗い紺の布、筆の質感、細い古金の縁。顔は暗がりに完全に隠し、性別・個人設定・小道具を付けない。
- [通常原本](source/portrait.png) / [被弾原本](source/hit.png) / [生成プロンプト全文](prompts.md)。被弾画は通常画を参照編集し、襟と留め具の位置をほぼ維持した小さな後退姿勢。
- 実行用: `client/public/art/seekers/faceless-v1/portrait.webp`、`hit.webp`、`poses.webp`。512pxの正方形2枚、実行時のアトラスは1024×512、約112 KiB。両コマ同じ倍率・同じ範囲で縮小する。
- 白背景。盤面の既存枠マスク内にフードと顔を大きく置き、肩は下端で自然に切れる。全身を縮小して収める構図は使わない。
- `node scripts/build-hooded-seekers.mjs` で原本から書き出し。[アセットハッシュ](asset-hashes.json)。

## 動作と設定

通常画 → 被弾画1枚を220ms → 同じ通常画。待機ループ、マナ、回復、烙印単独、勝利、敗北のキャラクター動作はない。正の実ダメージは大小共通、0ダメージは静止。連続被弾は復帰タイマーを更新し、再生待ちのキューを作らない。

常時のrequestAnimationFrameは使わない。描画は初回・被弾・復帰のみ。非表示・低減モーション・早送り時は通常画へ戻す。破棄時はタイマーと監視を解放する。対戦の早送りがプロフィールのプレビューを止めないよう、対戦プレイヤーだけへ適用する。

プロフィール概要と設定タブから1体を選択し、通常／被弾を確認して保存する。保存IDは `SEEKER_HOODED`。既存 `SEEKER_RED` / `SEEKER_BLUE` / 未設定は同じ新しい絵として表示し、男女選択は提供しない。サーバー既存の `/api/social/me` がID文字列を保存するためスキーマ変更は不要。旧全身スプライトは配信用アセットから削除した。

- [状態遷移とアセット](qa/asset-motion-tests.json): 1コマの保持時間、復帰、連続被弾、ダメージ境界、独立時計、素材寸法。
- [ブラウザー](qa/browser-tests.json): 静止・被弾・マナ・回復・烙印・勝敗、両側、再描画、低減モーション、早送り、破棄、390px、プロフィールの1体選択・保存・再読込・キャンセル・エラー再試行・320px。
- [実メニュー](qa/menu-tests.json): HOME、プロフィールAPI保存、ヘッダー反映、キャンセルと破棄、旧アセットリクエストの排除。
- クライアントTypeScript・Viteビルド、デザインガード。

機能検証と見た目の判断は別。通常画・被弾画の輪郭の関係と、PC／スマホ実盤面の顔の大きさを目視確認した。見た目の最終承認はユーザー確認待ち。

ローカル実装のみ。プロフィールのブラウザーテストはフィクスチャAPIで、実アカウント保存と認証済みオンライン対戦の証明ではない。ステージング／本番は未反映。
