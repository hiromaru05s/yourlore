# BOT NPC roster — 2026-10-07

ユーザー依頼に基づき、既存の4難易度チャレンジカードを、名前と顔を主役にしたNPC選択へ変更。既存の赤・青のシーカーの白／紺／赤／青と細い銀装飾を参照し、4人の新しい肖像を制作した。名前は仮名。既存プレイヤー2人の外見・プロフィール選択肢は維持する。

`client/src/shared/botNpcs.ts` にNPC・日英韓の名前／肩書き／戦術・8枚のデッキ3種類・購入方針を集約。固定アチューンはエンジンが追加する。初回は3択から均等に選び、同じページセッションの次回対戦／再戦では、そのNPCが直前に使ったデッキを除いた2択から選ぶ。再読み込み時は履歴をリセットする。デッキ構成とAIの購入方針を同時に渡し、NPC名はデッキに依存しない。

選択画面・開始演出・対戦アバターを同じ肖像へ接続。NPCは静止画の肖像であり、新しい表情アニメーションは制作していない。開始演出の動き・時間配分を維持し、使用する画像と正方形画像のトリミングを対応させた。
