## 1. 体験の中心

> 父の記録を求めて入館した主人公が、記録を扱う仕事と人々の暮らしを知り、八人に挑む。父との再会を経て、自分と、今ここに生きる人々の未来を選び始める。

物語は選抜試験の日から始める。ユンゲルの発明、魔導王国の滅亡、水晶の漂着を年代順に説明してからゲームへ入る構成にはしない。

一章の基本は「いま困っていること → 人物との会話・調査 → 必要な対戦や実習 → 小さな解決と新しい疑問」。毎章すべての工程を強制せず、対戦のない章、会話の短い章も設ける。資料を読んだ量を進行条件にしない。

プレイヤーが現在選択している章・ルートの次の目的を表示する。七人のルートは途中でも切り替えられ、進行は個別に保持する。収集済みの記録、任意の人物編、再戦は別の入口から読める。主人公が知っている重大な事実を、嘘の独白によってプレイヤーから隠さない。

## 2. プレイヤーに渡す問いの順番

| 段階 | この時点で分かること | 先を知りたくなる問い |
|---|---|---|
| 序章 | 主人公は父に関する記録を探している。ペンダントと家族との別れの断片がある | なぜ本人の持ち物なのに、登録されていないルーンがあるのか |
| 入館・実習 | 記録は選別され、公開には段階がある。主人公には帰りを待つ養育者がいる | 図書館が残すものと、隠すものは誰が決めているのか |
| 封じられた記録 | 父はユンゲル。主人公は漂着者で、レヴナントに育てられた。父を救う目的と組織の目的が食い違う | 自分の父が、なぜ誰かの故郷を滅ぼした人物として語られるのか |
| マスターへの挑戦 | 八人は二百年近く在任し、公共設備と記録管理を支えている。彼らも一致していない | 守っているのは人々の生活か、自分たちの権限か |
| 中盤のレヴナント接触 | 組織は主人公の養育者でもあり、赤子のユンゲルを殺す計画を持つ | 家族を救いたい自分と、彼らの違いはどこにあるのか |
| グランドマスター戦後 | 父の記録が主人公へ応答する | 過去を取り戻すために生きてきた自分は、この先どう生きるのか |
| 八人の起源 | 戦争孤児だった八人、崩壊の日の選抜、精霊の犠牲、原本との接続が一つにつながる | 八人が手放せなかったものを、どう変えればよいのか |
| 続編 | 魔導王国の新装置、財政悪化、渡航、八人との交渉の詳細を照合する | 故郷を救う願いと、今の王国に生きる人々をどう両立させるのか |

レヴナントの存在まで終盤に隠すと、主人公の離反が後付けに見える。前半から手紙や養育者の記憶で存在を描く。全容を伏せるのは、精霊の水晶化と八人の成立をつなぐ因果である。

## 3. 章構成

| 章 | 現在の出来事と物語の進展 | プレイする内容 | 完了・解放 |
|---|---|---|---|
| 序章「入館希望者」 | 試験の朝。門前でペンダントが青く反応する。父の「名を明かすな」という短い記憶。ゼノに受験目的を尋ねられ、「探している記録がある」と答える | 名前・導入、カードを選ぶ最小限の操作実習 | 第1章。序章終了までに、探している相手が父であることをプレイヤーへ示す |
| 第1章「最初の接続」 | 修練生として安全な起動・解除を学ぶ。勝敗より先に、なぜ対戦区域が必要かを体験する | 短い誘導対戦でマナ、購入、使用、墓地、精神力を学ぶ。ルミとの認定戦は第2章へ配置 | 基礎実習修了。ノーマル・ランクの既存アクセスは変更せず、ランクへの誘導課題は置かない |
| 第2章「一枚になるまで」 | 登録室で観測資料の仕分けを手伝う。断片をそのまま再現すると、必要な部分が欠けることを知る | 原記録と登録カードを比べる短い実習。スターターを組み、ルミと試し、1勝する | スターター・共通書庫・生成カードの違いを知る。登録室の人物との関係が始まる |
| 第3章「知らない相手」 | ゼノから、同じ教官ばかりでは記録の組み合わせが偏ると勧められる。主人公は他のシーカーとも顔見知りになる | 原則ノーマル対戦を2試合完了。勝敗不問。今回の指定ではNPC代替を置かない | 実習履修。育ての親からの連絡を読む場面。主人公が返信をためらい、そのまま連絡を断っていると分かる |
| 第4章「閉じた目録」 | ペンダントと一致する索引は見つかるが、普通の閲覧装置では像にならない。共通の説明場面で、ワルツが父の名と主人公の出自を知っていると明かす | 会話・記録照合。ノエル・ヴェラの認定実技を突破する（ルミを含め3種のNPC勝利） | 共通のマスター挑戦資格。七人全員のルートを同時解放。父の記録へ接続するには、正式な規則で七人とワルツに勝つ必要があると提示 |
| 第5章「七つの扉」 | 七人それぞれの担当領域で、記録を扱う仕事と判断に触れる。関心のある人物・領域から自由に進める | 各ルートは導入→領域任務・実習→担当マスターとの資格戦。七ルートに先後関係を付けず、途中で切替も可能 | 勝利したマスターの認証と個別編。七人すべてへの勝利でワルツへの挑戦資格を得る |
| 幕間「帰りを待つ人」 | 養育者が接触し、組織が裏切りを疑っていると告げる。父を消す計画を巡り、主人公は戻れない理由を語る | 任意の異なる3人への初回勝利で解放。会話中心。街の公認対戦場で、互いの接続を確かめる一戦を行う。勝利しても組織全体は説得できない | レヴナントとの決裂が表面化。残るルートをロックせず、グランドマスター章へ進む前に本編として完了する |
| 第6章「二百年の席」 | ワルツは主人公の願いを知ったうえで、正式な対戦を受ける。勝っても水晶の役目を引き継ぐわけではないと、事前に伝える | 七人すべての認証と幕間完了後、ワルツとの最終資格戦 | 本人が深層記録へ接続する力を得る。第7章、ワルツの個別編入口、起源譚の資格が解放される |
| 第7章「父の声」 | 記録の中のユンゲルが、成長した息子を認識する。別れの言葉と、父母が息子を逃がした意思を受け取る | 父の記録の場面。直後に説明用の戦闘や大量の報酬表示を挟まない。翌日の短い日常場面までを一章とする | 主人公の最初の目的に決着。八人の起源へ進むか、日常の対戦へ戻るかを選べる |
| 第8章「八人がいた日」 | ワルツに尋ね、図書館崩壊、リンケージ大会、八人の選抜と接続を知る | 起源譚を複数の短い記録に分けて閲覧。決着を改変しない回想対戦は任意の追加体験として検討 | 八人の一連の起源を初めて完全に開示。第一部完了。レヴナント編へ |
| 続編「帰れない者たち」 | 魔導王国とレヴナントの全容を知り、主人公が父の抹殺と水晶奪取を止めるために動く | 調査、協力、現在の対立を描く新章群。第一部の再試験は要求しない | 詳細な各章・最終決着は別途設計。帰還成功や八人の解放を、この文書だけで確定しない |

第1章までの必須操作部分は短くする。会話を飛ばした場合、認定まで10〜15分程度を目標にするが、これは未測定の設計目標。上級NPC全員への勝利やマスター攻略を、ノーマル・ランクの開始条件にはしない。

図書館への初回登録と、全カード・すべての部屋の開放は異なる。第1章で対戦資格を得ても、危険な記録の取り扱いやマスターへの正式挑戦はまだ許されない。この違いで「新人がいきなり最高位へ挑む」不自然さを避ける。

### 七人を自由な順で進めるための条件

- 第4章までを共通導入とし、その後は七人全員を同時に選べる。アリエスの勝利や、特定の領域の攻略を他ルートの前提にしない。
- 各ルート内の導入・任務・資格戦には順序を持たせる。挑戦資格を得ても、担当領域の事情を知らずに全員と連戦する構成にはしない。
- 各ルートで必要な知識は、そのルート内で説明する。他マスターの台詞や個別編を既読であると仮定しない。記録を複数読むことで意味が深まる構成にする。
- 共通の物語は「誰を倒したか」ではなく、異なるマスターへの勝利数で進める。幕間は一度だけ発生し、途中のルートへ割り込まず、帰館時に案内する。
- 七人は全員、最初に選んでも攻略可能な資格戦として設計する。隠れた推奨順や、別ルート限定の必須カードを作らない。デッキの得意不得意で相手を選び直せるようにする。
- 選択画面では七人の人物、担当領域、デッキの特徴、各ルートの進行を示す。特定の一人だけを「最初はこちら」と強調しない。各ルートには章内の独立したエピソード名を付ける。

## 4. 各マスターの本編と、勝利後の人物編

アリエスを教育・閲覧資格の担当に置く案を本設計で採る。残る六人は役職で記述し、固有名や見た目の承認済み設定があるかのようには扱わない。全員が同じ「最初は冷たいが本当は優しい」構成にならないよう、主人公に賛同する者、反対を貫く者、過去の判断を改める者を分ける。

| 担当 | 資格戦に至る本編の問題 | 勝利で解放する個別編の案 |
|---|---|---|
| アリエス／教育・閲覧資格 | 結果を理解せず深層記録へ進もうとする主人公。願いを奪わず、扱う能力をどう審査するか | 「合格者名簿」：適性は足りるのに深層研究へ進まなかった元教え子を訪ねる。シーカーを続けることだけが正しい生き方ではないと知る |
| 探索・観測経路 | 帰ってこない調査隊の痕跡。経路を広げれば救える可能性と、追加の行方不明者を出す危険 | 「閉じた航路」：探索を打ち切った相手の家族と向き合う。取り戻せないまま約束を守る日常を描く |
| 記録の検証 | 二つの証言が矛盾する。デュエルに強い証言者を真実として採用してよいのか | 「訂正されなかった一行」：自分の過去の検証に誤りを見つけ、公開訂正による権威の傷を引き受けるかを描く |
| 外部との接触 | 漂着者の持つ危険な知識と、保護を求める人間としての事情が両立する | 「届かない返事」：一度も故郷を見たことがない漂着者の子孫の手紙を扱う。レヴナントの家族という側面を補強する |
| 具現化・安全 | 主人公の高い適性に装置が追従するだけでは不十分。能力を増やすより、止める判断が必要になる | 「閉場の日」：事故を起こした職人とマスターが修理に立ち会う。責任を一人に押しつけず、再開に必要な条件を探す |
| マナ循環・生活基盤 | 都心の設備保全のため、地方の修理が後回しになっている。供給には限りがある | 「灯りのない通り」：夜の巡回で、管理上の数字の向こうにいる人々を見る。配分を変えても、すべては解決しない |
| 危険記録・封印 | 技術を閉じれば悪用を防げるが、その記録で助かる人もいる。何をどの範囲まで公開するか | 「消さなかった記録」：危険な記録を廃棄せず保存し続けた理由を知る。封印にも、抹消への抵抗という意味がある |
| ワルツ／中核の調整 | 七領域の判断を得た主人公に、自分で深層記録を読む力を認める最終資格戦 | 「明日の席」：父の記録と起源譚の後、八人以外による検証や異議申し立てを受け入れる具体的な運用を話し合う |

個別編はその人物の現在と過去の一部を知る報酬であり、次のマスター戦の必須条件にしない。未読でも主線が理解できるよう、必要な事実は本編で伝える。

七人の個別編では、戦災の記憶、長命を感じさせる交友、管理者としての失敗までは描ける。ただし、崩壊の日の大会、白い生き物の選抜、原本との接続の全容は先に明かさない。勝った人物から一人ずつ起源譚の核心を説明される構造にはしない。

専用デッキは各人の担当と判断をプレイへ結びつけるが、数値を極端に強化しただけの敵にしない。主人公と同じ公開された基本ルールの中で勝てる対戦を設計する。特別な試験条件がある場合は開始前に明示し、通常戦と正式な資格戦を識別する。

## 5. NPC・ノーマル・ランクの役割

- **NPC戦**：一つの技術の練習、人物との関係、資格の審査を担う。負けても再挑戦でき、会話や入館からやり直さない。後のフリー再戦はいつでも遊べる。
- **ノーマル戦**：不特定のシーカーとの交流と、教官が用意していない組み合わせへの対応を担う。必須の案内は第3章の2試合にまとめ、後半で何度も同じ消化課題を挟まない。
- **ランク戦**：正式な競技活動として、希望するシーカーが参加する。章、個別編、結末の解放に試合数・勝利・ランク・MMRを一切要求しない。

ノーマル課題は勝敗を問わず、正常に決着した試合を数える。サービス側の障害、未開始のキャンセル、無効試合は完了としない。正規の投了も結果が成立した試合として扱い、物語のために負け試合の継続を強制しない。カウントはクライアントの自己申告ではなく、対戦結果の確定を基準にする。

課題受領前に完了したノーマル戦も通算で認め、すでに2試合以上遊んだ人に追加を要求しない。シングルだけを遊びたい人、ゲスト、対戦相手が見つからない人向けに「図書館の交流試合へ切り替える」を置く。NPC代替を実際の対人戦と偽って表示せず、同じ履修条件を満たす別経路として明示する。

PvPの報酬、MMR、カード効果を物語の進行で増幅しない。世界観上の「力を得た」は深層記録への接続を意味し、通常対戦での隠れた有利補正にはしない。

## 6. 世界観を教える具体的な場面

### 第1章：対戦区域は何を防いでいるか

開始前にゼノが、床の一箇所にまだ青い光が入っていないことを指摘する。担当者が部材を交換し、最後の導路がつながるまで起動できない。短い実習の最後に、具現化したものを自分で解除する。

> ゼノ「ここは、強い魔法に耐えるだけの部屋じゃないんです。出せる大きさも、届く範囲も、先に決めてあるんですよ」

危険な事故をわざと起こして教える場面にはしない。後の循環設備や封印の章で、設備を保つ仕事の重さにつながる。

### 第2章：観測しただけではカードにならない

登録室に「村の収穫祭」の原記録が届く。主人公は大きな祝祭の映像を見るが、登録担当者が具現化用に選んだのは、ある作業の確かに読み取れる部分だけだった。

> 主人公「残りは、捨てるのか？」
>
> 登録担当者「残すよ。カードにしないことと、記録を消すことは違う」

その後、試験用の再現を確認し、刻印済みの一枚を渡す。イベント終了時に勝手にカードが湧く演出にせず、登録された瞬間が見えるようにする。これは設定の体験場面であり、新しい農業カードを必ず追加する指定ではない。

### 第2章：スターターと共通書庫

調律台に自分のスターターを並べる。試験場に移ると共通書庫が開き、まだ自分へ接続していない候補が現れる。

> ゼノ「持ち込んだ記録は、もう君のマナに合わせてあります。書庫の記録は、ここからつないでいくんです。最初に何を持つかで、つなぎやすい相手も変わります」

固定のアチューンを含む既存のデッキ規則・候補一覧はそのまま尊重し、世界観を説明するために枚数やカード効果を変更しない。

### 第4章：父の記録を早く見せられない理由

索引そのものは隠さず見せるが、通常の閲覧では像を結べない。共通導入でワルツは主人公の正体を知っていることを明かし、八人に勝つ条件を説明する。この説明を特定マスターのルートに置かない。

> ワルツ「俺たちが許可すれば読める記録なら、今ここで見せている。これには、お前自身が接続する力がいる」
>
> 主人公「その力を得るには、あなたたちを倒せと？」
>
> ワルツ「正式な規則の下で、七人と俺を。それが、今の水晶に定着している条件だ」

第7章のワルツの説明は、この時点の制約の回収になる。父の完成した遺言を八人が先に鑑賞し、息子へ見せずにいたという解釈を避ける。なぜ水晶にこの条件が定着したかという根本の謎は、別途扱う。

## 7. 非時系列の演出と回想のルール

回想は現在の行動に呼び起こされる短い断片から始める。ペンダントに触れた指から父にルーンを教わった記憶、手紙から養育者と食卓を囲んだ記憶、封印の刻印から家の金庫へ、と現在との接点を作る。

「記憶」「図書館の記録」「他人の証言」は枠や導入文で識別する。同じ映像表現にして、全場面が客観的な真実の再生に見えるようにはしない。主人公の記憶の省略も、後から都合よく内容を変更するためには使わない。

父との別れの全場面は、父の正体と主人公の目的を明かす第4章以降に分けて見せる。第7章は事件の説明を初めて聞く章ではなく、長く探してきた父に呼びかけられる章とする。

制作資料の年表は保管し、プレイヤー用の記録帳には到達済みの項目だけを載せる。未解放の章名や人物編の説明で「父の死」「未来の王国」などを先に明かさない。必要なら未到達分は「未解放」のみ表示する。

## 8. 実装時に守る進行仕様

今回コードは変更しない。後続の実装では以下を要件とする。

- 主線の章進行、各資格戦の初回勝利、個別編の解放と既読、各記録の公開を分けて保存する。個別編を開いただけで本編が進まない。
- 七ルートの進行は別々に保存し、切替・敗北・再ログインで失わない。初回に選んだ人物、最後まで残した人物を問わず、全員への勝利後は同じ主線へ合流する。共通幕間の解放と完了も別に保持する。
- 七人の資格戦の認証は固有のIDで保持し、同じ相手の周回勝利を七人分に数えない。通常の再戦結果や無効試合を資格戦の初回勝利に置き換えない。
- 父の記録と八人の起源の解放には、七人すべてとワルツの正式勝利を要求する。章の再生完了だけで認証を得られるようにはしない。
- 対戦の結果確定後に勝利を保存し、帰還時に会話を再開する。切断・画面再読み込みで勝利や報酬を失ったり、二重付与したりしない。
- 会話はスキップ・読み返し可能。スキップと未到達の飛び越しを区別し、試合勝利などの必須条件は残す。
- 従来から対人戦を遊べるアカウントを新設チュートリアルで再ロックしない。既存のNPC・アリエス勝利を調べ、対応する条件のみ引き継ぐ。未実装の六人やワルツへの勝利は捏造しない。
- ゲストは可能な範囲をローカルで継続できるようにし、ログイン時の引継ぎを設計する。対人戦にログインが必要な場合も、交流試合の代替で物語が止まらないようにする。
- 報酬の詳細は別途決める。人物編、図書館の変化、称号・外見などは候補。物語限定の強力な対人カードを必須報酬としては確定しない。
- 表示する次の条件は「ノーマル対戦をあと1試合」「ヴェラとの実技に勝利」など具体的にする。ランク参加を章目標に混ぜない。

シングルの入口は「物語を続ける」を主導線とし、「人物の記録」「再戦」を並列の補助導線に置く。既存の共通ヘッダー・下ナビ・選択済みキャラクターの扱いは [メニュー設計](menu-design-insights.md) に従う。新しい画面レイアウトの承認や、プレビューの確認が済んだという意味ではない。
