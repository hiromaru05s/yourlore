## 実装

- リフトの穴を Blender の穴と同じメートル座標で投影し、銀の枠・リブの後ろに配置。縮小時も独立した DOM の比率に依存しない。
- 黒紫の密度層、屈折する細い光、暗い核を共有する小さなシェーダーを追加。カードの被覆にも同じ材質を使う。常設リフトは最大約30fps、デスクトップの再描画範囲は85×402px（1280×720時）。盤面全体の3D再描画を常時要求しない。
- 虚無はプレイ表示の52%まで縮小してから、カード自体が渦に変わる。吸収完了後すぐ短い軌跡でリフトへ。水晶を介さない。
- 自分・相手の枠PNGそれぞれの開口部に合わせてアバターを切り抜き、画面座標の大きな枠へ。HPも同じ座標で追従。
- ターン終了のクリックで即座に赤い材質とENEMY TURNへ。押し込みと回転中もラベルを消さない。
- 従来の束シャッフルを呼ばず、シェルフを青い光が覆う→消失→デッキ位置に青いシルエット→マナ片が散って定着、という1450msの再構成へ。
- マナ増加は3本の折れた青い流れの収束、屈折の閃光、小さな三日月・結晶片の消散。実際の水晶は小さな反応だけに抑制。
- ドローはデッキからの抜き取り、弧を描く移動、表への回転、反射光、扇形への減速着地。1枚980ms、165msずつずらす。カードは同じDOMの画像・フレームフィルター・文字を使い続ける。相手は表を生成しない。手札の既存カードも実際の回転・縮尺・裏面画像を維持。
- カード名の文字サイズはカード固有の字幅から相対値で決定。アニメーション中の画面上の幅による再計測、別カードとの最小値共有、古い名前サイズの持ち越しを削除。
