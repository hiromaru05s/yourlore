# 盤面を画面いっぱいに拡大

2026-09-21のフィードバックに対応。カード拡張v50と最新デザインを統合した `4eeeb9c` からの変更。

- テーブルと盤上カードを横長画面で約32〜36%拡大。周囲の余白を減らして、画面幅の約9割以上を使用する。
- 自分のキャラクターの表示幅を58%から78%に変更し、相手側と同じ縦横比に揃えた。青い専用枠も透明な左右余白を補正して拡幅。
- 高さ1080px以上では相手キャラクターの210pxサイズを維持。低いウィンドウでは双方を同じ比率で調整し、中央のモンスターが顔を覆わないようにする。
- モンスター列を少し中央へ寄せ、手札を下げて残存魔法との重なりを減らした。

## 確認

- 2048×1081、2550×1346、1920×1080、1280×720、1814×1274、390×844のブラウザ表示。
- 両者のキャラクター表示領域が同寸法。山札、リフト、ターン終了、リロール、ポートレートが画面内に収まる。
- 各陣営モンスター7体＋残存魔法14枚を表示。1280×720でも自分のキャラクター枠とモンスター列に隙間を確保。
- リロールを実際にクリックしてマナを消費。手札の砲撃兵をドラッグし、場へ召喚。
- client/server型チェック、`tests/duel-ui.mjs`、`tests/motion-v2.mjs`、本番ビルド成功。
- 詳細は `geometry.json` と同ディレクトリの画面画像。

既存のViteチャンクサイズ警告は継続。ルール・カード数値は変更していない。
