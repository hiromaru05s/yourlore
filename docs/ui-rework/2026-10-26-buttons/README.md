# LORE ボタン比較プレビュー（02採用）

ユーザー承認済みの蒼銀の面取りパネルに合わせ、YES/NO・通常ボタンを検討するためのローカルプレビュー。比較後、ユーザーが02「隅のしるし」を採用し、全適用・本番公開を指定。01・03は未採用。

- 01 銀縁: 外周を面取りし、細い銀青の輪郭を一周。主要操作を明るい青、通常操作を深い青で区別する。提案上の推奨。
- 02 隅のしるし: 輪郭を減らして対角の短い線で示す。
- 03 小さな刻印: 決定だけに菱形を加え、内側に細い水平線を置く。

`client/button-ui-preview.html` をViteで開く。実際の `defaultUI.css` と承認済みパネル画像を使用。`buttonPreview.css` と `buttonPreview.ts` はこのプレビュー専用。ビルドエントリーへ登録していない。

確認: デスクトップと390px幅で目視、横はみ出しなし。3案の切り替え、YESのクリック反応、選択の解除・再選択、無効状態を確認。clientの型チェック成功。クリック結果はページ内の表示だけで、アカウント・デッキ・購入APIを呼ばない。

## 採用実装

`defaultButtons.css` を最終共通スタイルとして読み込む。選択済み02の面取りと対角の隅線をSVGの9分割へ移し、短いアイコンボタンから長い購入ボタンまで線幅を保つ。疑似要素やラッパーを追加せず、既存のレイアウト・アイコン・クリック処理を保つ。
