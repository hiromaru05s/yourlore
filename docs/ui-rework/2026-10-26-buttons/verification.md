# 02「隅のしるし」適用確認

## ローカルの実画面fixture

API応答をローカルで差し替えた実コンポーネントを使用。実アカウントの購入・デッキ保存・認証操作は行っていない。

- HOME: 対戦モードの選択表示。対戦紋章、ゼノ、クエスト面、下ナビは既存の表示を保持。
- デッキ: デッキ確定、デッキ切替、ローカルタブ、追加・削除、無効な追加、名前変更。
- カード: 種別フィルターとカード画像の表示。
- ショップ: カテゴリー、ガチャ操作、提供割合・一覧・履歴。購入処理は実行せず。
- チュートリアル: 開始・実習・章選択。ルール案内で「次へ」を押し、「ひとつ戻る」が無効から有効へ変わることを確認。
- プロフィールと設定: タブ切替、名前変更・テストボタンの表示。
- フレンド・ランキング: ページ表示。フレンド一覧とランキングはfixtureの空状態。
- 汎用確認: 保存・戻るの配色、戻るによる閉じる動作。
- ネイティブ購入確認: YES・NO、NOによる閉じる動作。
- カード選択: カード未選択の確定ボタンは無効。カードを選ぶと有効な青い面に切り替わる。
- 320px幅: 削除確認のキャンセル・削除が各120×46pxで横にはみ出さない。
- 390px幅: ログインのロゴ、タブ、ログイン・Googleボタン。前回追加したロゴも保持。

長いボタンでも隅線が伸びないよう、SVG内の13pxの線を14pxスライス内へ収める。最終版の中央の面だけが伸びる。
