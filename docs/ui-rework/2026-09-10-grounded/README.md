# 中央配置と接地感の調整 — 2026-09-10

直前の検証済みステージング `90c7c13`（実装 `7586511`）から分離した作業ツリーで実装した。カードバランスとアートの別作業は含めていない。

## 変更

- シャッフルは、少し傾けた束の下側の約1/3を抜き、上に戻すオーバーハンド方式。8回の受け渡しを加速しながら繰り返し、デッキ上で束を揃えて落とす。各反復の境界で位置と角度が連続する。
- リフト吸引は横揺れ・捻り・奥行きの反りを抑制。最後の端が裂け目へ届くまで不透明なカードを描く。
- ダイスはカメラを固定し、跳ねる高さを減衰させた。紺と真鍮の薄い楕円の受け面に実際の投影影を落とし、接触影も高さに追従する。最終出目は上向きのまま。
- 召喚の砂埃は不規則な濃淡の雲、地面を転がる低い煙、細かな砂粒を重ねる。重い着地は1.9秒、小さい着地は1.25秒。演出の残り時間でゲーム進行を待たせず、同時エフェクト数も制限する。
- モンスター列は常に中央揃え。召喚中に空きを確保し、既存カードが滑らかに寄る。飛来したカード面をそのまま列へ引き継ぐので、連続召喚でも着地位置が変わらない。破壊時は残ったカードが中央へ寄る。盤面の並び順は維持する。
- 広い画面では戦闘列とアバターの中心軸を一致させ、右側にデッキとシェルフを配置。小さくしたリフトを右側の置き場の下へ移した。狭い縦画面では中央の戦闘列を確保し、置き場を上下に分離する。
- デッキの裏面・シャッフル・ドロー・相手手札の輪郭を共通の内側形状へ統一。シェルフとフィールドのカード幅・高さは同じカード単位を使う。遠近による見かけの差は維持する。
- タイマーとターン終了ボタンを縮小し、表示中も右端に収める。

## 参考と確認範囲

Hearthstoneの[公式VFX制作解説](https://news.blizzard.com/en-gb/article/22552047/developer-insights-the-art-behind-the-science)と、同記事のKangor's Endless Army召喚映像を参照した。主動作のタイミング、周辺の副次的な粒子、盤面の読みやすさを基準とし、LORE用の砂埃を実装した。Hearthstoneの通常召喚の砂埃を同条件で比較した品質評価ではない。

## 検証

- `grounded-motion.mjs`: 8回の束の受け渡しの連続性、着地時の水平化、煙の寿命と消滅、控えめなリフトの反り。
- `grounded-board-browser.mjs`: 1280×720、1920×1080、1814×1274、390×844。1〜7体の中央揃えと右側の置き場・操作UIの境界。
- `grounded-motion-browser.mjs`: 実際のBaseController経由で3体連続召喚、中央の1体の破壊、ネイティブカードへの着地引き継ぎ（3体とも位置・サイズの差は0.46px未満）、14枚のシャッフル、1.6秒後の砂埃、出目2/6のダイス、reduced-motion。
- `duel-render-audit-browser.mjs`: 購入カードの前面レイヤー、在庫消去、シェルフ着地、購入後のグレーアウト、広い魔法ドラッグ範囲、手札破棄。
- `paper-card-browser.mjs`: ドロー面、相手の裏面、キャンセル・リサイズ・GPU喪失・低速画像読み込み・画面破棄、実際のLocalControllerの開始処理。
- `rift-fold-browser.mjs`: 不透明な吸引、最終端、相手側、キャンセル、reduced-motion、共用PaperCardのドロー。
- client/server型チェック、production build、design guard、ダイス形状、リフト形状、pile-stock、paper-card、opening-hands、duel-uiを確認。

ブラウザ検証は隔離したローカル実装で実施した。リモートでは配信資産のハッシュと匿名起動を確認し、ログインしたオンライン対戦は検証対象に含めない。今回の砂埃とダイスのGPU時間は別途計測していない。
