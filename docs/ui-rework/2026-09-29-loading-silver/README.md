# ビブリオンの銀紋 — ローディング置換

2026-09-29。メニュー／対戦準備の共通 `loadingScreen` を更新。ローカル実装とステージング公開済み。本番は未変更。

## 演出

ビブリオンの眼・コンパスを刻んだ濃紺のカード。3枚の厚いカードのうち中央が持ち上がり、刻印を下から上へ光が読み取り、カード面の反射が通り、同じカードが元の位置へ戻る。1周期5.6秒。ローディング進捗のタイマー代用ではなく、準備完了を待つ間のループ。

- 0–0.67秒: 着座、静かな溜め。
- 0.67–2.13秒: 浮上と銀紋の点灯。裏の2枚は僅かに開く。
- 2.13–3.36秒: 表面の反射と紋様を読ませる。
- 3.36–4.48秒: 点灯領域が上へ抜け、元の角度へ戻る。
- 4.48–5.6秒: 接地反射が細く収束し、次の周期へ。

承認基準 `docs/animation-quality-benchmark.md` と「銀紋の流墨」の動画から抽出した連続フレームを参照。今回へ翻案したのは、表面ディテール・細い明部・暗い芯・本体と光の同一座標・予兆と収束。ローディングなのでカードの破壊／リフト除外は行わない。世界観は `docs/world-bible.md` に従う。

## 接続と軽量性

- `client/src/ui/loadingSigil.ts`: インラインSVGの刻印とカード構造。演出用画像の追加取得なし。
- `client/src/styles/loadingScreen.css`: 全要素で共通の5.6秒周期。装飾は読み上げ対象外。低減モーション時は静止する。
- `client/src/ui/loadingScreen.ts`: 既存の準備進捗／再試行を維持した共通画面。
- `client/src/ui/menuAssets.ts`: 旧ドット絵アトラスを先読みから除外。
- `client/src/styles/presentation.css`: 旧走行スプライトのCSSを除去。その他の既存作業は維持。

演出にJSループ・イベントリスナー・WebGLコンテキストを追加していない。DOM除去時にCSSアニメーションも停止する。完成演出を見せるために画面の開放を遅らせない。実際の進捗とラベルの多言語対応は既存処理を維持。
