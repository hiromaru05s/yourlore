# Zeno / ゼノ / 제노

2026-10-14 ユーザー選定の月うさぎ02＋胸元01をHOME・チュートリアルの共通モデルへ採用。

- タップ専用の2.6秒の喜び: 耳が軽く立ち、手を内側へ寄せ、身体を少しかたむける。既存の笑う02（手のパタパタ）とは別のモーション。
- 既存の自然な耳の揺れ、眠りのしょんぼりした耳、ランダムな笑う／眠るを維持。
- ポインターを押して左右・上下へ動かすと向きが変わる。最終的な姿勢を左右±30度、上下±10度に制限し、離すと正面へ滑らかに戻る。
- ドラッグ後にタップ演出を発火しない。Pointer Capture、キャンセル、複数指、キーボード、破棄時のリスナー解放を扱う。
- 通常のHOMEには新しい説明UIを追加しない。名称はアクセシビリティラベルとチュートリアル本文へ反映。
- 低減モーションでは自動アニメーションを停止。WebGL非対応時は月うさぎの静止SVG。

実装: `client/src/ui/zenoRig.ts`、`manaSpiritMotion.ts`、`zenoInteraction.ts`。表示・入力ともHOMEとプレビューが同じ実装を使用。

ローカルプレビュー: `/zeno.html`。旧3状態比較は `/spirit-rabbit.html`。

検証:
- motion / rabbit rig / pointer interactionの3テストに合格（角度上限、復帰、タップとフリックの判別、中断・破棄を含む）。
- ブラウザーでタップ時の `happy`、横フリック時の約25度、縦フリック時の10度を確認。ドラッグで新たなhappyに切り替わらない。
- `qa/tap-*.png` は実レンダラーの連続フレーム。選択済みの形・胸元を維持しつつ、手・身体・耳が一緒に反応することを目視確認。
- ローカルHOME表示も確認。staging公開とその検証は公開後の別記録を参照。
