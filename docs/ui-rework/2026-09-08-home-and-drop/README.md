# HOMEと永続魔法の操作改善

2026-09-08。ステージング向け。

## 対戦画面

- 手札の位置から算出する不可視のドラッグ閾値を廃止。対戦盤面の矩形を表示し、その同じ矩形でドロップを判定。魔法・罠は自分の魔法欄、モンスターは自分のモンスター欄を強調する。
- 使用可能範囲では「離すとプレイ」。手札に戻す、盤外へ離す、pointercancelではキャンセル。既存のUID指定とプレイ開始位置を維持。
- 永続魔法を魔法欄・モンスター欄・マーケット上で離す実操作を、実際のBaseControllerと共通エンジンで確認。手札から除去され永続魔法に入り、論理状態はアニメーション完了を待たず更新される。
- 肖像はフレーム画像の余白差に合わせた共通座標へ。名前を枠の下に独立させ、HP・マナの揃った基準線を維持。

## HOME

左上プロフィール・シーカーレベル、右上シャード・設定、右側招待報酬・お問い合わせ、下部主要ナビゲーション。中心は既存の静止背景と正規LOREロゴ。動画機能は追加していない。

新規アイコンはオリジナルSVG。金属色の共通線画とフォーカス・ホバー表示。全メニューはネイティブbutton。

| 旧機能 | 新配置／接続 |
|---|---|
| ランク対戦 | 右側のメイン対戦ボタン |
| ノーマル対戦・BOT難易度選択 | メイン対戦ボタン直下 |
| デッキ・カード一覧・ランキング・ショップ・フレンド・チュートリアル | 下部ナビゲーション |
| プロフィール | 左上、既存画面へ |
| シャード | 右上、ショップへ |
| 招待イベント | 右側プレゼント、既存の招待進捗／リンク |
| 問い合わせ | 右側封筒、既存フォーム |
| フレンド申請数・対戦招待 | 既存watchSocialを維持 |
| 設定 | 右上、既存プロフィール設定タブ |

レベル条件はユーザーへ確認を提示した上で、未回答のため初期案として実装：`1 + floor((wins + losses) / 5)`。サーバーに記録されたオンライン勝敗のみ。BOT・引き分けは含まない。報酬・カード解放・ランクとは無関係。HOME表示時に既存セッションAPIを再取得して更新。退出後や別アカウントへ遅延レスポンスを適用しない。専用経験値DB／報酬システムは追加していない。レベル表示のバーに条件の説明を付与。
