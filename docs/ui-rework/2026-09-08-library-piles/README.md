# 3D library piles and card size adjustments

Implemented for staging `https://test.yourlore.xyz`.

- Empty field slot rectangles are invisible; their layout and drop positions remain.
- Expanded hand is 65% of its former rendered size. Compact hand is unchanged.
- Drag cards are at most the monster field width and 72% of the expanded card width. Fitted pixel text scales with the card.
- Decks are procedural rounded card stock with paper edges and the existing sleeve texture.
- Shelves are 3D stone / navy enamel / brass racks containing landscape, upright cards. Only the public discard top uses face art.
- `reshuffle` is emitted by the shared authoritative engine at the actual discard-to-deck transition. It carries player and public count only. No PRNG, card identities, or deck order are exposed.
- The controller awaits a 1.85 second lift / split / interleave / settle animation, then plays the existing deformable paper draw.
- Static piles share the hourglass WebGL context. At most 20 deck layers / 12 rack cards are represented visually; numeric labels retain the real counts. Active face textures and disposed shadow maps are released as piles change.
- Reduced motion, fast-forward, resize, visibility change, missing GPU, context loss and screen teardown release decorative playback. Raster pile art remains the GPU fallback.

The 3D mesh is generated by `pileModels.ts`; no external model files or Blender dependency are needed. Moving cards use `PaperCard` and a shared identity-free sleeve surface.
