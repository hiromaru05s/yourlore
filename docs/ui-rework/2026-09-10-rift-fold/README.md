# Rift folding — 2026-09-10

対象: https://test.yourlore.xyz 。ゲームルール・カード定義・DBは変更しない。

## 変更

- 途中から透明にしていた760msの縮小を、1.35秒の分割メッシュによる吸収に変更。
- 実際のカード面・裏面・紙の側面を持つPaperCardを変形する。元の投影姿勢から始まり、リフトに近い辺が先に引かれ、S字に曲がりながら伸びて入る。
- 各帯が裂け目に到達した時だけ、その帯の頂点を裂け目内の一点へ収束させる。全体のopacityは変更しない。先端が飲み込まれた後も末尾が残り、最後の端が1px未満まで収まってからメッシュを削除する。
- 元の盤面カードは最終状態の描画まで非表示を維持し、吸収後の一瞬の再表示をなくした。
- WebGLなし・低減モーション時は透明化せず裂け目へ縮小する。キャンセル・リサイズ・タブ非表示・コンテキストロストで一時メッシュを片付ける。
