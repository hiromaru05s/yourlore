## 参考にしたもの

[CRNG Games の元動画](https://www.youtube.com/shorts/X4TU3YKIN40): “Updating card VFX in our #indiegame about forgotten gods working retail! 💫⚡️” (18秒)。原神の映像ではない。

実映像の約2.15–4.15秒、5.6–7.6秒、10.7–12.7秒を細かく確認した。以下は見た目から読み取った構成であり、制作者の実装手法についての主張ではない。

- カードの縁を走る細い高輝度の芯と、その外側の柔らかい散乱光。
- カード面の短い光の走査、縮小・移動に同期する収束、短くずれた残光。
- カードの両側を通る細い曲面。大きな稲妻や強い全画面フラッシュは通常召喚に取り入れていない。

最低基準「銀紋の流墨」の保存動画の1500msの形状、および動画からの連続フレームも比較対象にした。輪郭・表面・運動を結び、暗い中間面と細い明部を分け、消え方を収束にする点を今回へ翻案した。基準の渦や紫色を流用する案ではない。

## 2案の違い

| | 01 蒼光の定着 | 02 マナの薄膜 |
|---|---|---|
| 主な形 | 実カードの縁から面へ満ちるマナ | カード前後を包む2枚の薄い流れ |
| 表面 | ずれた輪郭の走光、斜めの面走査 | 絵柄の細部を残す青い面、繊維状の光 |
| 動作 | 少し早く下降し、縁へ収束 | 短く溜め、膜が縮まりながら下降 |
| 補助 | 小さな隅の光、短い後流 | 曲面の細い芯・厚み・先細り |

共通の時間設計: 0.02–0.34秒で中央へ拡大、0.34–0.72秒でカードを読ませる。0.69秒以降に輪郭が反応し、0.80秒以降に面がマナ化。01は1.02秒、02は1.10秒から盤面へ下降し、1.78秒に接地する。接地時に局所光がカードの縁へ戻り、0.17秒・最大0.9度の剛体的な傾きで重さを示す。2.4秒で余光を消し、3.2秒まで静止状態を確認できる。

## 連続性

- 中央表示から移動、着地、終了まで同じ盤面カードのDOMと子要素・画像を使う。一時的にスクリーン上の層へ移し、空の席で盤面レイアウトを維持する。別のカード画像への交換は行わない。
- カード絵は `/art/cards/M4.webp` の採用画像。フレームと絵柄の内部サンプリングを開始前から一定に保ち、表示サイズの変化で中間画像を差し替えない。スマホでも中央表示の幅を確保する。
- 光用のマスクは実カード面を1024pxで採取し、コスト・攻撃・体力の突き出した輪郭を含む。影の薄いアルファを輪郭から除き、画像の四角い範囲を発光させない。カード本体を描き直すためのテクスチャではない。
- 小数座標を補正した射影で着地位置を合わせる。着地直前／直後の矩形差を0.15px未満で検査。
- 1.65秒以降はカードと光の層を手札の下へ戻す。終了時に反動・フィルター・一時ノードを復元する。
