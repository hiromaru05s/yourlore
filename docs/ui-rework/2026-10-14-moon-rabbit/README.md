## 変更

- 耳の根元を頭へ埋め込み、左右の長さをほぼ揃えた滑らかな立体面へ変更。根元から先端まで連続した曲線として曲げる。
- 待機: 呼吸と小さな耳の揺れ。左右に位相差、耳先には遅れを設ける。
- 笑う: 既存の表情・浮上を維持し、肩を支点に両手を大きくパタパタ。耳が少し立ち、先端が遅れて弾む。
- 眠る: まぶた・うなずきに合わせて耳が外側へ柔らかく垂れる。目覚めに合わせて戻る。
- 目周り・胸元01は維持。通常HOMEのシルエットはこのプレビュー変更では置き換えない。
- 旧5案ページの02も同じリグを使う。新規ページでは待機／笑う／眠るを同時表示し、正面／斜め・明背景・スロー・再生し直しを操作できる。
- 再生し直し・向きの切替でWebGLモデルを再生成しない。耳は既存バッファを書き換え、3体比較は30fpsに制限する。
