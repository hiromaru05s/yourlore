# カードフレーム再制作と前回依頼の再点検

対象: test.yourlore.xyz。2026-09-08。

## 今回の変更

- モンスター赤・魔法青・罠緑の生成PNGを、通常表示とコンパクト表示それぞれに用意（計6枚）。カード名の帯・効果欄・縁・区切り・フッターまで画像に含む。カードイラスト、翻訳、コスト、攻撃、HP、状態は実データを重ねる。旧リワークの共通枠2枚は利用を終了し削除。
- 素材は `client/public/art/biblion/card-polish/`。内蔵imagegen使用。生成プロンプトと原本パスは `assets.json`、画像形式・サイズ・ハッシュは `asset-verification.json`。採用PNGはRGB原本であり、透過PNGとは扱わない。イラストを濃紺の窓の上に合成し、画像のプレートをそのまま使う。
- 数字をバッジから独立した要素にし、攻撃は右寄りの青い内面、HPは盾の上寄りの内面へ配置。1桁・2桁・3桁で中央位置が変わらない。
- 初回ターンを省いていた条件を修正。コイントス終了→ターン告知＋初期ドロー→BOT行動の順序。途中ターン・再接続にも対応し、同一ターン更新では再表示しない。
- ドローは装備スリーブのデッキから手札への立体的な弧と裏返し。自分だけ表面が見え、相手は裏面のまま。大量ドローは最大6枚の連続演出。操作による省略・画面破棄で飛行カードと一時的な非表示を解除。
- 1280×720では市場カード高118.08→100.8px（約15%縮小）、フィールドカード辺長60.22→81.39px（約35%拡大）。市場の余白も圧縮。小画面のフィールド幅計算、手札下端、ヘルプと罠アイコンの干渉も修正。
