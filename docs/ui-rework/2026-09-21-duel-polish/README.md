# 対戦画面の8項目フィードバック対応

基点: `fb815b3`（v51カード調整、Biblion Lounge、MMR修正を含む統合済みツリー）。

1. リフト: Blenderの `ANCHOR_rift_player/opponent` と同じ位置・高さを共有し、DOMの操作領域、背景開口部、カードの吸い込み先を統一。相手側を含め、投影した中心と基準位置の誤差は約0.6px以内。
2. テンポ: Botの行動前待機600→220ms、通常ドロー980→680ms、購入960→620ms、相手カードの拡大表示1050→640ms。ダメージ後などの余分な待機も短縮。イベント順序・カード効果は変更しない。
3. シェルフ→デッキ: 束全体に同時に薄い青白光、白い縁の発光、柔らかい外側の光を加える。下から上への被覆を廃止。消失後に山札側で再構成。1450→980ms。新しい材質のGPU準備は演出時計を始める前に実施する。
4. 縮小手札: 同じカード・表示状態のDOMを維持。角度未確定時も縮小率が無効にならない既定値を設定し、縮小中の挿入時トランジションを停止。
5. サイコロ: 表示領域外から入り、移動距離に連動した回転、減衰する小さなバウンド、支持面に沿った高さで停止する。正しい出目は従来通りエンジンの値。GPU準備完了後に時計を開始し、初回の途中出現を防ぐ。最大5列で複数段にも対応。
6. END TURN: 900msの赤色維持タイマーを廃止。入力受付時に赤にし、その後は論理上の手番を反映。古い演出スナップショットは新しい手番を上書きしない。毎フレームの同じラベル再生成も廃止。
7. 拡大手札のホバー: 0.58→0.66（約14%拡大）、少し持ち上げる。
8. 勝敗: 書物の紋章、封印環、肖像から広がる光の欠片を用いた新演出。勝利は金と青白、敗北は銀紫。結果パネルも同じ意匠に揃え、ホーム・ログ・再戦、ランク変動表示は維持。結果に対戦タイマーを付けない。
