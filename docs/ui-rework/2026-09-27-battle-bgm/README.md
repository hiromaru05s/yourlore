# 対戦BGM「poised opening」

ユーザー指定のMP3を無変換で `client/public/music/poised-opening.mp3` に収録。
62.80秒、48 kHz、ステレオ、1,485,919 bytes。
SHA-256: `ccfb693a92823b80ce15386ab82226e02c2fdcff5378c84e726d24af481e4a15`
元音源・配置ファイル・ビルド出力のハッシュ一致を確認。

- ランクマ・ノーマル・BOTのgame画面で再生。チュートリアルは対象外。
- 曲末のendedイベントから3,000 ms待って先頭から再生。クリック、キー、音量操作、タブ切替で待ち時間を短縮しない。
- ユーザー確認済み仕様: 対戦BGMの再生ゲインはホームBGMの60%。共通設定70%ではホーム0.245、対戦0.147。既存の音量設定値は維持。
- sound.tsから音量変更イベントを通知し、ホーム・対戦のBGMへ即時反映。
- タブ非表示・ミュートで一時停止。ホームへ戻る／再戦／画面破棄時は音源と次再生タイマーを解放。
- ホーム用の画像準備待ち、自動再生拒否時の操作による再試行は共有モジュールへ移し、既存挙動を維持。

## 検証

`npm run build` 成功（既存のチャンクサイズ警告あり）、`git diff --check` 成功。
Chromeの実音源で次を検証。ページ例外なし。

- 実際のmountGame経由でノーマル／ランクマ／BOTを起動、対戦BGMが1つだけ再生。
- 曲末へシーク後、ended→playingの間隔 **3,001.5 ms**。待機中の入力・音量変更でも早期再生なし。
- 盤面の音量スライダーによる即時ミュート・音量変更、ホームの60%のゲイン。
- 非表示／再表示、無音待機中の画面破棄とタイマー取消、ホームBGMへの切替、チュートリアル除外。
- 既存ホームBGMのブラウザ検証も成功（画像準備待ち、再生拒否時の再試行、実再生と連続ループ、停止・解放）。

オンラインのWebSocketはローカルのスタブを使用。認証済みの実オンライン対戦はこの検証には含まない。visibilitychangeは注入して検証。
