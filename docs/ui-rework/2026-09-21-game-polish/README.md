# LORE メニューのゲーム画面化

既存の07案の画面構成を維持し、Webの管理画面に見えていた細部を更新。

- HOMEとナビゲーションから図書館名・英語の大見出しを撤去。ロゴ、プレイヤー、対戦の導線を残す。
- 紺のエナメル、真鍮の縁、明るい象牙色の操作面に統一。押し込み、選択枠、発光、スライダー、切替、カード枠、ダイアログ、結果以外の各メニューを調整。
- HOMEのデッキとフレンドを室内に重なるコンソールとして表示。ページの役割やAPIは維持。
- カード一覧は固定された検索・フィルターとスクロールするカード面に分割。旧 `max-height:94vh` と `overflow:visible` の組み合わせを解消し、背景をフレーム全体に維持。スマホではフィルターを横送りにしてカードの表示領域を確保。
- デッキ、カード、ランキング、フレンド、ショップ、ガイド、プロフィール、設定、認証・待機画面を同じ質感に揃える。

## PNG素材

内蔵 `image_gen` で25種類を個別生成。既存SVGナビゲーションと絵文字アイコンを置換。Googleの認証ブランドマークと既存のカード・キャラクターアートは維持。

- 実装用PNG: `client/public/art/lounge/icons/v2/`
- 生成原本: `icon-sources/`（透明背景を保持）
- 一覧: `icon-catalog.html`
- 各生成プロンプト・出力元: `icon-prompts.json`
- 配信PNGの寸法・SHA-256: `icon-manifest.json`
- `node scripts/build-lounge-icons.mjs`: 原本を256pxの透過PNGへ機械的に縮小。描き直し・色変更は行わない。25個合計2,209,449 bytes。

アイコンは装飾画像として空のaltを付け、ボタンのラベル・キーボード操作は維持。低モーション設定では演出を停止する。
