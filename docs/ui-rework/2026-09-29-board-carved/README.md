# 盤面と同材の浅い彫り込み

前回の淡い金色の太い曲線は、白い天板へ貼った印刷として見え、立体の金属枠から浮いていた。今回は模様の色を完全に廃止。アイボリーの無地面と同材の外周に、浅い段落ちと先細りの彫り跡を設ける。

- 広い中央面とカード配置範囲は平面のまま。左右対称の大紋章や中央の図柄はない。
- 上下と左の外縁に細い帯を設け、枠に沿う連続した溝へ統合。右側はデッキとリフトの余白が狭いため、上下の帯を外枠へ収める。
- 前回の塗り模様と異なり、ベースカラーは全域同一の `#e7e5df`。金色や灰色の模様は印刷しない。
- 段落ちと切り込みは負の高さだけから法線・遮蔽・粗さを生成。既存の照明で陰影がつく。盛り上がりは作らない。
- 溝は法線マップで表現し、輪郭・メッシュ頂点・当たり判定は保持。高さモデル上の深さは帯約0.7mm、最深部2.5mm。ポリゴン追加や描画呼び出しの追加はない。
- 浮いて見える色面を作らないことを優先し、装飾の存在感は控えめにしている。見た目の好みの承認はユーザー確認待ち。

## 再生成・確認

`node scripts/build-board-pattern.mjs`。編集元は `client/public/models/reading-board/v1/biblion-recess-v3.svg`。これは彫り込み用の白黒高さマスクであり、可視の色テクスチャではない。旧v1/v2 SVGは履歴資料として残るが、新しいモデルでは使用しない。

- UVの `[.092,.980] × [.085,.915]` をカード用平面として検査。両者のモンスター／魔法罠列とデッキ／シェルフの配置範囲を余白付きで包含する。
- 通常版190万点・軽量版47万点で高さゼロ／平面法線を検証。元モデルの頂点・法線・インデックスの保持も検証。
- 通常版1440×900で空盤面と両者7枚、軽量版640×420の実際のGameViewを撮影。両モデルのready状態、ページ例外なしを確認。
- `npm run typecheck`（client/server）と `npm run build` 成功。従来からある500kB超のJSチャンク警告は継続。
- v2比で通常モデル約88kB増、軽量版約20kB増。描画呼び出しは増えず、既存の盤面描画キャッシュを継続する。端末でのFPS改善を主張するものではない。

実画面は `board-1440-empty.png`、`board-1440-full.png`、`board-640-empty.png`。モデルサイズ・ハッシュ・検査値は `assets.json`。
