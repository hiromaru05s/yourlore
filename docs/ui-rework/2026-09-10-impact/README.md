# Duel impact and market continuity — 2026-09-10

配信先: https://test.yourlore.xyz （lore-server-staging）。ゲームルール・カード定義・DBスキーマは変更しない。

## 変更

- シャッフルは左右の束を約200msごとに分離・交差させ、8回混ぜてから揃えて着地する。持ち上げから着地まで2.45秒。キャンセル・低減モーション時の既存処理を保持。
- モンスターは560msの落下を加速カーブに変更。着地時にimpact音、最大3px・240msの揺れ、52粒の局所的な埃を発生。埃は素早く広がって減衰する。盤面とカードの角度は着地まで連続する。
- 購入カードは前面の平面DOMを拡大してから3Dへ切り替える処理をやめ、マーケットからシェルフまで同じ3Dカード・カメラ・深度バッファで動く。クイックカードとGPUフォールバックの出発姿勢も盤面の投影に合わせた。
- 在庫1の提示・固定カードは、テクスチャの準備を待つ前に元のカードを非表示にする。枠の配置は保持し、他のカードが途中で詰まらない。複数在庫の固定カードは通常の位置に残し、在庫表示だけ減らす。最終状態は既存の対戦スナップショットで描画する。
- 開始時のマーケット落下は4乗の加速カーブ。右から固定8枚／左から提示4枚の順・速度比・着地タイミングを保持。全カードが着地するまで同じWebGL描画で保持し、既に着地したDOMカードが飛行中カードを覆う問題を解消。
- 3D台の読み込み中は無地の背景を表示し、旧背景画像から3D台へのちらつきを防止。待機中のデッキ・シェルフの文字と枚数を隠す。コインの3D準備前にCSS版だけ先行表示することも防ぐ。
