# Duel stagecraft — 2026-09-10

## 変更内容

- 開始演出は空のマーケット土台を先に落とす。着地後、固定8枚は右上から右端順に80ms間隔、提示4枚は左上から左端順に160ms間隔で降り、最後のカードが同時に着地する。その後に両陣営のデッキ置き場・シェルフ、加速する初期デッキの順に登場する。
- 家具・初期デッキの出発位置を画面外の座標から逆投影する。一定の低い高さで突然出現する処理を廃止。落下カードも通常カードと同じ盤面カメラで描画する。
- コインは回転体の実体、面取り、72本の側面の刻み、両面の人物入りテクスチャを持つ3Dメッシュ。直径2に対して厚み0.16。接地支持高さを回転に合わせて計算し、2回の大きさの異なるバウンドから結果面を上にして止める。GPU不可時のCSS表示を保持する。
- 通常・ホバー・ドラッグ・不可・ローディングの5種類の40px SVGカーソルを作成。紺・アイボリー・金を使い、全状態で先端位置を揃えた。購入不可カードには画面外に切れない理由の吹き出しを表示する。
- 発動前の70個の条件チェックをエンジンから共有関数 `playBlockReason` に抽出。手札のグレーアウトと実際の使用判定が同じ条件を参照する。マナ不足、召喚条件、封印、使用回数、対象不在などを表示前に判断する。手札のカード情報以外に非公開情報を新たに露出しない。
- 魔法・スターター・クエストは左右の盤面余白まで広いドロップ範囲を使用する。手札に戻す操作ではプレイしない。
- カードの側面をわずかに厚くし、DOMフレームにも薄い重なりを加えた。シェルフと移動中のカード面は照明・トーンマッピングによる再着色を止め、元の印刷色を保持する。キャプチャは768pxで作成し、原寸アートを優先、未提供の原寸画像はサムネイルにフォールバックする。画像欠落によって開始演出が停止しないようにした。
- ダイスは反射とクリアコートを弱め、照明を中立色に変更。結果面を上にする幾何学的な判定は保持する。
- 紫黒の07を採用。別途生成した透過16フレームを、静止した基準フレームに16%の濃さで重ね、32秒で一周する控えめな動きにした。ホバー中は停止し、形とハイライトを僅かに変える。サイズを拡大し、シェルフとの間隔も確保した。[生成記録](rift-manifest.json)。
- アバター枠は同じ画像・同じ幅を使用。相手側の枠を上に寄せ、人物の頭は画面内に保持。自分側は下に寄せ、盤面に予約していた高さを削減。カードは縦横比を変えずに拡大し、ターン終了ボタンを含めた幅でサイズを計算する。相手手札は画面上端3px、自分の縮小手札と同じ幅・高さに統一した。
