## 保存・付与

- マイグレーション: `server/migrations/0021_gift_inbox.sql`
- 認証済み `/api/gifts`、`/api/gifts/read`、`/api/gifts/claim`
- D1の1トランザクションで受取状態、既存の `users.credits`、`rewards` 台帳を更新。同時受取・再送時は未受取の自分宛だけが付与される。途中失敗は全体をロールバック。
- 期限判定はサーバー時刻。GETは未受取を優先して最大300件と、全件の未受取数・合計額を返す。履歴が増えた場合は古い履歴が省略される。
- 一括受取は表示上限に関係なく有効な自分宛すべてを対象にする。

運営用の `POST /api/admin/gifts` は既存のadmin専用ホスト＋管理者認証を通した経路のみ。入力は `{id,title,body,amount,expiresAt,userId}`、全員宛は `userId` の代わりに `all:true`。`expiresAt` はミリ秒UTC。タイトル100文字、本文2000文字、1〜100000シャード、有効期限は1年以内。idは英数字・ハイフン・アンダースコア80文字まで。同じid・内容で再送しても二重配布せず、内容を変えた同じidは409。全員宛は配布時点に存在するアカウントを固定し、後日登録者は含めない。本文はプレーンテキスト。今回の依頼では実ユーザーへの配布は実施しない。
