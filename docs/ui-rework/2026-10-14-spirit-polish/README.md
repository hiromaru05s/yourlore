# 白いマナの精霊の品質・ホーム整理

## 変更

- 元のしずく形、暗い楕円の顔、左右のひれを維持。胴体の輪郭を補間して96分割で回転し、ひれの輪郭と厚みも滑らかにした。真珠色の穏やかな反射と滑らかな陰影を使用。
- 前面の水晶はテーブル・クラウン・ガードル・パビリオンを持つカット形状へ変更。実形状から抽出した面を用い、既存 `readingCrystalOptics` の内部反射を適用。金色の台座と4本の爪、暗い裏面により厚みを表現する。
- 共通光学処理は整数のscaleもGLSLでコンパイルできるようfloatへ明示変換。中心・スケールもシェーダーキャッシュキーに含めた。
- HOMEでは8〜14秒の休止を挟み、4.6秒の「羽ばたいて浮上し、ニコッとする」と6.8秒の「まぶたを落として傾き、うなずき・あくび」のどちらかをランダム再生。同じ動作が3回連続しない。クリック／Enterで笑顔になり、眠気からも滑らかに戻る。
- チュートリアル／初回案内は同じ高品質モデルを使用するが、ランダムな眠気はHOMEだけ。既存の初回案内・復習経路は維持。
- HOMEの「BIBLION」「次の一手を、ここから。」、吹き出し、モブ名・挨拶文、追加チュートリアル誘導を撤去。既存の下ナビのチュートリアルは復習用に維持。
- PC／縦長スマホ／横向きスマホでモブ自身を配置し、削除した案内パネルの空枠は残さない。

## 検証

- 型検査、ビルド成功。ビルドの既存チャンクサイズ警告あり。公開前の最終ビルド・全回帰はdeploy guardで改めて実行。
- `tests/mana-spirit-motion.mjs`: 180秒×4パターンの乱数入力で間隔・両動作・連続回数制限・有限値、笑顔の浮上／眠気のまぶた・うなずき・あくび、タップ復帰、チュートリアルの非ランダム動作を確認。productionスイートへ追加。
- `tests/menu-selected.mjs`: 余分なHOME誘導がないこと、既存の対戦選択・BOT・ショップ回帰。
- `tests/tutorial-academy.mjs`: 12課程の実リデューサーとサーバー報酬の重複防止・ロールバック・合計3,000を確認。
- CUAで通常アプリのゲストHOME、320/390/844px、チュートリアル経路を確認。横方向にはみ出しなし。横長ではモブを上に揃えた。
- CUAで実際のHOMEコンポーネントの連続フレームを採取。`qa/flutter.mp4` / `qa/sleep.mp4` は採取時刻の間隔で動画化したもの（描画60fpsの全フレーム記録ではない）。`qa/flutter-*.png` / `qa/sleep-*.png` は途中表情。
- 検証用ボタンで低減モーション・非表示を再現し、時間経過後のモブ領域のピクセル一致を確認。低減時のクリックでも静止、破棄後のcanvasは0、WebGLなしのSVG代替を確認。静止時も描画を保持する。
- 操作・再生・表示確認は実施。ユーザーの最終的な見た目の承認は別。
- 公開環境の認証済みホーム／初回ログインはこのローカル確認には含まない。
