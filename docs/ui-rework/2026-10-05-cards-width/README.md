# カード一覧の横はみ出し修正

## 原因と修正

公開済みビルドの1280×720画面では、約93pxのグリッド列に140pxのカードが入り、左端のカードは一覧の左端より約14pxはみ出していた。共有CSSチャンクの読み込み順で旧カード幅が適用されていた。

- カード本体と列の最小幅を同じ `--collection-card-width` で決定する。一覧に限定したセレクターで共有CSSの順序に依存させない。
- スマホの固定4列を自動列数にし、左右16pxの余白でコスト・攻撃力・防御力のバッジも収める。
- 一覧は縦スクロールのみ。種別ボタンも折り返し、横スクロールさせない。

## 確認方法

`npm run build` と `vite preview` を使用。開発サーバーだけでは共有CSSチャンクの順序を再現できない。

```sh
LORE_PLAYWRIGHT=/path/to/playwright/index.mjs node tests/cards-layout-browser.mjs
```

ブラウザ検証はAPIのみfixture。実際のカード描画・画像・CSSを使用して、9画面サイズ、端のバッジ、カード同士の重なり、縦スクロール、ページ切替、種別、検索空状態、キーボード拡大、日英韓表示を確認する。認証やオンライン対戦の検証とは別。
