# パッシブ紋章 v2

2026-09-29。ローカル実装済み。デプロイはしていない。

細い装飾のラスター画像を、縮小時の識別を優先した11種のSVGに置き換えた。
濃紺の不透明なエナメル面、面取りした金属縁、太い図柄を各SVGに含め、カードアートの明暗に依存しない。
背景プレートを含むアイコンの大きさは通常カードでカード幅の21%、小型盤面カードで24%。
付与は右上の小さな角印、回数は右下の数字。回数表示もサイズに追従する。
右側の説明パネルではアイコン・名前・説明を表示する。

## ソースと確認方法

- SVG原稿・生成: `scripts/build-passive-icons.mjs` → `client/public/ui/passives/v2/*.svg`。画像生成AIではなく、直接設計したベクター図形。
- 共通描画: `client/src/ui/passiveIcon.ts`。盤面、カード、説明、検索のアイコンとプリロードURLを共有。
- スタイル: `client/src/styles/passives.css`。
- 比較ページ: 開発サーバーの `/passive-lab.html`。実際の `cardEl` / `zoomCard` を利用。製品ビルドのページには含まない。
- `npm run typecheck`、`npm run build`、`git diff --check` 通過。
- Chrome: 全11種のSVG読み込み、33件の翻訳名と説明ハイライト、3画面サイズで実盤面のカード内に収まることを確認。詳細は `qa-report.json`。
- 見た目: `preview-desktop.png`、`preview-mobile.png`、`description-desktop.png`、`board-1440.png`、`board-390.png`、`board-844.png`。明暗と高周波背景、68px/100pxの小型カード、付与とカウンターを比較。

スマホ縦画面では既存の盤面全体縮小により図柄そのものは小さくなる。詳細パネルの名前と説明で確認できる。アイコンが直感的かどうかのユーザーテストは未実施。
