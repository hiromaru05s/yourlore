# 枠に沿うフラットな盤面装飾

前回の大きな目・円・菱形の紋章と均一な細線は、既存の曲線的な枠から独立した透かしに見えていた。今回は中央の紋章を撤去し、枠の流れに沿った装丁風の曲線へ変更。

- 中央のプレイ領域は無地。主な模様を外周と上下の縁に配置。
- 既存の枠にある葉／羽根に近い曲線と、太い根元から先へ細くなる塗りの形を使用。
- 盤面の縁を辿る線に装飾をまとめ、青灰色の独立したロゴを置かない構成。
- 色はアイボリーと既存の金属枠に寄せた、彩度の低い温かい色。影・グラデーション・ベベル・発光なし。
- 凹凸なし：ベースカラーだけに焼き込み、normalTextureなし、roughness 0.88で一定、metallic 0。頂点・法線・インデックス・当たり判定は変更しない。

編集元は `client/public/models/reading-board/v1/biblion-surface-v2.svg`。`node scripts/build-board-pattern.mjs` で通常／軽量GLBを生成。旧v1 SVGは過去の資料として残るが、現行モデルには使用しない。読み込みURLは `revision=flat-binding-v2-20260929`。
