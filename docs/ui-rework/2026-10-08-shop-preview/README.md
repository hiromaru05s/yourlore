# ショップの家具見本と画面内プレビュー

2026-10-08。ショップの商品見本が実盤面の家具と一致しないこと、別タブへ移動する導線の修正。

- 素材画像＋CSSの擬似家具を撤去。デッキ置き場・墓地の同じGLB、共通の基本材質処理、対戦で使う外装・材質アダプターから12組の静止見本を描画する。
- 見本生成には短時間のWebGLコンテキストを1つだけ使い、完了後にモデル・材質・テクスチャ・コンテキストを破棄。画像をセッション内に保持する。
- 「実盤面で見る」は同一オリジンの読み取り専用盤面をショップ内のダイアログに表示。全体・デッキ置き場・墓地の表示を切り替えられる。
- 選んだ商品の種類だけを自分側に適用する。スリーブを選んでも家具を変更しない。旧4種の家具も対象。
- 閉じる／Escでショップの選択とフォーカスを戻し、iframeを破棄する。画面破棄・カテゴリ変更でもプレビューを閉じる。
