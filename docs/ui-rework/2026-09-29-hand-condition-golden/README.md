# 手札の条件達成 — 黄金の双光を採用

2026-09-29。ユーザーが外周ハイライト第3稿の②「黄金の双光」を選定し、ステージングへの反映を指示。

カード枠・コスト・攻撃力・体力の素材を合成した最外周に、金色の帯・白い芯・二筋の光を表示する。2.3秒で一周する長さ22%の尾を半周離して配置。元試作と同じ輪郭抽出・色・線幅・尾の階調を使用し、周回はCSSアニメーションへ移した。カード面や数値には太い帯を重ねない。

## 接続

- `GameView.renderHand` が自分の条件付きカードだけを同期する。相手の手札や通常のカードには付けない。
- モンスターの `summonReq` は既存の `summonReqMet` を使用。魔法のカード固有条件は既存の `playBlockReason` から判定部分を共有化。支払いマナ・手番・場全体の封印とは別に条件達成を示す。プレイ可否は従来の判定のまま。
- 相手の非公開デッキを直接参照する `INQUISITION` はハイライト対象外。
- 未達成、手札からの除去、手札上限の捨て札選択、対戦終了で表示を除去。画面破棄時に予約フレームとDOMを解除し、遅れて届く画像から再生成しない。
- マナ不足などの暗転はカード内容へ適用し、条件達成の金色をグレースケール化しない。低減モーションでは静止した金色の縁を維持。
