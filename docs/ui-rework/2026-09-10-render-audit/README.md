# Duel rendering audit — 2026-09-10

対象: https://test.yourlore.xyz / lore-server-staging。今回の変更は対戦表示・入力・イベント再生。ゲームルール、カード定義、DBスキーマは変更しない。

## 今回修正した原因

- **開始時の藍色表示**: 以前の対応は旧背景画像を隠して無地の紺色を表示していた。モデルの取得を待つ間も白い天板と金の縁をCSSで表示する。待機中の家具ラベルを隠す処理も維持。
- **購入カードがマーケットの後ろを通る**: 家具用WebGLキャンバスはDOMカードの下にある。同じWebGL深度バッファへ移動カードを入れるだけでは解決しない。飛行カード用の透明キャンバスをDOMの前に置き、家具と同じカメラ・物理座標で描画する。空のときは描画を止め、最後のフレームだけ消去する。
- **再描画直後のフレーム飛び**: `render()` がカード・棚を作り直した直後から盤面投影と棚の3D表示状態を引き継ぐ。読み込み済みアートの0→1フェードを再発させない。同じ幅・文字のカードはフィット済み文字サイズも引き継ぐ。
- **シェルフの画質と色、着地の不一致**: 静止した棚の表面をキャプチャ画像に変換する処理を廃止し、通常カードと同じDOM・384pxアートで描画。盤面投影と積層高さを共有する。飛行中は1536px基準の透過テクスチャを使い、原寸アートを優先する。着地面を描画してから飛行カードを除去する。不要になった棚用GPUテクスチャの保持も廃止。
- **外側の四角**: 透過フレームの下にあった3Dカードの不透明な表裏キャップを取り除く。側面は保持。拡大演出の矩形の光沢・矩形の影を除去し、輪郭に沿う影を使用する。
- **魔法の反応範囲**: 展開中の手札がポインターの下へ広がり、キャンセル領域になっていた。魔法は盤面の左右・中央で使用でき、手札と重なる位置でも上へ28px以上ドラッグすれば発動可能。元の位置へ戻すキャンセルとモンスターの配置判定を保持。
- **手札の超過破棄**: エンジンのログだけだった hand→discard の公開状態差分を拾い、選んだカードを1枚ずつシェルフまで運ぶ。プレイ済み魔法と二重に再生しない。相手の裏向き手札は既存の公開UIDで対応付け、公開された捨て札だけを表示する。
- **シャッフル後の棚**: ネイティブ表面へ移行したため、全カードをデッキへ移したときは棚の旧表面も同時に取り除く。
