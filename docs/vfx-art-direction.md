# LORE VFX 制作指針 — Toon 基準

**2026-09-29 ユーザー確定:** [アニメーション品質の最低基準](animation-quality-benchmark.md)を必ず併読する。「銀紋の流墨」（第2稿②）がLORE全体の最低遵守ベンチマーク。カード表面の発光・細部・物質変化と動作の一体感を、今後の新規制作／改修で下回らないこと。リフトには②を採用。

## 基準リファレンス

[2026-09-20 Toon 動画と分析](vfx-references/2026-09-20-toon/README.md)。ユーザーが渡した135.33秒の画面録画を基準に、「原神ライク」という希望を具体的な形・色・時間変化へ落とし込む。映像内には Vefects の表記がある。原神の実素材であるとは確認していない。

世界観の正典は引き続き [world-bible.md](world-bible.md)。今回の合意は VFX の表現様式であり、カード・背景・キャラクター全体の画風変更ではない。

## 映像から確認した特徴

| 要素 | 観察した描写 | LORE で採用する基準 |
| --- | --- | --- |
| シルエット | 炎の尖り、煙の丸い塊、液体の曲線に明確な輪郭がある | 一瞬の静止画でも形と方向が読める主形状を作る |
| 色面 | 煙・緑の飛沫は大きな色面。炎は白黄色の芯と橙色の縁。発光には柔らかい部分もある | 主色・明るい芯・必要な影色を整理する。全体を一様にぼかさない |
| 消え方 | 塊が三日月・穴・細い断片へ変わり、最後に小さな欠片が残る | 透明度だけでなく、輪郭の欠け・分裂・縮小で消す |
| 衝撃 | 小さな光の塊から、尖った放射形が急に広がり、裂けた弧へ移る | 短い明確なピークと、その後の減速・消失を分ける |
| 炎 | 芯が太くなり、細い尾へ伸び、先端が分離する | 上昇方向に沿う太さの変化と先端の離脱を作る |
| 雷 | 白紫の細い線が点滅し、折れ・分岐・途切れが入れ替わる | 不規則な線の更新と明暗の切替で電気らしさを出す |
| 空間 | 接地点や進行方向が読み取れる。主形状と小片の大きさに差がある | 起点をカードまたはUIに固定し、主形状と補助粒子を分ける |

「高彩度の粒を増やす」だけではこの基準を満たさない。主形状そのものの変形と、発生・ピーク・消失のつながりを設計する。輪郭が明瞭であることと、全てに黒いアウトラインを付けることは同義ではない。

## LORE の読みやすさを守る

- 攻撃力上昇は青、モンスター体力上昇は赤。参考映像の属性色をそのままコピーして、UIとの対応を崩さない。
- バフは上矢印が主役。Toonの煙・光・弧は周辺の補助にし、矢印の飛行経路と重ねない。エフェクト内に数値を追加しない。
- 場に置いたカードの実位置・角度・大きさを基準にする。背景全体や隣のカードまで覆わない。
- ビブリオンの「眼・コンパス環・魔導書」は必要な演出に使う。全エフェクトへ一律に追加しない。
- 白い盤面、カード絵、モバイル実寸でも確認する。参照映像の暗い背景だけで成立する明るさ・透過合成にしない。

## 新規制作の手順

1. 元映像の該当区間と連続フレームを見て、今回参照する「形」「動き」「消え方」を明示する。
2. 主形状1つを先に作る。通常速度と途中フレームの両方で、意味・方向・ピークが読めるか確認する。
3. 色面、細い発光、補助の欠片を加える。補助が主形状の輪郭やUIマークを消していないか確認する。
4. 実盤面に置き、両陣営、スマホ実寸、同時発動、停止・中断を確認する。
5. 録画・代表フレーム・参照区間を保存し、見た目の承認とゲームへの接続確認を区別する。

制作時の仮説: 輪郭マスク、連番テクスチャ、帯状の形状、色を段階的に分ける描画を組み合わせると、参照の形の変化を実装しやすい。これは再現方法の候補であり、参照動画の元シェーダーや制作ソフトを特定したものではない。Blender の使用は必須条件にしない。

初回は参照の保存・分析・制作基準化を実施。その後、[5種類のプレイ演出](vfx-prototypes/2026-09-20-toon-play/README.md)を新たに実装し、実盤面で比較できる試作を追加した。見た目はユーザー確認待ち。既存の攻撃・体力バフ、マナ上昇、回復、残存魔法の効果発動まで一括でToon化したという意味ではない。

除外演出の追加指定（2026-09-20）: カードが浮上し、全面が黒紫に包まれてからブラックホールへ吸収。その後、ディテールとリアル感のある黒紫の水晶となってリフトへ移動する。水晶は厚み・屈折・反射・内部の陰影を表現し、周囲の魔力はToonの輪郭を維持する。

除外演出の前回修正: ブラックホールは独立した穴として出さない。浮上して黒紫になったカードの面・輪郭そのものが渦へ連続変形し、同じ中心で亜空間へ消える。水晶はその消失位置から現れる。

除外演出の最新指定（v4）: 水晶化を撤回。浮上・被覆・カード自身の渦化は維持し、渦へ消えた直後にリフトへ向かう。残るのは短い黒紫と薄紫の先細りの軌跡のみ。色面と裂ける小片を用いるToon表現を優先し、消失後の静止や水晶・飛行する物体を挟まない。
