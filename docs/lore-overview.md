## 1. 物語の芯

主人公は、失った父母を救うために図書館へ入る。

そこには、世界を守るために真実を封じた八人がいる。外には、故郷を救うために主人公の父を消そうとするレヴナントがいる。主人公はそのレヴナントに育てられた。

父の記録へ辿り着くまでに、主人公は「取り戻したい過去」を持つ人々と、「いま守らなければならない暮らし」に出会う。父との再会は、彼が自分の人生を選び始める転機になる。

中心の問い：

> 王国を守るためには、すべての記録を公開するべきか。それとも、危険な真実を誰かが管理するべきか。

> 大切な人を救うために過去を変えるなら、その先で変わる他の人々の人生を、誰が引き受けるのか。

## 2. 二つのビブリオン

| | 図書館のある時間線 A | 魔導王国へ至る時間線 B |
|---|---|---|
| 舞台 | 主人公が育ち、現在の物語が進むビブリオン王国 | 主人公が生まれた歴史。後に高度な魔導王国へ発達する |
| 古い時代 | 王国・戦争・普通の図書館・リンケージが先にある | 対応する古い時代に水晶は漂着しない |
| 大きな転機 | 約200年前、アチューンの水晶が漂着。八人が接続し、戦争を止める | 遥か後の時代、ユンゲルがマナ増幅器を発明。接収・普及から急成長が始まる |
| 現在の特徴 | 魔導図書館が記録とマナ循環を管理。八人はほとんど老いずに在任 | 増幅器へ依存する文明が破局を観測。帰還計画と危険な渡航を始める |
| 両者の関係 | 水晶が強制渡航の出口を引き寄せる | 水晶を追う部隊と後続の漂着者が、Aのレヴナントを育てる |

Aの未来が必ずBになるわけではない。Bの発明・崩壊・犠牲という順と、Aへの到着順も一致しない。主人公はBでは最初の追跡部隊より早い時代に出発し、Aでは部隊が作った組織に育てられる時代へ到着する。

「Aで200年が経ったから、Bでも200年が経った」とは言えない。後続隊の到着は、Bがいまも存続している証明ではない。AとBの「今」を同期する観測・通信の経路は確立していない。

## 3. 世界の法則

| 項目 | 定めること | 越えない境界 |
|---|---|---|
| 記録 | 観測できた範囲を、出所・時点・欠落とともに残す | 全宇宙の完全な真実ではない。矛盾する証言も残る |
| カード | 原記録の一部を、再現と解除ができる単位へ登録した媒体 | 観測のたびに自動発生しない。あらゆる記録がカードになるわけではない |
| 具現化 | マナで観測内容に基づく再現を作る | 元の本人・魂を呼び出さず、対戦で元の時間線の相手を傷つけない |
| スターター | 事前に使用者へ調律して持ち込む記録 | 初心者用・弱い記録という分類ではない |
| マーケット | 対戦につながる共通書庫から、追加の記録へ接続する | 図鑑全体と同義ではない。人物そのものの売買ではない |
| アチューン装置 | マナを調律し、具現化を安定させ、限界で接続を切る | 精霊アチューン本人ではない。通常使用で歴史を書き換えない |
| 対戦区域 | 出力・範囲を制限し、精神力の消耗として対戦を成立させる | 無限の耐久・電源ではない。破損・過負荷なら停止し、点検が要る |
| 深層記録 | 七人とワルツへの正式勝利で、本人が接続する力を得る | 職位、八人の身体的な負担、自由な因果改変能力は自動移譲されない |
| 時空渡航 | 通常装置の生存到着率は1〜2%ほどとされる | 推計であり全員の生死は不明。ユンゲルの試作の成功率は不明 |
| 因果干渉 | 精霊は出来事を識別して、その原因へ干渉できた | 八人も主人公も、好きな過去を安全に変えられるわけではない |

カード化は「観測 → 原記録の保存 → 再現範囲の選定 → 検証 → 登録・刻印」。公開はさらに別の判断となる。本、証言、地図、観測映像はそのまま保存できる。

## 4. 暮らしと建物

現代ビブリオンは農業、手工業、商業が基盤。馬車、水車、工房、印刷本、新聞があり、図書館周辺と主要区画には水晶灯、浄水・荷役の魔導設備がある。地方には井戸、油灯、家畜による作業も残る。魔法による産業の全面自動化、家庭用の瞬間移動、万能な治療はない。

図書館の外観は、古い石造アーチと木の書架に、復興後の真鍮導路と青い水晶が加わった姿。二百年の改修が重なる。人間が暮らし、修理し、使い続けている建物として描く。

| 場所 | 行われること | 物語・日常で見えるもの |
|---|---|---|
| 前庭・受付 | 選抜、来館、申請 | 行列、荷車、掲示、登録係 |
| 公開閲覧室 | 研究、読書、普通のリンケージ | 返却箱、読書する市民、閉館を知らせる係 |
| カード登録室 | 原記録の照合、試験、刻印 | 未刻印の媒体、訂正票、登録待ちの箱 |
| 七領域の研究室 | 専門調査、認証、マスターとの交流 | 人物ごとの生活と仕事の違い |
| 実習場・対戦場 | 具現化、訓練、公認デュエル | 境界柱、床の導路、点検する職人 |
| 循環設備 | 供給と回復の管理 | 交換部材、巡回表、供給待ちの街区 |
| 封架区域 | 危険な記録の管理 | 保存された原記録と、消去された危険な複製の区別 |
| 中核 | 水晶、八人の接続、深層記録 | 通常の閲覧とは異なる接続が起きる場所 |

## 5. 勢力と人物

王室と図書館は同一組織ではない。王室は行政と軍事を担うが、記録と魔導基盤について八人の承認を無視できない。停戦と自治の成立後も、貴族、都市、商人、図書館の間には利害の違いがある。

レヴナントは未来の精鋭部隊、その子孫、現地の協力者、後続の漂着者から成る。「この危険を冒して来る人間は、同じ救済目的の仲間だ」という前提があり、主人公を保護した。人間を育てる優しさと、赤子のユンゲルを殺す組織方針を同時に持つ。

### 確定している中心人物

- **主人公**：ユンゲルの息子。八歳で漂着し、レヴナントのもとで育つ。父を救うために選抜を受ける。父の名を伏せ、入館後は組織と連絡を断つ。
- **ユンゲル**：農夫であり、古代ルーンの第一人者。増幅器を発明するが公表せず、王国による接収と脅迫で研究を奪われる。処刑命令を受け、息子を一度限りの装置で逃がす。
- **主人公の母**：親族への報復を恐れながら息子の脱出を支え、ユンゲルと残る。息子が生きることを夫婦で選ぶ。
- **ワルツ**：グランドマスター。八人の中心。かつては戦争孤児で、反王国義勇兵団を興した。停戦を実現した後、自分も承認する側の権力者となった。
- **アリエス**：七人の一人。教育と閲覧資格を担当。速い判断と攻めの姿勢を持ち、願いと能力を区別して挑戦者を見る。
- **ゼノ**：修練生の司書。初回案内・実習とシングルで主人公に関わる。二百年前の白い生き物とは同一視しない。
- **セナス**：崩壊当時の王国一のプロ選手。未説明のマナ条件によってワルツに敗れた不公平感には理由がある。現代の所属や生死は未確定。
- **白い生き物**：水晶とともに現れた、機械とも生物ともつかない存在。精霊への敬意と軽口が同居する。名前・現在の所在は未確定。

## 6. 制作側の時系列

### B：主人公の故郷に起きたこと

1. 千年以上、魔法の出力と運用の限界が大きく変わらない時代が続く。
2. ユンゲルがマナ増幅器を研究・完成。危険を理解して非公開にする。
3. 王国が連行・押収し、家族を脅して研究を利用する。
4. 敵対勢力も情報を奪う。王国はユンゲルを責め、家族へ処刑を命じる。
5. 八歳の息子が一度限りの装置で出発する。
6. 増幅器の普及により文明が急成長。引き出す量が回復を超え、依存と異常が広がる。
7. 高度な観測技術がアチューンと文明崩壊の未来を捉える。
8. 精霊は増幅器のある世界を維持する道を探すが、人間は実現できない。
9. 新しい時空装置への巨費が財政を悪化させる。起動した干渉が複数の時間線へ波及する。
10. アチューンが水晶化して流れを支え、Aへ移る。精鋭部隊が追跡する。
11. まだ存在する各出発時点の魔導王国から後続隊が出る。彼らの到着時点はA側ではばらばらになる。

### A：図書館と主人公の現在に至ること

1. 王国が領土拡大の戦争を続ける。孤児院で八人が出会い、図書館でリンケージを遊ぶ。
2. ワルツが義勇兵団を興し、七人も参加する。
3. 約200年前、水晶が漂着。図書館崩壊、六十人の大会、十五人の選抜、代表戦を経て八人が接続する。
4. 追跡部隊が漂着。レヴナントの礎を築く。
5. 八人が戦争を止め、図書館を再建。レヴナントと接触し、危険な接続変更を拒む。
6. 魔導設備が普及し、八人の管理へ社会が依存する。レヴナントも世代交代と新たな漂着者によって拡大する。
7. 八歳の主人公が漂着し、組織に保護される。育つ中で、父を赤子の時点で殺す方針を知る。
8. 選抜試験、入館、組織との連絡断絶。七領域の任務と資格戦を経てワルツに勝つ。
9. 父の応答する記録へ接続。八人の起源とレヴナントとの交渉の全容を知る。
10. 父の抹殺と水晶奪取を止め、同時に養育者たちの願いへ向き合う段階へ進む。

## 7. 読者に見せる構成

| 部 | 読む内容 | 情報の役割 |
|---|---|---|
| 一・図書館へ | 選抜、登録室、交流戦、閉じた目録 | 父を探す目的と、カード・施設・街の暮らしを体験から知る |
| 二・帰らなかった子供 | 父の農場、接収、逃走、レヴナントでの養育 | 主人公の願いと、組織を離れた理由が分かる。現在の目録との照合から回想へ入る |
| 三・七つの扉 | 七人の任務・対戦・その後、養育者との再会 | 一つの主張だけでは管理の是非を決められなくなる |
| 四・父の声 | ワルツ戦、本人だけが接続できる記録、翌日 | 主人公の最初の願いに感情的な決着をつける |
| 五・八人がいた日 | 図書館崩壊とリンケージ大会、選抜、接続、停戦 | 現在の権力者たちが何を願っていたかを知る |
| 六・帰れない者たち | 魔導王国の崩壊予測、精霊の犠牲、最初の交渉、後続の漂着 | 八人とレヴナントのどちらもビブリオンを救おうとしていたと分かる |
| 終章・明日の約束 | 主人公が自分の言葉で養育者と向き合う | 第一部の到達点を描き、未解決の救済と制度の問題を次へ渡す |

小説では循環→検証→外部接触→幕間→探索→安全→教育→封印の順を採る。これは読みやすさのための一つの編集順であり、ゲームの攻略順ではない。ゲームでは七ルートを同時に開放し、各ルート内で必要な説明を完結させる。人物編の閲覧も任意。

小説内の対戦は、現在のルールと矛盾する新効果や専用カードの数値を確定しない範囲で描く。最終的なプレイログ、専用デッキ、難易度は別途制作する。

終章で主人公が養育者へ父の名を明かす場面は、今回の草稿で加えた展開。養育者個人への告白であり、組織全体への即時の伝達やレヴナントの和解は描かない。この先の対立は未解決のまま残る。

## 8. 第一部で答えること・残すこと

第一部で答えるのは、主人公が選抜を受ける理由、父の名を伏せる理由、レヴナントと連絡を断つ理由、八人が彼の正体を知っていたこと、記録へ接続する条件、父が息子に願ったこと、八人と第三勢力の成立である。

父の「俺の運命は不変」は、父自身の境遇についての言葉として残す。世界の全歴史が絶対に変わらないという宣言にはしない。記録の応答が保存された記憶か、限定的な過去との接続かも確定しない。

残す謎は、ルーンの起源、ユンゲルの出自、主人公の存在の痕跡が欠けた仕組み、精霊の意識、白い生き物の所在、帰還が同じ世界を救うのか別の分岐を作るのか、八人の接続を安全に解く方法である。

第一部の勝利だけで王国の政治は変わらない。しかし主人公が独立して深層の記録を確かめられるようになることで、八人だけが証拠に接続できる状態は変わる。続編では、異議申し立て、公開範囲の検証、漂着者保護など具体的な制度と選択へつなげる。故郷の救済や八人の解放を、未執筆のまま成功したことにはしない。

## 9. 整理にあたって統一した点

- 二つの時間線の順序と、読者への提示順を別表にした。
- 七人全員を制作し、ゲームではアリエスを最初に固定しない。
- 父の記録の存在と資格条件は、共通導入のワルツとの場面で伝える。
- 「普通に閲覧できる資料」「カードの再現」「本人だけが接続できる深層記録」を分けた。
- 原本の危険な複製を消す行為と、証拠となる原記録を捨てる行為を分けた。
- レヴナントの養育と抹殺方針の両方を前半から描く。精霊の犠牲との全因果は後半で明かす。
- 過去の三本文は詳細資料として残し、小説では重複する導入・説明・回想を整理した。
