# LORE 카드 효과 텍스트 표기 규칙 (v21)

모든 카드의 효과 텍스트는 ko/ja/en 3개 언어에서 **동일한 구조**를 따른다.
구현: `client/src/shared/cardText.ts`(빌드 시 전 카드에 기계 적용) · 렌더링: `ui/cardView.ts` `.fx-tag` 칩.

## 1. 발동조건 태그 【…】

효과 문장은 반드시 **발동 조건 태그**로 시작한다. 태그는 카드 위에서 강조 칩으로 렌더링된다.

| 트리거 | KO | JA | EN | 소스 필드 |
|---|---|---|---|---|
| 소환한 순간 1회 | 【소환시】 | 【召喚時】 | 【On Summon】 | `onSummon` |
| 함정: 공격에 반응 | 【피격시】 | 【攻撃された時】 | 【When Attacked】 | `react` (공격 반응류) |
| 함정: 상대 마법에 반응 | 【마법 반응】 | 【魔法に反応】 | 【On Enemy Spell】 | `react: nullspell` |
| 함정: 상대 소환에 반응 | 【소환 반응】 | 【召喚に反応】 | 【On Enemy Summon】 | `react: pitfall` |
| 필드에 있는 동안 계속 | 【상시】 | 【常時】 | 【Passive】 | `aura` / `condAtk` |
| 자신 턴 시작마다 | 【매턴】 | 【毎ターン】 | 【Each Turn】 | `turnFx` |
| 영구마법(무기한) | 【영구】 | 【永続】 | 【Permanent】 | `ench` (val 99) |
| 기한부 영구마법 | 【지속 N턴】 | 【持続Nターン】 | 【Lasts N Turns】 | `ench` (val<99 또는 `ENCH_TURN_LIMITS`) |
| 소환 조건 | 【조건】 | 【条件】 | 【Requires】 | `summonReq` |

- **태그 없는 마법 효과 = 시전 즉시 발동.** (마법의 기본형에는 태그를 붙이지 않는다)
- 한 카드에 여러 트리거가 있으면 절마다 태그를 앞세운다 (`【조건】… · 【소환시】…`).
- 특수 트리거는 같은 형식으로 새 태그를 만든다 (예: 미믹 파티 【보물상자 반응】).

## 2. 지속시간 표기

- `(이번 턴)` = 이번 턴 끝까지 / `(지속)` = 그 몬스터가 필드에 있는 동안 / `(영구)` = 플레이어 단위 영구.
- 【지속 N턴】 영구마법은 필드에서 **남은 턴 배지 ⏳N**이 크게 표시된다 (남은 1턴이면 점멸).
- 【영구】 영구마법은 필드에서 **턴 배지를 표시하지 않는다** (99턴 카운트 폐지).
- turns=99지만 bornTurn 기준으로 만료되는 카드(혈귀술 14턴, 고대 문명 13턴)는
  `cardText.ts`의 `ENCH_TURN_LIMITS`에 등록하면 텍스트 태그와 ⏳배지가 함께 따라온다.

## 3. 파괴 선택 = 양쪽 필드 (v21)

대상을 **선택**하는 파괴 효과(destroyMon / destroyTrap(전부파괴 제외) / destroyEnch /
신수 / 블러드 샤워 / breaktrap / 포식 시너지)는 **자신 필드의 카드도 선택 가능**하다.

- 텍스트: '적/상대' 한정을 빼고 문미에 **(양측) / (両方の場) / (either side)** 마커.
- 자기 카드를 자기 효과로 파괴해도 그 카드의 파괴/사망 처리(토큰 제외, 미믹 시너지 등)는 동일하게 발동한다.
- 아우라(ward)는 **상대의** 효과만 막는다 — 자기 아우라 몬스터는 자기 효과로 파괴 가능.
- 전체 파괴(상대 전부/전멸류)와 무작위 파괴가 아닌 것, 자동 최강 파괴는 종전대로 상대만 대상.
- 봇은 자기 카드를 부수지 않는다 (적 대상이 없으면 취소, 취소 불가면 자기 최저가치).

## 4. 신규 카드 작성 시

`cards.ts`에는 종전 관용 표기(`소환시: …`, `영구: …`, `공격을 받으면 …`)로 쓰면 된다 —
빌드 시 `standardizeCardTexts()`가 태그 표기로 자동 변환한다. **새 트리거 문구를 발명하지 말 것.**
어색하게 변환되는 카드는 `cardText.ts`의 `OVERRIDE`에 3개 국어 완성 텍스트를 넣는다.

- 다른 카드의 스탯을 텍스트에 하드코딩하지 않는다 (밸런스 패치 드리프트 방지 — 관련 카드 썸네일이 실제 스탯을 보여준다).
- `(시전 N)` / `(소환 N)`은 문미에 두면 배지로 자동 분리된다.
