# 対象選択・誤発動のUX監査 — 2026-10-08

対象はカードカタログ、手札の使用から対象選択まで、即効購入、召喚・報酬後の選択、取り消し、時間切れ、再接続、BOT。全カタログの分類は `catalog.json`。個別カードの全組み合わせを実対戦で網羅したという意味ではない。

## 修正

|問題|変更|
|---|---|
|対象を選ぶ前にカード・マナを消費していた|公開情報だけで決まる24種類の魔法は、発動前に対象を選択し、確定と同時に送信。キャンセルはゲーム操作を送らず消費ゼロ|
|選りすぐりの剣が自分側限定だった|ユーザー指定に従って両方の場を候補に変更。相手のオーラは対象外。相手を選ぶと強化先について明示|
|相手側への剣の強化の期限|付与ターンを記録し、そのターン終了時に加算した量だけ解除。他の一時強化を消さない|
|自動破壊が味方を選ぶ場合も即実行|城壁破砕・狙撃の単体自動破壊は発動前に実際の対象と自分／相手を表示。自動選択ルールは維持|
|自傷・全体効果・手札破棄・相手への利益|明示したリスクカードと追加効果のある状態で発動内容・消費マナを確認。自傷召喚・合成・ワインコレクターも対象|
|即効魔法の購入がそのまま発動|購入前にコストと効果を確認してキャンセル可能|
|選択肢の所属が分からず即確定|共通カード選択に自分／相手を表示。cardChoiceは選択後に確定する操作へ。複数選択も所属を表示|
|自分モンスター選択で不正UID・非卵が選択を消費|選択待ちを維持するよう修正。S3の種族不可をサーバーでも検証し、吸血鬼限定などの盤面候補を一致させる|
|強制メニューにも取消ボタンが出る|必須選択はallowCancelを尊重。任意選択ではEscも利用可能|
|確認中にターン終了・新しい状態が来る|確認を閉じて破棄。古いカードUID・無効対象・重複対象はサーバー側でも消費前に拒否|

## 取り消しと情報の境界

- 対象プレビューはエンジンを試行実行しない。ドロー、ダイス、隠れた罠の反応を発生させず、デッキ順も表示しない。
- 未確定のレビューはローカルにのみ存在し、カード・マナ・使用回数・乱数・相手の状態を変えない。
- 確定済みの処理を、結果を見た後で返金・巻き戻しする機能ではない。発動後の追加選択は従来の必須／任意ルールに従う。
- 選択後に発動時反応で状況が変わった場合、別の対象へ自動で差し替えない。別効果の選択や運命の輪は通常の選択画面で処理する。
- 選りすぐりの剣以外の対象範囲は拡張しない。味方専用の強化を、敵に強制適用する変更ではない。
