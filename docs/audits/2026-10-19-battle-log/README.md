# 対戦アクションログ監査（2026-10-19）

`Action` の全10種と、選択効果、クライアント表示、オンライン送信、再接続を追跡。

| 操作・経路 | 監査結果と対応 |
| --- | --- |
| play | 召喚・魔法・クエスト・旧罠セットは既存ログあり。解決済み効果の「満杯」「できません」まで消す表示側の文字列判定を廃止。実際の操作拒否だけ明示フラグで通知・非公開化。 |
| buyMarket / buySupply | 購入カード・消費マナの既存ログを維持。 |
| refresh | 従来の「提示更新」を「マーケットをリロール」に変更。マナ／カウンターの消費と公開された新しい候補を記録。カード効果の無料・強制更新も結果を記録。 |
| attack / chooseTarget | 確定した攻撃・対象・結果の既存記録を維持。未確定の対象選択・取り消しは操作履歴にしない。 |
| reorder | モンスター名と移動前後の1始まり位置を追加。 |
| pick | 運命の輪の出目維持、任意効果の終了、回収カード名を追加。世界樹の雫消費／辞退、防具職人の選択／強化先、エルフの破壊対象、選ばれし剣の一時強化、ハイエルフの公開除外／確認終了を追加。 |
| endTurn | 行動者、残りマナ、手札枚数を追加。手札上限の処理後に確定。開始効果とスキップも正しいターン見出し内に移動。 |
| surrender | 既存記録を維持。 |
| サーバー時間切れ・切断敗北 | 原因を追加。時間切れ解決中に勝敗が決まる場合も更新を送信。 |
| 墓地からデッキを再構成 | シャッフルした枚数を追加。カード順は非公開。 |
| 再接続・Durable Object復帰 | 公開ログ／ターン見出しだけを64行以下の永続バッチに保存。ゲーム状態とログのカーソルを同じ書き込みで保存。初期化時は履歴を置換し、演出の再生や重複追記をしない。 |

## 非公開情報と互換性

- デッキからのサーチは枚数のみ。手札・伏せカード・乱数・運命の輪の未確定スナップショットを履歴に保存しない。
- 無効入力、拒否されたプレイ／攻撃／リロールを相手の履歴に追加しない。
- `ready.battleLogVersion:1` のクライアントだけ履歴復元を使用。既存タブには従来の初期イベントを送る。
- この更新より前に保存されていなかった履歴は復元できない。既存ルームでは更新以降の公開ログを蓄積する。
- 試合一覧から終了済み対戦を再生する新機能ではなく、現在の対戦ログと同じルームへの復帰が対象。

- `tests/battle-action-log.mjs`: 両側・全アクション種別、選択効果、非公開情報、ソケット送信、切断中の行動、復帰、原子的書き込みの失敗。
- `tests/battle-log-ui.mjs`: 実表示・実コントローラーのログ処理、相手色分け、カード名リンク、日英切替、演出キューと履歴置換の順序。
- 既存の運命の輪／世界樹／ターゲット選択／開始時同期／ルール・セキュリティ回帰テスト。
- ローカルブラウザーで実GameLogと実リデューサーを使用したリロール・復元・日英切替を確認。本番の認証済み対戦での画面確認とは区別する。
- 型検査と本番ビルド。最終デプロイはコミット済みmainをガード経由で再検査する。
