# 全体監査と報酬・再接続の修正（2026-10-15）

対象: 最新の `gh/main`。HOME、デッキ、カード、ランキング、フレンド、ショップ、チュートリアル、プロフィール／設定、ゲームエンジン、BOT、対戦通信、報酬／購入処理。制作途中の元チェックアウトは変更せず、独立した worktree で監査した。

## 修正した問題

- **P1: 自己申告のBOT勝利で経験値・シャード・クリア記録を取得できる。** `/api/track/bot` が認証だけで勝利申告を信用していた。修正前に回帰テストで再現。互換レスポンスは残すが書き込みは行わず、既存のサーバー GameRoom の確定結果だけが対戦履歴と報酬を作る。4難易度の正規初回勝利・敗北・引き分け・再実行・レベル上限・支払いロールバックを検証する。
- **P1: 廃止済みチュートリアル報酬をキーだけで請求できる。** 現行チュートリアルには操作履歴の検証があるが、古い `tut:*` / `tuto:*` の請求口が残っていた。新規請求を410で拒否し、現在のレッスン完了経路へ統一。過去の支払い記録や移行計算は保持する。
- **P1: 再接続に失敗してHOMEへ戻っても、次の対戦開始で同じ無効な部屋へ戻される。** 再接続を断念してHOMEへ戻る操作で保存情報を消去する。一時的な切断・再試行中には消さない。ログアウトでも消去し、新規保存分にアカウントIDを付けて他アカウントへの持ち越しを拒否する。壊れた保存値、期限切れ、無効な部屋IDも除外する。旧保存形式はサーバーの参加資格検証を維持して読み込める。

## 検証と再現方法

- `npm run typecheck`、`npm run build`、`npm run test:production`。
- `tests/audit-reward-authority.mjs`: 自己申告によるEXP・対戦履歴・旧報酬の新規作成を拒否。
- `tests/player-experience.mjs`: 実際のGameRoom確定処理からの正規報酬と原子性。
- `tests/resume-account.mjs`、`tests/audit-session-browser.mjs`: 保存形式、アカウント分離、切断後のHOMEボタン、ログアウト。
- `tests/starter-collection-browser.mjs`: 5画面サイズ、購入と応答喪失後の再試行、所持制限、ガチャ結果、履歴、低減モーション。
- `tests/menu-content-browser.mjs`: 3言語、設定、招待、クーポン、提供割合。
- `tests/tutorial-academy-browser.mjs`: 現行の実盤面チュートリアル操作。
- `tests/full-game-staging-audit.mjs`: ステージング専用の一時アカウントで実パスワードログイン、7画面×4サイズ、デッキ保存、購入の重複防止、非公開対戦、実WebSocket再接続、結果・報酬確定、BOT開始・投了。公開マッチングには参加せず、検証用アカウントはfinallyで削除する。`--api-only` は画面検証を省略する。

BOT NPCテストは18デッキ×先後2通りの36シミュレーションを実行するため、低速／高負荷ホストでもケースを省略しないよう、個別のタイムアウトを10分へ設定した。テストの期待値・ケース数は減らしていない。

## 確認範囲の限界

有限の回帰テストと代表的な実操作であり、全カードの全組合せの無欠陥保証ではない。OAuth／外部メールの配送、Steamネイティブ実行環境、実ユーザー同士の公開ランクマッチ、全VFXの新規品質承認は別途。既存の演出デザインやゲームバランスは変更していない。本番へのデプロイは対象外。
