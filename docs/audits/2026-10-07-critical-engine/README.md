## 結果

| 不具合 | 再現と影響 | 修正 |
| --- | --- | --- |
| ガーディアンゴーレム NWL3 | 致命攻撃の直前に気合を補充し、何度でも体力1で耐える。攻撃力0でも増加 | 正の非致命攻撃ダメージを気合なしで耐えたときだけ追加。致命傷は既存の気合を消費する |
| C01 回復・ダイスの再帰 | 両者に BLOOD_RITE・LUCKY_ECHO・LIFE_CYCLE×7、seed 2、GRAPE使用でスタックオーバーフロー。WORLD_HEART追加時はターン終了でも再現 | 同じプレイヤーの幸運の残響は自身の効果解決中に再発動しない。別の処理では再び有効。ダイス記録やカジノ用カウントは維持 |
| C02 効果召喚の制限回避 | 隠遁者の召喚禁止中でも VAMP_PACT が召喚。孤独の2体上限がある盤面に3体目を召喚 | トークン・吸血鬼・通常の効果召喚で共通の召喚可否判定を使用。禁止時に進化回数、融合素材、蘇生元カードを失わない |
