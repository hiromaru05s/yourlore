2026-10-26。ユーザー指定「召喚中のモンスターは拡大手札より奥に表示する」を適用。

最新採用実装 `d74077f2` を土台に、`client/src/ui/boardView.ts` と `client/src/styles/reading-board.css` を修正。元のDesktop作業フォルダは未確定変更があるため変更していない。修正コミットは `8edc8f06`、検証の追加は `5c49467f`。

## 修正

召喚の印刷面・専用演出はbody直下の135/136に描画される。一方、拡大手札は外側の#appの1とstageの6という重なりの内側にあり、手札自身の120を上げるだけでは抜け出せなかった。実ゲームは#app直下に盤面rootを追加するため、#app自身にreading-boardクラスは付かない。公開後のDOM検査でこれを発見し、親を含む実構造でCSSとブラウザー試験を修正した。

拡大中だけ実際の#handを.game直下へ移し、#appの重なり制約を解除する。手札は145、確認ダイアログは150。stageは6のまま保ち、盤面のカード・マーケットと3Dテーブルの前後関係を維持する。閉じると#handを元の親・挿入位置へ戻す。カードDOMをコピーせず、uid・条件表示・ポインター操作を引き継ぐ。

## 検証

`tests/summon-hand-layer-browser.mjs` は製品main.tsと同じCSS一式、現在のcontroller・engine・盤面を読み込む。#appの子に盤面rootを追加する実ゲームと同じ親構造で検査する。旧実装では、実際の手札位置の描画順が `hand:1 / effect:0 / app:1 / stage:6 / handZ:120` となり失敗した。修正後は#appのz-indexが拡大中だけautoになり、手札が召喚より手前になった。
