**承認済みの最低ベンチマークは「銀紋の流墨」（第2稿の②）。今後のLOREアニメーションの新規制作・改修は、この品質を下回らないこと。**

これは全演出を紫・渦・紋様へ統一する指示ではない。動きの目的、素材、配色は各演出に合わせる。承認されたのは、発生源・表面ディテール・主形状・時間変化が一体になった仕上がりの水準。

## 最低限必要な品質

| 観点 | 必須条件 | 不十分な例 |
| --- | --- | --- |
| 発生源との一体感 | カード・物体の位置、傾き、輪郭、動作と演出が結びつく | 独立した輪・粒・光線を近くに重ねただけ |
| 物質としての連続性 | カード面→光や流体→移動→到着まで、同じ物質が変化して見える | カードを消して別の画像・物体へ突然交換する |
| 表面ディテール | 元の絵柄や枠を読ませ、表面・輪郭に沿う光や模様がある | 全体の色替え、透明度、均一な外周グローだけ |
| 主形状と細部 | 太い面、細い縁、微光の役割が分かれ、停止しても形が読める | 粒の量や強いぼかしで豪華さを代用する |
| 明暗と奥行き | 暗い芯、中間の色面、狭い明部、前後の重なりがある | 一様な発光で表面が白飛びする |
| 時間設計 | 予兆・溜め・変化・ピーク・余韻に因果関係と緩急がある | 全要素の同時出現、等速、同時消失 |
| 消え方 | 収束、裂け、先細り、形のほどけで物質の変化を見せる | フェードアウトだけで終わる |
| 接地と到着 | 影や局所光が場との関係を示し、到着反応が接触に同期する | 空中の影、接触前の衝撃、カードと独立する環 |
| 可読性 | 実寸の白い盤面とスマホで成立し、隣の情報を隠さない | 暗い拡大プレビューだけで成立する |
| 制御と性能 | 反復・同時発動・中断・低減モーション・資源解放を扱う | 終了後の残骸、スキップで消えるカード、GPU蓄積 |

UIの小さな動作に魔法演出を足す必要はない。目的に応じた精度・滑らかさ・一貫性がこの基準に見合うこと。低減モーションやWebGL非対応時は明示的な代替経路として簡略化できるが、標準経路の品質引き下げの理由にしない。

## 制作・レビュー手順

1. 上記②の**動画**と代表フレームを確認する。どの細部・運動・連続性を今回の演出へ翻案するか書く。
2. 発生源、変化、移動、到着の担当と共通時計を設計する。カードが動くなら、光と物質の境界もカードの動きに追従させる。
3. 主形状を決め、表面の変化、前後の層、光、補助粒子の順で作る。
4. 通常速度の連続再生、低速、発光・変形・転送の途中フレーム、実盤面の双方で基準と比較する。
5. 白／暗背景、PC／スマホ、両陣営、反復・同時発動・途中停止を検証し、動画・画像・検証結果を保存する。
6. **機能テストに通ったことと、見た目が基準を満たしたことを分けて報告する。** 静止画だけで動きの品質を合格扱いしない。

シェルフ→デッキなどへの適用例: カードの先端から表面がほどけ、その同じ帯が移動し、到着先のカード面に戻る。ゲートや環はこの連続変化を支える要素として位置・接触時刻を合わせる。

## 適用範囲と進捗

- リフト除外: 銀紋の流墨を通常経路として実装。通常除外・クイック魔法・生成カードが共通経路を使用。
- その他の既存アニメーション: 今後の制作・改修・レビューでこの基準を必須とする。今回の変更で全演出が同水準へ更新済みという意味ではない。
- デプロイ: 当初はローカル適用のみ。2026-09-29の追加指示「これステージングにあげて」によりステージングへ反映。本番への公開は行わない。[公開記録](ui-rework/2026-09-29-silver-ink/staging/deployment.json)。

従来の[Toon制作指針](vfx-art-direction.md)も併用する。世界観・色の意味・公開情報の扱いは既存の正典とゲーム仕様を維持する。
