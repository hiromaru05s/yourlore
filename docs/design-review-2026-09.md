### 0-2. エンジンの構造事実（設計に効くもの）

- **手札は毎ターン全捨て**、マナは毎ターン全回復（`endTurn` :1018 / `beginTurn` :471）。ターン間で持ち越せるのは「場」「永続魔法」「伏せ罠」「カウンター」だけ。
- **固定マーケット8枚は無限在庫**。買っても消えない。両者の争奪が発生しない。
- **提示4枚は毎ターン再抽選**、更新1マナで回数無制限。
- **攻撃は強制ブロック**: 相手の場にモンスターがいれば必ずそれを殴る（暗襲以外）。**反撃ダメージなし**。攻撃側のリスクは伏せ罠のみ。
- 購入カードは**捨て札**へ（次のシャッフルで山に入る）。デッキ切れで捨て札をシャッフル。
- 種族シナジーは「**場にある異なるID数**」で判定、段階ごとにゲーム中1回。
- 60ターン（各30）でHP判定。`rank.ts:96` のコメントは「75ターン」で不一致。
- `taxFlag` は購入時に立てるだけで**どこからも読まれない**（死に状態）。
- 手札上限なし。マリガンなし。

### 0-3. メタ層の実装状況

- 構築: 固定アチューン1 + 自由8枚。**構築プール35枚**（noShop）と **購入プール236枚**の二層。コピー上限は実質なし（8）。プリセット5、ウォッチリスト12。
- ランク: Elo(K=32)、月次シーズン、ソフトリセット、GM=上位25。
- 通貨💎の**出口がゼロ**（ショップ空、招待報酬 earned→paid 未実装）。
- 単人モード・観戦・リプレイ・エモート・クエスト・カード解放: なし。
- チュートリアルバッジが旧キー `tut:6` 参照で、新チュートリアル卒業者は取れない。
- 分析: 試合ごとに使用/購入カードJSONと `bver` を保存済み → **公開メタダッシュボードの素材は既にある**。

## 1. LoL から借りる設計原則 → LORE への写像

LOREは既に構造的にLoLに近い。**8枚デッキ = チャンピオン選択、マーケット購買 = アイテムビルド、提示 = ショップの品揃え運**。この見立てを明示すると、足りないものが見える。

| LoL の柱 | LORE の現状 | 足りないもの |
|---|---|---|
| **役割の明瞭さ**（タンク/ASSN/メイジ） | 18系統あるが、名前・見た目・資源が系統ごとに統一されていない | 系統ごとの「資源1つ・勝ち筋1つ・弱点1つ」宣言（§3） |
| **カウンターピック** | 幽霊↔世界樹、貴族↔アサシン、魔族↔呪術師などは良い | 系統の半分に専用カウンターがない。「対策札を買う」判断を促す情報表示 |
| **パワーカーブの位相**（早期/中期/後期チャンプ） | アグロ(幽霊)・ランプ(世界樹)・ビッグ(卵)で存在 | 「中期に強い」系統が薄い。後期系統の**到達を可視化するUI**がない |
| **中立目標**（ドラゴン/バロン） | なし。マーケットは無限在庫で争奪が起きない | 有限在庫・登場イベント・争奪（§4-3） |
| **視界/情報戦** | 伏せ罠、公開済みカード一覧（revealedCards）は良い基盤 | 情報を「使う」カード・UIがない（宣言、推理） |
| **逆転要素**（バウンティ） | 最後の砦、背水系は少数 | 負けている側に流れる資源（§4-5） |
| **技術介入 vs マクロ** | ターン内はほぼ「全部殴る・全部使う」が正解 | 攻撃しない理由、カードを残す理由（§2-2, 2-3） |
| **アイテム化のテンポ** | 購買は捨て札→次のシャッフル待ち | 「即戦力購買」の選択肢（傭兵契約） |
| **ピック/バン** | なし | 購入プールへの1枚バン（§4-2） |
| **ルーン/サモナースペル** | アチューン固定のみ | 試合前に選ぶ「紋章」1つ（§4-1）— 最も費用対効果が高い |
| **メタの透明性**（op.gg） | 管理画面にのみ | 公開メタページ（§4-8） |

## 2. 構造的フィードバック（ルール層）

### 2-1. 手札全捨てが生む長所と欠落
長所: ターンが独立し、初心者が「何を残すか」で悩まない。テンポが速い。
欠落: **計画の奥行き**がない。「次のターンのために取っておく」「相手の除去を誘ってから本命」がすべて不可能。対戦相手の手札を読む要素もない。
提案（軽量）: **キープ**キーワード — このカードは手札に残せる（ターン終了時に捨てない）。数枚に限定すれば全体ルールを変えずに「持ち越し」を導入できる。パッシブ辞書に1語追加するだけ。
提案（重い）: ターン終了時に1枚だけ残せる共通ルール。読み合いは増えるが、初心者の判断負荷も増える。まずキープカードで様子を見る。

### 2-2. 「攻撃は常に正解」問題
反撃がなく、疲労以外のコストもないため、**殴らない理由が存在しない**。決断が生まれるのは伏せ罠がある時のみ。
提案:
- **守勢**キーワード: このターン攻撃しなかったモンスターは相手ターン中 体力+3 / 挑発。→ 攻撃と防御のトレードオフが1語で生まれる。
- **反撃**キーワード: 攻撃されたとき攻撃者に自分の攻撃力の半分を与える。全体ルールにせず、壁系モンスターへ限定付与。
- 伏せ罠は既に「殴るか迷う」を作っている唯一の装置なので、罠の採用率を上げる方向（罠職人系、罠のコスト帯拡充）はゲーム性に直結する。

### 2-3. バースト決着 14.5% と情報の非対称
毎ターン手札が入れ替わるので、相手の大技は**原理的に予見不可能**。「気付いたら23点」が起きる。
提案: 大型直接火力（星墓の落下・ナイトロード・特級吸血鬼）に**チャージ**（発動の1ターン前に場に公開される「予告」状態）を導入。相手は1ターンの対応猶予を得る。予告中に破壊されれば不発。これにより「詰み」に読み合いが生まれ、除去札の価値が上がる。§4の「生命保険」型の保険カードも同方向。

### 2-4. 先後差
Bot戦で後攻 54.8%。HP差7点の補正が大きすぎる可能性。人間データ（`matches` の `first-player winrate` は管理画面にある）で確認して、後攻補正を「HP+7」から「HP+4 + 初回提示5枚」のような**選択肢型**に変える案（§4-4）。

### 2-5. 無限在庫マーケット
争奪がないため「相手が何を買ったか」を見る理由が薄い。§4-3で有限在庫案。

### 2-6. 場が薄い（平均2体）
7枠あるのに2〜2.5体。横並べ系統（城・兵士・かかし）が薄いのと、除去が単体高性能で揃っているため。横並べを支える報酬（供物・旗手系）と、全体除去のコスト是正で分布を広げられる。

## 3. 複雑さの予算（遊びやすさの担保）

### 3-1. カウンターの種類が多すぎる
現在プレイヤー/カードに乗るカウンターは **9種類**: 烙印・腐敗・気合・城・商会・提示・ワイン・世界樹・ギルド。さらに卵の孵化/耐久。
提案:
- **表示規格の統一**（色・位置・ツールチップ）を1本化。
- 「城」「商会」「提示」「ギルド」は用途が近い（**貯めて使う**）ので、UI上は同じ「蓄積カウンター」として見せる。
- 新規カウンターは原則追加しない。新要素は既存カウンターの**消費先**として設計する（§5）。

### 3-2. 近縁カードの統合候補
| 統合対象 | 理由 |
|---|---|
| 城壁破砕/狙撃、攻城崩壊/一斉射撃 | 条件がATK≤2 と HP≤3 の差だけ |
| 螺子抜き3種（DISARM1/2/3） | 段階が線形。1枚を「選択式（1枚 or 2枚相手のみ）」に |
| 孵化器/高級孵化器、ぶどう/高品質ぶどう | 線形 |
| ミミックキング/2世 | 2世が完全上位 |
| 虚空砲撃/虚空大崩壊 | 線形 |
| 初級/中級魔力遮断 | 中級が初級所持でさらに強化と複雑 |
| トゲトゲ盾/マジックカウンター | 効果先だけの差 |

削って空いた「枚数」を橋渡しカード（§6）に回す。カード数を増やさず奥深さを増やせる。

### 3-3. 系統宣言（Role Clarity）
各系統に「**資源1・勝ち筋1・弱点1**」を明記し、カード左上の小アイコンや系統タグで表示する。例:
- アサシン: 資源=直接攻撃回数、勝ち筋=ギルド14点+高ATK、弱点=貴族領主/ダンジョン
- 世界樹: 資源=最大体力、勝ち筋=ハイエルフ、弱点=幽霊/血税
- 呪術師: 資源=デッキ内魔法枚数、勝ち筋=汚染+ケロイド、弱点=魔族
これがそのままチュートリアルとメタページの骨格になる。

### 3-4. 「見えて分かる」条件表示
デッキ構成条件（魔法13枚以上、ゴーレム2種、始原1〜8）は**進捗バー**をカードに出す。プレイ中に「あと2枚」と見えると購買判断が楽しくなる（LoLのアイテム進捗と同じ）。

## 4. カード追加以外の要素（システム）

### 4-1. 紋章（Hero Power / ルーン）★最優先
試合開始前に1つ選ぶ、毎試合有効なパッシブ。8枚デッキと独立なので**組み合わせの深さが掛け算**で増え、デッキ自体は複雑化しない。カード実装より安く、アーキタイプの「顔」になる。
候補（各系統1つ + 汎用）:
- 商人の紋章: 提示更新の初回が毎ターン無料
- 屍術の紋章: ターン終了時、墓地の一番上のカードのコストが自分の最大マナの半分以下なら除外して1ドロー
- 血の紋章: 自傷ダメージが半分になる
- 城主の紋章: 兵士/騎士を召喚するたび城カウンター+1（城なしでも蓄積、城召喚時に付与）
- 賭博の紋章: ターン1回、ダイスの出目を1回だけ振り直せる
- 呪術の紋章: 相手が魔法を使うたび、ダイス6で呪い1枚
- 隠者の紋章: 場にモンスターがいないターン開始時、体力3回復
- 傭兵の紋章: 購入したモンスターをコスト+2でデッキを経由せず直接召喚（ターン1回）
- 蒐集の紋章: 除外したカード4枚ごとに1ドロー
- 汎用: 初手+1枚 / 最大マナ+1で開始（アチューン相当） / 提示5枚
バランス上の注意: 紋章は「デッキ8枚の1枚分」を上限にする。

### 4-2. バンフェーズ
マッチ成立後15秒（ランクは既にマーケット閲覧15秒がある）で、各自が**購入プール236枚から1枚バン**。バンされたカードはその試合のマーケット/提示に出ない。効果:
- 相手の8枚（非公開）を推理してキーカードを潰す → LoLのバンと同じ読み合い
- 「必須ピース1枚」で成立する系統（ナイトロード・ケロイド・闇商人）に自然なリスクを付与
- 実装: rollSupply/market生成のフィルタに1行。UIはウォッチリストの流用。

### 4-3. 有限在庫と中立目標
- **固定マーケットを在庫1**にし、買われたスロットは次の自分ターン開始時に補充。相手が欲しそうな札を先に買う「デナイ購買」が生まれる。
- **遺物イベント**: ターン10・20・30に「遺物」カード（強力・1枚限定）がマーケット中央に出現、先に買った側が獲得。ドラゴン/バロンに相当する**時間で区切られた争奪点**。遺物は試合中だけ存在するトークン（void）。
- 遺物例: 「王の玉座」（毎ターン+1ドロー）、「時の砂」（最大マナ+2）、「処刑台」（召喚時、相手最大コストモンスター破壊）。

### 4-4. 先後の選択肢化
後攻は「HP+7」の固定補正ではなく **3択**: HP+5 / 初回提示5枚+更新無料1回 / 最大マナ+1で開始（アチューン1回分）。先攻もミラーで弱い選択肢を得る。数値は人間データで調整。「サイド選択」がプレイヤーの表現になる。

### 4-5. 逆転メカニクス
- **懸賞金ルール**（システム）: 体力差が15以上開いた時、負けている側は次のターン提示更新が無料。小さいが「まだ買える」感を作る。
- **最後の砦**は現状カード依存。システム側に「体力10以下で初めて到達した時に1ドロー」程度の共通ルールを入れると、初心者の絶望を減らす。

### 4-6. マリガン
初手3枚のうち任意枚数を1回だけ入れ替え可能。8枚デッキなので効果は限定的だが、「カル4枚初手」の不快感を消す。

### 4-7. モード
- **ドラフト（アリーナ）**: 3枚提示×8回で8枚デッキを作って対戦。構築プール35枚を毎回全部使わせる最良の練習場。実装はデッキ画面の流用。
- **シールド**: ランダム12枚から8枚選ぶ。
- **単人ローグライク**（既に計画あり）: 「試合をまたいで購入カードが残る」ローグライトは、このゲームの購買システムと極めて相性が良い。Botの難度4段階 + ボスデッキ（各系統の完成形）で「系統を学ぶ」教材になる。
- **デイリーパズル**: 固定シードの局面で「このターンに勝て」。既にseed決定論なので安価。
- **観戦・リプレイ**: 状態が決定論（seed + action列）なので**リプレイはアクションログ保存だけで実現**できる。観戦は redactFor に観戦者視点を足す。
- **2v2**: 大改修。優先度低。

### 4-8. メタの透明性
`matches` に `bver` 付きで購入/使用JSONがある。**公開メタページ**（系統別勝率、購入率、ティア別採用、先後勝率）を出すと、上級者の議論とバランス調整のフィードバックループができる。LoLのop.ggが担っている役割。

### 4-9. 進行・報酬（💎の出口を作る）
現状💎は貯まるだけ。優先順:
1. スリーブ/フィールド/アバター枠（既に設計あり）
2. **系統マスタリー**: 系統で10勝ごとにその系統の演出・称号。系統宣言（§3-3）と連動
3. デイリー/ウィークリークエスト（「腐敗で3体破壊」など系統横断を促す内容）
4. シーズン報酬（ティアごとのカードバック）
5. 招待報酬の earned→paid 実装

### 4-10. ゲーム内 UI で奥深さを支える
- **相手の公開情報パネル**: revealedCards を「相手が使ったカード一覧 + 推定系統」として表示。推理の材料を見せることで、バン・カウンター購買・宣言カードが成立する。
- **ターン計画プレビュー**: カードにホバーで「使った後の残りマナで買えるもの」をハイライト。
- **条件進捗バー**（§3-4）。
- **なぜログ**: 「烙印ダイス3 → 3ダメ」のように因果を1行で。既存ログの拡張。
- **キーワードチップ**は既に良い。新キーワード（キープ/守勢/反撃/遺言/装備）も同規格へ。

### 4-11. バランス運用
- Botハーネスで**ペアA/B**（同seed・同デッキ・片側のみ新カード）を新カード追加のCIに。
- 3ヶ月ごとの**構築プール（35枚）ローテーション**: 数枚入替でメタを動かす。購入プールは固定。
- パッチノートをゲーム内で表示（`BALANCE_VERSION` はある）。

## 5. 資源経済の穴（デッドエンド）と埋め方

資源フロー分析から出た「生産はあるが消費がない」「消費はあるが生産がない」箇所。**ここを埋めるカードは自動的に複数系統の橋になる。**

| 穴 | 現状 | 埋めるカード案 |
|---|---|---|
| **烙印の消費** | 生産者11枚超、消費は火脈点火のみ | 「烙印の審判」spell3: 相手の烙印1個につき3ダメ、烙印を全て取り除く／「焼印の刃」装備2: 攻撃時、相手の烙印数だけ攻撃力+ |
| **自分の墓地の活用** | 回収はリコールのみ、他は全て除外 | 「屍術師」mon4 1/4: 【毎ターン】墓地のモンスター1体を1ターンだけ場に戻す（終了時除外）／「墓所の王」mon6: 墓地のカード枚数分+1/+1 |
| **相手の除外の消費** | 次元幽閉者・黒竜のみ | 「虚無の商人」mon3: 【召喚時】相手の除外カード1枚を自分の手札へ（コスト+2で使用可） |
| **気合の消費** | 致命打生存のみ | 「気合放出」spell2: 自分の気合カウンターを全て取り除き、1個につき相手に3ダメ／「闘気の鎧」: 気合1個につき体力+2 |

## 6. ブリッジカード（系統間の橋）

### 6-1. 現在の接続マップの要約
- **強い橋（既存）**: 血の魔法⇄吸血鬼、カル→虚無、世界樹→エルフ、腐敗→烙印（酸性雨）、腐敗→マナ（スラッグ）、呪術師⇄ルーン、罠→城、アサシン→烙印。

1. **共有資源を経由する**（烙印・除外・最大体力・トークン・ダイス・魔法枚数）。

3. 橋は**新しい弱点も持ち込む**（幽霊が世界樹を罰するように）。

## 8. 系統別の改善メモ（曲線・孤児）

- **アサシン**: 2/4/6/8の偶数のみ。3コスト「影の密偵」（潜伏・暗襲）と5コスト「暗殺教官」（他アサシン+2）で曲線を埋める。
- **吸血鬼/血**: 5コスト以上なし。マナを伸ばす祝祭のペイオフが本体にない → 「血の女王」mon6。
- **選ばれし**: 全員7コスト。3〜5に「見習いの選ばれし」を置いて中盤を作る。
- **魔族**: 魔界が必須すぎる。魔族側に「マナが低いほど強い」報酬（魔界の門）を足し、魔界依存を下げる。
- **卵**: 序盤札がない。抱卵の塔/始原の孵化で他系統と共有。エッグハンターが唯一の回答なのは健全（対策が1枚あれば十分）。
- **ゴーレム**: 2コストがダンジョンのみ。「小石ゴーレム」mon2。
- **孤児カード整理**: 時空間操作（14コスト）、先見の明、瞑想、古代文明、剣鬼、身代わり、復讐、記録者、逆算、奇襲、ダンジョン最下層。→ 削除候補 or 紋章/遺物へ転生（時空間操作は遺物向き）。
- **ギャンブラー**: 最弱アーキ（Bot 37%）。カジノがハブなので「ダイスを振る回数」を増やす安価な札（1コスト「小賭け」: ダイス1個、4以上で1ドロー）で回転を上げる。
