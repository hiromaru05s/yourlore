# LOREの標準UI — 蒼銀の面取り

2026-10-26、ユーザーが4案のうち02を選択し、「全てのポップアップ、ページに適用」「今後のデフォルトUI」と指定。外周の四隅も内側の斜線に沿って落とした版が承認対象。

## 共通仕様

- 深い青の面、細い銀青の輪郭、小さな斜線。厚い白亜枠、立体隅金、大きな結晶を加えない。
- 四角い画像の上に斜線を描くだけでは不十分。外周の塗りも面取りする。
- 素材は `client/public/art/ui/lore-panel-azure-cut.png`。既存の選択済み生成素材をそのまま使用。
- 実装は `client/src/styles/defaultUI.css`。100pxスライスの9分割で線を太らせず、中央の面だけを伸ばす。PCは40px描画／20px面取り、スマホは30px／15px。
- 新しい独立したパネルは `.lore-surface` を使う。共通 `.overlay > .modal` と通常のネイティブ `dialog` には自動適用。
- ページの主内容を一枚の面としてまとめる。入れ子の各行・カード・リスト項目まで同じ枠で囲まない。文字は白青、補助文字は灰青、主要ボタンは青。
- カードの顔、3D盤面、キャラクター、ガチャのフルスクリーン映像は内容アート。額縁UIの対象はそれを説明・操作する情報面。これらの内容アートをパネル画像で覆わない。
- 既存のナビ、ページごとの情報構成、選択／無効状態、入力、スクロール、ダイアログの終了操作を保つ。

以前のメニュー・ポップアップ案と外観が競合する場合、本仕様を優先する。世界観は `world-bible.md`、下ナビや配置は `menu-design-insights.md` に従う。

## 対象

HOME対戦パネル、カード一覧と詳細フィルター、デッキ、ランキング、フレンド、ショップ、プロフィールと設定、ログイン／待機、チュートリアルと初回案内。共通確認・入力・BOT選択・カード選択・勝敗、プレゼント、ガチャ情報・スターター購入・家具プレビュー・描画案内・ルール説明、カード拡大の外枠（説明欄は薄い区切り）。

制作時はPC・狭い画面で、枠外の四角い塗り残し、本文の可読性、カードの欠け、長文スクロール、操作ボタンの表示を確認する。

## 標準ボタン — 02「隅のしるし」

2026-10-26、ボタン比較の02をユーザーが採用し、全ページ・ポップアップへの適用を指定。

- 全周の枠を使わず、左上・右下の短い銀青線で操作面を示す。塗りの四隅は7pxの面取り。
- 主要操作／YESは明るい青、通常操作／NOは深い青。削除はくすんだ赤。戻る・閉じるは控えめに。
- 実装は `client/src/styles/defaultButtons.css`。`client/public/art/ui/buttons/*.svg` を9分割で描画し、幅が変わっても角度や線の太さを保つ。
- 既存の `.btn` とページ・ダイアログ内の通常ボタンに自動適用。新規の独立ボタンは `.lore-button` を使い、主要操作に `.lore-button-primary`、削除に `.lore-button-danger`、控えめな戻る／閉じるには `.lore-button-quiet` を追加する。
- ホバーは少し明るく、押下中は暗くする。選択中は明るい青と下線、無効は減光、キーボードフォーカスは外周の輪郭で区別する。既存のARIA属性・状態クラスを使う。
- カード画像・キャラクター選択タイル・HOMEの対戦紋章・アート付きデッキ面・クエスト面は内容アートやパネルとして維持。下ナビとヘッダーの採用済み構成も維持する。
- サイズ、絶対配置、アイコン、押した時の処理は各コンポーネントが担当する。共通ボタンに切り替えるために購入や認証の処理を変更しない。

## 対戦中・決着後の例外（2026-10-26）

ユーザー指定により、盤面の END TURN と勝利・敗北・引き分け後の結果画面は、共通パネル／共通ボタンの適用対象から外す。END TURN は既存の盤面専用の物理ボタン、結果画面は採用済みの finale 表示と専用操作ボタンを維持する。その他のページ・ダイアログは標準 UI を使う。

## ランキングの名前リンクの例外（2026-10-26）

ユーザー指定により、ランキングの名前のプロフィールリンク（`.lb-profile-trigger`）は共通ボタン装飾の対象から外す。背景・隅線を付けず、名前のホバー時に文字色と控えめな下線で操作を示す。キーボードフォーカスを維持し、ランキングとフレンドから共通プロフィールを開く。

## ガチャの購入ボタンの例外（2026-10-27）

ユーザー指定により「1回引く」「10回引く」は専用のリッチな外観を使用する。1回は銀青、10回は古金の縁と深い面で区別し、回数・シャード消費を主役にする。実装は `shopGachaTable.css` の `.gacha-draw-rich`。確認ダイアログやその他の操作は共通UIを維持する。
