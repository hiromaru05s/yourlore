# LOREの標準UI — 蒼銀の面取り

2026-10-26、ユーザーが4案のうち02を選択し、「全てのポップアップ、ページに適用」「今後のデフォルトUI」と指定。外周の四隅も内側の斜線に沿って落とした版が承認対象。

## 共通仕様

- 深い青の面、細い銀青の輪郭、小さな斜線。厚い白亜枠、立体隅金、大きな結晶を加えない。
- 四角い画像の上に斜線を描くだけでは不十分。外周の塗りも面取りする。
- 素材は `client/public/art/ui/lore-panel-azure-cut.png`。既存の選択済み生成素材をそのまま使用。
- 実装は `client/src/styles/defaultUI.css`。100pxスライスの9分割で線を太らせず、中央の面だけを伸ばす。PCは40px描画／20px面取り、スマホは30px／15px。
- 新しい独立したパネルは `.lore-surface` を使う。共通 `.overlay > .modal` と通常のネイティブ `dialog` には自動適用。
- ページの主内容を一枚の面としてまとめる。入れ子の各行・カード・リスト項目まで同じ枠で囲まない。文字は白青、補助文字は灰青、主要ボタンは青。
- カードの顔、3D盤面、キャラクター、ガチャのフルスクリーン映像は内容アート。額縁UIの対象はそれを説明・操作する情報面。これらの内容アートをパネル画像で覆わない。
- 既存のナビ、ページごとの情報構成、選択／無効状態、入力、スクロール、ダイアログの終了操作を保つ。

以前のメニュー・ポップアップ案と外観が競合する場合、本仕様を優先する。世界観は `world-bible.md`、下ナビや配置は `menu-design-insights.md` に従う。

## 対象

HOME対戦パネル、カード一覧と詳細フィルター、デッキ、ランキング、フレンド、ショップ、プロフィールと設定、ログイン／待機、チュートリアルと初回案内。共通確認・入力・BOT選択・カード選択・勝敗、プレゼント、ガチャ情報・スターター購入・家具プレビュー・描画案内・ルール説明、カード拡大の説明面。

制作時はPC・狭い画面で、枠外の四角い塗り残し、本文の可読性、カードの欠け、長文スクロール、操作ボタンの表示を確認する。
