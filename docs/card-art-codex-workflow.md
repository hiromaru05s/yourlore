# Codex 카드 아트 온디맨드 생성 프로세스

## 기본 원칙

- 전체 카드 자동 순차 생성은 하지 않는다.
- 사용자가 이번 요청에서 직접 지정한 카드만 Codex 내장 ImageGen으로 만든다.
- 카드 지정은 카드 ID 또는 현재 카드명의 정확한 일치로 해석한다.
- `진행해`만 단독으로 말하면 자동으로 다음 카드를 선택하지 않는다.
- 이전 요청에서 지정했던 카드를 다음 요청까지 암묵적으로 이어서 생성하지 않는다.

## 카드 지정 예시

```text
M1, M2 뽑아줘
스파크 임프랑 왕묘의 낙혈 진행해
GT10_2 다시 생성해
```

여러 장을 지정할 수 있지만, 요청에 없는 인접 카드나 다음 순번 카드는 추가하지
않는다.

## 생성 절차

1. `art/prompts/card-art-prompts.jsonl`에서 지정 카드의 행을 찾는다.
2. ID와 현재 한·일·영 카드명, 타입, 효과를 확인한다.
3. Codex 내장 ImageGen을 카드마다 한 번씩 별도 호출한다.
4. 결과를 시각 검수한다.
   - 카드 정체성과 효과가 읽히는가
   - 세계관 색·재질이 공통 아트 바이블과 맞는가
   - 마법·함정에 금지된 인물이나 손이 들어가지 않았는가
   - 핵심 피사체가 중앙 안전영역에 있는가
5. 통과한 결과만 `1472x1344`, WebP quality 92로 정규화하여
   `client/public/art/cards/{CARD_ID}.webp`에 적용한다.
6. 생성·저장·규격 검증을 모두 마친 ID만
   `art/codex-generation-state.json`의 `completedIds`에 기록한다.
7. 불합격 결과는 기존 이미지를 덮어쓰지 않는다. 재생성은 사용자가 별도로
   요청하거나 같은 요청에서 명시한 범위 안에서만 진행한다.

## 완료 보고

- 실제 생성한 카드 ID와 카드명
- 최종 저장 경로
- 최종 이미지 규격
- 기존 이미지 교체 여부
- 실패하거나 보류한 카드와 이유

기존 아트는 Git으로 복구할 수 있으며, 새 결과가 검수를 통과하기 전에는 대상
WebP를 덮어쓰지 않는다.
