# 起動後のロード・HOMEモード切替・デッキ表示の最適化

## 参照と実装

基準は本番で稼働していた `6019ab0873656838557b1b82ee80e994b93cd4dc`。統合時に最新 main `94f95159`（チュートリアルの文言修正と公開記録）を取り込んだ。

- `client/src/router.ts`: 初回入場だけを全画面ロードで保護。以後のページ移動は操作を止めず、カード一覧の画像待ちは一覧内で扱う。ページ全体の画像走査も繰り返さない。
- `client/src/ui/homeDuelButton.ts`, `homeDuelInk.ts`, `homeDuelAssets.ts`: 初回HOMEで3色を準備。モード変更では同じWebGLコンテキスト、プログラム、描画ターゲットを再利用し、元画像だけ差し替える。シェーダー参照位置もキャッシュ。古い非同期結果は現在のモードを上書きしない。
- 採用01の枠・3色は元PNGと可視画素が一致する可逆WebP。4枚合計6,559,535 → 4,286,176 bytes（34.7%減）。流墨のシェーダー、動き、形状は変更しない。
- `client/src/screens/deck.ts`, `ui/cardView.ts`, `deckCardQuality.ts`: 採用原画から512pxの表示用画像を作成（通常のカード幅は最大120 CSS px）。合計66,663,464 → 10,770,252 bytes（83.8%減）。原寸原画は保持し、拡大表示の経路も保持。候補一覧は遅延読込。カード生成直後に別の画像へ交換して二重に読み込む処理を廃止。
- 枠のアルファ処理は原寸で事前計算し、その後512px以下へ縮小。7枚合計6,285,364 → 1,716,282 bytes（72.7%減）。画面表示時のcanvas読取、画素ループ、PNGエンコード、blob保持を廃止。
- 新しい画像を既存のハッシュ検証付きキャッシュ一覧へ追加。

画像の再生成は `scripts/build-deck-display-assets.mjs`。`SHARP_MODULE`でインストール済みsharpを指定できる。各素材の容量は `deck-assets.json`、HOME画像の可視画素一致は `lossless-art.json`。
