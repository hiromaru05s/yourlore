## 実装と素材

`client/src/dev/shield-brand-twenty/` のみが演出実装。Canvasの材質片と共有WebGLの表面パスを組み合わせる。表面パスは微細な凹凸、液体のUV屈折、局所の反射・刻線を素材のUVに固定する。甲板・折板・帯・縫い目は別々の時間設計と主形状を持つ。粒子は溶接・破断の補助に限定。

シールドは現行 `shield-ui.webp`。烙印は別worktree `brand-seal-staging` の `brand-seal-ui.png` を比較専用ディレクトリにコピー。アイコン採用そのものや共有CSSは変更していない。肖像は現行の4×4 atlasの先頭フレーム。既存の静止肖像方針を維持。

実盤面は現行GameViewのfixture。アイコンの実矩形へローカル演出を重ねる。非表示時の復元、両側同時、途中切替、pagehideでのCanvasとGPU資源解放を扱う。WebGL非対応時は表面パスを省略し、同じ主形状のCanvas描画へ戻る。

- 全20案、各6時点で初期値／最終値が一致し、加算は一度のみ。ブラウザ例外・取得エラーとも0。

- TypeScript検査と比較ページ2入口のViteビルドが成功。ビルドは検証用で、公開アセットをコピーしない設定。
- 見た目の点検で修正：肖像atlasの正しい先頭フレーム、烙印の盤面矩形、分断された紅帯、材質片の接触影、液面への流入、録画前のGPUウォームアップ。
