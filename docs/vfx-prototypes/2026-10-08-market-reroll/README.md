## 演出

提示カードが左から55msずつずれて浮上し、一回転して新しい絵柄を見せ、同じ棚位置へ戻る。1枚780ms、3枠全体890ms。旧カード面から裏面、新カード面まで同じ立体の表裏を使い、表面の差し替えは裏面が見えている時刻に限定。接地影、細い金色の縁、裏面の反射をカードと共通の時計で制御する。固定マーケットの位置とカードは変更しない。

品質参照は `docs/animation-quality-benchmark.md` と `docs/vfx-art-direction.md`。承認済み「銀紋の流墨」の動画を連続フレームとして確認し、発生元の絵柄を保つこと、表面と動作の連続性、到着時の接地を今回の小さなUI動作へ適用した。黒紫の魔法や粒子を追加する意図ではない。

## 接続と制御

- 同一ターン・同一所有者の提示カードのUID全置換を検出。無料更新と相手側の公開更新も共通経路。
- 初期表示、非アニメーションの再接続、ターン交代、購入による空き枠、更新失敗は再生しない。
- ゲーム状態とマナ消費は既存リデューサーが即時確定。アニメーションから状態を変更しない。
- 画像が準備できるまで旧表示を保持する。表示中のUIDと最新状態が一致しない提示カードへの購入入力は送信せず、旧枠から新しい別カードを買うことを防ぐ。
- 裏面表示中の提示カードだけをinertにし、他の操作とリロール連打はfast-forwardへ接続。終了・中断でDOMと入力を復元する。
- リサイズ、非表示化、画面破棄、rAF停止時のタイムアウトで後始末する。
- 低減モーションは160msのクロスフェード。WebGLなしでも同じDOM演出を使用。
