## 六方向

1. 影布の開帳 — 黒絹がカードの両縁から折れ、赤い裏地を見せてほどける。
2. 抜刀の継ぎ目 — 絵柄を保持した斜めの面が移動し、鋼の反射とともに噛み合う。
3. 墨影の浮上 — 同じカード画像を連続した帯として圧縮・変形し、下端の濡れた墨から戻る。
4. 緋帯の解縛 — 赤い織布が時間差で締まり、反転した細い端へほどける。
5. 無音の合流 — 元絵を持つ影が時間差で合流する。分身にはコスト・攻守表示を複製しない。
6. 黒刃の折り羽 — 絵柄を持った薄い片が扇状に開き、順に一枚へ収束する。

初級・中級・上級は振幅・材質の層を段階化。ナイトロードは刃と布の厚み、スカッドは影の数と時間差を重点化。ゲーム効果を追加する表現ではない。

## 自己レビューで直した箇所

- 03で変形前のカードがハイライトとして二重に見えていた。反射も同じ変形座標へ移した。
- 01の左右の布が機械的なXに見えた。開く時間をずらし、折れ・織り・元絵の薄い転写で材質を与え、中央の絵柄を残した。
- 05の残像に数字まで複製されていた。絵柄部分だけを影身に使用した。
- 手札クリックで既存の拡大UIが同時に開く競合を目視で発見。プレビュー内のイベント所有を分け、再検証した。
- 再生バーがカードへ重なっていた。操作列をステージの前へ移し、上端固定にした。
