## 事前確認と研究

読んだ基準: `docs/animation-quality-benchmark.md`、`docs/vfx-art-direction.md`、`docs/world-bible.md`、承認②のREADME。銀紋の流墨の録画から4fpsで連続フレームを抽出し、0.8秒の原寸フレームも確認した。今回へ翻案したのは、元の表面を残すこと、暗い材質芯＋中間面＋細い明部、発生源と光の共通座標、同じ形が収束する連続性。召喚・除外の大きさや派手さは待機表示へ持ち込まない。

他チャットを直接確認したもの:

- 「ガチャ演出を制作」(01a11973-ce39-7672-8912-8073b56a6d0c): 2026-10-12の「ぼけは一瞬」「光が先に動き、クリアになってから本」「表紙貫通」「同じページ」「光から結果へ不自然な出現」。今回は広域ぼかしを使わず、枠と同じ座標に全形状を固定し、4案別の運動を書く。
- 「呪術師召喚エフェクトを6案制作」(01a1198c-cc60-7232-910c-8d5dad0561b4): 「既に適用された品質を確認」「演出直前に生カードが先に出る」。今回、画像が読めてから同じ描画呼び出しで元カードの非表示とactor表示を切り替える。
- 「演出制作の方法を徹底調査」: 研究の依頼を確認。モデルの優劣を今回の品質根拠にせず、実際の盤面と連続再生で自己評価する。
- 過去A–D却下の記録と呪術師比較の記録: 共通図形の色替え量産、粒の追加、カードから離れた物体、静止画だけでの合格扱いを避ける。

公式の一次資料を実際に開いて確認:

1. [Riot Games — Visual Effects](https://www.riotgames.com/en/artedu/visual-effects): 状態伝達と全体の調和、発生源に属する形を重視。左右の縁とカード面を発生源に決めた。
2. [Riot — Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/): 情報の優先順位と視覚的ノイズ。待機は攻撃・発動より小さい振幅と輝度にし、同時表示を確認する。
3. [Blizzard — The Art Behind THE SCIENCE](https://news.blizzard.com/en-us/article/22552047/developer-insights-the-art-behind-the-science): 持続VFXは長く表示しても邪魔にならない設計を行う。素材・主動作を決め、粒は補助にする説明を参照。今回、独立粒子は不要と判断した。

これらは制作上の原則を研究したもので、商用ゲームの素材・内部実装を再現したという意味ではない。

## 実装の所有範囲

- 新規エントリ2つと `client/src/dev/dual-ready-four/` のみ。既存Actor・boardProjection・ready renderer・attack runtimeを読み取り利用。
- ReadyStudyは元カード1枚につきactor1つ。canvasはactorの子で、DOMMatrixと遠近を共有。光だけが盤面からずれない。
- GameViewの既存待機ownerをclearMonsterStatesで解除してからstudyが描画。攻撃中はstudyをsuspendしてplayMonsterへ一時的に所有権を渡す。
- 画面非表示は時計停止と元カード復元。iframeを閉じる際はactor、盤面、観測・描画を破棄。
- reduced motionは静止形状、2つの識別要素と色を保持。
- 別チャットの未コミット編集を避け、8d7cdbe02c056b84fe1c0bb86502a72907c6ede3から独立worktreeで作成。固定fixtureの内容はそのコミットのゲーム状態。
