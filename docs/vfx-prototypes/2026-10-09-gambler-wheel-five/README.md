# ギャンブラー — ⑤の構成を再制作した5案

2026-10-09。ギャンブラー / 伝説のギャンブラーの比較用ローカル試作。

## 今回のフィードバックと変更

「05の演出構成はいい」「切り替わるところがダサい」「ペラペラの紙がパワポのアニメーション機能で動いているみたい」を受け、初稿の長方形パネル群と独立した円盤オーバーレイを廃止。カードの輪郭から円盤へ変形する、表・裏・側面を閉じた立体を新規実装した。

- カードの縁から体積が育ち、輪郭と彫り込みが連続して円盤になる。表面素材は半径方向に進む変化で置換し、復元時にも同じ形状をカードへ戻す。
- 溝・中心軸・縁の段差を実形状にし、側面と模様のある裏面を設けた。光源、環境反射、形状から落ちる影で厚みを読む。
- 形成・加速・減速・復元の時間を分ける。回転は整数周で終わり、元のカードに向きを合わせる。
- 粒子や発光環の追加で仕上げたものではない。①〜⑤は体積の構成と動作が異なる。

## 五つの方向

|案|素材と構成|動作の違い|
|---|---|---|
|01 王金の鋳盤|金と赤漆の一体鋳造|塊のまま形成、重い一回転から減速して復元|
|02 象牙の虹彩|厚い象牙の12扇形|隣接する扇形がわずかに上下して噛み合う|
|03 流金の賭卓|金属流体と赤い面|輪郭と表面がうねりながら円盤へ凝集|
|04 三層の天秤|中心・中輪・外輪の段付き構造|三層が異なる速度と向きに回り、同じ面へ戻る|
|05 黒曜の封輪|厚い黒曜石と金の縁、裏面の刻印|重心を保った一回の返しで断面と裏面を見せる|

両カードは正規ID `GAMBLER` / `LEGEND_GAMBLER` の実カード素材を使用。伝説版は24区画、通常版は16区画。伝説版の厚みを14%増しにしている。

## 検証

- TypeScript `tsc --noEmit -p client/tsconfig.json`: 成功。
- 専用Viteビルド: 成功。Three.jsと実盤面の共有コードを含むため500kB超のチャンク警告あり。通常ゲームのエントリには追加していない。
- `qa/report.json`: 5案 × 2カード × 2側 = 20通りで描画・完了・中断復帰を確認。
- 手札クリック、3枚同時、動きを低減、幅1280/390/320、ブラウザー例外なし。
- 30回の比較切替前後でリソース数は変化なし（rigs 10 / geometries 37 / textures 24）。これはリークの限定的検査であり性能保証ではない。
- 5案それぞれの8時点を静止画記録。連続再生 `qa/comparison.mp4` は両カードを同時に、5案順に収録。原録画WebMはローカルのみ。
- 実盤面、自分側・相手側、320/390幅、暗背景の静止画を保存。

自己確認: 表裏の厚み、形成／復元中の連続した輪郭、カードの面と盤面の対応、隣接カードとの大きさを見直した。⑤の裏面が無地に見えたため刻印を追加し、円周継ぎ目の不要な側面を除去した。見た目はユーザー選択待ち。通常ゲームへの採用、ステージング、本番デプロイはしていない。
