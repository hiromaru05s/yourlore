# 第3稿 — 現行比較、マナ召喚、共通の基本動作

2026-11-18。追加指定：現行と比較できること、召喚にマナによる具現化を加えること、ドローを派手にすること、攻撃・魔法発動は固有属性を持たない基本アニメーションにすること。

## 比較の使い方

`http://127.0.0.1:5298/cinematic-vfx.html`

初期設定の「現行 → 試作」で、同じサイズ・同じ盤面・同じカードを交互再生する。「現行のみ」「試作のみ」も選べる。「4種を順番に」と「連続」で全4種を反復比較する。

現行は `client/src/ui/anim.ts` の `animateDraw` / `ghostSummon` / `attackStrike` / `revealSpell` を直接呼ぶ。比較用に似せて作り直したアニメーションではない。両画面は同じ `fixture.ts` から `GameView` を描画し、採用済みのカード・キャラクター・背景・盤面を共有する。

現行の時間を伸縮せず通常速度で再生するため、比較時は速度・シーク・背景切替を無効にする。試作のみでは低速・シーク・白/暗背景を使える。現行の「停止」はアニメーションをキャンセルして盤面をリセットする。音のボタンは試作の補助音のみ。

## 変更

- 召喚：手札の表面がマナへほどけ、マナ表示から流れ込む光がカードの輪郭と印刷面を再構成する。透過・暗い青の芯・細い明部・具現化境界をカードのUVに固定。盤面と同じ投影、裏面全体の接地、1.47秒の衝突を維持する。白い盤面でも流れを読めるよう青い中間調を加えた。
- ドロー：カードの開示を少し大きくし、デッキからの立ち上がり、表面の光、実際の移動軌跡に沿う残光を強化した。
- 攻撃：引き・踏み込み・接触の短い停止・反動・戻りを主役にする。固有の刃や属性火花を外し、接触光とわずかな粉塵に整理した。
- 魔法発動：カードを提示 → 表面発光 → 墓地への移動。火球・炎・着弾・対象への攻撃演出を撤去。使用されなくなった炎のレンダラーも削除した。双月の啓示 / 刃の囁き / リコールを切り替えて、同じ基本動作を確認できる。

カード固有の効果解決やダメージはこの基本動作に含めない。盤面は固定状態のプレビューフィクスチャであり、マナ消費やカード効果によるゲーム状態更新、本番イベントへの接続は行っていない。
