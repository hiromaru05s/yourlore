## 演出

| 種類 | 時間 | 主動作・材質 | 注目時刻 |
|---|---:|---|---|
| 銀光のドロー | 2.35s | 束から引き抜き、反転して絵柄を開示。動くカードの端へ銀の軌跡が接続し、そのまま手札に定着 | 0.42–0.80 / 1.10–1.77 |
| 蒼銀の実体化 | 2.70s | 手札から浮上。絵柄の明暗を拾う表面光、枠に根を持つ蒼銀の膜、最後に加速して着地 | 0.65–1.20 / 接地1.47 |
| 閃刃の一撃 | 1.90s | 引き絞る溜め、三次加速の突進、70msの停止、対象の押し込みと斬撃、減速して帰還 | 命中0.67–0.74 |
| 焔の解放 | 2.80s | ファイアーボールのカード表面を下端から焼きほどき、燃焼境界から太い火の流れを射出、対象で破裂 | 0.97–1.51 / 着弾1.70 |

共通時計でカードの姿勢、表面、主形状、接地・着弾、効果音を制御。カード描画は実DOMのネイティブキャプチャ。GPUで元の絵柄の明暗勾配と輪郭を発光させ、燃焼境界も同じカードUVで進行する。炎は移流ノイズと色の階層を持つシェーダー。軌跡は尖る帯、衝撃は短い面と遅れる破片に分ける。
