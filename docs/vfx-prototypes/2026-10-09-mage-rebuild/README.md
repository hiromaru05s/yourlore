## 作り直した内容

共有Three.js描画器、実寸の立体形状、物理材質、環境反射、凹凸、動的な影を使用。炎・煙はノイズ密度を移流させ、吸収・発光を積分するボリューム近似。主形状の運動を邪魔しない補助層としても使用する。

| 番号 | 案 | 主材質と動き |
|---|---|---|
| 01 | 焔と影の立ち昇り | カード縁から密度のある炎・煙が生まれ、上方へ移流して薄くなる |
| 02 | 焼殻・黒曜の解放 | 不均等な割れ口の厚い殻が時間差で開く。亀裂の凹凸と熱が同位置 |
| 03 | 焦紙・呪符の解綴 | 三枚の紙が順番にしなり、元の面と裏を見せてほどける |
| 04 | 溶火・影脈の還流 | 丸い断面の流れが持ち上がり、先端まで遅れて張力を解く |
| 05 | 熔核・黒月の抱擁 | 炎術師は割れた熔石、黒魔術師はカード絵の杖に対応する黒月が開く |
| 06 | 炎書・禁書の開帳 | 実カードのUVを保った二面が曲がり、閉じてネイティブ面へ戻る |

エルサは流体と月の厚みを増し、アリスは素材の時計を1.08倍にする。炎術師は材質の発光と速度を変え、05は別の主形状を使う。全体3.8秒、接地は2.26秒。カードは盤面と平行に浮上・降下し、裏面で接地する。

6案同時、拡大、斜め／真上／横の視点、実GameView盤面、自分／相手、3枚同時、速度変更、停止・シーク・反復、低減モーションを備える。カード画像キャプチャの余白を正規化し、実盤面でのカードの大きさも修正。
