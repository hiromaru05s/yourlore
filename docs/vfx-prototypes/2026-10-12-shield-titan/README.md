## 着手前の確認と採用した判断

- `docs/animation-quality-benchmark.md` / `docs/vfx-art-direction.md` / `docs/world-bible.md` を確認。
- 「銀紋の流墨」②の代表フレームと動画から抽出した5fpsの連続フレームを確認。カードの輪郭・表面の模様・物質変化が同じ時計と座標でつながる構造を継承。色や渦は模倣しない。
- Toon参照の分析を確認。主形状を先に置き、影、面、細い明縁の順で作る。余韻は透明度だけで消さず、開口・格納・材質の浸食で形を失わせる。
- 実カード絵 `client/public/art/cards/SHIELD_TITAN.webp` を目視。白い石鎧、真鍮の補強、青い核、角盾を共通言語とした。カード以外の新しい絵素材は生成・流用していない。
- `dewShieldCards.ts` / `engine.ts` の条件と効果を照合。盾の巨神はコスト7、3/30、挑発・威厳・オーラ。召喚条件は直前相手ターン中のシールド20以上保有。シールド10は自分ターン終了時であり、召喚演出中の獲得表示は誤りになる。

## 他セッションの実際の指摘

読取専用で該当チャットのユーザーメッセージを再確認した。メモリー要約だけを根拠にしていない。

- 「ゴーレム召喚エフェクト6種を制作」: 他の採用済み演出の品質を見直すこと、開始直前に生のカードを一瞬出さず開始時点から石の皮を被せること。今回も時刻0から素材を表示し、実盤面の元カードを同時に隠す。
- 通常召喚6案のチャット: 「カードの面の方が着地面」、二重召喚を除去すること。boardMatrixで接地面を揃え、比較描画は単一所有者とする。既存のsummon-impact/dust経路を重ねない。
- 「吸血鬼召喚エフェクト6種を制作」: 「基本的に１パターンを使い回した６パターン」「もっと牙っぽい」「フレームの一番上と一番下」。今回は分節構造、主輪郭、運動軸、材質の変化を各案で変更。飾りの位置はカード寸法に固定する。

## 実装と境界

- `client/src/dev/shield-titan-four/` に閉じた実装。実カードDOMを `captureCardSurface` で取得し、CARD_PADDINGを除去して額縁・数値のずれを防止。
- シェーダーの粒度・刻みは各部品の座標に固定。装甲の動きから表面模様が滑らない。
- 四つの独立したリグを一つのWebGLコンテキストで描画。幾何・マテリアルは事前生成。動かない縁・留め具は可動部品単位に結合して描画呼出を削減。
- 実盤面の元カード・手札は描画の所有中だけ隠す。完了、中断、タブ非表示、低減モーション、破棄で復帰。プレビューの表示時刻は単一時計。
- ③は決定的な頂点変位で鋳膜を表現する美術用近似。流体物理シミュレーションとは呼ばない。
- 公開された召喚結果だけを描画する固定fixture。非公開手札の実対戦処理には未接続。採用後は `flyIntoSlot` と既存召喚runtimeの担当を整理して接続・検証する必要がある。

## 検証

`node tests/shield-titan-four-browser.mjs`。成果は `qa/report.json` とスクリーンショット、`qa/continuous.webm` に保存。

通常速度・低速で連続再生し、展開途中と終了までの画像を保存。機能検査の項目と実行時間はレポートを参照。見た目の判断は4つの主形状、接地、表面の連続性について行う。ユーザーの美術承認、通常対戦への採用、認証付き対戦、本番相当の性能保証を意味しない。

### 修正履歴

- ①と④の左右ヒンジが似ていたため、①を一枚盾の圧印へ変更。最終4案の運動は押下・積層解放・膜変位・壁起立。
- ③の核を膜の変位と同じ曲線に追従させ、途中で埋没しないよう修正。
- 初回ブラウザ検査は作業中のHMRで中断。次の検査で接地高さの `sin(π)` による浮動小数点残差を検出し、収束後は明示的に0を返すよう修正。失敗記録は `qa/failure.json`、最終結果は `qa/report.json`。

ビルド確認は通常ゲームのエントリと比較エントリを区別する。比較版の型検査・バンドルは次で再現できる。

```sh
./node_modules/.bin/tsc --noEmit -p docs/vfx-prototypes/2026-10-12-shield-titan/tsconfig.json
./node_modules/.bin/vite build --config client/src/dev/shield-titan-four/vite.config.mjs
```

QAの画像・動画はローカル保存し、代表画像とJSONのみGit管理する。`dist-shield-titan-preview` はローカル確認用の出力。

最終機能検査: **61項目成功**。ブラウザ例外、シェーダーエラー、アプリの素材欠落は0。反復前後ともGPU資源数は169 geometry / 10 textureで増加なし。4案描画のJS呼出時間は平均5.49msだったが、これはGPU完了時間・実機FPS保証ではない。

画像一括取得は途中で30秒タイムアウトしたため、機能検査を画像保存から切り離して完了した。必要時は `TITAN_CAPTURE=1 node tests/shield-titan-four-browser.mjs` で画像付き検証。比較動画は `node tests/shield-titan-four-record.mjs` で再生成する。

映像: `qa/continuous.webm` は通常速度と0.5倍の実時間録画。検証環境の録画にコマ落ちがあったため、`qa/comparison.mp4` を108枚の決定的な時刻サンプルから30fpsで生成した。後者は演出の時間設計を比較するための書き出しで、実機FPSの証明ではない。元フレームは `tests/shield-titan-four-frames.mjs` で再生成できる。
