# 蒼晶の巨盾 — 陰影の5案 / 第4稿

ユーザーが第3稿①「蒼晶の巨盾」の形・演出方式を支持し、見えづらさを改善する陰影・透明度の5案を要求。今回は形や動作を変えない素材比較。

| 案 | 主な違い |
|---|---|
| 01 薄影の水晶 | 元の透け感に、やわらかい落ち影を追加 |
| 02 縁影の水晶 | 外周の吸光と不透明度を上げ、透明な中心との境界を明確に |
| 03 厚硝子の水晶 | 正面の不透明度を上げ、カード絵に埋もれない量感を付ける |
| 04 稜影の水晶 | 光に背を向けた面を暗くして、結晶の稜面を読みやすく |
| 05 均衡の水晶 | 中程度の不透明度と、落ち影・外周・面の陰影を併用 |

全案とも同じ青色、同じ6×9分割の頂点、同じ中央隆起・尖った下端・5本の稜線を使う。3秒のタイムライン、1.41秒の接地、上端からほどける境界も第3稿①のまま。粒子や別の物体を追加しない。

## 比較元と調整内容

`client/src/dev/shield-titan-four/reference-r3/` にコミット `73684eee` の renderer / material / catalog を無変更で保存。`reference-manifest.json` でSHA-256と一致を記録。ページ上部「調整前の①を見る」からアクセスできる。第2稿の原版は `reference/` に引き続き保持。

元の水晶は正面の実効不透明度が約0.62（0.92 × 0.67）で、結晶自体の投影影は無効だった。5案では同じ輪郭から影を落とし、影の深度描画にも同じ消失境界を適用。面の吸光は環境反射にも適用し、明るい盤面で白飛び気味になる外周や結晶面を読めるようにする。全案の終了フレームで影強度とカード面を同一状態に戻す。

盤面用カメラは元のDOM投影を相殺行列でそのまま維持しながら、物理マテリアルへ正しい視点位置を渡すよう修正。原点に置かれたカメラによる灰色の環境反射を解消し、盤面でも同じ蒼いガラスとして表示する。スマートフォンは5個の選択ボタンに合わせ、盤面が下の操作バーと重ならない高さに調整。

## 最終確認結果

- 専用TypeScriptチェックと比較ページのViteビルド成功。Three.jsを含む約990KBの共有チャンク警告は残る。
- 最終ソースでライフサイクル **76項目成功**。ブラウザ例外・シェーダーエラー・不足アセット0。両陣営、3枚同時、終了時の同一カードへの復元、中断、低減モーション、反復後のリソース安定を確認（`qa/report.json`）。
- スマホの追加確認成功。自分／相手、1枚／3枚、手札移動の表示同期と復元、盤面の表示範囲を確認（`qa/mobile-controls.json`）。盤面の反射も蒼いガラスとして目視確認。
- 白／暗背景、5案同時比較、調整前①の保存を確認。幅840〜1000pxでも3列で5つの盾を比較可能。
- 通常速度／0.5倍の `qa/continuous.webm` を記録、シェーダー・実行エラー0。108枚の確定時刻フレームを保存。比較記録の拡大縮小は縦横比を維持する。

- 比較元3ファイルは第3稿コミットとバイト一致。ゲーム本体への採用、ステージング公開、mainへの更新は行っていない。機能確認をユーザーの見た目の承認とは扱わない。
