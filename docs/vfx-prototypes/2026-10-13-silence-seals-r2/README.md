# 沈黙の召喚 — 古き封印術 / 第2稿

2026-10-13。ユーザーから第1稿に「やり直し。もっと古代の魔法陣によって魔法自体を封鎖する重鎮なイメージ」との指摘。装甲の変形を主題にした前稿を撤回し、4案とも主形状と演出構造を再制作。

比較: http://127.0.0.1:5496/silence-four.html

|案|主形状|封鎖の原因|時間の特徴|
|---|---|---|---|
|天律の封圧|厚みのある暗い大印、金の凹刻|カード面から持ち上がる印が魔力を圧潰|ゆっくり持ち上がり、短く落ちて静止|
|四柱の禁域|四隅の石碑と秘文の壁|碑柱間の結界が閉じ、流路を遮断|四隅に時差、壁の接続、停止|
|双環の禁錠|逆回転する実体の二重錠|三本の封鍵が環を貫き回転を固定|反対方向の回転が減速、鍵が収まる|
|黒碑の勅封|五列の黒い碑文|上下から編み込まれた碑文に最後の勅印|列ごとの筆順、印の完成、面への還流|

対象: NT_SEAL5 / NT_SEAL3。両カードの実際の封鎖範囲はデータ定義を維持。演出中の魔力は主題を伝える視覚表現で、追加のゲーム効果・範囲判定ではない。

## 事前研究と翻案

- `docs/animation-quality-benchmark.md` / `docs/vfx-art-direction.md` / `docs/world-bible.md` を再読。
- 承認基準「銀紋の流墨」の動画を6fpsの連続フレームに展開して確認。カード表面の模様が主素材と連続すること、山場前の溜め、終端で形が収束することを翻案。前稿の粒子増量や色替えではなく主形状から再構成。
- 過去の呪術師レビューから、開始前の裸カード、独立物体の突然出現、カードの垂直着地、同時発動と中断の残骸を再点検項目に採用。
- [Riot: VFXアップデートの製作舞台裏](https://www.leagueoflegends.com/ja-jp/news/dev/dev-behind-the-scenes-of-vfx-updates/) を再読。視認性、ノイズ削減、テーマ表現の優先関係を確認。ここから「最大光量を短い刻印確定に限定」「主要な停止動作を先に読ませる」を設計判断とした。
- [Riot: Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/) を再確認。盤面で識別できる形状と情報の優先度を重視。
- 古代風の意匠は架空の字形、摩耗した二重罫、石と鈍金で表現。実在の文字体系や新たな世界設定は追加していない。

## 実装

`client/src/dev/silence-four/`。専用の架空字形・魔法陣テクスチャをCanvasで生成し、Three.jsの立体素材・段階描画シェーダーと組み合わせた。確定後は魔力の流れを止め、刻印の内側からの消去、石の沈下、碑文の短縮でカードへ戻る。3秒、共通時計で4案を比較。カード面は盤面と平行。

前稿はコミット `8c5b28ad` と前稿の記録に保存。通常対戦の演出、エンジン、ステージングへの採用は未実施。音は未追加。

- 専用TypeScript検査 / Vite build / `git diff --check`: 成功。Three.jsを含む約1MBの比較用rendererチャンクにサイズ警告あり。
