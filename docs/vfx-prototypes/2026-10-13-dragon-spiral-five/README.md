# 螺竜の誓槍 — 03を軸にした造形改訂・5案

2026-10-13。ユーザーは前作03の演出方式を好み、オブジェクト品質・ディテールの改善を要求。方向性の選択として受け取り、新しい5案をローカル比較用に実装した。通常ゲーム経路、ステージング、本番への採用は行っていない。

プレビュー: http://127.0.0.1:5497/dragon-spiral-five.html

既存サーバー: `node_modules/.bin/vite --config client/src/dev/dragon-fusion-four/vite.config.mjs`。新しい設定でも同じ5497ポートで起動できる。前作4案のモデル・時間設計は保持し、新ページへのリンクのみ追加。

## 研究と改訂判断

- `docs/animation-quality-benchmark.md`、`docs/vfx-art-direction.md`、`docs/world-bible.md`、比較UI用に`docs/menu-design-insights.md`を再読。
- 承認済み「銀紋の流墨」の元動画から3fpsで連続コマを抽出して再確認。発光を増やすのではなく、表面から主形状に変わり、主形状が薄くなって到着する過程を翻案。コマ抽出を動画全フレームの目視確認とは扱わない。
- 前作03の1600msを実際のブラウザーで確認。細い球節の胴、弱い竜頭、平たい槍先、小さすぎる表示を具体的な改訂対象とした。
- 過去のユーザー指摘から、無関係な物体への突然の交換、粒だけの装飾、垂直なカード着地、動きの色替えだけの案、停止できない比較画面を避ける。
- [Riot — VALORANT Shaders and Gameplay Clarity](https://www.riotgames.com/en/news/valorant-shaders-and-gameplay-clarity): 面の明暗、鏡面反射、環境光の役割を分けるという技術解説を参照。今回の翻案は暗い皮膚、中間色の鱗、狭い金属の稜線。Riotのシェーダーや素材そのものを移植していない。
- [Three.js — MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html): metallic/roughnessの組み合わせと環境光の使用を確認。皮膚・鱗・骨角・刃・革を独立材質にし、微細な粗さの変化は控えめな手続きシェーダーで実装。

## 実装上の変更

- 球を並べた38節の胴を、112断面×16周方向頂点の連続メッシュに置換。胴に沿って240枚の鱗とその金属縁、48枚の腹甲、48本の背棘を配置。
- 頭部は断面から構成した曲面、頬骨、眉、眼窩、瞳孔、鼻孔、歯列、別駆動の下顎、曲がった角を持つ。単純なカード画像の貼り付けではない。
- 槍先は菱形断面。刃の鎬、彫り線、ソケット、鍔、革巻きの柄、石突きを立体化。各穂先の長さに合わせて接触時の高さを計算。
- カード面→低い竜の浮彫→立体の螺旋→巻き締め→カード面の順に同じ時計で進行。カードは盤面に平行。翼・爪の収束は取り付け位置の胴に追従。
- 頭部と槍の静的パーツを材質単位で結合。鱗はInstancedMesh、胴は確保済み頂点配列を更新。フレーム毎にジオメトリを生成しない。
- 造形を見るボタン、通常/低速/反復/同時再生、時刻シーク、白/暗背景、低減モーション、両融合先、実GameView/融合reducerの盤面を維持。

## 検証と品質判断

機能結果は `qa/report.json`、ビルド結果は `qa/build.log`。連続再生は `qa/continuous-five.webm`、各案の形状は `qa/*-shape.png` に保存。録画時のframe intervalはこのローカル環境での比較ページの計測であり、実ゲーム/低性能端末のFPS保証ではない。

目視自己評価: 前作03に対して胴の連続性、主形状の大きさ、重なる鱗、竜頭と槍の立体感を改善。白背景での輪郭、翼竜と長角竜のシルエット差をブラウザーで確認した。機能テスト合格をユーザーの見た目の承認、あるいは製品品質の認定とは扱わない。

最終結果: 96項目合格、JS/シェーダーエラー0、HTTPエラー0。単独再生5案のフレーム間隔中央値16.7ms、p95 16.7〜16.8ms（`qa/single-performance.json`）。5案同時録画は中央値30.1ms、p95 82.5ms（`qa/report.json`）。同時録画時は他のローカル処理と競合するため、単独再生と分けて記録する。client typecheck、比較ビルド、design guard、diff checkも合格。ビルドにはThree.js/実盤面fixture由来の500kB超チャンク警告がある。

再現: `node tests/dragon-spiral-five-browser.mjs`、`node tests/dragon-spiral-five-performance.mjs`。
