全案3.4秒。形成・接地タイミングは案別。4職の見た目は剣／杖／弓／双短剣で区別し、剣の一振り、杖の揺動、弓の張力、双刃の開閉を頂点変形へ組み込む。形や材質の名前は制作上の比喩であり、世界観へ新設定を追加したものではない。

`client/public/vfx/chosen-heroes/` に4点の透過PNGを保存。原本・プロンプトは `prompts.json` に記録。兵装は画像を分割した変形メッシュ、周囲の薄殻・織布は立体ジオメトリ。フル3Dの武器モデルとは主張しない。

## 自己評価と修正

1. 初回の手続き的な武器は、幅広の金縁と単純な面が玩具的だった。専用の彫刻・反射を持つ兵装素材へ差し替えた。
2. 当初の③と⑤が同じ帯の色違いに近かった。③を幅のある織布、⑤を中央で流れる細い銀膜へ分けた。
3. ②と④で外殻のシルエットが近かった。②を細長い結晶、④を短い角形の分節へ変更した。
4. 盗賊の双刃が隣接カードへ張り出すため、双刃の素材全体を70%へ調整。露出中のカード情報を隠す面積を抑えた。
5. カード用共通CSSが比較画面の文字を白くしていた。プレビュー側で文字色を明示して修正した。

銀紋の流墨と同様に、素材が形成境界から現れ、最後は輪郭を削りながら戻る。兵装の細密感は拡大で確認できる一方、実盤面では主形状とタイミングの差が中心となる。機能検証の成功を、見た目の承認や最低基準達成の証明へ置き換えない。
