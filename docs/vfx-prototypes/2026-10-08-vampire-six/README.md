# 吸血鬼召喚 — 6案 × 6種

2026-10-08。ユーザー指定は「6種に対応する演出案を6案」。VAMP1 / VAMP2 / VAMP3 / VAMP4 / VAMP5 / VAMP_BUTLER の全36組合せ。ローカル選定用であり、通常対戦の選択ルート・ステージングは変更していない。

## 開く

http://127.0.0.1:5436/vampire-six.html

```sh
node node_modules/vite/bin/vite.js --config client/src/dev/vampire-six/vite.config.mjs
```

6案同時比較、拡大、白/暗背景、真上からの確認、両陣営の実GameView、手札から召喚、3枚同時、1/0.5/0.25倍、シーク、連続、低減モーション。実盤面はルール上の召喚条件を検証する対戦ではなく、公開カードの固定fixture。手札のカード操作、または「手札から召喚」で再生する。

## 一次資料からの制作判断

[Blizzard / The Art Behind THE SCIENCE](https://news.blizzard.com/en-us/article/22552047/developer-insights-the-art-behind-the-science): 種別を色・素材・形で伝える、主動作と二次動作を組み合わせる考え方を採用。粒子を豪華さの代用品にしない。

[Riot / Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/): シルエットと視覚的な優先順位を基準に、隣接カードの情報を隠す大規模な環や画面全体のフラッシュを避ける。

どちらも参照方針で、商用作品と同品質という主張ではない。

## 自己レビューと修正

初回描画では、環境反射が広がり血液・布まで灰色の金属板に見えた。環境光・メタルネス・粗さを再調整し、刺繍・毛細脈・彫金と不均等な曲面を追加。実盤面切替ではCSSのdisplay:gridがhiddenを上書きしていたため、表示とiframe位置を検査する項目を追加した。

### 最終結果

- PC 1280×720 / スマホ390×844: 各117項目、errors空。全6案×6種×両陣営の描画と復元を含む。
- ブラウザーで手札の実カード操作→再生を確認。元の拡大クリックと競合していたため、このプレビューの手札のみcaptureイベントで召喚操作を受け取り、拡大画面が出ないことを再確認した。
- 390pxのscrollWidthは375px（縦スクロールバーを除く）。実盤面も横にはみ出さない。拡大表示とは別に実寸で確認。
- TypeScript全体チェック・専用Vite build通過。既存GameView/Threeを含むためチャンク容量の警告は残る。
- `qa/six-continuous.mp4`: 30fps / 103フレーム / 3.433秒。動画を連続フレームにも展開して、各素材が被覆→開放→接地→収束することを確認。実時間FPSを示す録画ではない。
- 描画の自己確認と、ユーザーによる見た目の選定は別。まだ案を採用済みとは扱っていない。
