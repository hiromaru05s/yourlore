# 沈黙の巨神 / 沈黙の番人 — 召喚4案

ローカル比較版。両カード × 4方向。選定・通常ランタイムへの接続・デプロイは未実施。

プレビュー: http://127.0.0.1:5496/silence-four.html

起動:

```sh
node node_modules/vite/bin/vite.js --config client/src/dev/silence-four/vite.config.mjs
```

## 4案

| 案 | 素材・主形状 | 動き |
|---|---|---|
| 01 封鍵の締結 | 白石と金縁の二枚の封鍵 | カード長辺を支点に隆起、中央で締結、縁へ沈み込む |
| 02 静謐の天蓋 | カード面から連続して膨らむ薄膜と稜線 | 曲面の膨張、圧縮、面への定着 |
| 03 積層の鎮座 | 元のカード面を保持した七段の石板 | 時間差の浮上、上からの再積層、最後の面で接地 |
| 04 星章の収束 | 八枚の金縁・白石の星形羽根 | 浮彫から立体化、捻りながら閉じる、表面へ戻る |

巨神は浮上量を強め、番人は抑制した振幅。カード絵・名前・能力値は両者の実データから取得。この比較シーンでは両カードとも832px元絵を指定し、召喚面と通常表示の解像度を揃える。プレビュー用にカード絵を別制作・交換していない。素材のジオメトリと石目テクスチャはこの4案専用に制作。

## 調査

[制作前調査](RESEARCH.md) に既存基準・他セッションの指摘・外部一次資料・翻案の判断を記載。

「銀紋の流墨」の連続フレーム、Toon基準の衝撃フレーム、対象2枚のカード絵、魔法制限の実装を確認。粒や輪の増量で代用せず、カードと同じ面から主形状を連続して変化させる。新しい世界設定は追加しない。

## 比較操作

4案同時、1案拡大、GameView実盤面の3表示。両カード、白／暗背景、両陣営、3枚同時、1x / 0.5x / 0.25x、シーク、反復、途中停止・復元、動きの低減。

実盤面は既存GameViewと盤面投影を使うfixture。手札からのドラッグはプレビューの共通時計を開始する。ルールエンジンのPLAY dispatchや、ネットワーク対戦の召喚経路へ採用したものではない。公開されているフィールドカードの表面だけを使用。

## 描画・ライフサイクル

- 1ページ内の比較は1つのThree.js/WebGL contextを再利用し、Canvas2Dへ転送。
- カード画像の透明パディングを除き、元のカード面の位置・大きさへ合わせる。
- 盤面は既存boardProjectionを使用。立体の高さは盤面法線に対応するせん断投影、カード面の位置は元のカードに合わせる。スタジオは低い俯瞰視点。
- 盤面では通常のカードを同一描画タスクで非表示にし、プレビュー面に置換。終了・中断・低減・リサイズ・非表示化で元のカードを復元。
- 幾何・素材・テクスチャ・WebGL contextはページ破棄時に解放。共有ランタイムや通常の召喚トリガーは変更しない。
- 3秒は比較用尺。採用時の対戦テンポへの調整、実際の召喚イベントとの結線とネットワーク対戦検証は別工程。

### 最終結果（2026-10-13）

- 専用TypeScript noEmit / Viteビルド / git diff --check: 成功。比較用Three.jsを含む約1MBのチャンク警告あり。通常ゲームのバンドルは変更していない。
- 機能33ケース: 2枚×7時点の4案描画、2枚×4案×両陣営の開始・接地・終了、3枚同時から中断、実GameViewの手札ドラッグ、リサイズ復元。加えて低減モーションと320/390/844pxで横はみ出しなし。
- ブラウザ例外0、HTTP失敗0。通常時計の440フレームの間隔: 中央値16.7ms / P95 16.7ms / 50ms超0。これはローカル1環境の測定で、全端末の性能保証ではない。描画自体は30fpsに制限し、入力・時計はrequestAnimationFrameで更新する。
- 通常時計を録画した `qa/continuous-four.mp4` / `.webm`、連続フレームの `qa/continuous-contact.jpg`、両カードの比較・盤面4案・3枚同時・スマホ画像を保存。録画ではホスト負荷によるフレーム重複も含め、時間補間していない。最終性能値は上記独立計測の結果。
