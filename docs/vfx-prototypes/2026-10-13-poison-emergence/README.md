# 素材からカードが現れる召喚

2026-10-13 / 3体×4案、再制作。

## 選んだ方向

ユーザーから「演出自体が意味がわからない」と差し戻し。「素材からカードが現れる演出」を選択された。小さな薬瓶・スラッグ模型・キノコをカードの上に出す構造は撤去した。

手札のカードがその固有素材へ変化しながら盤面へ移動し、面全体で接地する。その素材が流れる・裂ける・ほどけることで、同じ場所にカードが現れて残る。カード面と素材は一枚のメッシュを共有する。露出済みの面は平面へ戻り、素材が残っている部分だけが持ち上がる。

実盤面fixtureにも意味上の誤りがあった。旧版は召喚前から対象カードを場に表示していたため、既存のカードに装飾を載せるように見えた。今回は召喚前の対象位置を空け、飛行中は手札を隠し、完了時は場だけにカードを残す。「召喚前へ戻す」は手札と空き位置へ戻る。

## 4案ずつの違い

| 素材 | 01 | 02 | 03 | 04 |
|---|---|---|---|---|
| 毒液 | 溜まりの中央から露出 | 一方向へ流れる | 複数の穴が連結 | 二液の境目が開く |
| 粘液 | 太い波が這い退く | 中央が裂けて伸びる | 一端へ収縮 | 片側へめくれる |
| 菌床 | 不規則な境界がほどける | 膨らんだ殻が中心から開く | 胞子層に空洞が増える | 三か所から解けて接続 |

カードの効果発動・腐敗カウンター付与とは別の召喚表現。ゲームルールは変更しない。

## 検証結果と残り

比較12案を0/640/1100/1400/1700/2400msで操作し、18枚の画像を保存。召喚前に対象位置が空き、手札が見えることをDOMで確認。実盤面はポイズンマスター自分側4案・相手側2案のピークまで確認した。Viteビルド成功（共有チャンクのサイズ警告あり）。

その後ブラウザ操作がタイムアウトし、再接続でもブラウザが利用不可になった。完了・リセットの再確認、残りカードの両陣営、連続再生、同時・低減・レスポンシブ・性能の最終検証は未完了。並行ステージング作業から重い検証を控える調整依頼もあり、追加のビルドやブラウザ起動はしていない。旧版の検証結果で穴埋めしない。

## 検証再開後の追記

待機解除後に再接続できたため、全12案×両陣営の24ケースを1350msで確認。対象カード・当該陣営の手札が隠れ、反対側の手札が見えることを保存したDOM結果に対して検証した。自分側・相手側の完了と召喚前への復帰も確認した。

陣営変更の盤面再構築中に古い手札を隠す描画が割り込む不具合を修正（arrangingガード）。相手側のソースを実際のcard--backへ接続。修正後の型検査成功。

3体とも通常速度で2回のループ境界を確認し、実時間画面キャプチャを保存。`live-*.json`の時刻は画面スライダーのDOM値。キャプチャの間隔は一定ではなく、固定fps動画やGPU性能の証明ではない。

別の統合公開の調整依頼で再び重い検証を保留。残りは同時発動・低減動作・レスポンシブ・性能の最終確認。上の接続停止時点の記録は履歴として残す。
