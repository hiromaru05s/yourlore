## 比較方法

「4案比較」は同じ実時間で同時再生。「拡大」は選択した1案。「実盤面」は現在のGameViewと3D盤面の固定状態を使用。自分/相手、3種×2陣営の同時再生を切り替えられる。シーク・0.5倍・0.25倍・暗背景・低減モーションに対応。「減少だけ8→5」は数値更新のみを確認する操作。

デスクトップの大きな表示だけで判断せず、実盤面とスマホの実寸も確認する。型検査・透明ピクセル検査・描画資源の検査は機能の証拠であり、見た目の承認ではない。
