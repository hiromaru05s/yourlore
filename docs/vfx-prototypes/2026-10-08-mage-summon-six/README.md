## 参照・自己修正

`docs/animation-quality-benchmark.md`、`docs/vfx-art-direction.md`、`docs/world-bible.md` を確認。「銀紋の流墨」の800/1500/2160msの参照と、動画を5fpsで連続フレーム化して確認。原Toon参照の44秒付近の炎連続フレームも確認。絵柄を保つ予兆→主形状と細部が同じ座標で変化→収束という連続性を用いる。

初稿の静止画で、外殻の反復形状、宙に離れた折面、矩形の裏板、広すぎる光が見えたため修正。外殻を片側3面へ減らし、折面の根元をカードへ寄せ、裏板と過大な発光を除去。炎の輪郭には上昇する侵食を加え、黒魔術は光沢のある密な面を維持した。これは制作者の自己評価であり、ユーザーの見た目承認を意味しない。

| 案 | 主形状と運動 | 表面の連続性 |
|---|---|---|
| 01 表皮の覚醒 | 両縁から厚い膜が立ち上がり、先端が細くなる | 絵柄の縁が波打ち、縁の材質へ接続 |
| 02 双流の交織 | 逆方向の二本の帯が前後を交差 | カードの変形位相と帯のねじれを共通化 |
| 03 秘殻の開放 | 片側3面の厚い外殻が開き、収束 | 枠の光脈と同じ色・元絵の色素を外殻へ継承 |
| 04 六葉の詠唱 | 行ごとに遅れた六枚の折面が開閉 | 絵柄の同じ行が折面へ伸びる |
| 05 深圧の解放 | 面が先に収縮し、遅れて四辺の曲面が開く | 光が四辺から中心へ圧縮される |
| 06 織影の顕現 | 面をうねる帯に変形し、順次定着 | 元絵のUVを帯とともに変形 |

炎: 速い上昇流、橙・金の厚い明部と侵食する先端。黒魔術: 緩い流れ、黒紫の本体と銀紫の細い反射。エルサは大きく重い展開、アリスは0.78倍の展開幅と1.1倍の材質時計。同じ各案の骨格を使うが色だけの切替ではない。
