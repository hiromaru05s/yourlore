## 着手前に確認したこと

`docs/animation-quality-benchmark.md`、`docs/vfx-art-direction.md`、`docs/world-bible.md` を確認。承認済みの「銀紋の流墨」動画から0.25秒間隔の連続フレームを作り、カード表面の発光→同じ絵柄の変形→収束の関係を観察。Toon参照の液体連続フレームも確認した。

今回の翻案は、同一のカードUVを分断・屈曲する面に維持すること、面と細い縁の明暗を分けること、形を元のカードへ戻して終えること。紫の渦や大量の粒子をコピーすることではない。

## 構造・制御

- 実カードDOMを `captureCardSurface` でキャプチャ。余白を除いて正しい面比率で描画する。2枚の元絵は新規の汎用エフェクト素材へ転用せず、本人のカード面として用いる。
- 4案は同じ時計で比較できるが、ピーク、復元、接地時刻は別々。ポーズは経過msのみから計算し、シークしても結果が変わらない。
- GPUは各ページで1コンテキスト。面構成は再利用し、時刻更新で頂点とuniformだけを更新。切替時にGPU資源を積み上げない。
- 低減モーションでは面の変形・檻・接地閃光を省略し、完成したカードを表示する。
- ページ破棄時にgeometry/material/texture/rendererをdispose。非表示時に再生を止める。
- 盤面は実装済み `GameView`、既存のカードUI、実盤面の配置行列を使う固定fixture。自分側は手札クリックから開始。相手側は公開された召喚カード位置を起点とし、相手の秘密の手札をキャプチャしない。
- プレビューでは `anim.ts → flyIntoSlot → playMonster('summon') → playSlateSummon` を重ねて呼ばない。専用描画のみ。採用時には既存経路をこの専用経路へ置き換えて、接触callback・AbortSignalを接続する必要がある。
- 本fixtureは召喚効果のダメージ・リフト移送を実行しない。使徒の自傷・成長や幽閉者の除外カード移送は、今回の召喚表現と別のゲームイベントである。

### 最終検証結果

- `qa/report.json`: **307 / 307 成功**。初回の檻残りは修正済み。
- 390px / 844px: 比較画面の横はみ出しなし。下段まで表示できる。
- `qa/void-apostle-timeline.mp4` / `qa/jailer-timeline.mp4`: 同じ描画コードを1/30秒刻みで保存した、各４案の固定時刻比較動画。GPU/実時間FPSの計測ではない。
- `qa/*-continuous.webm`: 通常時計による連続収録。今回の負荷下では平均フレーム間隔にばらつきが出た。固定時刻動画の滑らかさを、そのまま実機性能の証拠にはしない。
- 目視では膜、折り面、薄層、檻のシルエットの違い、実カードの絵柄の連続性、白／暗背景での明暗、終端での面への復帰を確認。商用タイトル同等という品質認定やユーザー承認ではない。
- バンドルはビルド可能。ただし検証用ビルドに400MB超の共通アートを複製しないため `copyPublicDir:false`。単独配布を行う際は既存の `/art` 等も別途配信する。通常のViteプレビューでは既存のpublicが使われる。

追加の操作検証では、通常ゲームのクリック拡大が比較ページの召喚操作を妨げていたため、fixtureの手札クリックだけを専用経路へ接続した。左端のカードをクリックし、そのカードが飛行元になることも確認。リサイズでシーク時刻を勝手に0へ戻さず、同じ時刻を新しい盤面の配置で再描画する。最終のブラウザログは `qa/browser-check.log` / `qa/browser-errors.json` に保存。

スマホの実盤面では、盤面全体を縮小する既存transformと演出の論理座標に差があった。実DOMの表示矩形と投影後の四隅から補正行列を求め、地面・カード面の両方へ適用した。390pxで着地後のオーバーレイと実カードの位置・幅・高さの差は各0.01px未満。単に「ノードが存在する」検査に加え、この幾何学的な一致を検証した。
