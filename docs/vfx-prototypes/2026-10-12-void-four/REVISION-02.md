# 第2稿 — 黒い穴から突然出現する4案

2026-10-13。使徒・幽閉者とも、何もない召喚位置の上空に開いた黒い穴から出現する。実盤面のリフト領域とはつながらない。手札クリックは開始操作だけで、カードが手札から飛ぶ軌道は廃止。通常召喚への採用・公開はまだ行っていない。

[比較プレビュー](http://127.0.0.1:55217/void-four.html)

| 案 | 入口 / 出現 / 閉じ方 | 接地 |
| --- | --- | --- |
| 01 黒淵の噴出 | 丸い黒淵が100msで開く。奥から直進して一気に現れ、背後の穴が収縮 | 1110ms |
| 02 斜裂の抜け駆け | 細い斜裂が70msで開く。カードの片縁から横に抜け、後端に続いて縫い閉じる | 1220ms |
| 03 渦底からの反転 | 扁平な渦が130msで開く。奥から旋回しながら抜け出し、流れを巻き取る | 1370ms |
| 04 黒膜の突破 | 黒い表面が70msで開く。カードが中央を押し破り、四方の膜が反って穴へ収縮 | 1160ms |

使徒は出現後にわずかな勢いを残す。幽閉者は渦を逆方向に回し、出現の制動と④の閉鎖を早める。同じ4方向を両カードで比較できる。

## 参照と変更理由

品質基準・Toon指針・world-bibleを再読。最低基準「銀紋の流墨」の動画を250ms間隔で確認し、現行「双環の秘文」の実盤面動画も連続フレームで確認した。`riftInkMaterial.ts` と `riftInkRenderer.ts` の、黒い芯 / 折り重なる流体膜 / 狭い反射 / 形の収縮を今回の穴の材質に翻案した。紫色の輪だけを重ねる構成にはしない。

初稿のカード自体の分割・折り・格子は撤回。過去の除外演出にあった「独立した穴を出さない」という指定は、今回のユーザーによる「唐突にブラックホールっぽいところからカードが出てくる」という明示指定に置き換わる。空中の穴は今回の出現源であり、ゲームのリフト移送イベントではない。

カード面は本人のDOMキャプチャを使い、入口を通る部分だけを描く。境界には黒紫の被覆と細い反射が残り、完全に出たあとに元の絵柄へ戻る。終端は元のカードの位置・寸法・傾斜に一致。着地の影と局所光は接触時計に同期する。

## 構造

- `portal.ts`: 黒い芯・螺旋の膜・反射を同じ座標場で描く。前縁がカードの手前を横切る。
- `renderer.ts`: 各案の異なる出現軌道、面の遮蔽、④の曲面、単一GPUの再利用。
- `board.ts`: 実GameViewの召喚スロットを投影したfixture。自分/相手、1/3枚、クリック開始。実アカウント対戦の検証ではない。
- 低減モーションは完成カードを即表示。中断・非表示・ページ破棄で一時レイヤーを復元・解放する。
- 初稿コードと証跡はGit履歴および `qa/` に保持。第2稿の証跡は `qa-r2/`。

## 検証

結果は `qa-r2/report.json`、`browser-check.log`、`browser-errors.json`、`typecheck.log`、`build.log` に保存する。機能テストと見た目の採用判断は別。連続録画は実時間の記録、固定30fpsの動画はタイムライン確認用であり実機FPSの証明ではない。

最終描画確認: 307/307。初期フレームは空、出現後は完成カード、低減モーションは完成形と一致。GPU資源は反復後も増加なし。初回コンパイルと2枚の画像転送を準備画面で完了させ、描画呼出しの最大測定時間は7.5msになった（GPU完了時間や全フレーム予算とは別）。

4案同時・実時間キャプチャの平均フレーム間隔は使徒25.04ms、幽閉者23.10ms。最大はそれぞれ149.9ms / 33.5ms。複数処理が動くこの環境で60fpsを保証する証拠にはしない。固定30fps動画は動きの設計確認用。実運用への接続時は対象端末で再測定が必要。

390px実盤面の終端誤差: X -0.00348px / Y 0.00003px / 幅 -0.00050px / 高さ -0.00800px。停止時刻を保持したリサイズ、クリックした手札0からの開始、ブラウザエラー0を確認。型検査・専用Viteビルドを実行。ビルドには実GameViewを含む大きなチャンクの警告があり、比較fixtureの配信サイズ最適化は通常ゲームの採用作業とは分離する。
