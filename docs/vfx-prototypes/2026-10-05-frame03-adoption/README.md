## 適用範囲

- 通常魔法・設置型魔法の公開後と、手札/購入クイック魔法の公開後。
- 元のDOMカードはそのまま維持。フレーム画像に一致するマスクを子canvasへ描画し、名前・絵窓・コストは除外。
- 四隅の起点を少しずつ遅らせ、青い明部がフレームを伝わって収束する3.2秒。低減モーションは移動しない弱い発光。
- 旧spell/quickの汎用Toon装飾をこの使用経路から除去。着地、効果解決待ち、クイックの保持、選定済みRift移動は維持。
- 早送り、AbortSignal、リサイズ、タブ非表示、離脱、重複再生、元カード切断は同じcleanupへ。非対応/読み込み失敗時にも元のカードと使用処理は残る。
- GPUモジュールは必要時に読み込み。完了/中断時にテクスチャ、描画ターゲット、WebGLコンテキストを解放。
