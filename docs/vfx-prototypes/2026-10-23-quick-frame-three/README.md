## プレビュー

[3案の比較](http://127.0.0.1:5278/quick-frame-three.html)

```sh
node_modules/.bin/vite client --host 127.0.0.1 --port 5278 --strictPort
```

1. **閃走のフレーム** — 金属枠に沿う二筋の雷光。白い細い芯、青白い面、短い折れた枝を分ける。
2. **速記の刻印** — フレーム上の44個の紋を順に点灯。濃い刻印の溝と明るい縁、内側の導光を重ねる。
3. **瞬風のヴェール** — フレームの両側から薄い面がほどける。3層の膜の形が変わり、根元は常にカードの縁と一致する。

全案で実際の `cardEl(fullArt:true)` を使用。枠の複製から局所的な金属反射を作り、カード名・絵を覆わず、下端の銘板に種別を示す。プレビュー加工中は既存の小さい種別チップを隠し、OFF時と破棄時に復元する。

5枚のクイック魔法、通常魔法との比較、白／暗背景、再生・停止・低速・拡大直後の再生・低減モーションに対応。各案の「拡大画面で見る」は既存 `cardInspection.zoomCard` へプレビューのみに加工を追加する。「実盤面で見る」は `GameView` の固定状態が描画完了してから同じ拡大を表示する。

## 参照と翻案

`animation-quality-benchmark.md` / `vfx-art-direction.md` / `world-bible.md` を確認。
「銀紋の流墨」動画から6fpsの連続フレームと800ms代表画像を確認。カード自体の彫金から発光が始まる関係、狭い明部と中間の色面を翻案。カードの消失や転送は今回の識別UIでは行わない。
Toon 60秒以降の雷の連続画像から、直線の折れと細い白い芯を①へ使用。各案の主形状は枠に接続し、周囲へ独立した粒子や環を増やさない。
