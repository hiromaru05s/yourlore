# 商人のコイン：不自然な整列と跳ね方の修正

2026-10-12。「すごく整頓された落ち方」「もっと自然に跳ねる」というフィードバックへの改稿。比較ページのみ。通常召喚と見習い2枚／王都6枚、4案の枠組みを維持。

以前は左右の組と段番号で軌道・到着点を決め、接地後に固定の放物線をもう一度再生し、Euler角を同じ時間でゼロへ戻していた。このため接触と回転に関係がなく、着地後が列状になっていた。

今回、1/300秒刻みの薄い円柱の剛体近似へ置換した。重力、姿勢に応じた最下点、慣性、法線方向の反発、接線方向の摩擦、接触中の転がり抵抗を計算する。空中で平らに戻す補間はない。コイン同士にも接触応答を入れ、位置補正は1ステップで大きく飛ばないよう制限した。

発射位置も左右の列から変更。01は周囲へ散る、02は手前へこぼれる、03は低く跳ねる、04は片隅から転がる。各コインの初速・軸・発生時刻・反発・摩擦・消失時刻は別々。シークと比較の再現性のため初期条件は固定シードで、毎フレーム乱数を加えてはいない。

黒貨も同じ接触モデルを使用し、等速落下と一定間隔を廃止。魔法の拡大表示・専用素材の構成は変更しない。音は描画と同じ接触イベントから発音し、強さと左右の位置も接触に対応させた。
