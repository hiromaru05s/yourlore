# 盾の巨神 — 結晶の4方向 / 第3稿

ユーザーは第2稿③「晶壁の覚醒」の方向性を明確に支持し、それを軸にしたユニークな4案を要求。青い透明面、透けて見える実カード、面に沿った稜線、浮上して面へ戻る結晶を共通の基準とする。選定は「結晶の方向性」までで、ゲーム本体へ採用する個別案の決定ではない。

## 保持した比較元

`client/src/dev/shield-titan-four/reference/` に第2稿のrenderer / material / catalogをバイト単位で保存。`/shield-titan-four.html?reference` で元③だけを再生可能。画面上部「比較元③を見る」から移動できる。第2稿の記録・画像・動画は書き換えない。

## 共通にしたもの、変えたもの

| 案 | 結晶の構造 | 成長 | 解放 |
|---|---|---|---|
| 01 蒼晶の巨盾 | 中央稜線を持つ一枚の大きな多面盾 | 下から上へ厚みが生まれる。元③に最も近い | 上端から順に面へ戻る |
| 02 双晶の契り | 左右二つの長い結晶面 | 時間差で浮上し、斜めに交差して中央で噛み合う | 中央の継ぎ目から両端へほどける |
| 03 八稜の花冠 | カード面を八つの放射状三角面へ分割 | 縁を動かさず、内側の尖りを持ち上げて中心を開く | 対となる結晶面が時間差で沈み、中心から消える |
| 04 連晶の城塞 | 縦方向に連続する七本の稜柱 | 上下・左右に遅れをつけ、稜柱が順に伸びる | 柱ごとに時間をずらして縦方向へ収まる |

同じシアン系の結晶素材を使い、色替えで差を出さない。カードの表面と位置は全案同じ。粒子や独立した環・飛来物へ置き換えない。接地はカード面が盤面と平行なまま行う。

## 参照・確認

- `docs/animation-quality-benchmark.md` と `docs/vfx-art-direction.md` を再読。前ターンで確認済みの「銀紋の流墨」の動画・途中フレーム・同一UVによる境界表現を継承。
- 制作研究は[第2稿の調査記録](../2026-10-13-shield-titan-r2/README.md)を継続使用。今回の直接的な造形・素材の基準はユーザーが指定した第2稿③。
- 原版③を保持したまま、通常速度／0.5倍、白／暗背景、実GameView固定盤面、両陣営、スマートフォン、3枚同時、途中停止、低減モーションを確認する。
- 機能テストと見た目の採用判断は分ける。固定盤面の確認はオンライン対戦での本実装・本番性能の証拠ではない。

```
TITAN_CAPTURE=1 node tests/shield-titan-four-browser.mjs

```

## 確認結果

- ライフサイクル **64項目成功**。元の61項目に、4案の描画結果が異なること、終了後に4案とも同一のカード画像へ戻ること、比較元③へアクセスできることを追加。ブラウザ例外・シェーダーエラー・不足アセット0。
- 1倍／0.5倍の連続記録 `qa/continuous.webm` とコンタクトシートを確認。108フレームから `qa/comparison.mp4` を生成。白／暗背景、PC／スマホ、両陣営、3枚同時、中断、低減モーションの証跡を保存。
- モバイルの盤面モードは見出しを畳み、盤面全体を確認できる高さへ変更。操作欄の表示も自分／相手・枚数・移動モードの実状態と同期。追加の専用スモークテスト成功（`qa/mobile-controls.json`）。
- 専用TypeScriptチェックと比較用Viteビルド成功。Three.jsを含む約990KBの共有チャンク警告は残る。
- CPU側の4案描画呼び出しはこの実行環境で平均約3.66ms。GPUフレーム時間や本番性能を示す値ではない。反復後もgeometry／texture数は安定。
- 原版③の3ファイルが第2稿コミットと完全一致することを確認し、`reference-manifest.json` にSHA-256を記録。
- 比較用第3稿の4案は、ユーザーの個別選定待ち。ゲーム本体やステージングへの接続・公開はしていない。

追加の操作確認: `node tests/shield-titan-four-mobile.mjs`。
