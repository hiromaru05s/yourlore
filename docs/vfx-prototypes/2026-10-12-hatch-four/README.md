## 事前確認と反映

他セッションの記録では、呪術師の「急に別の物体が出る」「大きな粒でチープ」「カードを立てて落とす」、選ばれし英雄の「カードアートの安易な流用」「二重発火」が再発防止事項だった。本作では専用の殻メッシュと表面テクスチャをコードで制作し、実カード画像は開始・終了のカード面にだけ使う。カードは一貫して盤面と平行、同じスロットで変化する。終了時に追加の召喚衝撃を重ねない。

保存済みToon参照は衝撃25.70秒からの連続24fpsシートと炎44.00秒からのシートを確認。急なピーク→形が欠ける→細い残り、という時間設計を翻案。銀紋の流墨ではカード表面の変化から転送まで同じ中心と素材が保たれる点を基準とした。

## ４案

|案|主素材と構造|運動|ピーク|
|---|---|---|---|
|01 竜牙の開殻|縦７枚の厚い殻|鼓動→縦の割れ目→外へ開く→下端へ侵食|1.28秒|
|02 螺旋の脱殻|６本の螺旋の鱗帯|下から順次解放→帯の端から巻きほどく→縮退|1.48秒|
|03 内圧の破殻|大小27枚の殻片|二度の内圧→短く跳ねる→重力で沈む→欠ける|1.15秒|
|04 双翼の孵化|２枚の殻と内部の膜|中央裂開→左右開き→内膜が張る→折り収まる|1.38秒|

全案3.40秒。冒頭はカード面から殻が立ち上がり、殻の内側から召喚先のカード面が広がる。ドラゴンは角張った鱗面、神獣は乳白色と金の筋。殻は専用形状であり、カード絵を引き伸ばした板ではない。

## ランタイム接続時の注意

現行 `engine.ts:hatchEgg` は同じスロットについて `destroy(egg)` と `summon(result)` を別々に発行する。既存 `anim.ts` の破壊・召喚経路を両方走らせると孵化の前後で二重演出になる。本比較は両者を一つの時計で扱う専用プレイヤーであり、ゲームイベントのペアリングはまだ変更していない。採用後の接続時は、孵化であることを明示するイベントまたはペア情報を使い、汎用破壊・汎用召喚を抑止する必要がある。

`board.ts` は既存GameViewとboardProjectionを使用するローカルfixture。実際の孵化ターンや召喚効果、認証済みオンライン対戦の証拠ではない。シーク完了後は実カードDOMに受け渡し、再開・中断時は元の卵へ戻す。
