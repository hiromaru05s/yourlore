## 改稿内容

1. 紫墨の解呪: カード面を覆った湿った黒紫の被膜が四つの縁から反り、収束する。
2. 鎖印の解放: 二本の交差する鎖が張力を増し、中央から解放される。
3. 黒帷の開帳: 左右の長辺を支点に二枚の広い帷が開く。布の凹凸と透過。
4. 黒曜の再成: 実際のカード絵柄を保持した不規則な薄片が浮き、元の面に再成する。
5. 血蝋の血判: 細い流路から蝋が凝り、押された印が表面に戻る。
6. 呪冠の降臨: 枠を支点とする曲がった呪角が成長し、接地とともに沈む。

5枚の固有カード面と2600–3700msの段階差を維持。表面シェーダー、線画の刻印、素材テクスチャ、照明を追加。拡大・盤面では素材からカード面への影を描画する。六案比較は軽量化のためこの投影影を省き、共通の接地影を使う。鎖はインスタンス描画、六案は一つの描画面にまとめて転送する。

型チェックが隣接JSを生成し、Viteが古いJSを優先した問題を修正。専用tsconfigにnoEmitを設定し、今回生成したファイルのみ除去。以下は最新TSを読み込んだ後の再検証。
