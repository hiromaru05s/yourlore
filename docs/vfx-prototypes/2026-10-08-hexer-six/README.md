## 6案

1. 黒蝋の封解 — 黒蝋の被膜が亀裂から反り返り、表面に沈む。
2. 呪糸の抜縫 — 張った細糸が一針ずつ抜け、枠へ戻る。
3. 影絹の脱皮 — 透ける広い布面がめくれ、裾へ細く収束。
4. 呪脈の還流 — 刻まれた溝から立体の呪液が伸び、先端から戻る。
5. 黒曜の開扉 — 薄い層が縁を支点に開き、折り戻って沈む。
6. 呪札の折解 — 架空の文字がある紙帯が伸び、連鎖する折り目で収まる。

見習い2600ms→ケロイド3700ms。上位ほど構造の本数、浮上量、溜めが増す。表面の枠と絵柄を維持し、粒・独立した環は使わない。呪い付与やダイス成功・魔法無効を成功扱いする演出は含めない。

## 自己レビューで修正した点

- 初稿の蝋は硬い扇形に見えたため、幅方向の立体断面と不均一な切れ目、柔らかい反りへ変更。
- 初稿の呪脈が星形の放射線に見えたため、縦方向の幹と側枝に変更。
- 暗いマテリアルが黒潰れしたため、反射色・粗さ・補助光を調整。
- 既存CSSによってプレビューの文字が白くなる点を修正。
- 比較6案ごとにWebGLキャンバスサイズをリセットしていた処理を廃止。
- 盤面のケロイドはオーラ込みの数値になるため、盤面から取得した実際のカード面を使用。手札からの移動中は手札面。
- 再選択でカードテクスチャが蓄積しないよう最大10面に制限。

## 機能検証と見た目の判断を分離

- 専用tsconfigによる型チェック: 成功。
- 専用Viteビルド: 成功。大きいThree/GameViewバンドルの警告あり。これは比較用の独立ビルド。
- 全5枚×6案×5時点の描画: 30/30組でカードの可視ピクセルあり（形や質感への承認ではない）。
- 全5枚の接地時・終了時の高さ: 0。
- 通常時間の6案同時録画: 217フレーム、フレーム間隔中央値20.0ms / P95 30.1ms / 50ms超0。録画時のローカル環境の計測で、全端末60fps保証ではない。
- CUAで手札クリック→再生開始、自分側、相手側3枚同時、途中シークを確認。
- 390pxで中級・呪札を表示、documentのscrollWidth=390。横スクロールなし。
- 低減モーションに切り替えると描画中カードが通常DOMに復元。再生中の別ビュー切替は停止・復元し、iframe破棄時に描画資源を解放。
- 白背景・暗背景、横からの接地、低速はUIで切り替え可能。

`qa/all-thirty.png` は30組の形比較、`qa/six-peak.png` は6案の代表フレーム、`qa/six-continuous.webm` は実時間再生、`qa/continuous-contact.jpg` はその時系列、`qa/report.json` は機能・時間計測。
