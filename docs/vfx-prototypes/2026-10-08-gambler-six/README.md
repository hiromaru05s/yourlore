## 6案 × 2カード

1. 切札の扇 — 5枚の象牙紙、扇形展開と重なり、閉じて着地。
2. 象牙の賽 — カードを構成する面が立体の賽へ折れ込む。通常は1個、伝説は3個。目は意匠として固定されておりゲーム結果ではない。
3. 黄金の掛金 — 12片のカード面を硬貨へ連続変形。通常は1列、伝説は3列の積層。厚い金属縁と反射。
4. 緋絹の手品 — 9本の絵柄を保った帯が波打って交差。裏面の彫金と時間差の復元。
5. 運命の歯車 — 12面の象嵌が扇形へ変わる。赤／黒漆の表面が浮かび、局所的な回転盤からカードへ戻る。
6. 三紋の戴冠 — 3枚の層が尖った硝子面へ変わり、青・金・赤の彫刻面を返して復元。

各案は同じ表面座標を保ったメッシュ変形。カードを消して別オブジェクトを突然生成しない。細い金属縁、厚み、裏面、環境反射を分離。粒子・独立した魔法環は使用しない。元カード名とゲーム情報以外に自然言語の装飾は追加しない。
