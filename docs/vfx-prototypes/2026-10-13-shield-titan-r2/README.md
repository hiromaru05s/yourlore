# 盾の巨神 — 第2稿 / 4方向

ユーザーの「ダサすぎる」「もっとクオリティをあげて」に対する全面改稿。第1稿の板の開閉・積層・金属膜・城壁は却下された比較案として履歴に残す。第2稿は比較専用で、選定・ゲーム実装・ステージング公開ではない。

## 再調査と設計

- `docs/animation-quality-benchmark.md` / `docs/vfx-art-direction.md` / `docs/world-bible.md` を再読。最低基準「銀紋の流墨」の同じUVで素材・模様・境界を運ぶ構成を参照。承認済み画像や実装を改変しない。
- 過去のゴーレム／吸血鬼／通常召喚へのフィードバック：素材のないカードが最初に瞬く、カードが垂直に着地、同一演出の色替え、主形状が記号に見える、既存演出との二重発火を避ける。
- [Edward Lu: Rift Core Shield VFX Breakdown](https://straypixels.net/riftcore-shield-fx/)：シールドは一様な発光ではなく、面・輪郭・表面変化の役割を分けて対象の可読性を守る。今回の晶壁は面に沿った稜線と薄い素材境界へ翻案。記事の円や六角装飾は移植しない。
- [Denis Korystin: Shield & Sword](https://gamesartist.co.uk/shield-sword/)：盾を構成する異素材の連続性、輪郭、スカルプトの量感を参照。今回の石殻は一つの彫刻面を切り分け、割れても金属象嵌が連続する。

## 4つの演出

| 案 | 主素材／形 | 運動 | 解放 |
|---|---|---|---|
| 神殻の解封 | 厚みと稜線を持つ石盾、彫刻と象嵌 | 重く下降し、接地を起点に24の不規則な殻へ破断 | 中央から露出し、殻がカード面へ戻る |
| 蒼鋼の奔流 | 金属の連続面、湾曲と狭い反射 | 流体の端が巻き、張力を持つ盾面へ鋳造 | 下端から波状にカードへ還流 |
| 晶壁の覚醒 | 半透明の多面盾、面の稜線 | 平面から結晶が隆起、稜線を順に点灯 | 面へ沈み込みながら段階的に解く |
| 守誓の天幕 | 蒼い織布、金糸の裾と紋章 | 下端とつながった偏った風、遅れる細かいひだ | 布の波に沿って織り戻す |

3秒の共通時計で同時比較可能。カード表面は実際の `cardEl` から取得。全案の接地面はカードの表面と平行。影・局所光は接地時刻に同期する。WebGLは比較画面につき1つを共有し、場面終了・中断・低減モーション時は元カードを復元する。

## 検証

再現コマンド（worktreeルート）:

```
./node_modules/.bin/tsc --noEmit -p docs/vfx-prototypes/2026-10-13-shield-titan-r2/tsconfig.json
./node_modules/.bin/vite build --config client/src/dev/shield-titan-four/vite.config.mjs
TITAN_CAPTURE=1 node tests/shield-titan-four-browser.mjs
node tests/shield-titan-four-frames.mjs
node tests/shield-titan-four-record.mjs
```

確認結果は `qa/report.json` と画像・動画に保存。機能検証は見た目の承認を意味しない。実盤面は GameView の固定fixtureであり、オンライン対戦での実行実績ではない。

### 第2稿の確認結果

- ライフサイクル61項目成功。両陣営の4案、各時刻の描画所有、3枚同時、中断、低減モーション、再生反復、リソース解放、390px幅を確認。例外・シェーダーエラー・不足アセットは0。
- 専用TypeScriptチェック成功。比較ページのViteビルド成功（166モジュール）。Three.jsを含む約1MBチャンクの警告あり。ゲーム本体全体の検証を代替するものではない。
- 1倍／0.5倍の連続記録 `qa/continuous.webm` と時系列コンタクトシート `qa/continuous-sequence.jpg` を確認。最終の布紋章修正後もシェーダー／実行時エラー0（`qa/video-errors.json`）。
- 108フレームの決定的タイムラインから `qa/comparison.mp4` を生成。再生映像は動作設計の証拠であり、実機のFPS保証ではない。
- 4案同時のCPU描画呼び出し平均約9.83ms（この計測環境のみ、GPU所要時間ではない）。リプレイでgeometry／texture数の増加なし。
- 比較画像 `qa/four-850.png`、白／暗背景、実盤面の両陣営、スマホの画像を保存。640〜1000px幅は2列にして、アプリ内ブラウザでも同時比較可能にした。

見た目の見直しでは、初稿の均一な板・平坦な素材・同じ消失に対し、厚い破断面、硬化する反射面、段階的な結晶成長、織布の偏った動きを分けた。第2稿へのユーザー評価は未取得。
