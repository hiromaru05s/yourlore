## 造形の変更

紋章に見える帯・翼板・結晶群を取り除いた。長い犬歯には丸い歯冠、楕円の断面、内側へ曲がる先端を設け、根元から先まで陰影が連続する形にした。短い前歯は別の生成関数による幅広い切縁を持つ。低水準の歯の生成関数を共有し、組み立てと動作は6つの独立したクラスで実装する。

傷の座標は噛み込み時に固定し、牙が溶ける間に傷まで移動する問題を防いだ。研究資料と判断は [research.md](research.md)。

## 今回確認できた範囲

- TypeScript型検査、Vite比較ページのビルド。
- Node上で全6種×6案の形状・座標・離散時刻での盤面非貫通を確認。閉口量が単調に一度だけ増加すること、接触前に圧力が出ないこと、噛んだ後に傷の座標が動かないことを確認。[結果](qa/geometry-report.json)。反復アサーション数を独立したテストケース数として扱わない。
- 同じThree.js形状データをBlenderに読み込み、[開口時](qa/geometry-open.png)と[接触時](qa/geometry-contact.png)の輪郭を目視。短い前歯のくびれを修正。画像は中立色の仮カードと別の照明を使った形状確認用で、実ページのスクリーンショットではない。
- Viteビルドでは既存盤面モジュールを含むchunkのサイズ警告あり。

## 01のフレーム位置修正

追加フィードバック「カードフレームの一番上と一番下に来ていない」への対応。開口時の歯列の付け根を、280pxのカード高さから求めた上下端へ配置した。半径3.5pxの根元を枠内へ収めるため、中心線はy=±136.5。顎の傾きによる位置ずれも補正する。01では階級による全体縮小を止め、全6種で同じフレーム端に揃える。一度噛み込んだ位置は維持し、そこまでの移動幅を調整。表面の血の起点も同じ端に移した。

全6種、210/650/930msで根元中心が上下端に一致することを数値確認（最大誤差2.85e-14）。既存の形状チェック、型検査、比較ページビルド成功。[修正後の形状確認用レンダリング](qa/01-frame-open.png)。先の6案画像は位置修正前の記録で、この画像も実ブラウザの撮影ではない。ブラウザ検証の制限は継続。

## 再現

リポジトリ直下で:

```sh
node node_modules/vite/bin/vite.js --config client/src/dev/vampire-six/vite.config.mjs
node node_modules/typescript/bin/tsc --project client/tsconfig.json --noEmit
node node_modules/vite/bin/vite.js build --config client/src/dev/vampire-six/vite.config.mjs
node client/src/dev/vampire-six/geometry-check.mjs
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python client/src/dev/vampire-six/render-geometry.py
```

最後の2つはブラウザ不要の形状確認。既存のブラウザQA機能とは別。
