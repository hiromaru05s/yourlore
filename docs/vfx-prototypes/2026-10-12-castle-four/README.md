## 事前調査と具体的な反映

### 過去のユーザー指摘

- 選ばれし4種（01a1198d-1e36-7030-b95f-b7b98644d4e6）: 物質の連続性、案ごとの差、二重再生防止。専用の形状を制作し、カード絵を周囲の飾りとして複製しない。
- 呪術師（01a1198c-cc60-7232-910c-8d5dad0561b4）とゴーレム（01a11987-bca9-7332-bcb3-b335a4c37dbf）: 演出前に生のカードが出る問題。時刻0からカード面が被膜や扉で覆われた状態を用意。手札移動にも同じ時刻0の形状を使用。
- 商人（01a1198f-96a0-7950-99d4-9f6f398b2843）: コインが整頓されすぎて不自然、スクロールできない。今回は力の向きと支点を設定し、局所の位相差を付ける。比較ページは縦スクロールを許可。
- 記録済み共通指摘: カードは面で接地。粒子・環・色替えだけで別案としない。物体を突然出して消すだけにしない。

### 承認済み参照

`docs/animation-quality-benchmark.md`、`docs/vfx-art-direction.md`、`docs/world-bible.md`を着手前に確認。銀紋の流墨のinscription.mp4から6fps・18フレームのシートを作り、表面の予兆→同じ材質の変形→収束の流れを確認。既存ゴーレムの専用石材レンダラーと盤面投影も確認した。今回の石材・門・城の形状は新規制作。

### 一次資料

- [Riot: Visual Effects](https://www.riotgames.com/en/artedu/visual-effects): 満足感と可読性、発生源固有の表現、全体との調和。今回はカード周辺に範囲を限定し、形・明度・時間を整理する。
- [Blizzard: Developer Insights — The Art Behind THE SCIENCE](https://news.blizzard.com/en-gb/article/22552047/developer-insights-the-art-behind-the-science): 主動作を核に副次動作を重ねる制作、カードの意味に沿った素材と形、大きな単純形による明確な接続。今回は石積み・扉・鋳造・折り畳みを核にし、粒子を増やして代用しない。
- GDC Artistic Principles of VFXの資料を検索したが、PDF本文の取得はサイズ制限で失敗。閲覧済み資料には含めない。

上記記事は本文を確認。商用ゲームと同等の完成度という認定や、参照作品の内部実装を調査済みという意味ではない。

## 実装と境界

専用Three.js形状、白亜石の手続きテクスチャ、実カードDOMのキャプチャ、物理ベースの材質と影。4案のWebGLコンテキストは共有。全形状を事前に生成し、フレームごとのジオメトリ生成を避ける。盤面は実GameViewとboardMatrixを使い、同一レンダラーを投影する。

比較ページの「手札から召喚」は固定盤面の操作fixture。オンラインの効果処理・音・ネットワークイベントへの接続は未実施。実運用への採用時にはsummon/runtime.ts、anim.ts、duelScene.ts、monster/runtime.tsの単一所有を維持して接続する。現時点では共有実装を変更しない。

機能検証と見た目の評価は別。自動チェックだけでユーザーの品質承認を代替しない。

## 検証結果

- `qa/report.json`: 25項目、ブラウザー例外0。4案の途中フレームの差、終了時の同じカード面、低減モーション、390/818px、両陣営×4案、3枚同時、中断復元、10回反復でのGPU資源数一定、破棄を確認。
- 比較表示の測定: 240フレームのrequestAnimationFrame間隔、中央値16.7ms・p95 16.7ms。ローカルChromeの測定であり、実機スマホの保証ではない。
- `qa/comparison.mp4` / `.webm`: 通常速度・2回連続の比較動画。`motion-contact-sheet.jpg`: 動画から4fpsで抜き出した動作推移。
- `qa/comparison-final-page.png`、`qa/board-final.png`: 最終材質・照明の代表フレーム。
- 視覚確認では、カード面を保った接地、専用形状の違い、面からの立ち上がりと回収、実盤面での位置を確認。塔を箱形から円形石積みへ変更し、面取り・窓・帯・旗・環境反射を追加。壁の回転方向の不具合を修正。
- これはユーザーの品質承認、採用、認証済み対戦確認を意味しない。音声は未制作。
- `qa/final-check.json`: 最終UIの一時停止・続きからの再開・中断復元を確認、例外0。postMessageによる制御完了を待ってから判定する。
- 比較ページのViteビルド成功。約1MBの共有Three.jsを含むチャンクについてサイズ警告あり。今回は開発用比較ページの独立エントリーで、ゲーム本体の配信エントリーには追加していない。
