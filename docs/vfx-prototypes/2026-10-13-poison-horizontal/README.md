# 毒と菌の召喚：カード面・重力の作り直し

2026-10-13。3カード×4案の比較用。通常ゲームへの採用・配信はしていない。

## 修正した誤り

旧比較はカードと演出を同じ2D面に描き、液体の運動を画面の縦方向に置いていた。カードが伏せられた面であることを表現できておらず、前回の機能チェック通過はこの物理的・視覚的な誤りを保証していなかった。旧資料は履歴として残すが、現行の検証結果には使用しない。

今回、カードをXZ平面・面法線を+Y・重力方向を-YとしたThree.js描画へ置き換えた。カードは高さ62から640msまで同じ姿勢で下降し、四隅と面全体が同時に接地する。カード面上の移動と面からの高さを別の座標にした。

- 毒液：瓶口から面へ落下／面に付いた膜が潰れる／合流で上がった滴が落ちる／中心を残して膜の縁が垂れる。
- スラッグ：腹足が面を這う／菌床から傘が成長／低い粘液の波が面を横切る／殻床が左右に開く。
- マッシュルーム：複数の芽／大きな一傘／傘の下から落下する胞子／三株の時間差成長。

比較画面の「横から接地を見る」「真上から」で姿勢を確認できる。実盤面は既存DOMの射影行列を使い、3D頂点をその盤面に合わせる。手札から対象まで位置だけを移動し、飛行中もカード面を盤面と平行に保つ。

## 検証の範囲

- `qa/report.json`: 全12案、両陣営、手札クリック、3体同時、停止復帰、低減動作、320/390/844pxの機能検証。
- `qa/horizontal-report.json`: 高さの単調減少と接地、液滴落下、24頂点についてGPU用行列とDOMの射影を別々に計算して照合。
- `qa/*-side-*.png`: 落下・着地・主動作・終了の横視点画像。数値テストとは別に目視する。
- `qa/*-continuous.mp4`: 全4案を同一時計で24fps固定フレーム出力。実時間FPSの証明ではない。
- `qa/performance.json`: 4画面分の同期処理時間。GPU完了時間や実機スマートフォンの性能保証ではない。

表示切替で非表示iframeの寸法が0になる場合をガードした。これは初回検証のブラウザ例外で発見した修正。

見た目の最終承認、認証付きオンライン対戦、製品への組み込み・配信は未実施。この試作は姿勢と重力を確認し直すための比較版であり、機能検証を品質承認とは扱わない。

## 今回の実測結果

54項目のブラウザ機能確認は全件通過、ブラウザ例外0件。24頂点の射影誤差最大2.28e-13px。3体分・各84フレームの動画を書き出し、落下から復帰までの連続フレームと横視点を目視確認した。

比較4画面の同期処理は中央値4.9ms、p95 20.3ms、最大1497.5ms（初期生成を含む）。初期生成・実時間GPU負荷は本番組み込み時の別検証が必要。Viteビルドは成功、大きな共有チャンクの警告あり。
