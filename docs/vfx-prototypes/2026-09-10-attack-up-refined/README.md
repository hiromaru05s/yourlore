# 攻撃力バフ — 上矢印を主役にした簡素化

原神の公式Collected Miscellanyから九条裟羅・雲菫・申鶴・ミカの該当区間を観察し、実盤面のカードに沿う攻撃強化エフェクトを再制作した。詳細は [RESEARCH.md](RESEARCH.md)。その後のユーザーフィードバックに従い、光の帯を廃止し、上矢印が最も目立つ構成へ修正した。

## リアルタイムで見る

リポジトリルートで以下を実行し、http://127.0.0.1:5196/ を開く。

```sh
./node_modules/.bin/vite --config docs/vfx-prototypes/2026-09-10-attack-up-refined/vite.config.mjs
```

場のモンスターをクリックして対象変更。再生、停止、スロー、シーク、ループで比較可能。効果音は任意の補助機能で初期状態OFF。ブラウザで合成する短い上昇音で、動画には含めない。音の聴感品質の検証は今回の視覚確認の範囲外。

## 現在の構成

- 上矢印3個の形・色・上昇位置・時間差・フェードは維持。
- 上矢印を最前面に描画（外側100／内側101、depthTestなし）。補助光で輪郭が隠れない。
- 太い光の筋6枚、回転する帯4本、拡散リング、中央の閃光を削除。画像テクスチャの読み込みも廃止。
- 補助は最大不透明度0.32の細い縁光と、外縁の小さな粒6個。カード面を塗らず、粒の上昇幅もカード幅の0.075倍に抑え、矢印の主な再生区間より先に消える。
- 数字・文字のオーバーレイなし。カード本体・数値は固定し、現在のGameViewとboardProjectionを利用。

## 検証

[qa.json](qa.json) に結果を保存。

- 初期・発動・終了で攻撃力表示は6のまま。数値オーバーレイ0個。
- 対象カードの矩形が再生前後で完全一致。
- 相手側のカードでも対象切替と固定された攻撃力表示を確認。
- 1280×720、1920×1080、390×844の表示。390pxで文書の横幅390px。
- 新規JavaScriptエラーなし。既存テーブルのPCFSoftShadowMap非推奨警告は残る。
- 現在のGameViewを含むesbuildバンドル検証、git diff --check通過。
- MP4: H.264、30fps、85フレーム、盤面1280×720／拡大600×440、2.833秒。

## 境界

採用済み。GameView の再描画で同一モンスターの実効攻撃力上昇を検出し、自動発動する。初回・新規召喚・減少・同一スナップショットの再描画では出さない。オーラや両陣営の同時強化も対象。終了・画面非表示・画面破棄時は停止し、reduced-motion時は出さない。通常のプレビューは演出専用フィクスチャ。`?integration=attack` を付けるとボタンでテスト用の攻撃力を1ずつ増やし、本番と同じ自動発動経路を確認できる。マルチプレイ実戦とGPUフレーム時間の実測は未実施。別の透明キャンバスを使っており、家具などと同一の深度バッファは共有しない。原神と同等品質を証明したという主張ではなく、具体的な映像観察を反映した再設計とその実物である。
