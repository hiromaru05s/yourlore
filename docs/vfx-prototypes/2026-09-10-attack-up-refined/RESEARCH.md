# 原神のスキル表現から攻撃強化の演出を設計する

## 結論

今回の攻撃強化は、カードを光の筒で包む演出ではなく、対象の下側から鋭い光が駆け上がり、暖色の上向きマークが追いかけ、短い余韻へ移る構成とする。カードそのものは盤面に置かれた姿勢を保つ。数字・文字・中央に貼り付く剣アイコンに意味を依存しない。

原神の品質を「粒子が多い」「金色に光る」と捉えるだけでは不十分である。調査した場面では、攻撃が起きる場所、強化される対象、効果が残る対象に、それぞれ異なる大きさと密度の形が割り当てられている。大きな発動の形と、説明の少ない持続状態の印を分けることが、今回の小さな盤面カードへの転用で特に重要になる。

以下の「観察」は公式映像の該当区間をブラウザでシークして目視した内容。「判断」「採用」はその観察から行った独自の設計判断であり、HoYoverseの内部制作資料・使用シェーダー・制作仕様を示すものではない。

## 資料の選定と観察範囲

派手なカメラ編集を含むキャラクターPVだけでなく、実際の戦闘画面とスキル説明が共に映る公式のCollected Miscellanyを主資料にした。比較対象は九条裟羅、雲菫、申鶴、ミカ。いずれも支援・強化に関わる表現を含むが、効果のゲーム上の意味は同一ではない。

九条裟羅は攻撃力強化の意味を伝える形の参照、雲菫は通常攻撃強化の状態を示す形の参照、申鶴は白い光の芯と形のまとまりの参照、ミカは攻撃速度・回復など複数の支援を混同しないための比較とする。ミカの回復や申鶴の氷元素の表現を、そのまま攻撃力UPの記号として転用しない。

## 公式資料から確認できる意味の違い

雲菫の元素爆発は、近くの味方に通常攻撃ダメージを高めるFlying Cloud Flag Formationを与える。この効果の存在と通常攻撃との関係は、公式のバージョン2.4更新説明にも記載されている。[1]

ミカのSoulwindは攻撃速度上昇、元素爆発は回復を含む別の支援である。これも公式のバージョン3.5更新説明に記載される。[2] 見た目の青白さだけを真似すると、攻撃強化より氷属性・回復を連想させる可能性がある。今回の主色を暖色に寄せるのは、この意味の混同を減らすための設計判断である。

九条裟羅の2:01付近では、攻撃力補正の説明とともに、対象周囲に暖色の上向きの形が見える。[3] ここから「攻撃力が増した」ことを数値なしで表す主な手掛かりを、上向きの形と上昇する運動に置く。

## 形の品質

### 主役の形と補助の粒子

雲菫の場面では、旗状の明るい形と周囲の小さな粒子を別々に読み取れる。申鶴の場面でも、白い縦の光や周回する形を先に認識し、細かな光はその後に見える。[4][5]

今回の判断は、主役を太さの変わる数本の光に限定すること。粒子を増やして主役を作ろうとしない。カード幅が約70〜80pxの画面では、小さな菱形を均等に並べても意味のある形にまとまりにくい。線だけの図形ではなく、太い胴・鋭い先端・細く途切れる尾を持つ形を使う。

### 芯・周縁・空白

申鶴の1:42付近は、白い芯と青い周囲、透明な空間を分けて認識できる。[5] 今回は色そのものをコピーせず、明るいアイボリーの芯、アンバーの周縁、透明な内部という構成へ置き換える。

カード中央の絵を常時塗りつぶすと、対象を強化したというより別のエフェクトを上に置いたように見える。筆状の光は主にカードの左右から立ち上げ、中央には一瞬の小さな光と、時間差の上向きマークだけを通す。

### 同じ形を同時に並べない

前の版は、均等な線・小片・中心アイコンが似た速度と濃さで動いていた。結果として、装飾が増えるだけで力が入る瞬間が弱かった。今回は発生時刻、幅、高さ、消える時刻をずらす。ただし無秩序なランダム化ではなく、全て上昇する一つの流れに従わせる。

## 時間の設計

以下は原神から測った秒数ではなく、LOREの盤面向けに設計した今回の値である。

| 時間 | 見えること | 意味 |
|---|---|---|
| 0.00–0.20秒 | カード面の縁に光が集まる | 対象の特定、直後の変化への予告 |
| 0.20–0.40秒 | 短い白い芯と接地する光の波 | 強化が成立した瞬間 |
| 0.37–1.20秒 | 筆状の光と上向きマークが時間差で上昇 | 数字を使わない上昇・強化の手掛かり |
| 1.20–2.20秒 | 光の輪郭が欠け、粒が細く散る | 力が対象に定着して余韻に移る |
| 2.20–2.80秒 | カードが通常の読みやすさに戻る | 連続再生の比較用の静かな間 |

最大の発光を長く保たず、短いピークへ集中させる。長い尾は単に透明度を下げるだけでなく、輪郭の一部が消え、残った細い光も消えるようにする。これは今回の制作上の選択で、原神の実装が同じ手法であるという主張ではない。

## 盤面への翻訳

このリポジトリの現在のGameView、カード原画、盤面の32度のカメラをそのまま読む。カードを立たせたり、拡大した別のカードへ置き換えたりしない。エフェクトの中心と大きさは対象の実レイアウトから毎フレーム算出する。

白い盤面では白だけの加算光が見えにくい。そこで、周縁にアンバーの色を残す通常の透明合成を主体とする。全画面Bloomは使用しない。加えて、新規に作成した透過の筆状テクスチャを使い、プログラム上の線だけでは出せなかった内部の筋や尾を作る。

上向きマークは原神の画像を切り抜いた素材ではなく、新しく描いた二層の形。動く方向を示すために使用する。数字・ATK文字・プラス記号・中央の剣はエフェクトに含めない。元のカード印に表示されている攻撃力などはゲーム画面の情報として残すが、この試作では数値を変えない。

## 旧版への評価と今回の変更

| 旧版の問題という判断 | 再設計 |
|---|---|
| 大きな螺旋や輪郭線が主役で、攻撃強化の意味が弱い | 主役を上昇する光と上向きマークに変更 |
| 一様な発光と均等な小片で装飾的に見える | 太さ・開始時刻・寿命・輪郭の欠け方を変える |
| 中央の剣が小さな記号に見える | 中央の剣を廃止 |
| 数値が意味を説明していた | 数字と文字のオーバーレイ、数値変更処理を廃止 |
| 小さなカードに対して細部が細すぎる | 実サイズで見える面積を持つ筆状の光へ変更 |

## 検証上の限界

この分析は、公式映像の選んだ区間と目視できる形を根拠とする。内部のテクスチャ解像度、粒子数、GPU予算、シェーダー構成、原作のフレームごとの速度曲線は確認できていない。今回のパラメータは独自設計であり、原神と同等品質を客観的に証明するものでもない。

単体エフェクトの見栄えと、実際の対戦で邪魔にならないことは別に評価する必要がある。この試作は実盤面を使うが、対戦ルールとの接続、多数同時発動、全端末の性能保証は含めない。好みへの適合は、再生した見た目に対する評価で最終確認する。

## 視認性の修正

ユーザーが上矢印の表現を評価し、光の筋がそれを隠すと指摘したため、太い光・帯・閃光を削除。上矢印の動きは維持し、最前面に描画する。現在の補助は細い縁光と外縁の小粒6個のみ。先述のテクスチャを使う構成は初版の記録である。
