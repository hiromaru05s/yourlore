# LOREのVision・Mission・Value

## Vision｜実現したい未来

カードゲーム領域において、最もエキサイティングなスポーツをつくる。

## Mission｜果たす使命

カジュアルさと奥深さの両立を、極限まで追求する。

## Value｜大切にする価値観

**創造性：プレイヤーの個性を尊重する。**

独自のコンボやデッキ構築を通じて、自分らしい戦い方を楽しめる。

**公正・公平：公正なゲームプレイ体験を届ける。**

パワーをお金で売らず、構築の工夫やプレイングで競い合える。

**遊びやすさと戦略性：すべてのカードに、カジュアルさと戦略性を織り込む。**

気軽に楽しめて、使い方を考えるほど奥深さが見つかる。

## LOREで届けたい体験

**自由に組み、何度でも試せる。**

お金を理由にデッキ構築を諦めず、さまざまなデッキやコンボを楽しめる。

**構築も、対戦中の判断も面白い。**

デッキの強さだけでなく、その場の判断やプレイングが勝敗を左右する。

**毎ゲーム、新しい戦略を考えられる。**

対戦ごとに有効な戦略が変わり、決まった正解をなぞるだけでは終わらない。

**ボードゲームのような駆け引きがある。**

『Splendor』のように、状況を読み、選択を積み重ねる面白さがある。

**カードの組み合わせで、遊びそのものが変わる。**

多様なコンセプトのカードを取り入れる。300枚のうち50枚が変わるだけでも、別のゲームのような体験を生み出したい。

## 背景にある考え

**カードゲームの競技としての可能性を広げたい。**

囲碁・将棋・チェスのように、カードゲームも頭脳で競い合うスポーツとして、もっと広く受け入れられる可能性がある。今後の社会では、人が夢中になって遊べるコンテンツの価値も、さらに高まると考えている。

**デッキ構築の楽しさを、課金で制限したくない。**

原点には「デッキを考え、組むことが好き」という思いがある。構築にお金がかかると、いろいろなデッキを試しづらくなる。試行錯誤そのものを、誰もが楽しめるようにしたい。

**強さの販売に依存する事業構造を避けたい。**

強いカードを売ることが収益につながると、より強いカードを販売する動機が生まれる。その構造に問題意識がある。プレイヤーの創造性と公正な競争を守れるビジネスモデルを目指したい。
