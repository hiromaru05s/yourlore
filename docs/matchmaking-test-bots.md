# マッチング確認用BOT

ステージングのノーマル／ランクで相手がいないとき、約10秒でテストBOTにマッチする。既存の人間同士のマッチを先に処理する。HOMEのBOTモードとは異なり、サーバーのオンライン対戦ルーム・ランクのマーケット確認・開始演出・結果処理を通る。

- BOT 01 Ember / 06 Flint: AGGRO
- BOT 02 Willow / 07 Reed: RAMP
- BOT 03 Slate / 08 Onyx: MIDRANGE
- BOT 04 Clover / 09 Hazel: GAMBLER
- BOT 05 Lumen / 10 Iris: ELF

10プロフィールを順番に使用。対戦名にBOT番号を表示する。実ユーザーの接続数や待機人数を偽装しない。BOT用ブラウザや常駐PCは不要。各ルームは独立し、同一プロフィールで複数ルームが並行しても動作する。

`MATCH_TEST_BOTS = "1"` の環境だけで新規BOTマッチを有効化する。初期設定はステージングのみ。本番には設定しない。フラグを外しても既に始まったBOTルームは完走できる。URLやクライアントメッセージでは有効化できない。

ランク戦は通常と同じMMR計算・勝敗記録を使うため、ステージングのユーザーとBOTのMMRが実際に変動する。BOTのランキング行も表示される。BOTアカウントは最初のBOTマッチ時に冪等作成し、ログイン用パスワードやセッションを発行しない。スキーマ変更なし。

BOTはプレイヤーと同じ情報制限を適用した状態から判断し、サーバーの乱数シード・相手の手札・伏せカード・デッキ順を読み取らない。1アクション約1.2秒で、永続化したAlarmから実行する。人間が切断した場合は行動を止め、再接続または既存の切断敗北期限を待つ。

検証: `node tests/match-bots.mjs`。10体のローテーション、両キュー、人間優先、無効環境、キャンセル、準備失敗、開始前入力制限、休止復帰、10体の複数ターン進行、ランク結果の二重加算防止、未参加無効試合、切断／再接続を確認する。
