# ガーディアンゴーレムの気合補充ループ調査

調査日: 2026-10-07 / 対象: `644fa2d7` の共有ゲームエンジン。

## 結論

`NWL3`（ガーディアンゴーレム）の `gutsOnHit` が、攻撃ダメージ判定より先に気合を1個付与する。同じ攻撃が致命傷でも、その気合を消費して体力1で耐える。次の攻撃でも再補充され、通常の被攻撃では気合を枯渇させられない。表示だけの問題ではない。

カード定義も「攻撃を受けるたびカウンター1個」となっているため、単なる重複実行ではなく効果仕様と気合の組み合わせに問題がある。オンラインも同じエンジンを利用するが、公開環境の配信コード・実対戦は今回未確認。

## 再現

リポジトリルートから `node docs/bugs/2026-10-07-golem-guts/reproduce.mjs`。
これは現在の不具合を確認する調査用スクリプトであり、修正済みであることを保証する回帰テストではない。通常の召喚・攻撃アクションを使用し、各攻撃の前に新しい攻撃側モンスターを設置する。致命攻撃の繰り返しで先にプレイヤーが敗北しないよう、プレイヤー体力を10000にしている。

| 攻撃力0で100回攻撃 | ダメージなしで気合が1から101に増加 |
| 攻撃力1で1回攻撃 | 体力9から8、気合1から2 |
| 兵士・リーダー・マナゴーレムに致命攻撃を2回 | 最初に気合を消費、次に破壊 |
| 戦士ゴーレムを召喚 | 単独なら気合1、他のゴーレムがいると気合4 |
| リーダーの味方を1体破壊 | リーダーの気合が1だけ増加。続く攻撃力0の攻撃では増加なし |

## 推奨する修正方針（未適用）

ガーディアンの追加付与条件を「0より大きい通常攻撃ダメージを受け、気合を消費せず生存した場合」にする。致命傷では手持ちの気合を消費するだけとし、攻撃力0では増やさない。日本語・韓国語・英語のカード説明も同期する必要がある。

単純にカウンターの上限を設けても、致命傷の直前に1個補充できる限り連続耐久は解消しない。また、付与をダメージ処理後に移すだけでは、気合で耐えた直後に再補充されるため、やはり解消しない。

今回は精査の依頼として、実装・カード効果は変更せず、調査結果と再現スクリプトのみを保存した。main・公開環境への反映は行っていない。

## ステージング反映依頼後の修正

ユーザーの反映依頼に従い、推奨方針を実装した。致命傷・攻撃力0・無効化・反撃では補充せず、非致命の正の通常攻撃ダメージを耐えた場合にだけ1個付与する。日韓英のカード説明を同期。`tests/golem-guts.mjs` の12ケースを通常のリリーステスト一覧に追加した。上記の再現スクリプトは修正前の記録として保存しており、修正後は不具合の期待値で失敗する。
