各案はスリーブと「デッキ置き場＆墓地」の2商品。既存ショップと同じ0シャードで取得し、デッキの外観から別々に装備できる。共有カタログをサーバーの取得・所持・装備検証にも使用する。既存の白磁のアイリス (`porcelain`) や翠銅の標本 (`verdigris`) とは異なるID。

原案: `docs/cosmetics/2026-10-07-living-duo` の revision 4。選択された2点の原寸PNGをバイト同一で移植。02/03/05の画像・商品は追加しない。新規モジュール `client/src/ui/cosmetics/living/` は原案の表面変形、白磁の曲面、革の縁・葉の変形を保持し、実盤面のカード・枚数・高さに接続する。墓地表面には実カードを表示し、空の置き場では底の絵柄が見える。

両陣営のスリーブと家具を独立解決。盤面と共通のカメラ・深度を使い、既存WebGLコンテキスト内で描く。非同期画像ロード完了時に再構築し、低減モーションでは静止。素材画像は参照カウントで共有し、盤面破棄・ショップサムネイル生成終了後に解放する。ショップの家具サムネイルも同じ形状から描画し、「実盤面で見る」は通常の装備アダプターを使用する。
