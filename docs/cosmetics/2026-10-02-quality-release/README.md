# コスメティック品質改修・ステージング採用

2026-10-02。前回の[品質監査](../2026-10-02-quality-audit/README.md)を受けた実装。厚みを増やす実験と、ぼけ／素材／装着価値の修正を分離した。新8セットを通常の装備カタログへ追加し、ショップから実盤面プレビューへ移動できる。

## 原因と対応

| 監査 | 今回の対応 | 境界 |
|---|---|---|
| Q01 描画密度 | 標準はDPR上限2、静止盤面600万画素。移動レイヤー420万画素。高密度時はキャッシュの重複MSAAを省き、既存の静止キャッシュを維持 | 4K画面でも無制限にDPR 2にしない。設定に旧予算の軽量モードを追加 |
| Q02 / Q07 実寸の主形状 | 微細な模様だけで区別させず、外周に太い面・別の形を配置。近景を同じ実盤面で確認するボタンを追加 | スリーブ原画そのものを2K/4Kに再生成したという変更ではない |
| Q03 反射 | 新スリーブを照明に反応するPhysical材質へ。箔領域／粗さ／微細な凹凸を印刷色から分離。白磁の縁のコントラストを追加調整 | カード表面の文字は元のDOM描画を維持 |
| Q04 素材情報 | 本体に木目・革・石・釉薬用の専用法線／粗さ。内張りの元の織物情報を保持。革をwoodとしていた分類を訂正 | 法線は絵の明暗から推測せず、材質空間で制作 |
| Q05 / Q06 外装 | 全8種に個別の外周形状。カードの接地面・座標・枚数は共通。潮硝子／琥珀の部分材質には薄い透過層 | ベースGLB全体を8個作り直したものではない。外装を共有筐体に組み合わせる方式 |
| Q08 / Q09 動的素材 | 待機面に明示的な象嵌マスク。共通位相をドロー裏面と購入の立体カードにも接続。ドロー断面の光もセットの色に合わせる | 手札の非公開面は公開しない。承認済みリシャッフル・リフトの変形演出は変更しない |
| Q10 所有者視点 | 自分／相手／両者、ドロー・購入の再生と近景で確認。通常のテンポは維持 | 自分の表向きカードに裏面柄を常時重ねる変更はしない |
| Q11 プレビュー | 盤面を厚み実験より上へ。選択欄を圧縮。装着部の拡大、回転できる家具の拡大、別画面表示 | 狭い画面では全景の物体は小さくなるため近景と併用 |
| Q12 原画 | 既存の生成原画・約1Kの配信画像を保持 | 機械的拡大を高画質化と呼ばない |

価格は既存コスメティックと同じ0シャード。取得・装備の認可は既存サーバーAPIを使い、アカウントへ自動付与しない。スリーブと家具を別テーマで装備した場合も独立して適用する。

## 8セットの見た目の判断

カードの載った白い実盤面で、両陣営・全8種類を確認。次は制作側の評価であり、ユーザーの見た目の承認ではない。

| セット | 外装と材質 | 判断 |
|---|---|---|
| 星を綴る夜 | 黒檀の段差、古銀の縁、切り欠いた角 | デフォルトより暗い本体と角の形で差が出る。紺と銀の系統自体は近い |
| 白磁のアイリス | 花弁の側面、釉薬、青灰色の金属縁 | 白い盤面への埋没を縁の明度差で改善。白さを主題として残す |
| 緋翼の誓約 | 重なった翼の側板、黒紅の漆 | 外周の斜めの形がカードに隠れず残る |
| 翠銅の標本 | 粒状の革、葉形の銅金具 | 茶色い木目の共通材質から離れ、緑と金具のまとまりが出る |
| 琥珀の記録 | 厚い琥珀色の角、木の本体、薄い透過材質 | 黄の中央と角が小さい盤面でも見つけやすい |
| 潮硝子の庭 | 波形の二重縁、銀と薄い硝子層 | 螺旋と波形の外周が対応。透過を盤面全体へ広げない |
| 銀脈の流墨 | 分割した石の側面、細い銀脈 | 暗い本体と面に沿う銀の変化。移動中にも同系統の箔が続く |
| 熾火の心臓 | 欠けた石の側面、橙の亀裂 | 銀とは異なる熱の周期。カードの断面まで橙で統一 |

厚みは通常の1倍を維持。3倍はプレビューで比較できる。少ない枚数を、枚数を偽装して厚い山にする対応ではない。

## 検証

- `cosmetic-studio-browser.mjs`: 8種×2陣営、0/1/8/12/40枚、7体配置、切替競合、停止、低減モーション、4画面サイズ、回転ビュー。装備変更前後のカード／家具アンカーの矩形は一致。
- `cosmetic-release-browser.mjs`: プレビュー専用アダプターを登録せず通常対戦の装備解決経路で8種×2陣営。スリーブと家具の混在装備、DPR 2で4サイズ、ドロー／購入／リシャッフル、終了後の残骸と描画エラー。
- `cosmetic-quality-audit.mjs`: 3画面サイズ×旧／高密度の6描画条件、16盤面、6固定位相。
- `cosmetic-quality-motion.mjs`: 動的2セット×両陣営の通常速度の待機→ドロー動画。時計の進行も検証。
- カタログの24アイテム（旧8＋新16）の未取得装備拒否、価格を偽装したリクエストの無視、重複取得、装備種別をサーバーテストで確認。
- 断面・厚み・山札のテスト。束内部の印刷面を省き、最上面と全カードの断面だけを描く。8枚なら面のメッシュは16個から2個へ、20枚なら40個から2個へ減る。GPU全体の改善率ではない。
- 型チェック・配信用ビルド・既存総合テストは配信ガードでも実行する。配信結果は `staging.json` に記録。

動的2セットを両側に表示した5秒区間で、重い盤面全体の描画は双方 **0回**、表面更新は301回だった。実測記録は `qa/studio-results.json`。これはキャッシュの保持を示す値で、端末全体のFPS・GPU時間の保証ではない。

機能検証と視覚評価を分ける。認証済みの二人対戦、実機モバイルでのGPU性能、ユーザーによる見た目の承認は今回の自動テストでは認定していない。
