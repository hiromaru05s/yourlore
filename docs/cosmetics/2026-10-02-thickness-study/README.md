# カードの厚み — 現状と3倍の比較

ローカルの実盤面プレビューで、同じスリーブ・枚数・カメラ・演出時間を保ち、既存のカード厚だけを3倍にする実験。通常対戦への採用、マージ、ステージングへの配信は行っていない。

[3倍のプレビュー](http://127.0.0.1:5336/cosmetic-studio.html?set=tidal&side=self&thickness=3) を開き、「現状 1×」「厚み 3×」で比較する。自分／相手の装備を選び、ドロー・購入・召喚・攻撃・リシャッフルを再生できる。「カード断面を拡大」では、家具を外した1枚と束を低い角度から比較できる。ドラッグで回転、スクロールで拡大。枚数選択は右側の束に反映する。

## 調査結果と見た目の判断

厚みは薄っぺらさの一因。ただし、現在は静止した束とドロー中で厚みが異なり、召喚・攻撃のカード面には立体の断面がない。

| 描画経路 | 現状の厚み／カード幅 | 3倍 | この実験の変化 |
|---|---:|---:|---|
| 山札・シェルフ・購入中の立体 | 約0.73% | 約2.18% | 断面、積層間隔、束の上面、購入の発着位置 |
| ドロー中の立体 | 2.4% | 7.2% | 本体、裏面、光の位置、山札からの開始位置 |
| 召喚・攻撃・通常の場のカード | 立体の厚みなし | 同じ | 既存の平面カード演出をそのまま比較再生 |
| リシャッフル | 転送中は平面 | 同じ | 束の高さに応じた発着位置が変わる |

静止した束を3倍にすると、少ない枚数でも高さが出る。一方、現状の束の側面は単色でカード同士が密着するため、拡大すると一体の板のように見える。厚みだけを増やしても、1枚ごとの境界や素材感が十分には増えない。ドローは元から束の約3.3倍の相対厚であり、さらに3倍にすると厚板に寄る。

**判断：少ない枚数のLOREに厚みを持たせる方向は有効。ただし一律3倍の本採用より、断面の境界・陰影と描画経路間の厚みの一貫性も一緒に設計するのがよい。** 本実験では判断を混ぜないよう、側面の材質・継ぎ目・動作の速度・回転・軌道を作り直していない。カード束の高さが変わるため、束を起点／終点にする動作の座標は追従する。

この見た目の判断は制作側の評価であり、ユーザーの採用承認ではない。

## 実装範囲

- `cardThickness.ts` に元の値を移動。通常ルートは常に初期値1倍。
- スタジオの独立したiframeが起動時に1倍／3倍を選ぶ。厚みの切り替えはiframeを再生成し、既存の形状キャッシュが残るのを防ぐ。アカウントやlocalStorageに保存しない。
- `pileModels`、`sceneMotion`、`drawStock`、`paperDraw` が使う既存の形状・積層計算へ反映。旧 `PaperCard` 経路も値を揃えるが、これは現在のドロー経路ではない。
- 既存の `animateDraw`、`buyReveal`、`ghostSummon`、`attackStrike`、`animateReshuffle` を破棄可能なサンプル対戦で呼ぶ。ゲームの入力・購入API・ネットワーク対戦は実行しない。各再生前に盤面をリセットする。
- 再生中は比較用操作をロック。終了後に解放する。

## 検証

機能検証と見た目の評価を分けている。

- `node tests/card-thickness-preview.mjs`：実形状の厚みを1→3→1倍で測定。1・4・8・12・40枚、デッキ／シェルフの上面座標と底面の位置を検証。
- `node tests/solid-draw.mjs`：既存ドローの立体、手札への着地、リサイズ／スキップ時の後始末などが成功。
- `tests/card-thickness-browser.mjs`：1／3倍 × 自分／相手 × 5演出の20パターンが成功。実際のドロー要素の厚み、演出後の残留要素、UIロック解除、断面ビューの枚数変更を検証。JS・HTTPエラーなし。
- 通常盤面の既存インテグレーション確認が成功。結果は `qa/normal-board.json`。
- 最終UIは1600×1000、1280×720、390×844で確認。横方向のはみ出しなし。
- `npm run typecheck`、`LORE_BUILD_PREVIEW=1 npm run build` 成功。既存のバンドルサイズ警告は残る。
- `qa/*-sequence.mp4` は1／3倍・自分／相手の連続録画。ドロー→購入→召喚→攻撃→リシャッフルの順。初期ロードも含め、先頭のドローを切り落とさず保存した。

ブラウザ検証の再実行例：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs \
STUDIO_ORIGIN=http://127.0.0.1:5336 \
STUDIO_QA_OUT=/tmp/lore-thickness-qa \
node tests/card-thickness-browser.mjs
```

ローカルの表示・実演出関数の検証であり、認証済みオンライン対戦やステージングでの検証ではない。起動方法と8セットの元の制作範囲は [前の制作資料](../2026-10-02-eight-sets/README.md) を参照。
