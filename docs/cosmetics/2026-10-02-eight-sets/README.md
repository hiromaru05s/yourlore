## 造形と画像

生成モードは **built-in imagegen**。各セットを別々のプロンプトで生成し、色替えだけの派生にしない。原画PNGと生成プロンプトを `source/<id>/` に保存。プロンプト全体と生成元の対応は [source/generation.json](source/generation.json)。

生成のネイティブ解像度は、星を綴る夜が1024×1536、その他が1003×1568。2K生成と称さず、元PNGを保存したうえでスリーブ比率へ整える。配信サイズは1024×1600 WebP、低解像度版512×800、一覧用256×400。従来の非デフォルト384×576画像を拡大したものではない。

家具は既存の共通GLBを使用し、形状とカード領域を守る。底面の意匠、側壁の無地素材、外装の細密彫刻、金属部を分けて仕上げる。底面には平面UVを与え、側壁へ絵柄が引き伸ばされないようにした。外装は編集可能な2K SVGとPNGから1024角へ書き出す。底面の画像は縦長の実寸に戻るUV用の1024角テクスチャ。金属度・粗さ・クリアコートも素材別に設定する。

配信画像：`client/public/cosmetics/atelier-v1/<id>/`。全配信画像のサイズ、SHA-256、元画像寸法は [assets.json](assets.json)。再生成：

```sh
node scripts/cosmetics/build-atelier.mjs
```

## アニメーションの範囲

銀／熱のマスクは画像中の銀色の刻線／橙色の亀裂から作る。外装の象嵌には専用マスクを使う。動く箇所は山札の一番上のスリーブ、デッキ置き場、シェルフの外装・底面。相手の手札裏面は同じ原画の静止画とし、手札全体を常時発光させない。粒子や輪を独立して飛ばす演出ではない。

家具の光はキャッシュした盤面深度で隠蔽し、カード下へ隠れた底面を透過表示しない。山札最上面の反射はそのカードの形状に限定する。通常の盤面キャッシュを保ち、動的な素材面だけを重ねて描画する。`prefers-reduced-motion: reduce` では静止素材になる。

## 実装範囲

`client/src/dev/cosmeticStudio/` にプレビューを隔離。通常対戦はアダプターを登録しないため、新セットの画像やアニメーションを読み込まない。プレビュー用SLEEVES登録は別ページ内だけで、共通ショップカタログ、購入状態、装備APIを変更しない。

通常ビルドのHTML入口には含めない。配信形式のプレビュー確認用には `LORE_BUILD_PREVIEW=1 npm run build` を使う。ステージング／本番へのデプロイやショップ採用は、この制作プレビューには含まれない。
