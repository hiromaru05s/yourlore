## 見た目

実盤面16枚と、家具拡大8枚を保存。画像の名前は `<set>-self.jpg`、`<set>-opponent.jpg`、`<set>-furniture.jpg`。`collection-sheet.webp` は8種のスリーブ一覧。`pile-*-dense.jpg` は束の枚数と7体展開の比較。

確認・修正した点：

1. 家具の底面で絵柄が歪まない平面UVに変更し、側壁は独立した無地素材にした。
2. 銀の反射が細い枝と羽根ペンの溝を渡り、熾火は細い亀裂だけを明暗変化させる。暗部全体の点滅や独立した粒子を足さない。
3. 動的面に加算反射と素材別マスクを使い、通常倍率でも変化が読めるよう調整した。
4. カードを載せた状態と空の家具を比較し、シェルフの前面カード表示を保った。
5. 自分／相手側それぞれの連続再生を録画。抽出した連続フレームでも反射位置／亀裂の明暗の推移を確認。`motion-samples.png` は停止位相0・2・4秒の拡大比較で、動画そのものではない。
