## 実装内容

- v44の関連カード7枚削除・10枚リワーク・トラップマスター廃止は[確定一覧](approved-rework.md)を参照。以下は前段の罠廃止（v43）の対応。

- `cards.ts` の既存の段階的バランス更新に合わせ、全定義・パッチの評価後、ローカライズと `ALL_IDS` / `BUYABLE_POOL` 生成前に全ての `t: "trap"` を最終DBから削除。
- 初期デッキ用のミミックパーティー／談合も `DECK_POOL` から除外。保存済みデッキは既存の `sanitizeDeck` で無効な罠を取り除き、不足分をカルで補う。残ったカードの順番・プリセットの選択を保持。
- 保存済みウォッチリストも既存の `sanitizeDecks` で補正。関連カード表示は存在しないIDを参照しない。
- 現行カードギャラリーの罠フィルターを撤去。
- 旧対戦の保存済みマーケット／提示に罠が残っている場合は購入を拒否。マナ・在庫・購入回数を消費せず、定義欠落による不正カード生成を防ぐ。
- 対話型チュートリアルから罠の注入・セット待ち・発動待ち・相手の実演を除去。9段階に変更し、日本語・韓国語・英語の表示と遊び方を修正。
- 残る報酬キーと金額は維持。現行9段階の合計は890クレジット。廃止した罠段階 `tuto:7` の110クレジットは旧クライアント／獲得履歴の互換性のためサーバー定義を保持し、現行クライアントからは請求しない。
- チュートリアルを最後まで検証した際、以前から削除済みの `S11` 注入と、混在した場では召喚できない `TSO5` 注入も進行を妨げていたため、それぞれ現行の `S13` と `TSO3` に変更。勝利報酬の遅延応答による合計表示も同期し、終了後のモーダルタイマーを解除。
