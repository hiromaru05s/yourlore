# 新カード16枚の画風修正

初稿は古い `docs/card-art-direction.md` の暗色・重厚・非アニメの記述に寄りすぎ、ユーザーに差し戻された。今回の16枚では現在の承認済みカード画像そのものを優先する。世界設定は `docs/world-bible.md` を維持。

- 人物: SOLDIER2 / VITAL2 の意図的な輪郭線、描かれた顔、大きな色面、整理された陰影。写真や実写俳優の顔、肌の微細な質感は使わない。
- クラウン: 白亜、青布、銀、抑えた金、明るい空。職人・装備・神官はそれぞれの役割を見せる。
- ゴーレム: GOLEM1 の白い陶板、暗い石の隙間、銅関節、青緑の核、採石場。人間の騎士にしない。
- 世界樹: WORLD_CARE の白い樹皮、翡翠の水、緑の葉、蜂蜜色の雫。建物・台座を持ち込まない。
- 虚無の剣／盾: 既存装備の形に紫の紙状の欠片を取り込む。
- フレーム、文字、数値なし。中央80%を安全域にし、1472×1344 WebPと384/192幅サムネイルを保存。

内蔵 image_gen を使用。プロンプト・参照画像・元PNGは `generated-art-v2.json`、配信画像のSHA-256は `art-manifest.json` に記録する。初稿の生成記録は履歴として保持するが配信には使わない。
