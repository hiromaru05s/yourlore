# ギフト・クエスト・即効魔法 — 罠廃止後のビルド分析と30案

2026-09-09。比較元は罠廃止前 `c2cd0cf / v42`、比較先は罠32枚・関連7枚を削除して10枚をリワーク済みの `181ccc2 / v44`。現在の最終DB274枚と独立スターター3枚、削除前の罠32枚、共有エンジンの効果・生成・種族条件を照合した。

これはカード候補の仕様検討。カード30案と新種別のゲーム処理は未実装。弱体化評価は失った機能と残存手段からの推定で、対戦勝率の比較実験ではない。前回のBot完走テストは安定性確認であり、バランスの証明には用いていない。

## 採用する前提と、案を比較するための仮ルール

ユーザー指定: ギフトは罠の緑枠を継承。クエストは既存形状を保った紫枠。即効カードは魔法へ統合する。ギフトはデッキ構成に含まれる限り有効で、山札・手札・墓地を移動しても有効。普通にドローされるがプレイできず、手札を圧迫する。

以下は30案を読み比べるための提案で、確定仕様ではない。

- ギフトは購入時に墓地へ入り、その時点から有効。効果は相手にも公開する。同名効果は重複しない。自分で除外すれば効果も失う。「1回」は同名カードを買い直しても対戦中の使用回数をリセットしない。購入前のイベントは発火対象にしない。
- クエストは購入後に通常どおりドローして発動。仮の発動コストは1。発動後から進捗を数え、達成時に一度だけ報酬を解決してクエストを除外する。進行中は専用の公開欄に置き、デッキ構成枚数に数える。進行中の同名は1枚まで、対戦中の同名達成は1回まで。クエスト自身の発動・報酬は自分自身の進捗に数えない。
- 即効魔法は購入直後に追加マナなしで発動し、解決後にゲームから除外する。再ドロー／再購入効果による無料連鎖を避けるため、初回試作は「同名即効魔法は自分のターンに1枚まで」。クエスト報酬などの獲得は購入と区別し、即効魔法を報酬・手札生成の候補に入れない。
- 魔法へ統合する即効魔法には魔法封印・使用回数制限・魔法使用時の効果を適用する。魔法を使えない状況では購入不可とし、購入だけで封印をすり抜けない。通常魔法の発動コスト軽減は、追加発動マナ0の即効魔法の購入価格を下げない。無効化されても消費される。
- 指定対象が必要な即効魔法は対象なしで購入できない。召喚は既存の場の上限と全体的な召喚制限に従い、入らない分は不発。既存の召喚時効果と種族シナジーも発動する。各ターンは双方のターンを個別に数え、自分のターンと書いた場合だけ自分側に限定する。
- 全ての購入コスト・条件回数・数値は仮値。新しい勝率や適正価格を算出したものではない。

実装上の重要点: 現在の `deckComp` は山札・手札・墓地・モンスターの場だけを集計し、永続魔法や除外を含まない。ギフトの有効性、進行中クエストの枚数、魔法13枚／デッキ8枚以下の判定は、この既存関数へ無条件に委ねず定義を明示する必要がある。また手札は毎ターン全捨てではなく5枚まで持ち越すため、ギフトは単なるドロー1枚分以上に保持枠の負担になる。

### ミミックは「多少」より大きい可能性

ミミックパーティーは自分に3体・相手に2体を供給していた。実装上の発火箇所は相手の基本宝箱の使用処理で、全宝箱に共通のフックではない。自分の3体が破壊されれば、キングの除外6枚条件の半分を一度に満たせた。リーダーは両者の場のミミックを数えるので、5体が残ればそれだけで+15/+15の材料だった。

隠れ家はミミック破壊後の自分の除外枚数×2を直接ダメージにしていた。例えば破壊分を含めて除外6枚なら12ダメージ。供給の削除でキング・始原のミミックの成長が遅れ、さらに除外を直接勝ちへ変える出口も減った。この二つは別々に補う方がよい。

一方、マスターミミックは自分の宝箱も封じる。新しい「宝箱からミミックを育てる」カードとキングの報酬を同時に設計すると、王を出した瞬間に供給が止まる。これは進め方を選ぶ要素として使えるが、自動的に強い組み合わせとは扱わない。

### 城は専用支援の密度を大きく失った

城壁強化はカウンター+5、宣戦布告は騎士3体、反撃命令は空き枠まで騎士、通行税は購入妨害の成功条件を城で改善していた。加えて城は兵士・騎士が召喚されるたびにカウンター+1を得るため、援軍喪失は攻撃力と城の維持力の両方に効く。城にはコスト5以上の召喚を禁じる制約も残っている。

## 最初の試作に絞るなら

G01「ミミック飼育許可証」、G03「城塞の設計図」、G05「八頁の奥義書」、Q01「偽りの王国」、I02「廃城の増援」、I08「禁書の封蝋」の6枚。供給・防御・対魔法の3機能を分けて検証できる。

G02はミミックの供給復旧後に決め手がまだ弱い場合の追加候補。供給と毎ターン火力を最初から両方盛ると過剰補填か切り分けづらい。G10は生存を全ビルドが買う状態にならないかを見てから。G09/Q08の烙印は1個あたり次の自分ターン開始から毎回ダイス1個分のダメージになるため、単発1ダメージと同じ感覚で配らない。

確認したい比較は、ミミックが除外6枚に到達するターン、城の生存ターンと援軍数、圧縮時の8枚条件達成率と被ダメージ、魔法コンボが相手へターンを返す頻度、ギフトを引いたときの有効手札枚数。罠削除前／削除後／新案追加後で同じ対戦組み合わせ・同じ先後配分を比較する。
