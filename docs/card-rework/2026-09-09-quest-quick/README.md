# クエストとクイック魔法（v45・仕様確認待ち）

作業ブランチ：`codex/remove-trap-cards-20260909`。デザイン作業中の元チェックアウトは変更していない。罠削除コミット群の後に独立した追加コミットとしてマージできる。

## 実装範囲

- ギフトカードは撤回。カード型・常時効果・緑枠のギフト流用は追加しない。
- クエスト8種を実装。9種目「反撃の狼煙」は定義と汎用ダメージ集計／報酬処理を準備し、烙印個数未指定のためライブDB・購入プールから除外。
- クイック魔法10種を `t: spell, quick: true` で実装。購入処理内で1回発動しリフトへ移動。手札・山札・墓地を経由せず、手札からの再プレイ不可。対象選択中や無効化時もカードは除外済み。
- 固定／提示／闇商人など別経路の購入に対応。条件未達なら支払い・在庫減少・効果発動なし。
- 魔法の使用回数・クエスト進捗・封印／使用上限／無効化に対応。ルーン学問の再発動対象にはしない（一度きり）。
- 紫枠を追加し、青い魔法枠をクイックにも使用。カード一覧にクエスト／クイック魔法フィルターを追加。クイックは魔法フィルターにも含まれる。
- 公開の魔法・クエスト欄（共通上限14枠）に進捗を表示。クリックで名前・条件・報酬・現在進捗を確認可能。
- 相手ターン中の報酬選択に `pending.owner` を追加。サーバーは手番と選択者を区別し、時間切れには有効な対象を自動選択する。

## 未確定・確認待ち

1. **反撃の狼煙：烙印カウンターの個数。** 数値を捏造しないため、このカードだけ購入プールに追加していない。`questQuickCards.ts` の該当定義に `val` を設定すると登録される。カード説明の3言語も個数に合わせて更新する。
2. **リフト研究の報酬：既存のカル7枚の除外か、新たなカル7枚のリフト追加か。** 現在は既存の墓地→山札→手札から最大7枚を除外する暫定実装。既存のカルを達成前に使い切ると報酬が空振りするため、ユーザーに確認中。

## 明記した暫定解釈（ユーザーの返答があれば優先する）

- クエストは購入後に墓地へ入り、引いて記載コストを払って発動。進捗は発動後のみ。達成した物理カードは除外して報酬1回。破壊され墓地へ戻った未達成カードは再発動時0から。
- 条件の回数／ダメージ／最大体力増加は累計。同じ種族の繰り返し召喚や効果召喚も数える。最大体力増加は現在HP回復を含まず、正の増加イベントを数える。
- 対攻城作戦：双方のターン終了を数え、同じ城の継続9回。城がいなくなったり置き換わると0へ戻る。
- 一族の誓い：現在の自分の場の種族を基準に、同種族で自分の場にいない別名モンスター1体を全モンスタープールから選び、既存の効果召喚方式で召喚。召喚時効果は発動しない。
- ミミックパーティー：召喚する1枚とは別に、新しいミミック2枚を生成して自分のリフトへ追加。
- 強制輪廻：墓地にモンスターがあれば購入可能。自分で1体選択し、7コスト以下なら虚無を付与して復活。8以上を選んだ場合は復活せず、カードは墓地に残る。
- 召喚効果は既存の場上限・召喚封鎖を尊重し、空き枠に入る分だけ召喚する。最大マナ上限30も維持。
- 総攻撃は異なる2体を選択。ポイズン／総攻撃は必要な有効対象がないと購入不可。アウラの対象耐性を維持。
- クイック魔法の購入額はプレイ割引では変化しない。呪術魔法書は手札からの魔法プレイに適用し、0が下限・複数購入は加算・ターン終了時に解除。
- クイック自身や報酬による除外もリフト関連の集計対象。神器は除外数に含めない。
